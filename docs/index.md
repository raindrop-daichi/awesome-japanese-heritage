# awesome-japanese-heritage

日本の城・神社仏閣・史跡について、**公開されているのに散在している一次資料**への道しるべをつくるリンク集です。

自治体の遺跡地図、文化財データベース、調査報告書、縄張り図——価値ある資料はすでに公開されています。ただし都道府県・市町村・機関ごとにバラバラの場所に、バラバラの形式で。ここでは、それらへのリンクを体系的に整理します。

## 収録内容

左のサイドバーから各セクションをたどれます。

- **[城郭]({{ '/castles/' | relative_url }})** — 全国横断の資料と、都道府県別の遺跡地図・悉皆調査報告書
- **[神社仏閣]({{ '/shrines-temples/' | relative_url }})** — 宗教年鑑・宗教法人名簿・各宗派の寺院検索など
- **[史跡全般]({{ '/general/' | relative_url }})** — ジャパンサーチ・文化遺産オンライン・オープンデータ基盤など

集めた結果から見えてきたことは、こちらに書いています。

- **[都道府県別 資料公開状況]({{ '/status.html' | relative_url }})** — 悉皆調査報告書が実際に読めるかどうかの一覧
- **[調査ノート]({{ '/notes/' | relative_url }})** — なぜ統合データベースが無いのか、公開格差はどうなっているか
- **[検証の方法と結果]({{ '/verification.html' | relative_url }})** — 1,450本のリンクを何でどう確かめたか、何を確かめていないか

## このサイトの方針

- **リンクと出典整理が主役**。他サイトのコンテンツは転載しません。一方で、**集めた結果から自分で読み取ったことは書きます**
- 掲載リンクは編纂時に実在を確認していますが、リンク切れを見つけたら [Issue](https://github.com/raindrop-daichi/awesome-japanese-heritage/issues) でお知らせください
- 「日本100名城」等の選定リストは日本城郭協会の著作物であり、事実としての言及に留めます
- 自治体GISへのリンクは各サイトの利用規約を確認のうえ掲載しています
