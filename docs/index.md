# awesome-japanese-heritage

日本の城・神社仏閣・史跡について、**公開されているのに散在している一次資料**への道しるべをつくるリンク集です。

自治体の遺跡地図、文化財データベース、調査報告書、縄張り図——価値ある資料はすでに公開されています。ただし都道府県・市町村・機関ごとにバラバラの場所に、バラバラの形式で。ここでは、それらへのリンクを体系的に整理します。

## 目次

### 城郭

- [全国横断の資料](castles/national.md) — 文化財データベース・遺跡報告総覧・地図ツールなど
- 都道府県別（近畿）
  - [滋賀県](castles/shiga.md) — 県内1,300超の山城密集地帯。安土城・小谷城・甲賀の城館
  - [京都府](castles/kyoto.md) — 府教委の悉皆調査（約1,300城館）あり。二条城・勝龍寺城
  - [大阪府](castles/osaka.md) — 大坂城・飯盛城・芥川山城・千早城
  - [兵庫県](castles/hyogo.md) — 山城密集地帯。姫路城・竹田城・篠山城
  - [奈良県](castles/nara.md) — 高取城・信貴山城・郡山城。遺跡地図GISが充実
  - [和歌山県](castles/wakayama.md) — 和歌山城・新宮城・安宅氏城館跡

### 神社仏閣

- [全国横断の資料](shrines-temples/national.md) — 宗教年鑑・宗教法人名簿・各宗派の寺院検索など

### 史跡全般

- [横断データベース](general/index.md) — ジャパンサーチ・文化遺産オンライン・オープンデータ基盤など

## このサイトの方針

- **リンクと出典整理が主役**。他サイトのコンテンツは転載しません
- 掲載リンクは編纂時に実在を確認していますが、リンク切れを見つけたら [Issue](https://github.com/raindrop-daichi/awesome-japanese-heritage/issues) でお知らせください
- 「日本100名城」等の選定リストは日本城郭協会の著作物であり、事実としての言及に留めます
- 自治体GISへのリンクは各サイトの利用規約を確認のうえ掲載しています
