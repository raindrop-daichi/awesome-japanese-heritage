# 都道府県別 資料公開状況

この調査は文化庁の国庫補助事業として全国で行われたが、成果物の公開レベルは県ごとにまったく揃っていない。

## この表の作り方と限界

- 各県ページが挙げる[全国文化財総覧](https://sitereports.nabunken.go.jp/ja)（奈良文化財研究所）の報告書ページを2026年8月2日に実際に取得し、**本文PDFファイルへのリンクが存在するかを機械的に数えた**結果。散文の記述からではなく、取得結果から直接組み立てている
- 対象は県単位の城館悉皆調査に限る。市町村単位の調査（高知市・南国市など）や、個別城郭の発掘調査報告書は数えていない
- **「県レベルの登録なし」は「調査をしていない」という意味ではない**。紙のみで電子化されていない例（滋賀県『滋賀県中世城郭分布調査』全10巻）、市町村単位でのみ実施された例（高知県）、総覧以外の場所で公開している例などが混在する。詳細は各県のページを参照
- ファイル数は分冊・図版・モバイル版を含む総数で、報告書の巻数とは一致しない
