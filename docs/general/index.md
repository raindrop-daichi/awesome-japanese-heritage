# 史跡全般 — 横断データベース

城郭・神社仏閣に限らず、史跡・文化財全般を横断して調べられるデータベースとオープンデータ基盤を整理する。

[トップ](../index.md)

## 統合検索ポータル

- **[ジャパンサーチ](https://jpsearch.go.jp/)**(国立国会図書館)
  300超のデータベース・約3,000万件超のメタデータを串刺し検索できる国レベルの統合ポータル。※連携先ごとに二次利用条件（ライセンス）が異なるため、コンテンツ利用時は連携元の規約を確認
- **[文化遺産オンライン](https://online.bunka.go.jp/)**（文化庁）
  全国1,000館超の博物館・美術館等が提供する文化財情報のポータル。指定・未指定を問わず収録。時代・地域別の検索機能あり。
- **[国指定文化財等データベース](https://kunishitei.bunka.go.jp/)**（文化庁）
  国指定・登録・選定文化財の公式DB。史跡・名勝・天然記念物もカバー。
- **[全国文化財総覧](https://sitereports.nabunken.go.jp/ja)**（奈良文化財研究所）
  埋蔵文化財発掘調査報告書の全文検索・閲覧。2025年3月に「全国遺跡報告総覧」から改称。

## 人文学オープンデータ

- **[人文学オープンデータ共同利用センター（CODH）](https://codh.rois.ac.jp/)**（ROIS-DS）
  人文学データのオープンサイエンス化を推進するセンター。IIIF Curation Platform、江戸マップ等のツール群のハブ。
- **[歴史GIS（歴史的行政区域データセットβ版 ほか）](https://codh.rois.ac.jp/historical-gis/)**（CODH）
  明治22年以降の市区町村境界変遷データ、約30万件収録の歴史地名マップ、『日本歴史地名大系』関連データセット等。史跡の旧行政区域・歴史地名の照合に有用。

## 国土数値情報（GISデータ）

いずれも国土交通省が整備するGISデータ。**非商用利用限定**の条件に注意。

- **[観光資源データ（P12）](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P12-v2_2.html)**
  社寺・城跡城郭・庭園公園・歴史景観等を含む観光資源の位置データ（2014年時点版）。
- **[都道府県指定文化財データ（P32）](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P32.html)**
  都道府県指定の有形・無形・民俗文化財の位置情報（2014年版）。一部県のデータは非公開。
- **[世界文化遺産データ（A34）](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A34-v1_2.html)**
  世界遺産登録資産の範囲・構成資産の地図データ。
