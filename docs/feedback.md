# 間違いを見つけたら

**このリンク集には必ず間違いがあります。** 1,400本を超える外部リンクを載せていて、そのすべてを人の目で読み直したわけではありません。[何をどう確かめて、何を確かめていないか](verification.html)は正直に書いていますが、それでも取りこぼしは残ります。

見つけたら教えてください。**指摘は本当に助かります。**

実際、徳島県神社庁と鳥取県神社庁の記述が直ったのは読者からの指摘によるものでした。前者は公式サイトのドメインが不通で「窓口が確認できない」としていたところ、公式Instagramが稼働していると教えていただきました。後者はこちらの集計スクリプトが「神社庁」しか検索しておらず、旧字の「神社**廳**」を使っている鳥取を取りこぼしていた、というこちら側のミスでした。

## こんな指摘が特に助かります

- **リンクが切れている、別のページに変わっている**
- **説明が事実と違う**（指定区分、年代、公開状況など）
- **載っているべき資料が抜けている**（特にお住まいの都道府県のもの）
- **利用条件が変わった**（オープンデータ化された、逆に非公開になった、など）
- **こちらが「確認できず」としているものが、実は公開されている**

最後のものは特にありがたいです。今日の調査でも、入口が手続き案内ページに見えて**その一段先に名簿本体が置かれていた**県が3つありました（滋賀・静岡・福岡）。同じ見落としが他にもあるはずです。

## 知らせ方

どちらでも構いません。**フォームのほうが手軽です。**

### フォーム（アカウント不要）

**[指摘・訂正フォーム](https://docs.google.com/forms/d/e/1FAIpQLSdrcxrJ-a7Jm7FZu8OgSTRl77LDcpAdI37Mvo8GvM-U8ZDVcg/viewform)**

Googleアカウントもログインも要りません。ページのURLか都道府県名と、何が違っていたかを書いていただければ十分です。出典や正しい情報があれば助かりますが、「ここが変な気がする」だけでも構いません。**こちらで確かめます。**

お名前や連絡先は任意です。返信が必要な場合だけ書いてください。

### GitHub の Issue

[Issue を作成する](https://github.com/raindrop-daichi/awesome-japanese-heritage/issues)

GitHubのアカウント（無料）が必要ですが、やりとりが公開の記録として残るので、他の人も「その指摘は既出か」を確認できます。技術的な内容や、議論になりそうな話はこちらが向いています。

## 直せないこともあります

- **リンク先の内容そのもの**は各機関のものなので、こちらでは直せません。リンク先の誤りは、その機関へ直接お知らせください
- **他サイトの内容の転載**はしません。このリンク集はリンクと出典整理に徹する方針です
- **個別の調査代行**はできません

## リンク切れについて

外部リンクは[毎月自動で生存確認](verification.html)しています。ただし確認しているのは「ページが読めるか」だけで、**内容が説明と合っているかは機械には判断できません**。そこは人の目に頼るしかない部分です。

また自動確認は米国のサーバーから実行しているため、海外IPを弾く日本の官公庁サイトは「到達できない」と出ることがあります。それも自動では判定しきれないので、日本国内から見ておかしいと気づいたら教えてください。
