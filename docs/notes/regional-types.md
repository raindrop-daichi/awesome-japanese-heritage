# 「城」も「寺社」も全国一様ではない

47都道府県分をそろえて初めて分かるのは、**同じ枠組みで扱えない地域がはっきりある**ということだった。全国横断のデータベースが作りにくい理由の一つでもある。

## 北海道と沖縄は、そもそも別の体系

[北海道](../castles/hokkaido.html)には本土型の中世城館がほとんど無い。近世以前の遺構としてはアイヌのチャシが道内に約500ヶ所あり、根室・釧路管内に4割弱が集中する。五稜郭や松前城といった和人の城郭は幕末から明治にかけてのもので、時代も系譜も本土の山城とつながらない。県レベルの「中世城館悉皆調査」が無いのは、調査を怠ったからではなく**対象が存在しないから**である。

[沖縄](../castles/okinawa.html)はさらに明確で、城といえばグスクを指す。首里城・今帰仁城・中城城・座喜味城・勝連城は世界遺産「琉球王国のグスク及び関連遺産群」の構成資産であり、琉球王国という別の国家の遺構である。社寺の側も同じで、[沖縄の神社仏閣](../shrines-temples/okinawa.html)は御嶽（うたき）を中心とする琉球固有の信仰と、琉球八社という独自の神社体系が軸になる。本土の神社庁・宗派という枠組みは後から重なったものにすぎない。

## 南九州は縄張りの作りが違う

[鹿児島](../castles/kagoshima.html)の城郭は、シラス台地を深い空堀で刻んで曲輪を分ける「南九州型城郭」と呼ばれる独特の類型をとる。知覧城・志布志城・清色城はいずれも国史跡で、石垣で囲う近世城郭とも、尾根を削平する本土の山城とも構造が異なる。地形が縄張りの発想そのものを規定している例である。

## 古代山城という別レイヤー

中世城館とはまったく別に、7世紀後半の古代山城がある。白村江の敗戦後に大宰府や瀬戸内の防衛のため築かれたもので、[福岡の大野城・水城](../castles/fukuoka.html)、[長崎（対馬）の金田城](../castles/nagasaki.html)、[熊本の鞠智城](../castles/kumamoto.html)、[岡山の鬼ノ城](../castles/okayama.html)などが該当する。鬼ノ城は城壁の延長2.8km、日本で初めて角楼跡が確認された城でもある。これらは中世城館の悉皆調査の対象外で、別の調査体系に属している。

## 寺院が消えた県がある

[鹿児島の神社仏閣](../shrines-temples/kagoshima.html)を調べていて手が止まったのが、明治初期の廃仏毀釈である。薩摩藩内では寺院がほぼ全廃され、その結果いま何が起きているかというと、**寺院の一次資料の中心が「県立埋蔵文化財センターの発掘調査報告書」になっている**。他県なら現存する寺の公式サイトや寺誌にあたる情報が、鹿児島では廃寺跡の考古学資料として出てくる。歴史的事件が、資料の在り処の形をそのまま変えている。

## 長崎には他県に無い2系統がある

[長崎](../shrines-temples/nagasaki.html)は、崇福寺・興福寺のような唐寺（黄檗宗）と、大浦天主堂をはじめとするキリスト教会堂という、他県に無い二つの系統を持つ。前者は近世の中国人居留地に、後者は世界遺産「長崎と天草地方の潜伏キリシタン関連遺産」につながる。「神社仏閣」という括り自体が、この県ではうまく機能しない。

## 災害の記録が一次資料になっている県

[熊本](../shrines-temples/kumamoto.html)では2016年の熊本地震と2020年の球磨川水害の両方で文化財が被災し、県教育庁が復旧記録集を公開している。阿蘇神社の楼門は2023年に復旧が完了し、青井阿蘇神社の国宝社殿群も水害の被害を受けた。[石川](../shrines-temples/ishikawa.html)も2024年の能登半島地震で同様の状況にある。**被災と復旧の行政記録が、そのまま建造物の詳細な一次資料になっている。**

---

これらはどれも、47都道府県を同じテンプレートで埋めようとして「埋まらなかった」ところから見えたものである。全国統一のデータモデルを作るとき、真っ先に壊れるのがこの手の地域差になる。
