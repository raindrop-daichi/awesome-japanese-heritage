# なぜ城の統合データベースが存在しないのか

日本の城跡は全国で3〜4万ヶ所あるといわれる。にもかかわらず、その全体を一覧できるデータベースは、国にも民間にも存在しない。これは誰かの怠慢というより、**制度の設計がそうなっている**結果である。

## 台帳は国のものではなく、自治体のもの

城跡の9割以上は中世の山城で、その大半は「周知の埋蔵文化財包蔵地」として扱われる。文化財保護法の建て付けでは、包蔵地の把握と台帳管理は都道府県・市町村の教育委員会の仕事であり、国が直接持つ台帳ではない。

このため、国が運営する[国指定文化財等データベース](https://kunishitei.bunka.go.jp/)に載るのは、国が指定・登録・選定したものに限られる。城跡でいえば国史跡になっている数百件であって、残りの数万件は入口にも現れない。**国のデータベースを見ても、日本の城の全体像は見えない。**

## 悉皆調査は全国で行われた。成果の置き場所だけが無かった

各都道府県は1980年代を中心に、県内の中世城館を網羅的に記録する調査を実施している。本リンク集で確認できた範囲でも、報告書の刊行が1981年に8件、1987年に9件と特定の時期に集中しており、名称も『○○県の中世城館』『○○県中世城館跡分布調査報告書』とほぼ揃っている。兵庫県の報告書は正式名称が「兵庫県中世城館・荘園遺跡**緊急調査**報告」で、全国的な事業の一環だったことがうかがえる。

つまり調査そのものは、ばらばらに思いつきで行われたわけではない。**それでも成果物は47通りの紙の報告書として各県に着地し、集約する受け皿は作られなかった。**

## 集約層にいちばん近いもの、そしてその限界

現状もっとも集約層に近いのが、奈良文化財研究所の[全国文化財総覧](https://sitereports.nabunken.go.jp/ja)（2025年3月に「全国遺跡報告総覧」から改称）である。埋蔵文化財の発掘調査報告書を全文電子化して横断検索できる、この分野で最も重要な基盤といっていい。

ただし**登録は発行機関の任意**である。その結果どうなっているかは、[都道府県別 資料公開状況](../status.html)に実測値がある。県レベルの城館悉皆調査について、本文PDFまで読めるのが13県、書誌情報だけが14県、そもそも県レベルの登録が無いのが20県。同じ性格の調査が、県によって三通りの状態で存在している。

加えて、城館の悉皆調査は「発掘を伴わない分布調査」であり、発掘調査報告書を主対象とする総覧の中では周縁的な位置にある。もっとも集約に近い場所ですら、城館調査は取りこぼされやすい。

## 諸外国との違い

海外では、[OpenStreetMap](https://wiki.openstreetmap.org/wiki/JA:Tag:historic=castle) や [Wikidata](https://www.wikidata.org/wiki/Q92026) のような汎用のオープンデータ層と、国が機関や資産を一元登録する公式レジストリ層が、それぞれ役割を分けて存在している。日本は前者には参加しているが、**後者にあたる層が城郭・社寺の分野では極端に弱い**。

このリンク集がやっているのは、その空白を埋めることではない。**空白の形を可視化すること**である。どこに何があり、どこに何が無いのかが分かって初めて、次に何を作るべきかが決まる。
