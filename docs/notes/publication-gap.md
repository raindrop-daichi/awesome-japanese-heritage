# 悉皆調査の公開格差

同じ種類の調査報告書が、県によって「全文が読める」「書名しか分からない」「そもそも登録が無い」の三通りに分かれている。その内訳を実測した記録。

数字の根拠と限界は[都道府県別 資料公開状況](../status.html)に、検証の手順は[検証の方法と結果](../verification.html)に書いた。

## 三つの状態

**本文PDFあり（13県）** — 岩手・山形・福島・茨城・群馬・山梨・三重・島根・岡山・長崎・熊本・大分・鹿児島

分冊構成でそのまま公開されている県もあり、当該報告書自身の添付として茨城は14ファイル、群馬は9ファイル、岩手は7ファイルが並ぶ。縄張り図や地名表を含む分冊が読める。岡山県は2020年刊行の『岡山県中世城館跡総合調査報告書』全3冊を県のサイトでも[PDF公開](https://www.pref.okayama.jp/site/kodai/670342.html)しており、総覧とあわせて二重に到達できる。

**書誌情報のみ（14県）** — 秋田・千葉・東京・福井・岐阜・静岡・愛知・京都・兵庫・鳥取・広島・山口・愛媛・佐賀

総覧にレコードは存在するが、ファイルが1件も添付されていない。書名と発行年が分かるだけで、中身にはたどり着けない。愛知県の『愛知県中世城館跡調査報告』は全4冊すべてがこの状態にある。

**県レベルの登録なし（20県）** — 北海道・青森・宮城・栃木・埼玉・神奈川・新潟・富山・石川・長野・滋賀・大阪・奈良・和歌山・徳島・香川・高知・福岡・宮崎・沖縄

ここは中身が一様でない。滋賀県には『滋賀県中世城郭分布調査』全10巻＋索引編という大部の調査があるが電子化されていない。高知県は県単位ではなく市町村単位で実施され、[高知市](https://sitereports.nabunken.go.jp/ja/9807)・[南国市](https://sitereports.nabunken.go.jp/ja/9353)の報告書がPDF公開されている。北海道と沖縄は本土の中世城館とは別の体系（チャシ、グスク）であり、そもそも同じ枠組みでは調査されていない。**「登録なし」は「調査していない」を意味しない。**

## 首都圏と大都市圏に「書誌のみ」が寄っている

書誌のみ14県の顔ぶれを見ると、東京・千葉・愛知・京都・兵庫と、人口も研究機関も多い地域が並ぶ。逆に本文PDFが公開されているのは、岩手・山形・福島・島根・大分・鹿児島など、どちらかといえば地方圏に多い。

大都市圏のほうが公開に消極的に見える、という直感に反する分布になっている。理由は本調査では特定できていない。刊行部数や在庫の有無、権利処理の手間、担当部署の体制など複数の要因が考えられるが、いずれも推測の域を出ない。**分布としてそうなっている、という観察だけを記録しておく。**

## Phase 2 に向けた含意

事実データ（城名・座標・種別・年代）の構造化に進むなら、着手すべき順序はこの表がそのまま示している。**本文PDFが公開されている13県から始めるのが合理的**で、なかでも岡山・島根・群馬・茨城は縄張り図付きの悉皆調査がそろっている。

一方で、利用条件は県ごとに大きく異なる点に注意がいる。山口県は遺跡地図をオープンデータとして公開しているが [CC BY-NC-ND](https://yamaguchi-opendata.jp/ckan/dataset/iseki-test) で改変が禁じられている。島根県の統合GISは個人利用以外の複製を禁止している。広島県の遺跡地図は営利目的の利用が不可。**「公開されている」と「使える」は別問題である。**
