# 悉皆調査の公開格差

同じ種類の調査報告書が、県によって「全文が読める」「書名しか分からない」「そもそも登録が無い」の三通りに分かれている。その内訳を実測した記録。

数字の根拠と限界は[都道府県別 資料公開状況](../status.html)に、検証の手順は[検証の方法と結果](../verification.html)に書いた。

## 三つの状態

**本文PDFあり（13県）** — 岩手・山形・福島・茨城・群馬・山梨・三重・島根・岡山・長崎・熊本・大分・鹿児島

分冊構成でそのまま公開されている県もあり、当該報告書自身の添付として茨城は14ファイル、群馬は9ファイル、岩手は7ファイルが並ぶ。縄張り図や地名表を含む分冊が読める。岡山県は2020年刊行の『岡山県中世城館跡総合調査報告書』全3冊を県のサイトでも[PDF公開](https://www.pref.okayama.jp/site/kodai/670342.html)しており、総覧とあわせて二重に到達できる。

**書誌情報のみ（14県）** — 秋田・千葉・東京・福井・岐阜・静岡・愛知・京都・兵庫・鳥取・広島・山口・愛媛・佐賀

総覧にレコードは存在するが、ファイルが1件も添付されていない。書名と発行年が分かるだけで、中身にはたどり着けない。愛知県の『愛知県中世城館跡調査報告』は全4冊すべてがこの状態にある。

**県レベルの登録なし（20県）** — 北海道・青森・宮城・栃木・埼玉・神奈川・新潟・富山・石川・長野・滋賀・大阪・奈良・和歌山・徳島・香川・高知・福岡・宮崎・沖縄

ここは中身が一様でない。滋賀県には『滋賀県中世城郭分布調査』全10巻＋索引編という大部の調査があるが電子化されていない。高知県は県単位ではなく市町村単位で実施され、[高知市](https://sitereports.nabunken.go.jp/ja/9807)・[南国市](https://sitereports.nabunken.go.jp/ja/9353)の報告書がPDF公開されている。北海道と沖縄は本土の中世城館とは別の体系（チャシ、グスク）であり、そもそも同じ枠組みでは調査されていない。**「登録なし」は「調査していない」を意味しない。**

## 首都圏と大都市圏に「書誌のみ」が寄っている

書誌のみ14県の顔ぶれを見ると、東京・千葉・愛知・京都・兵庫と、人口も研究機関も多い地域が並ぶ。逆に本文PDFが公開されているのは、岩手・山形・福島・島根・大分・鹿児島など、どちらかといえば地方圏に多い。

大都市圏のほうが公開に消極的に見える、という直感に反する分布になっている。理由は本調査では特定できていない。刊行部数や在庫の有無、権利処理の手間、担当部署の体制など複数の要因が考えられるが、いずれも推測の域を出ない。**分布としてそうなっている、という観察だけを記録しておく。**

## Phase 2 に向けた含意

事実データ（城名・座標・種別・年代）の構造化に進むなら、本文PDFが公開されている13県が入口になる。ただし**「公開されている」と「機械で読める」の間にもう一段の落差がある**ことが、実際に開いてみて分かった。以下はその記録である。

### 岡山県で実際に試してみた

『岡山県中世城館跡総合調査報告書』第1冊（備前編、475ページ、約39MB）を取得して中身を確かめた。結果は良好だった。

- **スキャン画像ではなくテキスト層を持つPDF**である。文字がそのまま取り出せる
- 第2章に「備前国中世城館跡一覧表」があり、**城館番号・城館跡名・旧郡・所在地・緯度経度・立地・標高・比高・城域・現況・概要**が表形式で並ぶ。構造化に必要な項目がほぼ揃っている
- 座標は `北緯34°52′58″ 東経133°45′46″` の度分秒表記。備前編だけで**282件**
- 素朴な正規表現による抽出で**253件（90%）**が名称と座標のペアとして取れた。得られた座標はすべて岡山県の緯度経度範囲に収まっており、明らかな誤抽出は無かった

残る1割と、番号と名称の対応がずれる箇所は、行の流し込みテキストではなく**桁位置を見るパーサ**に替えれば解消できる見込みである。第1冊が備前編なので、備中編・美作編を合わせれば岡山県だけで800件規模になる。

### 残る11県も開いてみたら、岡山が例外だった

「他県も同じ書式なのか」を確かめるため、本文PDFが読める残り12県について、実際にPDFを1本ずつ取得して中身を機械的に走査した。すべて同一サーバー上にあるため、2秒間隔の逐次アクセスで行っている。

| 県 | サイズ／頁数 | 抽出文字数 | 度分秒座標 | 緯度・経度の語 |
|---|---|---|---|---|
| 岩手 | 49MB / 66p | 1,113,929 | 0 | 0 |
| 山形 | 49MB / 157p | 240,452 | 0 | 0 |
| 福島 | 89MB / 297p | 1,178,475 | 0 | 0 |
| 茨城 | 1MB / 19p | 45,689 | 0 | 1 |
| 群馬 | 76MB / 97p | 280,164 | 0 | 0 |
| 山梨 | 123MB / 308p | 852,107 | 0 | 0 |
| 三重 | 18MB / 350p | **1,283** | 0 | 0 |
| 島根 | 30MB / 47p | 98,196 | 0 | 0 |
| 長崎 | 38MB / 170p | 555,630 | 0 | 0 |
| 熊本 | 25MB / 401p | 1,500,861 | 0 | 0 |
| 大分 | 59MB / 98p | 658,804 | 0 | 0 |
| 鹿児島 | 45MB / 219p | 1,042,845 | 0 | 0 |

**座標を持っていたのは岡山だけだった。** 茨城の1件は「緯度」「経度」という語が1行に現れるだけで、座標欄ではない。

分かったことは三つある。

**1. 座標が無い代わりに、所在地と標高がある。** 一覧表を確実に含む福島・熊本・山形を個別に調べたところ、「所在地」が206回・86回・133回、「大字」が101回・523回・53回、「標高」が121回・393回・72回出現する。一方で「緯度」「経度」「メッシュ」「座標」はいずれも0件だった。**1980年代の報告書は、位置を大字・字の地名と標高で記述している。** 岡山の報告書が2020年刊行でGIS時代の産物だったという、それだけの違いである。

**2. テキスト層が無い県がある。** 三重県の350ページから取り出せた文字はわずか1,283字だった。ページあたり4文字未満で、これは全ページがスキャン画像であることを意味する。読むには先にOCRが要る。

**3. 縦書きの表は壊れる。** 熊本の一覧表を取り出すと `松石山桜寵湯亀湯平動満南鼠滋駒今高柏高村社芹中川下長市峯吉` のように、縦組みの列が1行へ潰れて出てくる。文字は取れているが、行と列の対応が失われている。福島も『城館地名表』が市町村コード順に並ぶ構成で、番号・名称・所在地の対応を復元するには単純な正規表現では足りない。

なお、この走査で開いたのは**各県の添付PDF1本目のみ**である。分冊構成の県では他の巻を見ていない。頁数と「一覧表」「所在地」の出現数から判断して、山形・福島・長崎・熊本・大分は一覧表本体を含んでいるとみてよいが、茨城（19ページ）や群馬・山梨・島根は概説編にあたる可能性がある。**「この県には座標が無い」ではなく「1本目には無かった」が正確な言い方である。**

### 総覧の遺跡抄録ページは代わりになるか

PDFが読みにくいなら、総覧側が持つ構造化データを使えないかを確かめた。全国文化財総覧には遺跡単位の「遺跡抄録」ページがあるが、[1件](https://sitereports.nabunken.go.jp/ja/cultural-property/236255)を取得して調べたところ、緯度・経度の記載も、JSON-LD などの構造化データ埋め込みも、公開APIへの手がかりも見つからなかった。**この経路でも座標は得られない。**

### したがって

「13県から始められる」は事実だが、「13県から同じ品質のデータが取れる」は誤りだった。実際に必要になるのは以下である。

- **県ごとのパーサ** — 表組みも項目名も刊行年もばらばらで、共通コードで処理できる見込みは薄い
- **住所文字列からのジオコーディング** — 座標が入っているのは岡山だけなので、他県は「○○郡○○町大字○○字○○」から位置を起こすしかない。字レベルの地名は現在の住所体系から消えているものも多く、精度は場所によって大きく変わる
- **OCR** — 少なくとも三重県には必要
- **精度が県ごとに不揃いであることの明示** — 岡山は秒単位、他県は大字レベル。同じ地図に載せるなら、この差をデータ自体が持っていなければ誤読される

つまり Phase 2 は「PDFをパースする」作業ではなく、**精度の異なる47通りの記述を、精度の違いごと記録するデータモデルを作る**作業になる。

一方で、利用条件は県ごとに大きく異なる点に注意がいる。山口県は遺跡地図をオープンデータとして公開しているが [CC BY-NC-ND](https://yamaguchi-opendata.jp/ckan/dataset/iseki-test) で改変が禁じられている。島根県の統合GISは個人利用以外の複製を禁止している。広島県の遺跡地図は営利目的の利用が不可。**「公開されている」と「使える」は別問題である。**
