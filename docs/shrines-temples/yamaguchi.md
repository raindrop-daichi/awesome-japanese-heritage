# 山口県の神社仏閣資料

周防国・長門国からなる山口県は、大内氏・毛利氏の庇護を受けた社寺が多く、瑠璃光寺五重塔・功山寺仏殿・住吉神社本殿と3件の国宝建造物を有する。宗教法人の網羅的な名簿は公開を確認できなかったが、県神社庁は743社の神社検索ページを、県文化財データベースは国宝・重文建造物を分野別に検索できる。

## 宗教法人名簿

- ※山口県知事所轄の宗教法人について、法人名・所在地を網羅した名簿（Excel/PDF等）の公開は確認できなかった。
- **[宗教法人の事務所備付け書類の写しの提出](https://www.pref.yamaguchi.lg.jp/cms/a10400/syuukyou/syuukyou-jimu/201903080001.html)**（山口県 学事文書課）
  宗教法人の年次提出書類（役員名簿・財産目録等）に関する手続き案内ページ。法人名簿そのものへのリンクはない。

## 神社庁・仏教会

- **[山口県神社庁](https://www.yamaguchi-jinjacho.or.jp/)**
  神社本庁と包括関係を結ぶ743社（トップページ表記では県内750社）を統括。[下関市](https://www.yamaguchi-jinjacho.or.jp/shimonoseki/)など市町ごとの神社検索ページを提供。
- ※「山口県仏教会」に相当する県域組織のウェブサイトは公開を確認できず。各宗派・市郡単位の仏教会は存在する可能性があるが未特定。

## 文化財データベース

- **[文化財・山口県の文化財](https://bunkazai.pref.yamaguchi.lg.jp/bunkazai/list.html)**（山口県観光スポーツ文化部文化振興課）
  国宝・重要文化財・県指定文化財等を指定区分・分野・時代で検索できる。神社・寺院の建造物も含む。
- **[国指定文化財等データベース](https://kunishitei.bunka.go.jp/)**（文化庁）
  全国横断DBだが県内分の絞り込みが可能。
- **[山口県 - 文化遺産オンライン](https://online.bunka.go.jp/heritages/region/35)**（国立文化財機構）
  地域から見る文化遺産オンラインの山口県分。

## 主要社寺の公式資料

- **[香山公園 国宝瑠璃光寺五重塔](https://yamaguchi-city.jp/kozantop/topjp.html)**（山口市）
  嘉吉2年（1442年）建立の国宝五重塔。法隆寺・醍醐寺と並び日本三名塔とも称される。
- **[功山寺（公式サイト）](http://kouzanji.org)**（下関市）※`http://`でのみアクセス可
  曹洞宗の古刹。仏殿は嘉暦2年（1327年）頃の建立で、年代の判明する禅宗様建築として日本最古級の国宝。高杉晋作挙兵の地。
- **[長門國一宮 住吉神社本殿 特別拝観案内](https://yamaguchi-tourism.jp/spot/detail_19402.html)**（山口県観光サイト、下関市）※神社独自の公式サイトは確認できず、県観光サイトの解説ページを掲載
  応安3年（1370年）大内弘世造営とされる本殿は国宝。九間社流造という類例の少ない様式。
- **[防府天満宮（公式サイト）](https://www.hofutenmangu.com/)**（防府市）
  延喜4年（904年）創建、日本で最初に菅原道真を祀った天満宮とされる。
- **[赤間神宮（公式サイト）](https://akama-jingu.com/)**（下関市）
  壇ノ浦の戦いで入水した第八十一代安徳天皇を祀る。
- **[元乃隅神社](https://www.city.nagato.yamaguchi.jp/site/kanko/21422.html)**（長門市ホームページ）※神社独自の公式サイトは確認できず、長門市の案内ページを掲載
  海沿いに123基の鳥居が連なる。

## デジタルアーカイブ

- **[山口県文書館 詳細検索](https://archives.pref.yamaguchi.lg.jp/msearch/detail/)**（山口県文書館）
  毛利家文庫等の所蔵資料を詳細条件で検索できる。社寺関連文書も含まれるとみられる。
- **[山口県文書館 絵図・地図検索](https://archives.pref.yamaguchi.lg.jp/document-search/maps/)**（山口県文書館）
  毛利家文庫絵図・袋入絵図 計2,103点を検索できる。防長の寺社境内絵図等が含まれる可能性がある。
- **[WEB版明治維新資料室](https://adeac.jp/yamaguchi-pref-lib/top/)**（山口県立山口図書館・山口県文書館）
  明治維新関係資料をデジタル化。社寺専門アーカイブではないが関連史料を含む可能性がある。
