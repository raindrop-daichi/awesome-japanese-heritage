# 栃木県の神社仏閣資料

旧国名は下野（しもつけ）。世界遺産「日光の社寺」（日光東照宮・日光二荒山神社・日光山輪王寺）を擁し、二社一寺それぞれが充実した公式資料を公開している点が最大の特徴だ。宗教法人名簿はオンライン公開を確認できず、県担当課への直接照会が必要になる。

## 宗教法人名簿

- ※栃木県の宗教法人名簿（Excel/PDF等の一覧ファイル）はオンライン上での公開を確認できず。栃木県経営管理部文書学事課 私学・宗教法人担当のページ（[宗教法人｜栃木県](https://www.pref.tochigi.lg.jp/kyouiku/bunka/shuukyou/index.html)、[宗教法人の各種申請・届出｜栃木県](https://www.pref.tochigi.lg.jp/b05/270324syukyohoujin1.html)）は認証書交付や各種届出の手続き案内のみで、法人一覧の掲載はない。

## 神社庁・仏教会

- **[栃木県神社庁](http://www.tochigi-jinjacho.or.jp/)**
  県内神社の紹介、市町村別・五十音別の神社検索機能を提供する公式サイト。
- ※栃木県仏教会に相当する組織の公式サイトは確認できず。

## 文化財データベース

- **[とちぎの文化財](https://bunkazai.pref.tochigi.lg.jp/)**（栃木県教育委員会文化財課）
  国指定・県指定・市区町村指定の文化財を種別（史跡・工芸品など）や市町名で検索できるデータベース。神社・寺院固有のカテゴリ絞り込みは明記されていないが、個別物件の検索は可能。

## 主要社寺の公式資料

- **[日光の社寺（世界遺産）｜栃木県](https://www.pref.tochigi.lg.jp/c05/m/gate/gate15.html)**
  1999年世界遺産登録の概要と栃木県による紹介ページ。
- **[日光の社寺｜文化遺産オンライン](https://online.bunka.go.jp/special_content/hlink8)**（文化庁）
  世界遺産「日光の社寺」の構成資産解説。
- **[「日光の社寺」の保護体制｜日光市公式ホームページ](https://www.city.nikko.lg.jp/soshiki/10/1041/1_1/2/2429.html)**
  日光山内地区保存管理計画の策定経緯や国史跡指定の保護体制を解説。
- **[世界遺産日光の社寺｜日光市公式ホームページ](https://www.city.nikko.lg.jp/kanko_bunka_sports/bunkazai/3/index.html)**
  二社一寺（東照宮・輪王寺・二荒山神社）それぞれの個別解説ページへの入口。
- **[日光東照宮ホームページ](https://toshogu.jp/)**
  徳川家康を祀る東照宮の公式サイト。由緒・社殿・行事案内を掲載。
- **[日光山 輪王寺 オフィシャルサイト](https://www.rinnoji.or.jp/)**
  国宝・本堂（三仏堂）を含む輪王寺の公式サイト。
- **[日光の社寺：二荒山神社｜日光市公式ホームページ](https://www.city.nikko.lg.jp/soshiki/10/1041/1_1/2/2430.html)**
  日光二荒山神社の解説。※独自の公式ドメインは確認できず、日光市の解説ページを掲載。
- **[大谷寺｜宇都宮市公式ホームページ](https://www.city.utsunomiya.lg.jp/citypromotion/kanko/1032109/1032112.html)**
  日本最古とされる磨崖仏・大谷観音を擁する大谷寺の市公式紹介。
- **[大谷寺公式サイト](https://www.ooyaji.jp/)**
  大谷観音および平和観音の由緒・拝観案内。
- **[鑁阿寺本堂（国宝）｜足利市公式ホームページ](https://www.city.ashikaga.tochigi.jp/education/000029/000169/000627/p001299.html)**
  2013年国宝指定の鑁阿寺本堂に関する足利市の解説。
- **[鑁阿寺本堂｜文化遺産オンライン](https://online.bunka.go.jp/heritages/detail/184416)**（文化庁）
  国宝建造物としての公式データ。

## デジタルアーカイブ

- **[デジタル史料室｜栃木県立文書館](https://www.pref.tochigi.lg.jp/m58/education/bunka/monjyokan/shiryoushitsu.html)**
  中世〜近代の古文書を時代別にPDF公開（画像・釈文・解説付き）。社寺文書が含まれるかは個別確認が必要。
- **[栃木県立文書館が公開している古文書・公文書](https://www.pref.tochigi.lg.jp/m58/education/bunka/monjyokan/koukai.html)**
  公開史料の分類一覧。
- **[栃木県立図書館デジタルコレクション](http://www.lib.pref.tochigi.lg.jp/?page_id=455)**
  貴重書・行政資料のデジタル化公開。社寺縁起・境内絵図の収蔵有無はトップページからは判断できず、個別確認が必要。
