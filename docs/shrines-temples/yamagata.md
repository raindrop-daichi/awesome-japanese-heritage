# 山形県の神社仏閣資料

旧国名は羽前（村山・置賜・庄内の一部）・羽後（庄内の一部）にまたがる。羽黒山・月山・湯殿山からなる出羽三山は神仏習合の修験道の霊場として知られ、羽黒山五重塔（国宝）をはじめ関連文化財が集積する。山寺（立石寺）・慈恩寺など天台系の古刹も国指定文化財・史跡を擁する。宗教法人の網羅的な名簿は県サイト上での公開を確認できなかった。

## 宗教法人名簿

- **[宗教法人｜山形県](https://www.pref.yamagata.jp/020023/kurashi/npo/koeki/shuukyou.html)**（山形県）
  宗教法人の認証・届出手続と各地域振興局（村山・最上・置賜・庄内）の窓口一覧を掲載するページ。※ダウンロード可能な網羅的名簿（Excel/PDF）の掲載は確認できず。

## 神社庁・仏教会

- **[山形県神社庁](https://yamagata-jinjyacho.or.jp/)**
  県内神社を統括する神社本庁傘下組織の公式サイト。支部（山形・村山・最上・置賜・庄内など）ごとの活動案内を掲載。
  ※神社検索・一覧機能の有無はサイト内で要確認。
- ※山形県仏教会など仏教系の県内統括組織の公式サイトは公開を確認できず。

## 文化財データベース

- **[山形の文化財検索サイト「山形の宝 検索navi」](https://www.pref.yamagata.jp/cgi-bin/yamagata-takara/?m=list&k=1)**（山形県）
  国指定文化財を含む県内文化財の検索データベース。建造物区分で社寺建築も検索可能。
- **[県指定文化財一覧](https://www.pref.yamagata.jp/cgi-bin/yamagata-takara/?m=list&k=2)**（山形県、同検索サイト内）
  県指定文化財の一覧表示。
- **[山形県内の文化財について](https://www.pref.yamagata.jp/020077/bunkyo/bunka/bunkazai/kennaibunkazai.html)**（山形県）
  国・県・市町村指定等の文化財件数・制度の解説ページ。
- **[国指定文化財等データベース](https://kunishitei.bunka.go.jp/)**（文化庁）
  全国横断で検索可能。山形県内の国宝・重要文化財（建造物）である羽黒山五重塔・立石寺根本中堂・慈恩寺本堂などを個別に確認できる。
- **[山形市の指定・登録文化財](https://www.city.yamagata-yamagata.lg.jp/bunkasports/bunkazai/1006708/1005891.html)**（山形市）
  市内指定・登録文化財の一覧（令和7年5月時点）。
- **[鶴岡市内 指定文化財一覧](https://www.city.tsuruoka.lg.jp/bunka/rekishi/shitei-bunka-ichiran.html)**（鶴岡市）
  出羽三山神社関連を含む市内指定文化財の目録。

## 主要社寺の公式資料

- **[出羽三山神社 公式ホームページ](http://www.dewasanzan.jp/)**
  羽黒山・月山・湯殿山の三神を祀る出羽三山神社の公式サイト。※httpのみで疎通、httpsは非対応。
- **[羽黒山｜出羽三山神社](http://www.dewasanzan.jp/publics/index/71/)**（同神社）
  国宝五重塔・三神合祭殿など羽黒山境内の解説ページ。
- **[羽黒派古修験道｜出羽三山神社](http://www.dewasanzan.jp/publics/index/75/)**（同神社）
  出羽三山に伝わる羽黒派古修験道の由来・行事を紹介するページ。
- **[宝珠山 立石寺 公式ホームページ](https://rissyakuji.jp/)**
  通称「山寺」として知られる立石寺（慈覚大師円仁開山）の公式サイト。根本中堂は重要文化財。
- **[国史跡慈恩寺旧境内](https://www.city.sagae.yamagata.jp/kanko/bunka/jionji/index.html)**（寒河江市）
  平成26年度に国史跡指定された慈恩寺旧境内一帯の解説ページ。本堂は国指定重要文化財。
- **[史跡慈恩寺旧境内総合広報誌「慈恩寺Times」](https://www.city.sagae.yamagata.jp/kanko/bunka/jionji/shisekizionzhi.html)**（寒河江市）
  史跡の保存・活用に関する広報誌のバックナンバー。
- **[慈恩寺について｜本山慈恩寺](https://honzan-jionji.jp/about-page/)**
  慈恩寺の公式サイトによる由緒・伽藍の解説ページ。
- **[上杉神社](https://www.uesugi-jinja.or.jp/)**
  米沢城本丸跡に建つ、上杉謙信を祭神とする上杉神社の公式サイト。
