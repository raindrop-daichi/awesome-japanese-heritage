# 宮城県の神社仏閣資料

旧国名は陸前国（一部は陸中国・磐城国）。伊達政宗ゆかりの社寺が多く、鹽竈神社・大崎八幡宮・瑞巌寺など国宝・重要文化財の建造物が県内に集中する。宗教法人名簿は令和8年版がPDFで公開されている。

## 宗教法人名簿

- **[宮城県宗教法人名簿（令和8年4月1日現在）](https://www.pref.miyagi.jp/documents/23428/r08syuukyoumeibo_0002.pdf)**（宮城県総務部私学・公益法人課）
  知事所轄の宗教法人（神社・寺院等）を網羅したPDF名簿。県庁地下1階の県政情報センター等でも閲覧可能。
- **[宮城県内の宗教法人](https://www.pref.miyagi.jp/soshiki/sibun/shuukyou-index.html)**（宮城県）
  宗教法人制度・所轄庁の案内ページ。文部科学大臣所轄の法人については文化庁宗務課への照会が必要と案内されている。

## 神社庁・仏教会

- **[宮城県神社庁](https://miyagi-jinjacho.or.jp/)**（神社本庁）
  県内神社を包括する神社本庁の地方機関。神社の基礎知識や歳時記等を掲載。
- **[仙台仏教会](http://www.sendai-bukkyoukai.jp/)**
  仙台市内の仏教各宗派が加盟する連合組織。※県域全体を包括する「宮城県仏教会」の現存公式サイトは確認できず

## 文化財データベース

- **[指定文化財一覧](https://www.pref.miyagi.jp/site/sitei/list543-944.html)**（宮城県）
  国宝・重要文化財・県指定有形文化財・史跡等を網羅した総合リスト。瑞巌寺本堂・多賀城碑などが含まれる。
- **[宮城県の有形文化財（建造物）一覧](https://www.pref.miyagi.jp/site/sitei/kenzoubutu.html)**（宮城県）
  建造物区分に絞った一覧。社寺建築の多くがここに含まれる。
- **[国指定文化財等データベース](https://kunishitei.bunka.go.jp/)**（文化庁）
  都道府県・種別で絞り込んで検索可能な全国データベース。

## 主要社寺の公式資料

- **[志波彦神社・鹽竈神社](https://shiogamajinja.jp/)**
  陸奥国一宮。現在の社殿は伊達家4代綱村・5代吉村の時代に造営され、国の重要文化財に指定されている。
- **[国宝 大崎八幡宮](https://www.oosaki-hachiman.or.jp/)**
  慶長9〜12年、伊達政宗の命により造営された御社殿（本殿・石の間・拝殿）が国宝。安土桃山期の権現造遺構として貴重。
- **[国宝 瑞巌寺](https://www.zuiganji.or.jp/)**
  慶長14年（1609）伊達政宗創建。本堂・庫裡が国宝に指定される禅宗様建築の傑作。
  - 参考: **[指定文化財〈国宝〉瑞巌寺本堂](https://www.pref.miyagi.jp/soshiki/bunkazai/04zuiganji.html)**（宮城県）
- **[円通院 臨済宗妙心寺派](https://www.entuuin.or.jp/)**
  1647年、伊達政宗の嫡孫・光宗の霊廟である三慧殿の建立とともに開山。

## デジタルアーカイブ
