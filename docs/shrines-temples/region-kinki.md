# 近畿

近畿地方は伊勢・伊賀・志摩（三重）、近江（滋賀）、山城・丹波・丹後（京都）、摂津・河内・和泉（大阪）、播磨・但馬・丹波・摂津・淡路（兵庫）、大和（奈良）、紀伊（和歌山）の旧国からなり、日本仏教・神道の中枢が集積する。世界遺産の社寺構成資産だけでも「古都京都の文化財」「古都奈良の文化財」「法隆寺地域の仏教建造物」「紀伊山地の霊場と参詣道」の4件を数え、伊勢神宮（三重）・比叡山延暦寺（滋賀）・高野山金剛峯寺と熊野三山（和歌山）など神社本庁の本宗や各宗派の総本山が集中する。奈良県は国宝建造物の指定数が全国最多。

宗教法人名簿の公開形式は県ごとに差があり、三重県はPDF、大阪府・奈良県はExcelで公開している一方、滋賀県・京都府・兵庫県・和歌山県はオンラインでの一般公開を確認できず、閲覧や照会が必要な状態にとどまる。個別社寺の網羅的な列挙が難しい規模の府県もあり、京都府・奈良県は世界遺産構成資産や文化財データベースなど面で押さえる資料を優先して収録する方針を取っている。

## この地方の資料

- **[三重県](mie.html)** — 伊勢神宮が神社本庁の本宗として神宮司廳の直接管掌下にあり、宗教法人名簿はPDFで公開
- **[滋賀県](shiga.html)** — 比叡山延暦寺・三井寺・日吉大社・石山寺・湖東三山など国宝・重要文化財建造物が全国有数の密度で集積、宗教法人名簿のオンライン公開は未確認
- **[京都府](kyoto.html)** — 宗教法人数が全国有数の規模で個別列挙が困難なため、世界遺産「古都京都の文化財」や公的文化財データベースなど面で押さえる資料を優先
- **[大阪府](osaka.html)** — 四天王寺・住吉大社の古代官寺・大社と、南河内の観心寺・金剛寺など中世山岳寺院の国宝建築が併存、宗教法人名簿はExcelで公開
- **[兵庫県](hyogo.html)** — 播磨・但馬・丹波・摂津・淡路の「五国ひょうご」にまたがり、播磨には浄土寺・鶴林寺・一乗寺など国宝建造物が集中
- **[奈良県](nara.html)** — 国宝建造物の指定数が全国最多で、世界遺産「古都奈良の文化財」「法隆寺地域の仏教建造物」の2件を県内に持つ。宗教法人名簿はExcelで公開
- **[和歌山県](wakayama.html)** — 高野山金剛峯寺と熊野三山を核に世界遺産「紀伊山地の霊場と参詣道」の構成資産が集中、宗教法人名簿はオンライン非公開
