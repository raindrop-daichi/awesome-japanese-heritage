# 和歌山県の神社仏閣資料

旧国名は紀伊。高野山金剛峯寺と熊野三山（熊野本宮大社・熊野速玉大社・熊野那智大社）を核に、世界遺産「紀伊山地の霊場と参詣道」の構成資産が集中する。宗教法人名簿はオンライン非公開だが、県教育委員会の指定文化財目録と各社寺の公式資料は充実している。

## 宗教法人名簿

- 和歌山県の[宗教法人について](https://www.pref.wakayama.lg.jp/prefg/010100/koukai/jkhome/d00218684.html)（和歌山県）のページによれば、県所轄の宗教法人名簿は情報公開コーナーでの閲覧のみとされ、Excel/PDF等でのオンライン公開は確認できず。

## 神社庁・仏教会

- **[和歌山県神社庁](https://wakayama-jinjacho.or.jp/)**（和歌山県神社庁）
  県内約400社の神社を包括する神社本庁の地方機関。組織概要を掲載。神社検索・一覧機能は確認できず。
- **[和歌山県仏教会](https://www.jbf.ne.jp/member?id=15751)**（全日本仏教会加盟団体ページ）
  全日本仏教会サイト内の会員紹介ページ。独自の公式サイトは確認できず。

- **[国指定文化財・有形文化財・建造物](https://www.pref.wakayama.lg.jp/prefg/500700/mokuroku/d00155261.html)**（和歌山県教育委員会）

- **[県指定文化財・民俗文化財](https://www.pref.wakayama.lg.jp/prefg/500700/mokuroku/d00155461.html)**（和歌山県教育委員会）

## 主要社寺の公式資料

- **[高野山真言宗 総本山金剛峯寺](http://www.koyasan.or.jp/)**（金剛峯寺）
  高野山真言宗の総本山。世界遺産「紀伊山地の霊場と参詣道」の構成資産。
- **[高野山 霊宝館](https://reihokan.or.jp/)**（高野山霊宝館）
  高野山内の国宝21件・重要文化財148件を含む約2万8千点を収蔵する宝物館。展覧会情報を随時公開。
- **[熊野本宮大社](https://www.hongutaisha.jp/)**（熊野本宮大社）
  熊野三山の一社。由緒・聖地熊野の解説を掲載。
- **[熊野速玉大社](https://kumanohayatama.jp/)**（熊野速玉大社）
  熊野三山の一社。新宮市に鎮座。
- **[熊野那智大社 飛瀧神社 那智御瀧](https://kumanonachitaisha.or.jp/)**（熊野那智大社）
  熊野三山の一社。宝物殿の紹介あり。
- **[熊野三山協議会](https://www.kumano-sanzan.jp/)**（熊野三山協議会）
  熊野本宮・速玉・那智の三社を横断的に紹介する公式協議会サイト。
- **[那智山青岸渡寺](https://seigantoji.or.jp/)**（青岸渡寺）
  西国三十三所第一番札所。熊野那智大社に隣接し神仏習合の歴史を伝える。
- **[新義真言宗 総本山 根來寺](https://www.negoroji.org/)**（根来寺）
  新義真言宗の総本山。国宝大塔などを有する。
- **[道成寺](http://www.dojoji.com/)**（道成寺）
  天台宗の古刹。安珍・清姫伝説で知られる。
- **[粉河寺](https://www.kokawadera.org/)**（粉河寺）
  粉河観音宗総本山。西国三十三所第三番札所。国宝『粉河寺縁起絵巻』を伝える。

## デジタルアーカイブ

- **[和歌山県立図書館 デジタルアーカイブ](https://www.lib.wakayama-c.ed.jp/digitalarchive/)**（和歌山県立図書館）
  古文書・古地図等の郷土資料を公開。社寺関連の絵図・記録も含まれる。
- **[和歌山県立博物館 収蔵品データベース](https://jmapps.ne.jp/hakubutuwakayama/index.html)**（和歌山県立博物館）
  社寺伝来の仏像・仏画・古文書を含む収蔵資料の検索データベース。
- **[和歌山ミュージアムコレクション](https://wakayama.museum/hakubutu-wakayama/?lang=ja)**（和歌山県立博物館）
  収蔵品を地図・年表・テーマから閲覧できる高精細画像アーカイブ。
