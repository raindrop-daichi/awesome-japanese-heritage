# 東京都の神社仏閣資料

旧武蔵国南部・南関東の中心。都は宗教法人名簿をPDFで公開しており、神社庁・仏教連合会も所在が確認できる。浅草寺・明治神宮のような全国有数の参拝者数を誇る社寺から、深大寺の国宝仏像まで一次資料が幅広く整っている一方、都の文化財情報データベース本体は接続不可の状態が続いている。

## 宗教法人名簿

- **[宗教法人｜法人の認定等｜東京都生活文化局](https://www.seikatubunka.metro.tokyo.lg.jp/houjin/shukyo_houjin)**（東京都生活文化スポーツ局都民生活部管理法人課）
  知事所轄宗教法人に関する制度・手続きの案内ページ。ここから最新の名簿PDFへのリンクが張られている。
- **[東京都宗教法人名簿（令和5年12月31日現在）](https://www.seikatubunka.metro.tokyo.lg.jp/documents/d/seikatubunka/houjinnmeibo051231)**（同上）
  系統名・包括団体名称・法人名称・事務所所在地・代表役員氏名等を収録したPDF一覧。

## 神社庁・仏教会

- **[東京都神社庁](http://www.tokyo-jinjacho.or.jp/)**（神社本庁 東京都事務所）
  ※`http://`でのみアクセス可（`https://`は接続不可）。都内約1,400社を管轄。[神社を探す](http://www.tokyo-jinjacho.or.jp/jinja/)ページで区市町村別に神社を検索できる。
- **[東京都仏教連合会](http://tokyo-buddhism.net/)**
  都内仏教各宗派の連合組織。成道会など合同法要の告知や活動ニュースを公開。

## 文化財データベース

- ※東京都文化財情報データベース（`bunkazai.metro.tokyo.lg.jp`）は2026-08-02時点で接続不可（メンテナンス中とみられる）。公開を確認できず
- **[都内の文化財情報｜文化財｜東京都教育委員会](https://www.kyoiku.metro.tokyo.lg.jp/lifelong/cultural_property/resource)**（東京都教育委員会生涯学習部）
  国宝・重要文化財・都指定文化財の一覧・解説ページへの入口。上記データベース休止中の代替窓口となっている。
- **[東京都文化財デジタルマップ](https://platinumaps.jp/d/tokyo-heritage-assets)**（東京都教育委員会、2025年公開）
  公開・活用に協力する文化財を地図上で検索できる新サービス。社寺建造物も含まれる。
- **[文化遺産オンライン 東京都の国指定文化財等検索結果](https://online.bunka.go.jp/heritages/search/prefecture_cd:13)**（文化庁）
  都内の国宝・重要文化財・史跡等を横断検索できる。建造物区分から社寺関連を絞り込める。

## 主要社寺の公式資料

- **[浅草寺](https://www.senso-ji.jp/)**（台東区）
  都内最古級の寺院。年間参拝者数が国内屈指の観音霊場で、由緒・年中行事を公式サイトで公開。
- **[明治神宮](https://www.meijijingu.or.jp/)**（渋谷区）
  明治天皇・昭憲皇太后を祀る近代創建の神社。鎮座百年史等の資料紹介を含む公式サイト。
- **[東叡山 寛永寺](https://kaneiji.jp/)**（台東区）
  徳川将軍家の菩提寺の一つ。山内の子院・徳川霊廟の案内を公式サイトで公開。
- **[三縁山 増上寺](https://www.zojoji.or.jp/)**（港区）
  徳川将軍家のもう一つの菩提寺。三解脱門（重要文化財）等の伽藍案内を公開。
- **[神田明神（神田神社）](https://www.kandamyoujin.or.jp/)**（千代田区）
  江戸総鎮守。神田祭を含む祭事・由緒を公式サイトで公開。
- **[大國魂神社](https://www.ookunitamajinja.or.jp/)**（府中市）
  武蔵国総社。くらやみ祭で知られる古社の由緒・境内案内を公開。
- **[深大寺](https://www.jindaiji.or.jp/)**（調布市）
  国宝・銅造釈迦如来倚像（白鳳仏）を蔵する天台宗別格本山。寺史・文化財解説を公開。

## デジタルアーカイブ

- **[東京都立図書館デジタルアーカイブ TOKYOアーカイブ](https://archive.library.metro.tokyo.lg.jp/da/top)**
  江戸城造営関係資料・浮世絵・江戸図・古写真等をデジタル画像で公開。社寺参詣曼荼羅・境内絵図を含む。
- **[江戸・東京資料案内](https://www.library.metro.tokyo.lg.jp/edo_tokyo/)**（東京都立図書館）
  江戸・東京関連資料の探し方ガイド。社寺文書・地誌類の所蔵先案内を含む。
- **[EDO-TOKYO MUSEUM Digital Archives](https://www.edohakuarchives.jp/)**（江戸東京博物館）
  収蔵する社寺絵図・古文書等の資料画像を検索・閲覧できる。
