# 群馬県の神社仏閣資料

旧国名は上野（こうずけ）。榛名山・妙義山・赤城山の山岳信仰と、上野国一之宮としての貫前神社の存在が特徴的である。宗教法人名簿は県がPDFで公開しており、文化財の指定リストもExcel/PDFで整備されている。

## 宗教法人名簿

- **[群馬県宗教法人名簿（令和6年12月31日現在）](https://www.pref.gunma.jp/uploaded/attachment/654058.pdf)**（群馬県生活こども部県民活動支援・広聴課）
  神道系・仏教系・キリスト教系・諸教の系統別、地域別に宗教法人を一覧化したPDF。単立法人も明記されている。

## 神社庁・仏教会

- **[群馬県神社庁](https://www.gunma-jinjacho.jp/)**（神社本庁包括下の県神社庁）
  高崎市に所在。前橋・前橋赤城・伊勢崎佐波・太田新田・桐生みどり・館林邑楽・吾妻・渋川北群馬・沼田利根の各支部区分で構成。
  - **[県内神社紹介](https://www.gunma-jinjacho.jp/jinja/)** — 支部別の神社一覧ページ
- ※群馬県仏教会に相当する統一組織の公式サイトは公開を確認できず。県内には「更生保護法人 群馬県仏教保護会」（[サイト](https://gunmabukyohogokai.p-kit.com/)）があるが、これは更生保護事業を目的とする別組織である。

## 文化財データベース

- **[群馬の文化財](https://www.pref.gunma.jp/page/5190.html)**（群馬県文化遺産課）
  国・県指定文化財の件数統計と、国指定文化財一覧（Excel）・県指定文化財一覧（PDF）のダウンロードリンクを掲載。年度別の新規指定履歴も追える。
- **[文化遺産課](https://www.pref.gunma.jp/soshiki/38/)**（群馬県）
  文化財行政の窓口ページ。個別の指定文化財解説記事へのリンクが並ぶ。

## 主要社寺の公式資料

- **[榛名神社](https://www.haruna.or.jp/)**（高崎市、公式サイト）
  6世紀創建と伝わる古社。本社・幣殿・拝殿・国祖社・額殿など複数棟が国の重要文化財に指定されている。
- **[一之宮貫前神社](http://nukisaki.or.jp/)**（富岡市、公式サイト）
  上野国一之宮。本殿・拝殿・楼門が国指定重要文化財。※`http://`でのみ疎通確認（`https://`は接続不可）。
- **[妙義神社](https://myougi.or.jp/)**（富岡市、公式サイト）
  妙義山東麓に鎮座。本社・幣殿・拝殿・唐門などが国指定重要文化財。
- **[少林山達磨寺](https://www.daruma.or.jp/)**（高崎市、黄檗宗、公式サイト）
  だるま市発祥の寺として知られる黄檗宗寺院。境内図・由緒を公式サイトで公開。

## デジタルアーカイブ

- **[古文書（デジタルギャラリー）](https://www.pref.gunma.jp/site/monjyokan/130509.html)**（群馬県立文書館）
  文書館が所蔵する古文書のデジタル画像を公開。
- **[収蔵資料の検索](https://www.pref.gunma.jp/site/monjyokan/130572.html)**（群馬県立文書館）
  古文書・県史複製資料・マイクロ資料の目録検索。
- **[群馬県立図書館デジタルライブラリー](https://www.library.pref.gunma.jp/%E6%8E%A2%E3%81%99%E3%83%BB%E8%AA%BF%E3%81%B9%E3%82%8B/%E3%83%87%E3%82%B8%E3%82%BF%E3%83%AB%E3%83%A9%E3%82%A4%E3%83%96%E3%83%A9%E3%83%AA%E3%83%BC)**（群馬県立図書館）
  郷土資料主体で古地図・絵図・貴重書など約1,200点を公開。社寺の絵図・縁起類も含まれる可能性がある。
