# 高知県の神社仏閣資料

旧国名は土佐国。太平洋に面した黒潮の国という地理条件から、四国霊場（お遍路）の関連寺院が県内に16か寺集中し、足摺岬の金剛福寺・室戸岬の最御崎寺など海を望む古刹が多い。大豊町の豊楽寺薬師堂は四国最古級の木造建築として国宝に指定されている。宗教法人の個別名簿はオンライン公開を確認できず、文化財の詳細一覧は県教育委員会の旧ドメインに残る個別ページ経由でのみ辿れる。

## 宗教法人名簿

- ※高知県が知事所轄の宗教法人について、法人名まで含む名簿のオンライン公開は確認できず。[宗教法人について](https://www.pref.kochi.lg.jp/doc/shukyohoujin/)（高知県総務部法務文書課）は認証・届出手続きの案内ページで、掲載リンクは申請様式（Word/PDF）のみであり、既存法人の一覧は掲載されていない。

## 神社庁・仏教会

- **[高知県神社庁](https://www.kochi-jinjyacho.com/)**（高知県神社庁）
  神社本庁の地方機関。所在地・沿革のほか、[高知県神社一覧](https://www.kochi-jinjyacho.com/高知県神社一覧)で管内神社の情報を掲載する。
- ※高知県仏教会は[全日本仏教会の会員名簿](https://www.jbf.ne.jp/member?id=15758)に名称のみ掲載されており、独自の公式サイトは確認できず。

## 主要社寺の公式資料

- **[土佐神社](https://tosajinja.com)**（土佐神社公式）
  高知市一宮に鎮座する土佐国一宮。本殿・幣殿・拝殿・鼓楼は国指定重要文化財。
- **[竹林寺](http://www.chikurinji.com/)**（竹林寺公式、※https証明書エラーのためhttpでのみアクセス可）
  四国霊場第31番、高知市五台山。本堂は国指定重要文化財。
- **[金剛福寺](https://kongoufukuji.com/)**（金剛福寺公式）
  四国霊場第38番、土佐清水市足摺岬。弘法大師開基と伝わる補陀落信仰の霊場。
- **[最御崎寺（四国八十八ヶ所霊場会）](https://www.88shikokuhenro.jp/24hotsumisakiji/)**（四国八十八ヶ所霊場会）
  四国霊場第24番、室戸市室戸岬。寺院独自の公式サイトは確認できず、四国霊場会公式ページを掲載。
- **[豊楽寺薬師堂（高知県教育委員会文化財課）](https://www.kochinet.ed.jp/bunkazai/details/110-1/110-1-01.htm)**（高知県教育委員会文化財課）
  大豊町、平安末期建立とされ四国最古級の木造建築。国宝指定。寺院独自の公式サイトは確認できず。
