# 静岡県の神社仏閣資料

旧国名は駿河・遠江・伊豆の三国。富士山信仰の総本社である富士山本宮浅間大社、徳川家康を祀る国宝社殿の久能山東照宮など、全国的に知られる社寺が多い。宗教法人名簿は県が公開してきた実績があるが、本稿執筆時点では従来の公開URLが404となっており最新の所在を確認できなかった。

## 宗教法人名簿

- 静岡県は総務部法務文書課が「静岡県知事所轄宗教法人名簿」をPDFで公開してきた実績がある（Internet Archiveの2026年5月時点のスナップショットで実在を確認）。ただし2026年8月2日時点で従来の公開URL（`pref.shizuoka.jp/kensei/gyoseikaikaku/kouekihoujin/1002313/`配下）はいずれも404となっており、現行の公開ページを確認できず。県サイトの大規模リニューアル（2023年1月）以降のURL移行が未完了である可能性がある

## 神社庁・仏教会

- **[静岡県神社庁](http://www.shizuoka-jinjacho.or.jp/)**（神社本庁）
  静岡県内約2,800社を包括する神社本庁の地方機関。氏神検索や祭事情報を掲載
- **[静岡県仏教会](https://sizuoka-bukkyo.org/)**（静岡県仏教会）
  県内の伝統仏教各宗派の寺院約2,000ヶ寺が加盟する連合組織。役員一覧等を公開

## 文化財データベース

- **[しずおか文化財ナビ](https://www.pref.shizuoka.jp/kankosports/bunkageijutsu/bunkazai/1002825/index.html)**（静岡県）
  県・市町指定および国指定の文化財を検索できるポータル。社寺の建造物・仏像等も種別から絞り込み可能

## 主要社寺の公式資料

- **[富士山本宮浅間大社](http://fuji-hongu.or.jp/sengen/)**（富士山本宮浅間大社）
  全国1,300余の浅間神社の総本宮、駿河国一宮。世界文化遺産「富士山－信仰の対象と芸術の源泉」の構成資産。※httpsは接続不可のため`http://`でのみリンク
- **[静岡県富士山世界遺産センター](https://mtfuji-whc.jp/)**（静岡県）
  富士山の世界遺産としての価値・構成資産（浅間大社含む）を解説する県の公式センター
- **[久能山東照宮](https://www.toshogu.or.jp/)**（久能山東照宮）
  徳川家康を祀る全国東照宮の創祀。権現造の社殿は2010年に国宝指定
- **[三嶋大社](https://www.mishimataisha.or.jp/)**（三嶋大社）
  伊豆国一宮。源頼朝が崇敬したことで知られる
- **[秋葉総本殿 可睡斎](https://www.kasuisai.or.jp/)**（可睡斎）
  袋井市の曹洞宗寺院。徳川家との縁起や火防信仰の秋葉信仰の総本殿を称する
- **[龍潭寺](https://www.ryotanji.com/index.html)**（龍潭寺）
  浜松市の臨済宗妙心寺派寺院。小堀遠州作庭の庭園は国指定名勝。※SSL証明書が期限切れのためブラウザで警告が表示される場合がある

## デジタルアーカイブ

- **[デジタルアーカイブ（ふじのくにアーカイブ）](https://www.tosyokan.pref.shizuoka.jp/contents/library/index.html)**（静岡県立中央図書館）
  県立図書館および県内市町立図書館所蔵の古文書・郷土資料等の画像を公開
- **[オンラインデータベース案内](https://www.tosyokan.pref.shizuoka.jp/contents/institution/online_db.html)**（静岡県立中央図書館）
  館内・館外から利用できる各種データベースの一覧。郷土史・古文書関連の外部DBへの案内を含む
