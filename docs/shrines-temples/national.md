# 神社仏閣 — 全国横断の資料

神社・寺院の全国横断資料を整理する。重要な前提として、**都道府県知事所轄の宗教法人（＝大多数の個別神社・寺院）を横断検索できる全国データベースは存在しない**。文化庁の統計（宗教年鑑）、各都道府県の宗教法人名簿、神社庁・各宗派の検索がそれぞれ部分的にカバーしているのが現状である。

[トップ](../index.md)

## 統計・公的資料

- **[宗教年鑑](https://www.bunka.go.jp/tokei_hakusho_shuppan/hakusho_nenjihokokusho/shukyo_nenkan/index.html)**（文化庁）
  全国の宗教法人数・信者数等の統計（第2部）と文部科学大臣所轄法人一覧（第3部）を収録する年次報告書。平成7年版以降30年分超のPDFをこのページからダウンロードできる。※年度更新でPDFのパスが変わるため、このランディングページにリンクする
- **[国指定文化財等データベース](https://kunishitei.bunka.go.jp/)**（文化庁）
  建造物カテゴリで種別「近世以前／神社」「近世以前／寺院」を選ぶと、国宝・重要文化財の社寺建造物を絞り込み検索できる。

## 宗教法人名簿（都道府県別）

全国統一のDBはなく、各都道府県が知事所轄の宗教法人名簿を個別に公開している（形式・更新頻度はバラバラ）。代表例:

- **[大阪府知事所轄宗教法人名簿](https://www.pref.osaka.lg.jp/o070010/shigaku/shukyo/index.html)**（大阪府 学事課）
  知事所轄の宗教法人一覧をExcel/PDFで公開。
- 他県も「〔県名〕 宗教法人名簿」で検索すると公開ページが見つかることが多い。今後、都道府県別ページの整備に合わせて個別収集する。

## 神社

- **[神社本庁](https://www.jinjahoncho.or.jp/)**
  伊勢神宮を本宗とする包括宗教法人。全国約8万社のうち約7.8万社が被包括。
- **[全国の神社庁一覧](https://www.jinjahoncho.or.jp/jinjahoncho/jinjacho/)**（神社本庁）
  47都道府県の神社庁の住所・連絡先一覧。※各神社庁サイトへの外部リンクは掲載されていないため、県別URLは個別に収集する必要がある
- **[滋賀県神社庁](https://www.shiga-jinjacho.jp/)** / **[兵庫県神社庁](https://www.hyogo-jinjacho.com/)**
  都道府県単位の神社庁の例。兵庫県神社庁は県内3,800余社の神社検索機能あり。

## 寺院（宗派別の公式検索）

- **[曹洞宗 寺院検索（曹洞禅ナビ）](https://www.sotozen-net.or.jp/searchsystem_jiin)**（曹洞宗）
  坐禅可・写経可等の条件で絞り込み検索できる。※「検索データを用いての商行為などは一切ご遠慮ください」と明記あり
- **[天台宗 寺院検索](https://www.tendai.or.jp/tera/kensaku.php)**（天台宗）
  寺院名・読み・郵便番号・都道府県・教区等で複数条件検索。
- **[浄土真宗本願寺派（西本願寺）](https://www.hongwanji.or.jp/)**
  末寺の網羅的検索ではなく「お近くの別院・教務所」検索が中心。
- **[真言宗豊山派 寺院マップ](http://www.buzan.or.jp/shingonshu_buzan/map/)**（真言宗豊山派）
  寺院名から各寺サイトへ遷移する形式。※サーバー証明書設定の都合で https 接続に難がある場合あり
