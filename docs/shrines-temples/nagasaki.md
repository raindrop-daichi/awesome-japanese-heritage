# 長崎県の神社仏閣資料

旧国名は肥前国（西部）・壱岐国・対馬国。鎖国時代の対外窓口だったため、唐寺（黄檗宗の中国寺院）とキリスト教会堂という他県にはない2系統の宗教建築が集積し、世界遺産「長崎と天草地方の潜伏キリシタン関連遺産」の構成資産も多い。宗教法人名簿のオンライン公開は確認できず、文化財はエリア検索型のデータベースで整備されている。

## 宗教法人名簿

- ※長崎県の宗教法人名簿は、オンラインでの一般公開を確認できず。所管は学事振興課で、[宗教法人関係](https://www.pref.nagasaki.lg.jp/bunrui/kanko-kyoiku-bunka/bunka-geijyutsu/shukyohojin/syukyo/)（長崎県）のページ本文および配下の各手続きページ（事務所備え付け書類、代表役員変更届等）をすべて確認したが、いずれも様式ダウンロードのみで名簿本体へのリンクはない。

## 神社庁・仏教会

- **[長崎県神社庁](https://nagasaki-jinjacho.or.jp/)**（長崎県神社庁）
  「県内の神社」リンクから神社検索・一覧にアクセスできる。
- **[長崎県仏教連合会](https://www.jbf.ne.jp/member?id=15760)**（全日本仏教会 加盟団体一覧）
  独自の公式サイトは確認できず、全日本仏教会の都道府県仏教会一覧内に連絡先が掲載されている。

## 文化財データベース

- **[長崎県文化財データベース](https://www.pref.nagasaki.lg.jp/bunkadb/index.php)**（長崎県）
  体系別・エリア別・複数条件検索に対応。対馬市・壱岐市を含む市町村単位で文化財を検索できる。
- **[文化財件数一覧](https://www.pref.nagasaki.lg.jp/bunkadb/ichiran_ken.html)**（長崎県）
  国指定・県指定の文化財件数を市町村・分類別に集計した一覧（2026年3月16日時点更新）。個別建造物の詳細は上記データベース側で確認する必要がある。
- **[国指定文化財等データベース](https://kunishitei.bunka.go.jp/)**（文化庁）
  全国の国宝・重要文化財等を横断検索。崇福寺大雄宝殿・第一峰門、大浦天主堂など長崎県分も抽出可能。

## 主要社寺の公式資料

- **[国宝 大浦天主堂](https://oura-church.jp/)**
  1864年建立の現存最古の木造ゴシック様式教会堂。国宝指定であり、世界遺産「長崎と天草地方の潜伏キリシタン関連遺産」の構成資産。
- **[世界文化遺産 長崎と天草地方の潜伏キリシタン関連遺産](https://kirishitan.jp/)**（長崎県歴史文化遺産課）
  大浦天主堂を含む12の構成資産を紹介する公式サイト。禁教期の信仰継承の歴史的背景を解説。
- **[黄檗宗 東明山 興福寺](http://kofukuji.com/)**
  1620年創建、隠元禅師来朝ゆかりの唐寺（南京寺）。拝観案内・アクセスを掲載。
- **[鎮西大社 諏訪神社](https://www.osuwasan.jp/)**（お諏訪さん）
  長崎の氏神。長崎くんち（国指定重要無形民俗文化財）の奉納神社として知られる。
- ※崇福寺（長崎市、国宝・大雄宝殿・第一峰門）は独自の公式サイトを確認できず。長崎県観光連盟が運営する[ながさき旅ネット（崇福寺）](https://www.nagasaki-tabinet.com/guide/96/)に概要・国宝指定の説明がある。
- ※海神神社（対馬市、対馬国一宮）は公式サイト・観光協会ページとも確認できず、名称のみ言及。所蔵の重要文化財（銅造如来立像）を含め、上記「長崎県文化財データベース」の対馬市エリア検索で個別情報を確認できる。
