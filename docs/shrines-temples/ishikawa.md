# 石川県の神社仏閣資料

旧国名は加賀・能登。白山信仰の総本宮や能登国一宮、加賀藩前田家ゆかりの寺院など重要文化財建造物が県内に集積する。県の宗教法人名簿そのものは公開を確認できなかったが、神社庁・文化財ナビ・図書館デジタルコレクションなど周辺資料は充実している。2024年の能登半島地震では能登地域の社寺が甚大な被害を受け、県による文化財レスキュー事業が進行中である。

## 宗教法人名簿

- ※石川県が所轄する宗教法人の網羅的な名簿（Excel/PDF等）の一般公開は確認できず。県の[宗教法人に関するお知らせ](https://www.pref.ishikawa.lg.jp/soumu/houki/shuukyo.html)（石川県総務課）は制度・手続きの案内が中心で、法人一覧の掲載はない
- **[宗教法人事務所備付け書類の提出](https://www.pref.ishikawa.lg.jp/soumu/tethuzuki/shuukyo08.html)**（石川県）
  宗教法人が毎年提出する備付け書類の様式案内ページ。個別法人の一覧ではないが、所轄庁の窓口情報を確認できる

## 神社庁・仏教会

- **[石川県神社庁](https://www.ishikawa-jinjacho.or.jp/)**（神社本庁包括下の県神社庁）
  県内約1,860社を包括する。[神社検索](https://www.ishikawa-jinjacho.or.jp/shrine/)で鎮座地・氏子区域・神社名・御祭神から検索できる
- **[曹洞宗石川県宗務所](https://www.sotozen-net.jp/)**（曹洞宗）
  加賀・能登の禅寺を統括する県内組織。地域教区ごとの寺院情報を扱う
- **[真宗大谷派金沢教区・金沢別院（おやまねっと）](https://www.oyama-net.jp/)**（真宗大谷派）
  金沢別院（金沢東別院）・鶴来別院を中心とする県内教区の公式サイト
- ※「石川県仏教会」単独の公式サイトは確認できず。全日本仏教会加盟団体としての存在は言及されるが、独自ページは未特定

## 文化財データベース

- **[いしかわ文化財ナビ](https://www.bunkazainavi.pref.ishikawa.lg.jp/)**（石川県教育委員会）
  遺跡・建造物など県内文化財を地図・キーワードから検索できるWEBサービス。指定建造物の種別で神社・寺院建築も検索可能
- **[石川県文化財一覧（国指定）](https://www.pref.ishikawa.lg.jp/kyoiku/bunkazai/ichiran/kuniichiran.html)**（石川県）
  国宝・重要文化財等の県内一覧を掲載
- **[文化遺産オンライン 石川県検索](https://bunka.nii.ac.jp/heritages/search/prefecture_cd:17)**（文化庁）
  国指定文化財を都道府県別に横断検索できる

## 主要社寺の公式資料

- **[氣多大社](https://keta.jp/)**（羽咋市、能登国一宮）
  本殿・拝殿・神門など5棟が国の重要文化財。社叢「入らずの森」は国天然記念物
- **[白山比咩神社](https://www.shirayama.or.jp/)**（白山市、加賀一宮・白山信仰総本宮）
  全国三千余の白山神社の総本宮。境内の白山ひめ神社文化博物館で社宝を公開
- **[那谷寺](https://natadera.com/)**（小松市、高野山真言宗別格本山）
  717年泰澄創建、1640年に加賀藩前田利常が再建。本堂・三重塔・護摩堂など7棟が国指定重要文化財
- **[妙成寺](http://myojoji-noto.jp/)**（羽咋市、日蓮宗本山）※`http://`でのみアクセス可
  五重塔を含む境内10棟が国指定重要文化財。五重塔は北陸地方唯一の遺構

- **[令和6年能登半島地震 被災写真](https://www.ishikawa-jinjacho.or.jp/news/%E4%BB%A4%E5%92%8C6%E5%B9%B4%E8%83%BD%E7%99%BB%E5%8D%8A%E5%B3%B6%E5%9C%B0%E9%9C%87-%E8%A2%AB%E7%81%BD%E5%86%99%E7%9C%9F/)**（石川県神社庁）

  地震・豪雨による被害記録のアーカイブ。社寺を含む地域被害の記録を収録
