# 京都府の神社仏閣資料

旧国名は山城・丹波・丹後。平安京以来1200年にわたり社寺が集積し、府内の宗教法人数は全国有数の規模に上るため、個別社寺の列挙ではなく世界遺産や公的データベースなど**面で押さえられる資料**を優先して収録する。宗教法人の網羅的名簿の一般公開は確認できないが、世界遺産「古都京都の文化財」の構成資産一覧、京都市・京都府の文化財データベース、京都国立博物館の社寺寄託品情報など、公的機関による整理は他県に比べて厚い。

## 宗教法人名簿

- 京都府内の宗教法人（約5,400件、2025年3月31日時点）は個別名を載せた名簿としては一般公開されておらず、府のFAQで**各施設の情報公開窓口での閲覧のみ**と明記されている。
  - **[宗教法人名簿を入手したい（京都府FAQ）](http://faq.pref.kyoto.lg.jp/faq.asp?faqno=04458)**（京都府）
    「当該記載事項は、個人・法人問わず、前記の各施設の情報公開窓口で閲覧できます」と回答。名簿自体は存在するが閲覧のみで、Web公開・郵送等での入手は不可。
  - **[宗教法人関係データ](https://www.pref.kyoto.jp/bunkyo/1186098257650.html)**（京都府文化生活部文教課）
    宗派別・市町村別の法人「数」の統計PDFを公開。個別法人名は含まない。
  - **[宗教法人関係の各種届出・申請について](https://www.pref.kyoto.jp/bunkyo/syukyouhoujin.html)**（京都府文教課）
    設立・規則変更等の届出手続きページ。名簿ではなく事務手続き用。

## 神社庁・仏教会

- **[京都府神社庁](http://www.kyoto-jinjacho.or.jp/)**（京都府神社庁）
  府内神社を包括する神社庁の公式サイト。※`http://` でのみアクセス可（https は疎通せず）
- **[京都府仏教連合会](https://kbf.kyoto/)**（京都府仏教連合会）
  1987年設立、府内約700ヶ寺が加盟する超宗派の仏教連合会。
- **[一般財団法人 京都仏教会](https://www.kbo.gr.jp/)**（京都仏教会）
  京都市内の大本山・本山クラスの寺院が加盟する財団法人。文化財保護に関する提言活動でも知られる。

## 文化財データベース

- **[京都の文化遺産（京都市指定・登録文化財データベース）](https://kyoto-bunkaisan.city.kyoto.lg.jp/)**（京都市文化市民局文化財保護課）
  京都市指定・登録の建造物・美術工芸品等、約550件を検索できるデータベース。社寺建造物も多数収録。
- **[京都府内の文化財](https://www.kyoto-be.ne.jp/bunkazai/cms/?page_id=431)**（京都府教育委員会文化財保護課）
  府指定・登録文化財の紹介ページ群への入口。市町村別・種別に社寺建造物を確認できる。
- **[世界遺産「古都京都の文化財」](https://www.pref.kyoto.jp/isan/)**（京都府）
  1994年登録、京都市・宇治市・大津市にまたがる構成資産17件（うち社寺13件）を紹介する公式ページ。
  - **[世界遺産「古都京都の文化財（京都市、宇治市、大津市）」](https://www.city.kyoto.lg.jp/bunshi/page/0000005538.html)**（京都市）京都市所在の構成資産（賀茂別雷神社・賀茂御祖神社・教王護国寺＝東寺など）を個別解説。

## 主要社寺の公式資料

- **[清水寺](https://www.kiyomizudera.or.jp/)**（音羽山清水寺）
  世界遺産構成資産、北法相宗大本山。本堂（国宝）ほか境内の解説を掲載。
- **[東寺](https://toji.or.jp/)**（教王護国寺）
  世界遺産構成資産、真言宗総本山。五重塔（国宝）等の伽藍案内。
- **[平等院](https://www.byodoin.or.jp/)**（平等院）
  宇治市所在の世界遺産構成資産。鳳凰堂（国宝）と鳳翔館（ミュージアム）の情報を掲載。
- **[賀茂別雷神社（上賀茂神社）](http://www.kamigamojinja.jp/)**（賀茂別雷神社）
  世界遺産構成資産、山城国一宮。
- **[賀茂御祖神社（下鴨神社）](https://www.shimogamo-jinja.or.jp/)**（賀茂御祖神社）
  世界遺産構成資産、糺の森を境内に持つ山城国一宮。
- **[伏見稲荷大社](http://inari.jp/)**（伏見稲荷大社）
  全国約3万社の稲荷神社の総本宮。千本鳥居で知られる。

## デジタルアーカイブ

- **[東寺百合文書WEB](https://hyakugo.pref.kyoto.lg.jp/)**（京都府立京都学・歴彩館）
  国宝・東寺百合文書（約2万5千通、8〜18世紀）の全件画像・目録を公開するデジタルアーカイブ。
- **[京都府立京都学・歴彩館](https://www.pref.kyoto.jp/rekisaikan/)**（京都府）
  東寺百合文書のほか府政史料・地域史資料等を所蔵する府立の図書館・文書館・研究機関。
- **[コレクション](https://www.kyohaku.go.jp/jp/collection/)**（京都国立博物館）
  館蔵品に加え、府内社寺からの寄託品（国宝・重要文化財多数）を含む収蔵品情報の入口。
- **[名品紹介](https://www.kyohaku.go.jp/jp/collection/meihin/)**（京都国立博物館）
  館蔵品・社寺寄託品から選んだ名品を分野別に紹介するページ。
