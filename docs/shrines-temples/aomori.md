# 青森県の神社仏閣資料

旧陸奥国（津軽・南部）。宗教法人名簿をExcel形式で公開しており、県内神社の重要文化財建造物（岩木山神社楼門・拝殿・本殿など）と八戸の南部氏ゆかりの国宝武具（櫛引八幡宮）が資料の柱になる。

## 宗教法人名簿

- **[宗教法人（宗教法人名簿）](https://www.pref.aomori.lg.jp/soshiki/kotsu/seikatsu/shukyohojin_top.html)**（青森県庁 交通生活安全課）
  「青森県所轄宗教法人名簿」をExcel形式で公開。県知事所轄の神社・寺院等の名称・所在地が一覧できる。

## 神社庁・仏教会

- **[青森県神社庁](http://www.aomori-jinjacho.or.jp/)**
  神社本庁の地方機関。県内を支部単位で統括する。※SSL証明書が不整合のため `http://` でのみ疎通を確認。ブラウザでは警告が出る場合がある
- **[青森県仏教会](https://www.jbf.ne.jp/member?id=15720)**（全日本仏教会 加盟団体ページ）
  全日本仏教会の会員団体紹介ページ。青森県仏教会自体の独立サイトは公開を確認できず

## 文化財データベース

- **[重要文化財（建造物）](https://www.pref.aomori.lg.jp/soshiki/kyoiku/e-bunka/jubun_kenzoubutu_index_1.html)**（青森県庁 教育庁文化財保護課）
  県内の国指定重要文化財建造物一覧。最勝院五重塔、岩木山神社（本殿・拝殿・中門・楼門・瑞垣・奥門）、櫛引八幡宮本殿など34件超を収録
- **[国宝 赤糸威鎧兜・大袖付／白糸威褄取鎧兜・大袖付](https://www.pref.aomori.lg.jp/soshiki/kyoiku/e-bunka/kokuho_01.html)**（青森県庁 教育庁文化財保護課）
  櫛引八幡宮所蔵の国宝2領の解説ページ

## 主要社寺の公式資料

- **[岩木山神社](https://iwakiyamajinja.or.jp/)**（弘前市）
  津軽国一宮。本殿・拝殿・中門・楼門など6棟が国指定重要文化財
- **[櫛引八幡宮](https://www.kushihikihachimangu.com/)**（八戸市）
  南部氏の総鎮守。国宝「赤糸威鎧」「白糸威褄取鎧」を含む国宝館の情報を掲載
- **[金剛山最勝院](https://saisyouin.jp/jp/)**（弘前市）
  五重塔（重要文化財、寛文6年建立、日本最北端の国指定重要文化財五重塔）を有する
- 恐山菩提寺（むつ市）※公式サイト（osorezan.or.jp）は2026-08-02時点でDNS応答なし（名前解決不能）のため掲載を見送り、代わりに[恐山霊場／恐山菩提寺](https://aomori-tourism.com/spot/detail_47.html)（【公式】青森県観光情報サイト Amazing AOMORI）の解説ページを掲載

## デジタルアーカイブ

- **[青森県立図書館デジタルアーカイブ](https://www.plib.pref.aomori.lg.jp/digital-archive/)**（青森県立図書館）
  郷土資料・古文書等をデジタル化して公開。検索画面は `da.plib.pref.aomori.lg.jp`
- **[青森県史デジタルアーカイブスシステム](https://kenshi-archives.pref.aomori.lg.jp/contents/kenshi-front/)**（青森県庁）
  県史編さん事業で収集した文化財・古文書・絵はがき等のDB。ジャパンサーチと連携
