# 九州・沖縄

旧国名は筑前・筑後・豊前・肥前・肥後・豊後・日向・薩摩・大隅、そして旧琉球王国。宗像・沖ノ島、潜伏キリシタン関連遺産、琉球王国のグスク及び関連遺産群と、世界遺産の構成資産となる社寺・聖地が集積する地方だ。北部の英彦山（修験道）や国東半島の六郷満山（神仏習合）のような山岳信仰、南部の高千穂（記紀神話の舞台）と、県ごとに信仰の性格が大きく異なる。最南端の鹿児島では廃仏毀釈による寺院の壊滅、沖縄では沖縄戦による焼失と、近代以降の激しい断絶を経た県もある。

資料公開の状況は県ごとの差が大きい。宗教法人名簿は熊本県がオープンデータ（XLSX）、沖縄県がPDFで公開する一方、福岡・佐賀・長崎・大分・宮崎・鹿児島の各県では個別名簿の公開を確認できず、統計データのみにとどまる県もある。文化財データベースは佐賀・長崎・大分・宮崎・鹿児島が独自の検索システムを整備し、熊本県は二度の大規模災害（2016年熊本地震、2020年7月豪雨）からの文化財復旧記録という独自の資料の厚みを持つ。

## この地方の資料

- **[福岡県](fukuoka.html)** — 世界遺産「宗像・沖ノ島」と大宰府政庁跡周辺の古代寺社群を擁し、九州歴史資料館が発掘報告書・収蔵品DBを公開。
- **[長崎県](nagasaki.html)** — 唐寺とキリスト教会堂という他県にない2系統の宗教建築が集積し、世界遺産「潜伏キリシタン関連遺産」の構成資産も多い。
- **[熊本県](kumamoto.html)** — 阿蘇神社・青井阿蘇神社を擁し、2016年熊本地震と2020年7月豪雨からの文化財復旧記録を県教育庁文化課が詳細に公開。
- **[大分県](oita.html)** — 全国八幡宮の総本宮・宇佐神宮と、神仏習合文化発祥の地とされる国東半島の六郷満山寺院群・磨崖仏群を擁する。
- **[鹿児島県](kagoshima.html)** — 明治初年の廃仏毀釈で寺院がほぼ全廃した経緯を持ち、寺院側の一次資料は埋蔵文化財センターの発掘調査報告書が中心。
- **[沖縄県](okinawa.html)** — 琉球固有の御嶽信仰と神社・仏教が並存し、多くの寺院建造物は1945年の沖縄戦で焼失、宗教法人名簿はPDFで公開。
