# 宮崎県の神社仏閣資料

旧国名は日向国。記紀神話の舞台が集中する高千穂地方（天岩戸神社、高千穂神社）と、神武天皇東征伝承ゆかりの宮崎神宮・鵜戸神宮など、神話色の強い社寺が特徴だ。宗教法人名簿の県によるオンライン公開は確認できなかった一方、県教育委員会は「みやざきの文化財情報」で国・県指定文化財の一覧をデータベース化しており、高千穂の夜神楽（国指定重要無形民俗文化財）を含む神楽専用データベースも整備されている。

## 宗教法人名簿

- 宮崎県公式サイトの「[宗教法人](https://www.pref.miyazaki.lg.jp/kanko/bunka/sonota/index.html)」ページを開いて中身を確認したところ、規則変更認証申請・規則謄本再交付・登記完了届など手続き案内のみで構成されており、法人名が並ぶ名簿・一覧・検索システムへのリンクは無い。九州域のオープンデータ基盤（BODIK）内の宮崎県オープンデータカタログ（`odcs.bodik.jp/450006/`）にも該当データセットは見当たらなかった。**名簿の公開は確認できず（procedure_only のページのみ）**

## 神社庁・仏教会

- **宮崎県神社庁**（宮崎市神宮2-4-2、宮崎神宮境内）は県内約650社を包括するが、独自の公式サイトは確認できず。神社本庁公式サイトの「[神社庁一覧](https://www.jinjahoncho.or.jp/jinjahoncho/jinjacho/)」にも個別リンクの掲載はない
- **[宮崎県仏教連合会](https://www.jbf.ne.jp/member?id=15762)**（全日本仏教会加盟団体ページ）
  全日本仏教会の会員団体紹介ページ。連合会自体の独立サイトは未確認

## 文化財データベース

- **[みやざきの文化財情報](https://www.miyazaki-archive.jp/d-museum/mch/)**（宮崎県教育委員会文化財課）
  文化財マップ、見学ルート、神楽一覧などを含む総合サイト
  - **[国指定等文化財一覧](https://www.miyazaki-archive.jp/d-museum/mch/bunka/ichiran02_01_00.html)** — 高千穂神社本殿、宮崎神宮神殿など建造物・史跡を含む
  - **[県指定文化財一覧](https://www.miyazaki-archive.jp/d-museum/mch/bunka/ichiran02_02_00.html)**
- **[文化財課](https://www.pref.miyazaki.lg.jp/ky-bunka/index.html)**（宮崎県教育委員会）
  文化財行政の窓口ページ。新着指定情報や神楽関連の取り組みも掲載

## 主要社寺の公式資料

- **[高千穂神社](https://www.town-takachiho.jp/top/soshiki/kikakukanko/2/3/315.html)**（高千穂町公式）
  高千穂郷八十八社の総社。本殿と鉄造狛犬一対が国の重要文化財
- **[天岩戸神社](https://amanoiwato-jinja.jp/)**（高千穂町、公式）
  天岩戸神話の舞台。西本宮・東本宮からなる
- **[鵜戸神宮](https://www.udojingu.or.jp/)**（日南市、公式）
  海食洞内に本殿を構える。国指定名勝
- **[宮﨑神宮](https://miyazakijingu.or.jp/)**（宮崎市、公式）
  神武天皇を祀る旧官幣大社。神殿は登録有形文化財
- **[都農神社](https://tunojinjya6.webnode.jp/)**（都農町、公式）
  日向国一之宮

## デジタルアーカイブ

- **[みやざきの神楽データベース](https://www.miyazaki-archive.jp/kagura/database/173/)**（全国神楽継承・振興協議会、事務局：宮崎県教育庁文化財課）
  高千穂の夜神楽（国指定重要無形民俗文化財）を含む県内神楽の由来・保存体制・公開日程を収録
- **[デジタル宮崎県史](https://adeac.jp/miyazaki-pref-lib/top/)**（宮崎県立図書館）
  『宮崎県史』通史編・資料編（民俗芸能等を含む）をデジタル公開
- **[貴重書デジタルアーカイブ](https://www2.lib.pref.miyazaki.lg.jp/?page_id=625)**（宮崎県立図書館）
  古典籍・地域資料のデジタル化コレクション。社寺関連の個別収録内容は要問い合わせ
