# 福井県の神社仏閣資料

旧国名は越前・若狭。越前は曹洞宗大本山永平寺と白山信仰の拠点、若狭は古代から大陸交流の玄関口として古刹が密集し「海のある奈良」とも呼ばれる。宗教法人名簿の公開は確認できなかったが、神社庁・文化財データベース・デジタルアーカイブは整備されている。

## 宗教法人名簿

- ※県の「宗教法人関係様式一覧」ページに役員名簿・財産目録などの届出様式は公開されているが、県内宗教法人の網羅的な名簿そのものの公開は確認できず。
  - **[宗教法人関係様式一覧](https://www.pref.fukui.lg.jp/doc/koukaihou/syuukyouhoujin/syuukyou-homepage.html)**（福井県）
    宗教法人の設立・変更手続きに関する届出様式集。名簿ではなく事務手続き用のフォーム集。

## 神社庁・仏教会

- **[福井県神社庁](https://www.jinja-fukui.jp/)**（福井県神社庁）
  県内約1,700社を包括する神社庁の公式サイト。市町・10支部から神社を検索できる「神社を探す」機能あり。
- **[福井県仏教会](https://www.jbf.ne.jp/member?id=15735)**（全日本仏教会）
  全日本仏教会サイト内の福井県仏教会プロフィールページ。事務局は真宗大谷派福井教務所内。独自の公式サイトは持たない。
- **[福井教区（浄土真宗本願寺派）](https://fukui-hongwanji.jp/)**（浄土真宗本願寺派福井教区）
  県内本願寺派寺院・法座情報・本願寺福井別院の案内を掲載。

## 文化財データベース

- **[県内文化財を探す](https://bunkazai.pref.fukui.lg.jp/search_category)**（福井県）
  種別（建造物・彫刻・古文書等）、指定区分（国宝・国指定・県指定・登録等）、嶺北・嶺南の地域別に文化財を横断検索できる。神社仏閣の建造物も種別「建造物」で検索可能。

## 主要社寺の公式資料

- **[大本山永平寺](https://daihonzan-eiheiji.com/)**（曹洞宗大本山永平寺）
  道元禅師開山、曹洞宗二大本山の一つ。伽藍案内・参禅情報を掲載する公式サイト。
- **[明通寺](https://www1.city.obama.fukui.jp/kanko-bunka/jisha-shiseki/96.html)**（小浜市公式ホームページ）
  本堂・三重塔は福井県唯一の国宝建造物。小浜市による寺院解説ページ。
  - **[明通寺三重塔（文化遺産オンライン）](https://online.bunka.go.jp/heritages/detail/146021)**（文化庁）文永7年（1270）建立の三重塔の詳細解説。
- **[劔神社](https://www.tsurugi-jinja.jp/)**（越前二の宮 劔神社）
  越前二の宮。国宝の梵鐘、県指定文化財の社殿を紹介する公式サイト。
- **[国史跡白山平泉寺旧境内](https://www.city.katsuyama.fukui.jp/heisenji/)**（勝山市）
  白山信仰の拠点として栄えた平泉寺の国史跡指定区域を紹介する勝山市の公式ページ。
  - **[平泉寺白山神社](https://heisenji.jp/)**（平泉寺白山神社）境内の見どころ・発掘調査の情報を掲載する神社公式サイト。
- **[お水送り（神宮寺）](https://wakasa-obama.jp/special/wakasa-omizuokuri/)**（小浜市公式 若狭おばま観光サイト）
  奈良・東大寺のお水取りに先立ち行われる神宮寺の神事「お水送り」の公式案内。
- **[小浜八ヶ寺巡り](https://www.obama-8-temples.jp/)**（小浜市）
  明通寺・神宮寺・萬徳寺など小浜市内の国宝・重要文化財を有する古刹八ヶ寺をまとめた公式サイト。若狭が「海のある奈良」と呼ばれる所以となる古寺群。

## デジタルアーカイブ

- **[デジタルアーカイブ福井](https://www.digital-archives.pref.fukui.lg.jp/s/fukui/page/top)**（福井県文書館・図書館・ふるさと文学館）
  古文書・絵図（越前国之図など）・古写真等を公開。※自動巡回ツール（curl等）には403を返すが、通常のブラウザからは閲覧可能。
- **[福井県立図書館](https://www.library-archives.pref.fukui.lg.jp/tosyo/index.html)**（福井県）
  郷土資料・古文書関連の所蔵検索の入口。
