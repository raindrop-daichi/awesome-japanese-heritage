# 富山県の神社仏閣資料

旧越中国。加賀藩政下で真宗（浄土真宗）が強く根付いた地であり、勝興寺・瑞龍寺の2件の国宝建築、立山信仰の拠点である雄山神社を擁する。宗教法人名簿の単独公開は確認できなかったが、県神社庁サイトと「とやまの文化遺産」検索サイトが横断的な入口になる。

## 宗教法人名簿

- ※富山県知事所轄の宗教法人名簿（Excel/PDF等の一覧）は、県の公益法人・宗教法人手続きページ上での公開を確認できず。[富山県／宗教法人の手続等](https://www.pref.toyama.jp/1103/kensei/kouhou/kouekihoujin/kj00004690/index.html)（富山県）には法人設立・変更・解散等の手続き案内はあるが、名簿ファイルへのリンクは無い。

## 神社庁・仏教会

- **[富山県神社庁](https://toyama-jinjacho.sakura.ne.jp/)**（富山県神社庁）
  県内神社の氏神検索、御朱印案内、広報「敬報かわら版」等を掲載。
- ※富山県仏教会にあたる公式サイトは公開を確認できず。

## 文化財データベース

- **[とやまの文化遺産](https://toyama-bunkaisan.jp/search/)**（とやまの文化遺産魅力発信事業実行委員会／事務局：富山県教育委員会生涯学習・文化財室）
  国指定・県指定の建造物・美術工芸品・史跡等を横断検索できる。神社・寺院専用の分類は明示されていないが、建造物区分から社寺建築を辿れる。
- **[富山県／県内文化財](https://www.pref.toyama.jp/miryokukankou/bunka/bunkazai/kennai/index.html)**（富山県）
  指定文化財一覧、文化財GIS、富山県デジタル文化財ミュージアムへの入口。
- **[文化遺産オンライン 富山県](https://online.bunka.go.jp/heritages/search?page=1&prefecture_cd=16)**（文化庁）
  国指定文化財を都道府県横断で検索できる。

## 主要社寺の公式資料

- **[国宝高岡山瑞龍寺](https://www.zuiryuji.jp/)**（瑞龍寺）
  高岡市。前田利長を弔うため建立された曹洞宗寺院で、仏殿・法堂・山門が国宝。
- **[国宝 雲龍山勝興寺](https://www.shoukouji.jp/)**（勝興寺）
  高岡市伏木。浄土真宗本願寺派の寺院で、本堂・大広間及び式台が国宝、12棟が重要文化財。
- **[大岩山日石寺（由来）](https://www.town.kamiichi.toyama.jp/page/2054.html)**（上市町公式ホームページ）／**[真言密宗大本山 大岩山日石寺](https://ooiwasan.com/)**（日石寺）
  上市町。磨崖仏の不動明王像（重要文化財）で知られる真言密宗の寺院。「大岩不動」の通称で親しまれる。
- **[雄山神社](http://www.oyamajinja.org)**（雄山神社）※`http://`でのみアクセス可（https は証明書エラー）
  立山町。峰本社・中宮祈願殿・前立社壇の三社からなり、立山信仰の中心。前立社壇は個別サイト[雄山神社前立社壇](https://www.oyamajinjya-maetateshadan.org/)も公開。
- **[富山県［立山博物館］](https://tatehaku.jp/)**（公益財団法人富山県文化振興財団）
  立山信仰・立山曼荼羅を専門に扱う博物館。[立山曼荼羅絵解き解説](https://tatehaku.jp/culture_and_history/etoki/)、[収蔵資料](https://tatehaku.jp/collection/)のページで資料内容を確認できる。
