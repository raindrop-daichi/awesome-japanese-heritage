# 北海道・東北

北海道・東北は、明治以降の開拓地である北海道と、中世以前からの古社古刹が集積する東北6県とで性格が大きく分かれる地方だ。東北では伊達氏（宮城）・南部氏（青森）・佐竹氏（秋田・山形置賜）など近世大名ゆかりの社寺が国宝・重要文化財建造物として残る一方、岩手県平泉や山形県出羽三山では中世以前に遡る神仏習合の霊場が一次資料の中心をなす。北海道は開拓神社・移住者が勧請した本州の分社が多く、中世以前の古社古刹はほとんどない。

宗教法人名簿の公開状況は県ごとに差が大きい。北海道・青森・宮城・秋田・福島はExcelまたはPDF形式で網羅的な名簿を公開しているが、岩手・山形は一括公開する名簿の所在が確認できていない。文化財データベースは各県とも国指定文化財等データベース（文化庁）に加え県独自の一覧ページを整備しており、建造物区分で社寺を抽出できる県が多い。

## この地方の資料

- **[北海道](hokkaido.html)** — 開拓期以降の分社・近代宗教建築が中心。宗教法人名簿（4,500件超）をExcelで公開
- **[青森県](aomori.html)** — 岩木山神社（重要文化財6棟）と櫛引八幡宮の国宝武具2領が資料の柱
- **[岩手県](iwate.html)** — 世界遺産「平泉」の中尊寺金色堂・毛越寺を擁し、専用の学術資料データベースを併設
- **[宮城県](miyagi.html)** — 伊達政宗ゆかりの鹽竈神社・大崎八幡宮（国宝）・瑞巌寺（国宝）が集中
- **[秋田県](akita.html)** — 県神社庁管内約1,110社。宗教法人名簿はPDF・Excelでオープンデータ公開
- **[山形県](yamagata.html)** — 出羽三山（羽黒山五重塔ほか国宝）と山寺・慈恩寺の天台系古刹が中心
- **[福島県](fukushima.html)** — 宗教法人名簿（4,732法人）を公開。県内唯一の国宝建造物・白水阿弥陀堂を有する
