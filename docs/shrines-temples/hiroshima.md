# 広島県の神社仏閣資料

広島県（安芸・備後）は世界遺産・国宝の厳島神社を筆頭に、不動院金堂、浄土寺、明王院など中世以来の国宝建造物を複数擁する。宗教法人名簿の公開は確認できなかった一方、厳島神社は世界遺産としての保全状況報告書・保存活用計画がPDFで充実している。

## 宗教法人名簿

- ※広島県の宗教法人名簿の公開は確認できず。県の「宗教法人に係る届出事務」ページには様式例と問い合わせ先（学事課）のみが掲載されている。

## 神社庁・仏教会

- **[広島県神社庁](https://www.hiroshima-jinjacho.jp/)**（広島県神社庁）
  県内神社を包括する神社本庁の地方機関。
- **[広島の神社](https://www.hiroshima-jinjacho.jp/hirosima_jinja/)**（広島県神社庁）
  管内神社の紹介ページ。
- **[浄土真宗本願寺派 安芸教区](https://www.aki.or.jp/)**（浄土真宗本願寺派 安芸教区）
  広島別院を中心とする教区サイト。※広島県仏教会としての横断的な公式サイトは公開を確認できず。

## 文化財データベース

- **[広島県の文化財（指定種別）](https://www.pref.hiroshima.lg.jp/site/bunkazai/bunkazai-shitei-index.html)**（広島県教育委員会）
  国宝・重要文化財・県指定文化財等を種別ごとに一覧できる。
- **[広島県の文化財（市町別）](https://www.pref.hiroshima.lg.jp/site/bunkazai/bunkazai-area-index.html)**（広島県教育委員会）
  市町ごとの指定文化財一覧PDFへのリンク集。神社仏閣建造物も含まれる。

## 主要社寺の公式資料

- **[国宝・世界遺産 嚴島神社【公式サイト】](https://www.itsukushimajinja.jp/)**（厳島神社）
  廿日市市宮島町。1996年登録の世界文化遺産、社殿群は国宝・重要文化財。
- **[世界遺産一覧表記載資産 保全状況報告書（厳島神社）](https://www.bunka.go.jp/seisaku/bunkashingikai/isanbukai/sekaitokubetsu/4_01/gijishidai/pdf/shiryo_3_2_6.pdf)**（文化庁）
  文化審議会世界文化遺産部会に提出された保全状況報告のPDF。
- **[世界遺産推薦書 附属資料（厳島）](https://online.bunka.go.jp/suisensyo/itsukushima/appendices_index-j.html)**（文化庁）
  登録時の推薦書付属資料一覧。保存管理計画の要旨等を収録。
- **[廿日市市宮島町伝統的建造物群保存地区保存活用計画](https://www.city.hatsukaichi.hiroshima.jp/uploaded/attachment/71206.pdf)**（廿日市市）
  厳島神社の門前町・宮島の伝建地区に関する保存活用計画PDF。
- **[不動院金堂 - 文化遺産オンライン](https://online.bunka.go.jp/heritages/detail/148301)**（文化庁）
  1540年建立、1958年国宝指定。広島市内唯一の国宝建造物。
- **[不動院 - ひろしまたてものがたり](https://www.pref.hiroshima.lg.jp/soshiki_file/tatemonogatari/page005.html)**（広島県）
  建築的特徴の解説ページ。
- **[浄土寺本堂及び境内地、多宝塔など - 日本遺産ポータルサイト](https://japan-heritage.bunka.go.jp/ja/culturalproperties/result/1256/)**（文化庁）
  尾道市。本堂・多宝塔は国宝、山門・阿弥陀堂は重要文化財。
- **[浄土寺｜尾道 七佛めぐり](https://shichibutsu.jp/temple/joudoji.php)**（尾道市仏教会 七佛めぐり実行委員会）
  境内・伽藍の紹介ページ。
- **[明王院｜福山市ホームページ](https://www.city.fukuyama.hiroshima.jp/site/miryoku2023/288940.html)**（福山市）
  807年開基と伝わる真言宗大覚寺派の古刹。本堂・五重塔が国宝。
- **[国宝　明王院 オフィシャルホームページ](http://www.chisan.net/myooin/)**（明王院）
  ※httpsは証明書エラーのため`http://`でのみアクセス可。
- **[千光寺、尾道、公式ホームページ](https://www.senkouji.jp/)**（千光寺）
  尾道市。大同元年（806年）開基と伝わる真言宗単立寺院。朱塗りの本堂「赤堂」で知られる。
- **[千光寺公園｜尾道市ホームページ](https://www.city.onomichi.hiroshima.jp/site/onomichikanko/1316.html)**（尾道市）
  千光寺周辺を含む公園の観光案内。
