# 佐賀県の神社仏閣資料

旧国名は肥前国東部。県神社庁は「神社を探す」機能を持つ独自サイトを公開している一方、宗教法人の個別名簿は確認できず、県が公表するのは不活動宗教法人の統計のみだ。文化財面では「佐賀県文化財データベース」が種類別・市町別の検索機能を備え、県立図書館は古文書検索システムと郷土資料室「サガスバ」を運営している。

## 宗教法人名簿

- ※佐賀県の宗教法人個別名簿（一覧）の公開は確認できず
- **[佐賀県内の不活動宗教法人の状況等を取りまとめました](https://www.pref.saga.lg.jp/kiji003120472/index.html)**（佐賀県・法務私学課）
  宗教活動を停止している「不活動宗教法人」の件数推移（令和7年末時点で76法人）をまとめた統計ページ。個別法人名は含まない。
- **[宗教法人事務所備付書類の写しの提出について](https://denshi-shinsei.pref.saga.lg.jp/ShinseiContents.aspx?StyleCode=000203)**（佐賀県電子申請システム）
  宗教法人法第25条第4項に基づく役員名簿・財産目録等の写し提出手続きの案内。名簿の一般公開ではなく、法人から所轄庁への提出手続きに関するページ。

## 神社庁・仏教会

- **[佐賀県神社庁](https://saga-jinjacho.jp/)**（佐賀県神社庁）
  神社本庁の地方機関で、県内1,095社を包括する。「[神社を探す](https://saga-jinjacho.jp/jinja-map/)」から神社マップを利用できる。
- ※「佐賀県仏教会」に相当する統括組織の公式サイトは確認できず

## 文化財データベース

- **[佐賀県文化財データベース（指定文化財の検索）](https://www.pref.saga.lg.jp/list03036.html)**（佐賀県教育委員会）
  種類別・市町別に県内の指定文化財を検索できる。神社・寺院建造物も対象に含まれる。
- **[佐賀県内所在指定文化財等件数一覧](https://www.pref.saga.lg.jp/list03035.html)**（佐賀県教育委員会）
  国・県指定文化財の件数を種別・市町別に集計した一覧。
- **[佐賀県文化財調査報告書](https://www.pref.saga.lg.jp/list03037.html)**（佐賀県教育委員会）
  埋蔵文化財を含む各種調査報告書の一覧。
- **[国指定文化財等データベース（佐賀県）](https://online.bunka.go.jp/heritages/search?prefecture_cd=41)**（文化庁）
  都道府県別に国宝・重要文化財等を横断検索できる。佐賀県分（陶山神社鳥居等）を抽出可能。

## 主要社寺の公式資料

- **[祐徳稲荷神社](https://www.yutokusan.jp/)**（祐徳稲荷神社）
  鹿島市に鎮座し、日本三大稲荷の一つに数えられることが多い。壮麗な楼門・本殿は「鎮西日光」とも称される。
- **[陶山神社](http://arita-toso.net/)**（陶山神社）
  有田町の焼き物の神を祀る神社。鳥居・狛犬・門柱・絵馬まで磁器で作られた「陶磁器の鳥居」（明治21年完成）は登録有形文化財。
- **[與止日女神社](https://yodohime-jinja.jimdofree.com/)**（與止日女神社）
  佐賀市大和町に鎮座する肥前国一宮。欽明天皇25年（564年）鎮座と伝わり、延喜式神名帳にも記載される式内社。
- **[大興善寺](https://daikouzenji.com)**（大興善寺）
  基山町にある養老元年（717年）開創の古刹。「つつじ寺」として知られ、春は5万本のツツジ、秋は紅葉で知られる。
- **田島神社**（唐津市）
  肥前国唯一の名神大社。呼子町加部島に鎮座する。※公式サイトは確認できず

## デジタルアーカイブ

- **[佐賀県立図書館](https://www.tosyo-saga.jp/)**（佐賀県立図書館）
  郷土資料室「[サガスバ](https://www.tosyo-saga.jp/page_id137)」を運営し、古文書資料の閲覧案内・検索システムを提供する。
- **[佐賀県立図書館 古文書検索](https://www2.tosyo-saga.jp/archives/opac/search-detail-archives.do?lang=ja)**（佐賀県立図書館）
  館蔵の古文書を横断検索できるOPAC。社寺文書・縁起類が含まれる可能性がある。
- **[佐賀関連データベース](http://www.sagalibdb.jp/)**（佐賀県立図書館）
  郷土に関する各種データベースの入口。佐賀の民謡など郷土資料への導線となっている。
