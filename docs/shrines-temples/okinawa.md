# 沖縄県の神社仏閣資料

旧琉球王国。本土の神社仏閣とは信仰の基層構造そのものが異なり、御嶽（うたき）を中心とする琉球固有の自然信仰と、それを覆う形で移入された神社・仏教が並存する。神社は「琉球八社」という独自の体系にまとまり、寺院の多くは1945年の沖縄戦で建造物を焼失し、石造の門や礎石のみが遺構として残る。宗教法人名簿はPDFで公開されている。

## 宗教法人名簿

- **[宗教法人名簿](https://www.pref.okinawa.jp/site/somu/somushi/shigaku/syuukyou/syuukyouhoujinmeibo.html)**（沖縄県総務部総務私学課）
  「宗教法人名簿（令和7年3月31日現在）」を[PDF](https://www.pref.okinawa.lg.jp/_res/projects/default_project/_page_/001/014/071/r70331shukyouhoujin.pdf)で公開。系統・包括団体名・法人名・所在地・代表役員・認証年月日を記載。

## 神社庁・仏教会

- **[沖縄県神社庁](http://jinjacho.naminouegu.jp/)**（沖縄県神社庁）
  1972年の本土復帰に伴い設立。神宮大麻の頒布や県内神社の連絡調整を担う。
- **[沖縄神社 由緒](http://jinjacho.naminouegu.jp/okinawajinja.html)**（沖縄県神社庁）
  沖縄神社の由緒を中心に、末尾に県内神社一覧（各社サイトへのリンク付き）を掲載。個別由緒までは網羅していない。
- **[沖縄県仏教会](http://w1.nirai.ne.jp/njm/sub6.html)**（沖縄県仏教会）
  ※個人運営に近い簡易なページ構成で、更新状況は不明。県内仏教会の連絡先情報として掲載。

## 主要社寺の公式資料

- **[斎場御嶽](https://www.kankou-nanjo.okinawa/tokusyu/safa/)**（南城市観光ポータル「らしいね南城市」）
  世界遺産「琉球王国のグスク及び関連遺産群」構成資産。琉球最高の聖地とされ、久高島を望む。歴史学習施設「緑の館・セーファ」が併設。運営は[南城市役所](https://www.city.nanjo.okinawa.jp/movie_library/movie_ja/1579046288/1579074902/)。
- **[園比屋武御嶽石門](https://oki-park.jp/shurijo/gakusei/8282/8289)**（首里城公園）
  1519年、尚真王代に築造された国指定重要文化財かつ世界遺産構成資産。首里城外の御嶽を拝む石造の門で、国王が各地へ赴く前に祈りを捧げた場所。詳細解説は[文化遺産オンライン](https://bunka.nii.ac.jp/heritages/detail/176882)にも掲載。
- **[波上宮](http://naminouegu.jp/)**（波上宮）
  琉球八社の首位に位置づけられた社。那覇市若狭の崖上に鎮座し、海神信仰の中心地とされる。
- **[識名宮](http://sikinagu.com/index.html)**（識名宮）
  琉球八社の一社。尚元王代の創建と伝わり、沖縄戦で焼失後1968年に再建。首里城との関わりが深い。
- **[旧崇元寺第一門及び石牆](https://bunka.nii.ac.jp/heritages/detail/191483)**（文化遺産オンライン）
  崇元寺は歴代琉球国王の神霊を祀った国廟。円覚寺とともに琉球仏教の中心だったが1945年の沖縄戦で本堂等を焼失し、石門・石牆のみが残り国指定重要文化財。境内一帯の史跡指定については[那覇市の発表資料](https://www.city.naha.okinawa.jp/mayor/kaiken/1007264/1007292.html)を参照。
- **[円覚寺跡](https://oki-park.jp/shurijo/shuri-aruki/siseki/2014/01/enkakuji.html)**（首里城公園）
  1494年尚真王創建、琉球臨済宗の総本山。旧国宝の建造物群は沖縄戦で全て焼失し、現在の総門は1968年の復元。

## デジタルアーカイブ

- **[沖縄県公文書館](https://www.archives.pref.okinawa.jp/)**（沖縄県公文書館）
  琉球王国期から戦後の琉球政府期までの公文書・写真・映像を所蔵・検索できる。
- **[琉球政府の時代（琉球政府文書デジタルアーカイブ）](https://www3.archives.pref.okinawa.jp/GRI/)**（沖縄県公文書館）
  1945〜1972年の琉球政府文書を公開する専用デジタルアーカイブサイト。
- **[沖縄県立博物館・美術館](https://okimu.jp/)**（沖縄県立博物館・美術館）
  琉球王国関連資料を含む所蔵品情報や企画展情報を公開。東京大学史料編纂所と共同で「琉球国図」等のデジタルアーカイブも構築。
- **[那覇市歴史博物館デジタルミュージアム](https://www.rekishi-archive.city.naha.okinawa.jp/digital-museum/)**（那覇市歴史博物館）
  那覇市域の史跡調査報告や王朝文化資料を公開。崇元寺跡の[史跡指定に係る調査報告](https://www.rekishi-archive.city.naha.okinawa.jp/digital-museum/7/95025)等、社寺跡の一次資料も収録。
