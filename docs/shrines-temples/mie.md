# 三重県の神社仏閣資料

旧伊勢国・伊賀国・志摩国、および紀伊国の一部にまたがる三重県は、伊勢神宮を筆頭に神道史上特別な位置を占める。宗教法人名簿は県がPDFで定期公開しており、伊勢神宮は三重県神社庁の傘下ではなく神社本庁の本宗として神宮司廳が直接管掌する点が他県と異なる。

## 宗教法人名簿

- **[三重県宗教法人名簿（三重県環境生活部文化振興課）](https://www.pref.mie.lg.jp/common/content/001217775.pdf)**（三重県）
  市町別に神道系・仏教系・キリスト教系・諸教系で区分し、法人名・代表役員・所在地・包括団体名を掲載するPDF名簿。単立法人は「単立」と表示。
- **[宗教法人の各種届出](https://www.bunka.pref.mie.lg.jp/42537034973.htm)**（三重県文化振興課）
  名簿の位置づけと宗教法人の認証・届出手続きの案内ページ。最新版の名簿はここから辿れる。

## 神社庁・仏教会

- **[三重県神社庁](https://www.mie-jinjachou.page/)**（三重県神社庁）
  神社本庁傘下、県内約815社を包括。ただし伊勢神宮（内宮・外宮ほか125社）は神社本庁の「本宗」として別格に位置づけられ、三重県神社庁の包括下ではなく神宮司廳が直接管掌する。
- **[三重県の神社一覧](https://www.mie-jinjachou.page/%E4%B8%89%E9%87%8D%E7%9C%8C%E3%81%AE%E7%A5%9E%E7%A4%BE%E4%B8%80%E8%A6%A7)**（三重県神社庁）
  市町別の神社一覧ページ。
- **[本宗・神宮とは（伊勢神宮の位置づけ）](https://www.jinjahoncho.or.jp/honsou_jingu/ise/)**（神社本庁）
  伊勢神宮が神社本庁の本宗である旨と神宮司廳の役割を解説する公式ページ。
- ※三重県仏教会の独立公式サイトは公開を確認できず。

## 文化財データベース

- **[三重の文化財データベース](https://www.bunka.pref.mie.lg.jp/bunkazai/da/)**（三重県教育委員会事務局社会教育・文化財保護課）
  県指定・国指定文化財を横断検索できるトップページ。
- **[文化財検索画面](https://www.bunka.pref.mie.lg.jp/Miebunka/search?cls=cultural_heritage)**（三重県教育委員会）
  種別・市町・時代等で絞り込める文化財検索フォーム。神社仏閣建造物も検索対象。
- **[三重県｜文化財](https://www.bunka.pref.mie.lg.jp/bunkazai/index.htm)**（三重県教育委員会）
  文化財保護行政の総合案内ページ。新規指定・登録情報もここから確認できる。
- **[三重県埋蔵文化財センター（全国遺跡報告総覧）](https://sitereports.nabunken.go.jp/ja/list/24/24000/p/5?sort=publish_date:r)**（奈良文化財研究所）
  三重県内の発掘調査報告書をPDFで公開。社寺境内地の発掘事例も含まれる。

## 主要社寺の公式資料

- **[伊勢神宮](https://www.isejingu.or.jp/)**（神宮司廳）
  内宮・外宮および別宮・摂社末社125社からなる神社本庁の本宗。参拝案内・式年遷宮の解説・神宮の博物館情報を掲載。
- **[神宮の博物館・文化施設](https://www.isejingu.or.jp/about/cultural/)**（神宮司廳）
  神宮徴古館・神宮農業館・神宮文庫の紹介ページ。神宮文庫（蔵書約30万冊）は春秋の神楽祭期間中のみ一般公開される旨の案内あり。
- **[真宗高田派本山 専修寺](http://www.senjuji.or.jp/)**（専修寺）
  津市一身田町に所在。御影堂・如来堂が三重県で初めて建造物として国宝指定された。国宝施設の解説ページを掲載。
- **[椿大神社](https://tsubaki.or.jp/)**（椿大神社）
  鈴鹿市山本町に鎮座、猿田彦大神を祀る神社の総本宮とされる。
- **[朝熊岳金剛證寺（伊勢志摩観光ナビ）](https://www.iseshima-kanko.jp/spot/1403)**（伊勢志摩観光コンベンション機構）
  伊勢市朝熊町の臨済宗南禅寺派の寺院。「お伊勢参らば朝熊をかけよ」と伊勢音頭に唄われた奥宮的存在。金剛證寺自体の独立公式サイトは確認できず、公的観光機構の解説ページを掲載。
- **[熊野古道伊勢路とは](https://kumanokodocenter.com/kodo/)**（三重県立熊野古道センター）
  世界遺産「紀伊山地の霊場と参詣道」構成資産の一つ、伊勢路の解説。伊勢神宮から熊野三山へ至る参詣道沿いの社寺・史跡を紹介。
- **[世界遺産熊野古道・保存管理計画](https://www.pref.mie.lg.jp/BUNKAZAI/HP/sekaiisan/4708000001.htm)**（三重県教育委員会）
  三重県内の構成資産に関する保存管理計画のページ。

## デジタルアーカイブ

- **[斎宮歴史博物館](https://www.pref.mie.lg.jp/SAIKU/)**（三重県立斎宮歴史博物館）
  伊勢神宮に奉仕した斎王の御所・斎宮跡（国史跡）に隣接する県立博物館。発掘資料や復元模型を展示。
- **[三重県総合博物館（MieMu）](https://www.bunka.pref.mie.lg.jp/MieMu/)**（三重県総合博物館）
  県内の仏像・神像等を含む特別展を随時開催。館蔵資料の詳細なオンライン公開状況は未確認。
- **[三重県立図書館 デジタルライブラリー](https://www.library.pref.mie.lg.jp/find-book/digital-library/)**（三重県立図書館）
  郷土資料・貴重書等をデジタル化して公開。分類別一覧はあるが、社寺関連資料の個別目録はページ上では確認できず。
