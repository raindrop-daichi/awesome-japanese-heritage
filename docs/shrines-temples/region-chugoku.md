# 中国

中国地方は旧因幡・伯耆（鳥取）、出雲・石見・隠岐（島根）、備前・備中・美作（岡山）、安芸・備後（広島）、周防・長門（山口）からなり、5県すべてに国宝指定の社寺建造物がある。鳥取は三徳山三佛寺投入堂、島根は出雲大社本殿・神魂神社本殿、岡山は吉備津神社本殿及び拝殿、広島は厳島神社・不動院金堂・浄土寺・明王院、山口は瑠璃光寺五重塔・功山寺仏殿・住吉神社本殿と、それぞれ古代からの信仰（出雲・吉備・因幡の白兎神話等）や中世の有力武家（大内氏・毛利氏など）の庇護に由来する建造物を伝えている。

資料公開の状況は県ごとに差がある。宗教法人名簿は島根県のみ毎年PDFで公開しており、鳥取・岡山・広島・山口の4県は網羅的な名簿の公開を確認できなかった。神社庁は5県すべてに公式サイトがあり神社検索機能を備えるが、県域を束ねる仏教会の公式サイトは島根県仏教会以外は未確認・未特定である。文化財データベースは各県の教育委員会・文化財課が整備しており、島根県は遺跡データベースやオープンデータカタログも公開している。

## この地方の資料

- **[鳥取県](tottori.html)** — 山岳信仰系の社寺（三徳山三佛寺投入堂・大山寺・大神山神社奥宮）が中心。宗教法人名簿・県仏教会サイトは未確認
- **[島根県](shimane.html)** — 出雲大社を筆頭とする神話の国。宗教法人名簿がPDF公開されている唯一の県で、島根大学の遺跡データベースも利用できる
- **[岡山県](okayama.html)** — 吉備氏族ゆかりの古社（吉備津神社・吉備津彦神社）と閑谷学校聖廟等の儒教施設が並ぶ
- **[広島県](hiroshima.html)** — 世界遺産・国宝の厳島神社を筆頭に、不動院金堂・浄土寺・明王院と国宝建造物を複数擁する
- **[山口県](yamaguchi.html)** — 大内氏・毛利氏の庇護を受けた社寺が多く、瑠璃光寺五重塔・功山寺仏殿・住吉神社本殿と3件の国宝建造物を有する
