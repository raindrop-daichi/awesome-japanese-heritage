# 長野県の神社仏閣資料

旧国名は信濃国。善光寺・諏訪大社をはじめ国宝建造物の宝庫であり、安楽寺八角三重塔・大法寺三重塔・仁科神明宮など全国的にも希少な中世神社建築が現存する。宗教法人名簿は県公式サイトでPDF一括公開されており、文化財情報も財団のデータベースで検索できる。

## 宗教法人名簿

- **[長野県知事が所轄する宗教法人の一覧](https://www.pref.nagano.lg.jp/ken-manabi/kensei/shichoson/hojin/shukyo/ichiran.html)**（長野県）
  令和7年12月31日現在の名簿PDFを公開。表紙・注意事項（[hyoshir7_1231.pdf](https://www.pref.nagano.lg.jp/ken-manabi/kensei/shichoson/hojin/shukyo/documents/hyoshir7_1231.pdf)）と名簿一覧（[meibor7_1231.pdf](https://www.pref.nagano.lg.jp/ken-manabi/kensei/shichoson/hojin/shukyo/documents/meibor7_1231.pdf)）の2ファイル構成。毎年更新。

## 神社庁・仏教会

- **[長野県神社庁](https://www.nagano-jinjacho.jp/)**（神社本庁）
  県内神社を包括する神社本庁の地方機関。神社紹介・支部一覧・広報誌「神州」等を掲載。
- **[長野市仏教会](https://bukkyo-nagano.com/)**
  長野市内の宗派を超えた寺院連合（152ヶ寺）。善光寺の花まつり主催等の活動を紹介。※県全域を包括する仏教会は公開を確認できず、市町村単位の組織のみ確認

## 文化財データベース

- **[信州の文化財](https://www.82bunka.or.jp/bunkazai/)**（公益財団法人八十二文化財団、長野県監修）
  県内の国宝・重要文化財・県宝等を横断検索できるデータベース。毎年内容を更改。

## 主要社寺の公式資料

- **[善光寺](https://www.zenkoji.jp/)**
  無宗派の古刹で、本堂は国宝。一光三尊阿弥陀如来を本尊とし、宗派を問わず参拝を受け入れる。
- **[信濃國一之宮 諏訪大社](https://suwataisha.or.jp/)**
  上社本宮・前宮（諏訪市・茅野市）、下社春宮・秋宮（下諏訪町）の四社からなる信濃国一宮。建造物の多くが重要文化財に指定されている。
- **[安楽寺](https://anrakuji.com/)**（曹洞宗）
  上田市別所温泉。境内の八角三重塔は日本で唯一現存する木造八角塔で国宝。
- **[大法寺](https://www.daihoujitemple.com/)**（天台宗）
  青木村。「見返りの塔」と呼ばれる三重塔は正慶2年（1333年）建立で国宝。
- **[国宝 仁科神明宮](https://www.sinmeigu.jp/)**
  大町市。現存最古の神明造社殿とされ、本殿・中門・釣屋が国宝。
- **[国宝 仁科神明宮｜大町市公式サイト](https://www.city.omachi.nagano.jp/00014000/00014100/00149401/00151201/00151003.html)**（大町市）
  自治体による解説ページ。

## デジタルアーカイブ

- **[長野県立歴史館](https://www.npmh.net/)**
  歴史博物館機能と公文書館機能を併せ持つ県立施設。信濃国の古文書・史料を収蔵。
- **[信州地域史料アーカイブ](https://adeac.jp/shinshu-chiiki/top/topg/digital-archives-of-nagano-pref/index.html)**（NPO長野県図書館等協働機構）
  善光寺関係・真田氏関係等、県内の図書館・博物館・文書館の貴重史料を高精細画像・翻刻付きで公開。
- **[長野県立歴史館／信濃史料](https://adeac.jp/npmh/top/)**（ADEAC）
  信濃国の古代〜近世史料を翻刻・公開するデジタルアーカイブ。
- **[郷土資料｜県立長野図書館](https://www.knowledge.pref.nagano.lg.jp/collection/local/index.html)**（県立長野図書館）
  郷土資料のデジタル化画像・目録を公開。
