# 愛媛県の神社仏閣資料

旧国名は伊予国。瀬戸内海と四国山地に挟まれた地形を反映し、大三島の大山祇神社には全国の武将が奉納した武具甲冑（国宝・重要文化財）が集積し、松山周辺には太山寺本堂・大宝寺本堂の2件の国宝建造物と道後温泉ゆかりの伊佐爾波神社が集中する。宗教法人の個別名簿は公開を確認できず、県公式オープンデータでは市町村別の法人数集計のみが得られる。

## 宗教法人名簿

- ※愛媛県が知事所轄の宗教法人について、法人名まで含む名簿のオンライン公開は確認できず。関連データとして「[市町村別宗教法人数](https://www.pref.ehime.jp/opendata-catalog/dataset/dataland-263.html)」（愛媛県オープンデータカタログ）がXLS形式で公開されているが、これは1988年（昭和63年）以降の市町村別法人数の集計のみで、個々の法人名は含まれない。

## 神社庁・仏教会

- **[愛媛県神社庁](http://ehime-jinjacho.jp/)**（愛媛県神社庁）
  神社本庁の地方機関。「[神社庁について](http://ehime-jinjacho.jp/about/)」ページに沿革・所在地を掲載。
- **[愛媛県仏教会](https://ehimebukyoukai.org/)**（愛媛県仏教会）
  西条仏教会・伊予仏教会・今治市仏教会・松山市仏教会・大洲市仏教会・八幡浜市仏教会・宇和島仏教六和会など県内約20の単位仏教会を包括する連合組織。
- **[加盟寺院一覧](https://ehimebukyoukai.org/member-temple/)**（愛媛県仏教会）
  単位仏教会別・宗派別に加盟寺院を検索できる。宗派別の件数集計（曹洞宗96、臨済宗妙心寺派74など）も併記。

## 文化財データベース

- **[国・県指定文化財等](https://ehime-kyoiku.esnet.ed.jp/bunkazai/shiteibunkazai)**（愛媛県教育委員会）
  国・県指定文化財の概要ページ。2024年2月時点で558件、うち建造物83件を含む有形文化財の内訳を掲載。個別一覧は「建造物」等のカテゴリ別リンクから参照する。
- **[国県指定文化財一覧](https://ehime-c.esnet.ed.jp/bunkazai/kennobunkazai/shiteibunkazai/shiteibunkazai.htm)**（愛媛県立学校教育支援センター旧ドメイン）
  国・県指定文化財を種別ごとに一覧化した資料。神社・寺院の建造物も含まれる。
- **[愛媛県の文化財](https://ehime-c.esnet.ed.jp/bunkazai/kennobunkazai/ehimenobunkazai.htm)**（同上）
  文化財保護行政の概要と一覧への導線。
- **[国指定文化財等データベース](https://kunishitei.bunka.go.jp/bsys/index)**（文化庁）
  国指定の建造物・美術工芸品等を全国横断で検索可能。愛媛県分の抽出にも利用できる。

## 主要社寺の公式資料

- **[大山祇神社](https://oomishimagu.jp/)**（大山祇神社）／**[宝物館「宝物さんぽ」](https://oomishimagu.jp/treasure/)**（同）
  今治市大三島に鎮座する日本総鎮守。全国の武将が奉納した武具甲冑を多数所蔵し、国宝・国指定重要文化財に指定された甲冑・刀剣類の点数は全国屈指とされる。
- **[石手寺](https://nehan.net/)**（石手寺公式）／**[石手寺（四国八十八ヶ所霊場会）](https://www.88shikokuhenro.jp/51ishiteji/)**（四国八十八ヶ所霊場会）
  四国霊場第51番。仁王門は鎌倉期建立とみられる三間一戸楼門・入母屋造で、昭和27年（1952年）に国宝指定。
- **[太山寺（四国八十八ヶ所霊場会）](https://www.88shikokuhenro.jp/52taisanji/)**（四国八十八ヶ所霊場会）
  四国霊場第52番、松山市。本堂は嘉元3年（1305年）建立の墨書が残る木造建築として県下最大級の規模を持ち、昭和31年（1956年）に国宝指定。
- **[伊佐爾波神社](https://isaniwa.official.jp/)**（伊佐爾波神社公式）
  道後温泉に隣接する松山市の古社。建物全体が日本に3例しかない八幡造で国指定重要文化財。太刀「国行」も国指定重要文化財として所蔵。
- **[大宝寺本堂（国宝）](https://www.city.matsuyama.ehime.jp/kanko/kankoguide/rekishibunka/bunkazai/kuni/taihouji_hondou.html)**（松山市公式）
  大宝寺は松山市。本堂・附厨子・棟札が国宝指定。大宝寺自体の独立公式サイトは確認できず、松山市による文化財解説ページを掲載。

## デジタルアーカイブ

- **[愛媛県立図書館 デジタルアーカイブ](https://adeac.jp/ehime-pref-lib/top/)**（愛媛県立図書館／ADEAC）
  「伊予八藩土地関係資料」等の郷土資料をデジタル公開する県立図書館所蔵資料のアーカイブ。
- **[愛媛県立図書館](https://lib.ehimetosyokan.jp/)**（愛媛県立図書館）
  4階「えひめ資料室」で伊予八藩土地関係資料・伊予俳諧文庫等の郷土資料を所蔵。上記デジタルアーカイブへの導線もこのサイトから。
- **[愛媛県歴史文化博物館](https://www.i-rekihaku.jp/)**（愛媛県歴史文化博物館）
  西予市に立地する県立博物館。県内の考古・歴史・民俗資料を扱い、社寺関連の収蔵資料展示も行う。
