# 茨城県の神社仏閣資料

旧国名は常陸国・下総国の一部。鹿島神宮を筆頭に、国宝・重要文化財を有する古社寺が県内に点在する。宗教法人名簿は県公式サイトで案内があり、文化財は県教育委員会のページで一覧できる。

## 宗教法人名簿

- **[宗教法人 - 茨城県](https://www.pref.ibaraki.jp/shiru/annai/chiikijoho/syukyo-hojin/index.html)**（茨城県）
  宗教法人制度の案内ページ。名簿そのものの一括ダウンロードは確認できず、個別の宗教法人情報は県への問い合わせが必要な様子。※網羅的な名簿PDF/Excelの直接公開は確認できず

## 神社庁・仏教会

- **[茨城県神社庁](https://www.ibarakiken-jinjacho.or.jp/)**（神社本庁）
  県内約2,500社を包括する神社本庁の地方機関。組織概要や関連情報を掲載。
- **[茨城県仏教会](https://www.ibaraki-bukkyou.com/)**
  県内の仏教各宗派が加盟する連合組織。活動報告等を掲載。

## 文化財データベース

- **[いばらきの文化財](https://kyoiku.pref.ibaraki.jp/art-and-culture/ibaraki-bunkazai/)**（茨城県教育委員会）
  国指定・県指定文化財の一覧・解説ページ。神社仏閣の建造物・美術工芸品も多数含まれる。
- **[直刀 黒漆平文大刀拵（鹿島神宮）](https://kyoiku.pref.ibaraki.jp/bunkazai/kuni-56/)**（茨城県教育委員会）
  国宝・鹿島神宮所蔵の直刀の解説ページ。上記文化財一覧内の個別ページの例。

## 主要社寺の公式資料

- **[鹿島神宮](https://kashimajingu.jp/)**
  常陸国一宮。本殿・拝殿・石の間・幣殿は国指定重要文化財、所蔵の直刀（附刀唐櫃）は国宝に指定されている。宝物館は令和以降、境内整備計画のため休館中。
- **[笠間稲荷神社](http://www.kasama.or.jp/)**
  白雉2年（651年）創建と伝わる稲荷信仰の古社。本殿は国指定重要文化財。
- **[筑波山神社](https://tsukubasanjinja.jp/)**
  筑波山を御神体とする古社。境内は中腹の拝殿から山頂に及ぶ約370ha。
- **[雨引山楽法寺（雨引観音）](http://www.amabiki.or.jp/)**
  坂東三十三観音第24番札所。厄除け・安産・子育ての観音霊場として知られる。

## デジタルアーカイブ

- **[茨城県立歴史館デジタルアーカイブ](https://ibarakida.ro-da.jp/)**（茨城県立歴史館）
  明治期から昭和20年までの行政文書等の画像を公開。寺社関連の旧公文書が含まれる場合がある。
- **[茨城県立図書館デジタルライブラリー](https://www.lib.pref.ibaraki.jp/guide/shiryou/digital_lib/digital_lib_main.html)**（茨城県立図書館）
  貴重資料のデジタル化画像を公開。
- **[その他の貴重資料：古文書一覧](https://www.lib.pref.ibaraki.jp/guide/shiryou/digital_lib/sonota_syurui_komon.html)**（茨城県立図書館）
  古文書類の一覧ページ。県内寺社の縁起・記録が含まれるか個別確認が必要。
