# 福島県の神社仏閣資料

旧国名は岩代・磐城。会津地方には慧日寺に代表される古代仏教文化、浜通り・中通りには奥州藤原氏ゆかりの白水阿弥陀堂など、地域ごとに異なる信仰史が残る。宗教法人名簿はExcel形式で公開されており、都道府県別資料としては充実している。

## 宗教法人名簿

- **[宗教法人名簿](https://www.pref.fukushima.lg.jp/sec/01135b/shigaku01.html)**（福島県 総務部 私学・法人課）
  令和8年1月1日現在で4,732法人を収録したExcelファイルを公開。県内の神社・寺院・教会等を横断的に確認できる数少ない一次資料。

## 神社庁・仏教会

- **[福島県神社庁](https://fukushima-jinjacho.or.jp/)**（神社本庁 福島県支部）
  県内約3,000社を対象とした[神社検索](https://fukushima-jinjacho.or.jp/search/)機能あり。
- ※福島県仏教会は独自の公式サイトを確認できず。全日本仏教会の[加盟団体ページ](https://www.jbf.ne.jp/member?id=15723)に連絡先（会津若松市・秀安寺内）のみ掲載されている。

## 文化財データベース

- **[ふくしまの文化財情報](https://www.pref.fukushima.lg.jp/site/edu/bunkazai01.html)**（福島県 教育庁 文化財課）
  「国・県指定等文化財一覧」「登録有形文化財（建造物）一覧」等のPDFを掲載。
- **[文化遺産オンライン 福島県](https://online.bunka.go.jp/heritages/region/7)**（文化庁）
  国指定文化財を地域別に検索できる。

## 主要社寺の公式資料

- **[白水阿弥陀堂](http://shiramizu-amidado.org/)**（願成寺）
  福島県内唯一の国宝建造物。平安末期の1160年、岩城則道の妻・徳姫（藤原清衡の娘）が建立。※証明書エラーのため `http://` でのみアクセス可
  補足として[いわき市生涯学習プラザの解説ページ](http://gakusyuplaza.city.iwaki.fukushima.jp/facility/bunka10-01/)もあり。
- **[伊佐須美神社](https://isasumi.or.jp/)**（岩代国一之宮・会津総鎮守）
  会津美里町に鎮座する式内社（名神大社）。
- **[磐梯山慧日寺資料館・史跡慧日寺跡](https://www.town.bandai.fukushima.jp/site/enichiji/)**（磐梯町）
  平安時代初期に僧・徳一が開創した慧日寺の跡地。昭和45年（1970）に国史跡指定。資料館で発掘調査資料を公開。
  ※開館期間は4月10日〜11月30日。
- **[旧正宗寺三匝堂（さざえ堂）](https://www.city.aizuwakamatsu.fukushima.jp/docs/2012110900017/)**（会津若松市）
  寛政8年（1796）建立、二重螺旋構造の六角三層堂。平成8年（1996）国重要文化財指定。
  [文化庁VR動画](https://cb.bunka.go.jp/ja/contents/fb09510d-b027-430a-aa24-b876b12927a7)でも内部構造を確認できる。

## デジタルアーカイブ

- **[福島県歴史資料館](https://www.fcp.or.jp/history/)**（福島県文化振興財団）
  旧家・寺社・団体等に伝わった江戸・明治期の古文書・地域史料を収蔵・公開。
- **[福島県立博物館 所蔵資料データベース](https://jmapps.ne.jp/fukushima/)**（福島県立博物館）
  34,000件超の所蔵資料を横断検索可能。
