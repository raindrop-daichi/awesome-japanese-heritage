# 北海道の神社仏閣資料

北海道は明治以降の開拓とともに社寺が整備された地域で、中世以前に遡る古社古刹はほとんどない。かわりに開拓神社・移住者が勧請した本州の分社が多く、函館など早くから開けた港町には和洋折衷の近代建築が残る。宗教法人名簿はExcel形式で公開されており、道指定文化財一覧も整備されている。

## 宗教法人名簿

- **[宗教法人（北海道知事所轄）](https://www.pref.hokkaido.lg.jp/category/d008/c056/s248/)**（北海道 総務部 学事課）
  「北海道宗教法人名簿」をExcelファイルで公開。[R7.12.31時点の名簿](https://www.pref.hokkaido.lg.jp/fs/1/2/8/3/2/5/6/8/_/02_%E3%80%90%E5%85%AC%E8%A1%A8%E7%94%A8%E3%80%91R7.12.31%E6%99%82%E7%82%B9%E5%8C%97%E6%B5%B7%E9%81%93%E7%9F%A5%E4%BA%8B%E6%89%80%E8%BD%84%E5%AE%97%E6%95%99%E6%B3%95%E4%BA%BA%E5%90%8D%E7%B0%BF.xlsx)は4,500件超の神社・寺院・教会等を収録する。

## 神社庁・仏教会

- **[北海道神社庁](https://hokkaidojinjacho.jp/)**（神社本庁 北海道支部）
  道内約600社を収録した[神社検索](https://hokkaidojinjacho.jp/jinja/)機能あり。
- **[北海道仏教会連盟](https://www.jbf.ne.jp/member?id=15718)**（全日本仏教会 加盟団体ページ）
  ※独自の公式サイトは確認できず。連絡先（札幌市中央区）のみ全日本仏教会サイトに掲載。

## 文化財データベース

- **[北海道指定の文化財一覧](https://www.dokyoi.pref.hokkaido.lg.jp/hk/bnh/bun-hogo-do-sitei.html)**（北海道教育庁 生涯学習推進局 文化財・博物館課）
  振興局管内別に道指定文化財（建造物含む）をPDFで一覧化。
- **[北海道の文化財件数一覧](https://www.dokyoi.pref.hokkaido.lg.jp/hk/bnh/dounai-shiteibunkazai-kenshuuichiran.html)**（同上）
  国指定・国登録・道指定の文化財を種別ごとに集計した総括表を掲載。
- **[文化遺産オンライン 北海道](https://online.bunka.go.jp/index.php/heritages/search?prefecture_cd=1&museum=%E5%9B%BD%E6%8C%87%E5%AE%9A%E6%96%87%E5%8C%96%E8%B2%A1%E7%AD%89%E3%83%87%E3%83%BC%E3%82%BF%E3%83%99%E3%83%BC%E3%82%B9)**（文化庁）
  国指定文化財等データベースを都道府県別に検索できる。

## 主要社寺の公式資料

- **[北海道神宮](http://www.hokkaidojingu.or.jp/)**（札幌市中央区）
  明治2年（1869）創建の開拓三神・明治天皇を祀る北海道総鎮守。旧官幣大社。
- **函館八幡宮**（函館市）※独自の公式サイトは確認できず
  1445年創建と伝わる道南最古級の神社。[北海道神社庁の紹介ページ](https://hokkaidojinjacho.jp/%E5%87%BD%E9%A4%A8%E5%85%AB%E5%B9%A1%E5%AE%AE/)で由緒・現社殿（大正4年竣成）を確認できる。
- **[上川神社](https://kamikawajinja.jp/)**（旭川市神楽岡）
  明治26年（1893）創建の上川一帯総鎮守。大正13年（1924）に現在地の神楽岡へ遷座。
- **真宗大谷派函館別院（東本願寺函館別院）**（函館市元町）
  大正4年（1915）再建の日本初の鉄筋コンクリート造寺院。本堂・正門・鐘楼が平成19年（2007）国重要文化財指定。文化遺産オンラインで各建造物の解説を確認できる：[本堂](https://online.bunka.go.jp/heritages/detail/125187)／[正門](https://online.bunka.go.jp/heritages/detail/203109)／[鐘楼](https://online.bunka.go.jp/heritages/detail/147878)。

## デジタルアーカイブ

- **[北海道立文書館デジタルアーカイブズ](https://www.pref.hokkaido.lg.jp/sm/mnj/digital/monjokan_digital_archive.html)**（北海道 総務部行政局 文書課文書館）
  箱館奉行所文書・開拓使文書等を公開。社寺に特化した収蔵物は確認できないが、明治前期の行政文書に社寺関連の記録が含まれる。
- **[北海道デジタル地域資料アーカイブズ](https://www3.library.pref.hokkaido.jp/)**（北海道立図書館）
  道内市町村史・郷土資料を横断検索できる。社寺の縁起・沿革を含む郷土誌が一部収録される。
