# 島根県の神社仏閣資料

旧国名は出雲国・石見国・隠岐国。出雲大社を筆頭に『出雲国風土記』が今に伝わる神話の国であり、県立古代出雲歴史博物館では出雲大社境内遺跡出土の宇豆柱（巨大柱根）を常設展示している。宗教法人名簿は県公式サイトで毎年PDF公開されており、遺跡データベースも島根大学が運営するものが利用できる。

## 宗教法人名簿

- **[島根県宗教法人名簿（令和7年12月31日現在）](https://www.pref.shimane.lg.jp/admin/pref/syukyo_hojin/syukyo_hojin/shuukyouhoujinmeibo.html)**（島根県総務部総務課）
  神道系・仏教系・キリスト教系・諸教に分類し市郡別に収録したPDF名簿。[令和7年12月31日現在のPDF直リンク](https://www.pref.shimane.lg.jp/admin/pref/syukyo_hojin/syukyo_hojin/shuukyouhoujinmeibo.data/meibo_071231-2.pdf)。毎年12月末時点で更新。

## 神社庁・仏教会

- **[島根県神社庁](https://www.shimane-jinjacho.or.jp/)**（神社本庁）
  管内1,158社・19支部を包括。市町村別の神社検索、氏神様検索（郵便番号）、庁報「石見国」等を掲載。
- **[島根県仏教会](http://shima-butsu.jp/)**
  全日本仏教会加盟の県仏教会公式サイト。令和8年（2026年）に創立70周年を迎える。組織概要・災害救援助成・講演会等の活動を紹介。

## 文化財データベース

- **[島根県の文化財](https://www.pref.shimane.lg.jp/life/bunka/bunkazai/shimane/shimanekennobunkazai.html)**（島根県）
  有形民俗文化財・史跡・名勝・天然記念物・登録文化財等の県指定文化財を分類別に一覧公開。
- **[島根県遺跡データベース](https://iseki.shimane-u.ac.jp/)**（島根大学）
  県内遺跡の遺構・遺物・調査・文献を検索でき、地図上に表示できる。出雲大社境内遺跡など発掘調査済み遺跡の情報源。
- **[文化遺産オンライン｜島根県の検索結果](https://online.bunka.go.jp/heritages/search/prefecture_cd:32)**（文化庁）
  国指定文化財を都道府県横断で検索できるデータベースの島根県絞り込み結果。
- **[データカタログ｜島根県 data eye](https://shimane-opendata.jp/datasets?group=02)**（島根県）
  市町村別の文化財一覧をCSV・XLSX形式で公開するオープンデータカタログ。

## 主要社寺の公式資料

- **[出雲大社](https://izumooyashiro.or.jp/)**
  出雲市大社町に鎮座する出雲国一宮。現本殿は延享元年（1744年）造替の大社造で国宝。
- **[神魂神社｜しまね観光ナビ](https://www.kankou-shimane.com/destination/20261)**（島根県公式観光情報サイト）
  松江市大庭町。現存する大社造社殿のうち最古とされる本殿が国宝。※神社独自の公式サイトは確認できず、県公式観光サイトの解説ページを掲載
- **[日御碕神社](https://hinomisaki-jinja.jp/)**
  出雲市大社町日御碕。上の宮（神の宮）・下の宮（日沉宮）からなり、権現造の社殿群は重要文化財。
- **[国史跡鰐淵寺境内のご紹介](https://www.city.izumo.shimane.jp/www/contents/1516949654620/index.html)**（出雲市）
  推古2年（594年）創建と伝わる天台宗の古刹。境内一帯が国史跡に指定されている。※寺独自の公式サイトは確認できず、出雲市公式サイトの解説ページを掲載
- **[安来清水寺](https://www.kiyomizudera.jp/)**
  安来市清水町。天台宗、山陰地方唯一現存の木造三重塔（重要文化財）を有する厄除観音霊場。

## デジタルアーカイブ

- **[島根県立古代出雲歴史博物館](https://www.izm.ed.jp/)**
  出雲大社に隣接。出雲大社の歴史、『出雲国風土記』の世界、荒神谷遺跡・加茂岩倉遺跡の青銅器群等、古代出雲を紹介する県立施設。境内遺跡出土の宇豆柱（巨大柱根）を展示。
- **[『出雲国風土記』写本等写真の公開](https://www.pref.shimane.lg.jp/bunkazai/kodai/library/database/fudoki/)**（島根県教育庁文化財課古代文化センター）
  平成5年（1993年）以降撮影した写本写真を準備の整ったものから順次公開。
- **[天下無双の大廈、出雲大社巨大柱の発見](https://www.pref.shimane.lg.jp/life/bunka/bunkazai/tayori/inisiewohuru/index.data/izumoyasiro.pdf)**（島根県）
  平成12年（2000年）の出雲大社境内遺跡発掘調査で発見された巨大柱根（宇豆柱）について、調査の経緯と成果を解説したPDF資料。
- **[発掘調査概要 島根県大社町出雲大社境内遺跡の発掘調査の成果](https://www.jstage.jst.go.jp/article/nihonkokogaku1994/8/11/8_11_153/_article/-char/ja)**（J-STAGE、日本考古学）
  巨大柱遺構の位置・環境・調査経緯・年代（炭素同位体比測定による伐採年1215〜1240年）を報告した学術論文。[PDF版](https://www.jstage.jst.go.jp/article/nihonkokogaku1994/8/11/8_11_153/_pdf/-char/ja)も公開。
- **[出雲大社境内遺跡｜全国遺跡報告総覧](https://sitereports.nabunken.go.jp/ja/14291)**（奈良文化財研究所）
  発掘調査報告書の書誌情報・本文PDFへのリンクを収録。
