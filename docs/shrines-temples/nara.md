# 奈良県の神社仏閣資料

旧国名は大和。国宝建造物の指定数は全国最多で、世界遺産「古都奈良の文化財」（東大寺・興福寺・春日大社・元興寺・薬師寺・唐招提寺・春日山原始林・平城宮跡の8資産）と「法隆寺地域の仏教建造物」の二つを県内に抱える。宗教法人名簿は最新版がExcelで公開されており、県レベルの資料公開は比較的充実している。個別社寺は数が膨大なため、ここでは面で押さえる公式資料を中心に掲載する。

## 宗教法人名簿

- **[宗教法人名簿（令和8年5月31日時点、Excel）](https://www.pref.nara.lg.jp/documents/6860/20260708113825.xlsx)**（奈良県）
  奈良県知事所轄の宗教法人（神社・寺院を含む）の名称・代表役員・事務所所在地を収録した最新版名簿
- **[宗教法人について](https://www.pref.nara.lg.jp/n017/43616.html)**（奈良県地域振興部法務文書課）
  宗教法人名簿の掲載元ページ。制度・手続き案内と併せて名簿ファイルへのリンクを掲載
- **[よくあるご質問と回答](https://www.pref.nara.lg.jp/n017/53773.html)**（奈良県）
  宗教法人に関する問い合わせ対応をまとめたFAQページ

## 神社庁・仏教会

- **[奈良県神社庁](https://www.naraken-jinjacho.jp/)**（神社本庁包括下の県神社庁）
  県内約1,300社を包括する。市郡別の神社一覧ページを掲載
- ※「奈良県仏教会」単独の公式サイトは確認できず。県内仏教会の存在は各種資料で言及されるが、独自ページは未特定

## 文化財データベース

- **[文化財課・文化財保存事務所](https://www.pref.nara.lg.jp/n035/p094000.html)**（奈良県地域創造部文化財課）
  県の文化財行政の窓口ページ。指定文化財の答申・調査事業などの案内を掲載
- **[奈良県指定文化財](https://www.pref.nara.lg.jp/n035/40277.html)**（奈良県）
  昭和31年から発行する県指定文化財の記録刊行物の案内。平成22・23年度版以降は電子書籍ポータル「nara-ebooks」で閲覧可能
- **[県指定文化財一覧](https://www.pref.nara.lg.jp/n035/40279.html)**（奈良県）
  県指定文化財（建造物含む）の一覧ページ
- **[奈良県歴史文化資源データベース「いかす・なら」](https://www.pref.nara.lg.jp/ikasu-nara/bunkazai/index.html)**（奈良県）
  指定文化財に限らず地域の歴史文化資源を紹介するデータベース。文化財保護の取り組み紹介も含む
- **[国指定文化財等データベース](https://kunishitei.bunka.go.jp/)**（文化庁）
  国宝・重要文化財を都道府県別に横断検索できる

## 主要社寺の公式資料

- **[東大寺](https://www.todaiji.or.jp/)**（奈良市、華厳宗大本山）
  「古都奈良の文化財」構成資産。大仏殿・法華堂・二月堂など多数の国宝・重要文化財建造物を有する
- **[法隆寺](https://www.horyuji.or.jp/)**（斑鳩町、聖徳宗総本山）
  世界遺産「法隆寺地域の仏教建造物」。金堂・五重塔など現存する世界最古の木造建造物群を含む
- **[春日大社](https://www.kasugataisha.or.jp/)**（奈良市、旧官幣大社）
  「古都奈良の文化財」構成資産。本殿4棟が国宝、境内の春日山原始林も世界遺産構成資産
- **[室生寺](https://www.murouji.or.jp/)**（宇陀市、真言宗室生寺派大本山）
  「女人高野」の通称で知られる。五重塔・金堂など国宝建造物を有する
- **[長谷寺](https://www.hasedera.or.jp/)**（桜井市、真言宗豊山派総本山）
  本堂が国宝。「花の御寺」として知られ、西国三十三所第八番札所

## デジタルアーカイブ

- **[まほろばデジタルライブラリー](https://www.library.pref.nara.jp/digital_archives/mahoroba)**（奈良県立図書情報館）
  県立図書情報館が所蔵する古文書・絵図・古典籍などをデジタル画像で公開。江戸期〜昭和戦前期の絵図を含む
- **[デジタルアーカイブ](https://www.library.pref.nara.jp/digital_archives)**（奈良県立図書情報館）
  公文書・古文書・絵図等を横断検索できるポータル
- **[データベース](https://www.narahaku.go.jp/lesson/database/)**（奈良国立博物館）
  収蔵品データベース・画像データベースへの入口。館蔵品約2,000件に加え、県内外の社寺からの寄託品約2,000件を収蔵、寄託品には秋篠寺・當麻寺・浄瑠璃寺等の重要文化財を含む
- **[全国遺跡報告総覧](https://sitereports.nabunken.go.jp/ja)**（奈良文化財研究所）
  埋蔵文化財発掘調査報告書を全文電子化した横断検索サービス。社寺境内地の発掘調査報告も収録
- **[文化財総覧WebGIS](https://heritagemap.nabunken.go.jp/)**（奈良文化財研究所）
  全国47都道府県の遺跡・建造物等の文化財データ約61万件を地図上で検索できる
