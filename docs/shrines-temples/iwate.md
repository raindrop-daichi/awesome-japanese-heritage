# 岩手県の神社仏閣資料

旧陸中国・陸前国北部にあたる岩手県は、平泉町に世界遺産「平泉－仏国土（浄土）を表す建築・庭園及び考古学的遺跡群－」を擁し、中尊寺金色堂をはじめとする奥州藤原氏関連の一次資料が突出して充実している。県全体の宗教法人名簿はExcel/PDF単位での一括公開が確認できず、申請窓口ページのみが公開されている。

## 宗教法人名簿

- ※ 岩手県が一括公開する宗教法人名簿（Excel/PDF等）は確認できず。県の窓口ページ（[宗教法人｜岩手県](https://www.pref.iwate.jp/kensei/houkikenpou/houjin/index.html)、岩手県学事文書課）は設立・規則変更等の認証申請手続きの案内が中心で、名簿そのものは掲載されていない。

## 主要社寺の公式資料

- **[関山 中尊寺（公式）](https://www.chusonji.or.jp/)**（中尊寺）
  天台宗東北大本山。世界遺産「平泉」構成資産の一つで、金色堂は国宝建造物第1号。
- **[金色堂について｜中尊寺](https://www.chusonji.or.jp/know/konjikido.html)**（中尊寺）
  金色堂の建立経緯・内陣構成に関する公式解説。
- **[天台宗 別格本山 毛越寺（公式）](https://www.motsuji.or.jp/)**（毛越寺）
  奥州藤原氏ゆかりの浄土庭園寺院。国の特別史跡・特別名勝の二重指定を受け、世界遺産「平泉」構成資産の一つ。
- **[盛岡八幡宮（公式）](https://morioka8man.jp/)**（盛岡八幡宮）
  延宝八年（1680）南部重信公創建、盛岡総鎮守。
- **[達谷窟毘沙門堂 別當 達谷西光寺（公式）](http://www.iwayabetto.com/)**（達谷西光寺）
  坂上田村麻呂創建と伝わる毘沙門堂。国史跡「達谷窟」。
- **[「平泉の文化遺産」の概要｜平泉町](https://www.town.hiraizumi.iwate.jp/heritage/about/index.html)**（平泉町）
  世界遺産構成資産（中尊寺・毛越寺・観自在王院跡・無量光院跡・金鶏山）の公式概要。
- **[ひらいずみ遺産 公式サイト](https://hiraizumi-heritage.pref.iwate.jp/)**（岩手県）
  平泉の文化遺産に関する県の公式ポータル。学術資料・論文データベースを併設。
- **[資料・論文データベース｜ひらいずみ遺産](https://hiraizumi-heritage.pref.iwate.jp/learning/database/treatise.php)**（岩手県）
  平泉関連の発掘調査・学術論文の一覧データベース。
