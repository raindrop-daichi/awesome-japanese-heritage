# 愛知県の神社仏閣資料

旧尾張国・三河国にまたがる愛知県は、熱田神宮を筆頭に、徳川家ゆかりの寺院、そして国宝建造物を複数擁する。宗教法人名簿は県が定期的にPDFで更新公開しており、文化財データベース「文化財ナビ愛知」も充実している。

## 宗教法人名簿

- **[宗教法人名簿（愛知県県民文化局学事振興課）](https://www.pref.aichi.jp/uploaded/attachment/607301.pdf)**（愛知県）
  知事所轄の宗教法人を市町村別に整理したPDF名簿。定期的に更新され、名古屋市・津島市・豊田市など県内全域の法人が掲載されている。
- **[宗教法人に関する事務について](https://www.pref.aichi.jp/soshiki/gakuji/0000004003.html)**（愛知県県民文化局学事振興課）
  名簿の位置づけや宗教法人の認証・届出手続きを解説する案内ページ。最新の名簿はここから辿れる。

## 神社庁・仏教会

- **[愛知県神社庁](https://aichi-jinjacho.or.jp/)**（愛知県神社庁）
  熱田区に所在。「氏神様をさがそう」機能で県内神社を検索できる。
- **[氏神様をさがそう（神社検索）](https://aichi-jinjacho.or.jp/search.html)**（愛知県神社庁）
  地域・支部別に神社を絞り込める検索ページ。
- **[愛知県仏教会（全日本仏教会 加盟団体紹介）](https://www.jbf.ne.jp/member?id=15743)**（全日本仏教会）
  愛知県仏教会自体の独立公式サイトは確認できず、全日本仏教会サイト内の紹介ページのみ掲載。

## 文化財データベース

- **[文化財ナビ愛知](https://jmapps.ne.jp/aichi_bunkazai/)**（愛知県）
  県内の国指定・県指定文化財、国登録文化財の建造物・美術工芸品を検索できる。神社仏閣建造物の絞り込みも可能。
- **[文化財課のページ](https://www.pref.aichi.jp/soshiki/bunkazai/)**（愛知県）
  県指定文化財の新規指定・登録情報を随時公表。
- **[愛知県 - 地域から見る 文化遺産オンライン](https://online.bunka.go.jp/heritages/region/23)**（文化庁・国立情報学研究所）
  市区町村単位で国指定文化財を一覧できる全国データベースの愛知県部分。

## 主要社寺の公式資料

- **[熱田神宮](https://www.atsutajingu.or.jp/)**（熱田神宮）
  三種の神器の一つ草薙神剣を祀る、伊勢神宮に次ぐ格式とされる古社。名古屋市熱田区に鎮座。
- **[真清田神社](http://www.masumida.or.jp/)**（真清田神社）
  尾張国一之宮。一宮市の市名の由来となった社で、おりもの感謝祭など地域行事の情報も掲載。
- **[大樹寺（成道山松安院）](https://daijuji.jp/)**（大樹寺）
  松平家・徳川将軍家の菩提寺。岡崎城とを結ぶ「ビスタライン」の起点としても知られる。
- **[大縣神社](http://ooagata.urdr.weblife.me/)**（大縣神社）
  犬山市宮山に鎮座する古社。尾張本宮山山頂から現在地に遷座して2000年以上の歴史を持つとされる。
  ※ドメインが個人向けホスティング（weblife.me）のため、リンク切れの可能性に留意。
- **[金蓮寺弥陀堂（文化遺産オンライン）](https://online.bunka.go.jp/heritages/detail/185426)**（文化庁）
  西尾市にある県内最古級の木造建築で国宝指定。金蓮寺自体の公式サイトは確認できず、文化庁のデータベース解説ページを掲載。

## デジタルアーカイブ

- **[愛知県図書館 デジタルアーカイブ](https://www.aichi-pref-library.jp/s005/search/040/index.html)**（愛知県図書館）
  貴重和本・絵図・絵はがきや、県内市町村立図書館の関連デジタルアーカイブへのリンクを集約。
- **[愛知県公文書館](https://kobunshokan.pref.aichi.jp/)**（愛知県公文書館）
  県が保存する行政文書・古文書の検索・閲覧案内。
- **[収蔵品データベース](https://www.museum.city.nagoya.jp/collection/database/index.html)**（名古屋市博物館）
  尾張藩関連資料や社寺の祭礼・見世物を記録した絵入り本などを検索できる。
