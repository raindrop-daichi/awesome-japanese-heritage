# 大分県の神社仏閣資料

旧国名は豊後国・豊前国の一部。全国八幡宮の総本宮・宇佐神宮を擁し、国東半島には神仏習合文化発祥の地として知られる六郷満山の寺院群・磨崖仏群が集積する。宗教法人名簿のオンライン公開は確認できず、県神社庁も公式サイトを持たない模様。文化財一覧はPDFで整備され、県教育委員会が「おおいた文化財ずかん」として3D画像等も含む独自データベースを公開している。

## 宗教法人名簿

- ※大分県の宗教法人名簿は、オンラインでの一般公開を確認できず。所管は[宗教法人に関する事務について](https://www.pref.oita.jp/soshiki/11700/shuhoujin.html)（大分県）のページで、宗教法人の認証・証明手続きの案内はあるが、名簿本体へのリンクはない。[宗教法人に係る申請・証明関係](https://www.pref.oita.jp/soshiki/11700/shukyo-houjin.html)（大分県）も参照可。

## 神社庁・仏教会

- ※大分県神社庁の公式サイトは確認できず（所在地・電話番号のみ各種地図サービスに掲載）。神社本庁公式サイト内の[神社庁一覧](https://www.jinjahoncho.or.jp/jinjahoncho/jinjacho/)から連絡先を辿ることは可能。
- ※「大分県仏教会」に相当する統括組織の公式サイトは確認できず。

## 文化財データベース

- **[国指定文化財等データベース](https://online.bunka.go.jp/heritages/search?prefecture_cd=44)**（文化庁）
  国宝・重要文化財等を都道府県別に横断検索できる。大分県分（宇佐神宮本殿、富貴寺大堂、臼杵石仏等）を抽出可能。
- **[県内の国・県指定文化財（令和7年3月31日現在）](https://www.pref.oita.jp/site/kyoiku/r7-3-31-kuni-ken-shiteibunkazai.html)**（大分県教育委員会）
  国指定・県指定の文化財を市町村別にPDF一覧で公開。建造物・史跡・美術工芸品等を網羅。
- **[おおいた文化財ずかん](https://oita-digitalzukan.jp/)**（大分県）
  2024年公開の県独自データベース。国・県指定文化財の解説、3D画像、地域の先人紹介動画等を収録。

## 主要社寺の公式資料

- **[八幡総本宮 宇佐神宮](http://www.usajinguu.com/)**
  725年創建、全国約4万社の八幡宮の総本宮。国宝の本殿3棟（八幡造）を有する。
- **[富貴寺（豊後高田市公式観光サイト）](https://www.city.bungotakada.oita.jp/site/showanomachi/1251.html)**
  平安時代創建。阿弥陀堂（富貴寺大堂）は現存する九州最古の木造建築で国宝指定、宇治平等院鳳凰堂・中尊寺金色堂と並び称される。
- **[国宝臼杵石仏](https://sekibutsu.com/)**（臼杵石仏公式サイト）
  平安末期から鎌倉期にかけて彫刻された磨崖仏群。古園石仏大日如来像を含む多数の石仏が国宝指定。
- **[天台宗別格本山 両子寺](http://www.futagoji.jp/)**
  718年仁聞菩薩開創と伝わる六郷満山の中山本寺。江戸期には満山を統括する総持院であった。
- **[六郷満山について（豊後高田市文化財室）](https://www.city.bungotakada.oita.jp/site/bunkazai/2105.html)**
  国東半島に広がる神仏習合文化「六郷満山」の概要と、市内寺院・岩屋群の解説。
- **[六郷満山、悟りの道をゆく（国東市）](https://www.city.kunisaki.oita.jp/site/kanko/yumekikou-satori.html)**
  国東市内の六郷満山寺院を巡るモデルコースと文化解説。「六郷山」は国史跡指定の答申を受けている（[日本遺産ポータルサイトの関連ニュース](https://www.japan-heritage.bunka.go.jp/ja/news/3952/)参照）。

## デジタルアーカイブ

- **[おおいたデジタル資料室](https://www.pref.oita.jp/site/346/oita-digital.html)**（大分県立図書館・大分県立先哲史料館・大分県公文書館）
  「豊の国情報ライブラリー」を構成する3館の所蔵資料を横断検索でき、一部はデジタル画像を閲覧可能。古文書・行政資料等を順次拡大収録中。
- **[大分県立図書館](https://www.oita-library.jp/)**（大分県立図書館）
  郷土資料・行政資料の所蔵情報を提供。
