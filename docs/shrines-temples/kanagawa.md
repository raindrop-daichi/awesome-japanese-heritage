# 神奈川県の神社仏閣資料

旧国名は相模国と武蔵国の一部（川崎市・横浜市の一部）。鎌倉幕府以来の禅宗五山（円覚寺・建長寺）、真言律宗の称名寺、厄除けで知られる川崎大師など中世〜近世の社寺が集積する。県は宗教法人名簿をPDFで公開し、金沢文庫は国宝典籍のデータベースを整備するなど、資料公開の水準は高い。

## 宗教法人名簿

- **[神奈川県知事所轄の宗教法人名簿（令和7年1月1日現在）](https://www.pref.kanagawa.jp/docs/a7g/cnt/f7176/meibo070101.html)**（神奈川県 総務局組織人材部文書課）
  知事所轄の宗教法人（主に単立・小規模包括宗教法人傘下）の名称・所在地等を市区町村別・系統別にPDF・Excel両形式で毎年1月時点公開。
- **[宗教法人について](https://www.pref.kanagawa.jp/docs/a7g/cnt/f7176/index.html)**（神奈川県ホームページ）
  名簿更新の経緯や宗教法人制度の案内ページ。過去年度分の名簿へのリンクもここから辿れる。

## 神社庁・仏教会

- **[神奈川県神社庁](https://www.kanagawa-jinja.or.jp/)**（神社本庁 神奈川県支部）
  県内神社の情報を発信する公式サイト。
- **[神社検索](https://www.kanagawa-jinja.or.jp/search/)**（神奈川県神社庁）
  神社名・御祭神名・鎮座地・祭礼名などで県内神社を検索できる。
- **[神奈川県仏教会](https://kborg.jp/index.html)**（神奈川県仏教会）
  宗派を超えて県内約1,500ヶ寺が協力する仏教会の公式サイト。事務局所在地・電話番号（全日本仏教会の加盟団体一覧の記載と一致）を確認済み。会報「仏教神奈川」や宗教法人講習会等の情報を掲載。

## 文化財データベース

- **[国指定文化財等データベース 神奈川県の検索結果](https://online.bunka.go.jp/index.php/heritages/search/prefecture_cd:14/museum:%E5%9B%BD%E6%8C%87%E5%AE%9A%E6%96%87%E5%8C%96%E8%B2%A1%E7%AD%89%E3%83%87%E3%83%BC%E3%82%BF%E3%83%99%E3%83%BC%E3%82%B9)**（文化庁 文化遺産オンライン）
  神奈川県内の国宝・重要文化財等を一覧・検索できる。円覚寺舎利殿など建造物も含まれる。
- **[県指定重要文化財（建造物）](https://www.pref.kanagawa.jp/docs/ar3/ken_kenzoubutu.html)**（神奈川県ホームページ）
  神奈川県指定の重要文化財のうち建造物を一覧掲載。多くが社寺建築。
- **[鎌倉市内指定文化財一覧](https://www.city.kamakura.kanagawa.jp/treasury/shiteibunkazai-kensu-list.html)**（鎌倉市）
  国・県・市指定文化財の件数・種別を鎌倉市域に絞って確認できる。

## 主要社寺の公式資料

- **[鶴岡八幡宮](https://www.hachimangu.or.jp/)**（鶴岡八幡宮）
  鎌倉幕府の氏神として源頼義・頼朝が整えた鎌倉の中心的神社。公式サイトで由緒・年中行事を公開。
- **[臨済宗大本山 円覚寺](https://www.engakuji.or.jp/)**（円覚寺）
  1282年北条時宗創建。境内の舎利殿は神奈川県内で唯一の建造物国宝（禅宗様仏堂）で、通常非公開だが正月・GW・11月の宝物風入時に特別公開される。
- **[巨福山 建長寺](https://www.kenchoji.com/)**（建長寺）
  鎌倉五山第一位。国宝の梵鐘（1255年鋳造）を含む文化財を有する臨済宗建長寺派大本山。
- **[称名寺と金沢文庫](https://www.city.yokohama.lg.jp/kanazawa/shokai/rekishi/ikizuku/shisan/shomyo-kanazawa.html)**（横浜市金沢区）
  横浜市金沢区の称名寺は北条実時ゆかりの真言律宗寺院。隣接する神奈川県立金沢文庫の沿革とあわせて市が解説。称名寺自体の公式サイトは公開を確認できず。
- **[川崎大師 平間寺](https://www.kawasakidaishi.com/)**（川崎大師 平間寺）
  真言宗智山派の厄除け大師として知られる川崎市の名刹。公式サイトで年中行事・祈祷案内を公開。

## デジタルアーカイブ

- **[国宝 金沢文庫文書データベース](https://kanazawabunko-db.pen-kanagawa.ed.jp/)**（神奈川県立金沢文庫・東京大学史料編纂所）
  称名寺聖教（16,692点）・金沢文庫文書（4,149点）は2016年に国宝指定。画像と翻刻データを検索・閲覧できる。2022年に東京大学史料編纂所との連携でリニューアル。
- **[神奈川県立金沢文庫の収蔵資料](https://www.pen-kanagawa.ed.jp/kanazawabunko/gaiyou/bunkosiryo.html)**（神奈川県教育委員会）
  金沢文庫の収蔵資料の概要説明ページ。
- **[古文書・私文書資料群一覧（鎌倉市）](https://archives.pref.kanagawa.jp/publications/inventory/collection/kamakura.html)**（神奈川県立公文書館）
  鎌倉市域に関する古文書・私文書資料群の目録一覧。
- **[鎌倉の文化財について](https://www.city.kamakura.kanagawa.jp/treasury/bunkazai_top.html)**（鎌倉市）
  鎌倉市の指定文化財・埋蔵文化財に関する解説と関連ページへの入口。
