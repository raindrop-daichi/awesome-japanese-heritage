# 山梨県の神社仏閣資料

旧国名は甲斐。日蓮宗総本山の身延山久遠寺を筆頭に、武田氏ゆかりの武田神社、国宝建造物を持つ大善寺・清白寺、富士山世界文化遺産の構成資産である北口本宮冨士浅間神社など、山岳信仰と戦国期の武家信仰が色濃く残る。県は宗教法人名簿をPDFで公開しており、文化財ガイドのデータベースも整備されている。

## 宗教法人名簿

- **[山梨県の宗教法人](https://www.pref.yamanashi.jp/gyousei-kk/syukyohojin.html)**（山梨県）
  行政法務課が所轄する宗教法人の名簿ページ。県内の宗教法人名簿PDFへのリンクがまとまっている。
- **[山梨県宗教法人名簿（令和7年12月31日現在）](https://www.pref.yamanashi.jp/documents/7901/r71231_syuukyouhoujinnmeibo.pdf)**（山梨県）
  包括団体・法人名・住所を掲載したPDF一覧。神社本庁包括の神社、単立寺院なども含めて網羅的に確認できる。

## 主要社寺の公式資料

- **[身延山久遠寺オフィシャルウェブサイト](https://www.kuonji.jp/)**（身延山久遠寺）
  日蓮宗総本山。境内案内・歴史・行事情報を公開。
- **[大善寺](https://daizenji.org/)**（大善寺、甲州市）
  本堂（薬師堂）は国宝。弘安九年（1286年）立柱、徳治2年（1306年）頃竣工の中世密教仏堂。
- **[清白寺](https://seihakuji.com/)**（清白寺、山梨市）
  仏殿は国宝。応永22年（1415年）建立の禅宗様建築。
- **[北口本宮冨士浅間神社](https://www.sengenjinja.jp)**（北口本宮冨士浅間神社、富士吉田市）
  世界文化遺産「富士山－信仰の対象と芸術の源泉」の構成資産で、吉田口登山道の起点。
- **[武田神社](http://www.takedajinja.or.jp/)**（武田神社、甲府市）
  武田氏館跡（躑躅ヶ崎館）に鎮座し、武田信玄を祀る。
