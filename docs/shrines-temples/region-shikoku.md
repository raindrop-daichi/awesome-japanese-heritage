# 四国

四国は阿波・讃岐・伊予・土佐の旧4か国からなり、四国八十八箇所霊場（お遍路）が県境を越えて連続する点が最大の共通項である。徳島県には発願の第1番霊山寺から第23番薬王寺までが集中し、香川県には第70番本山寺・第75番善通寺・第81番白峯寺、愛媛県には第51番石手寺・第52番太山寺、高知県には第24番最御崎寺・第38番金剛福寺など計16か寺が点在する。この霊場と遍路道は徳島・香川・愛媛・高知の4県・58市町村で構成される推進協議会が世界遺産暫定一覧表入りを目指して活動している。国宝建造物も各県に散在し、香川の金刀比羅宮・善通寺・本山寺・神谷神社、愛媛の石手寺仁王門・太山寺本堂・大宝寺本堂、高知の豊楽寺薬師堂が指定を受けている。

宗教法人名簿の公開状況は県によって差が大きい。香川県は神道系・仏教系など4カテゴリ別のPDF名簿を公開しており4県の中で最も充実するが、愛媛県は市町村別の法人数集計のみで個々の法人名は非公開、徳島県・高知県はオンライン公開自体を確認できていない。神社庁については香川・愛媛・高知の3県が公式サイトの疎通を確認できた一方、徳島県神社庁は公式サイトのドメインが応答せず、稼働を確認できるのは公式Instagramのみである。仏教会は徳島県・愛媛県が独自の公式サイトを持つ一方、香川県・高知県は全日本仏教会の会員名簿にしか名称が掲載されていない。

## この地方の資料

- **[徳島県](tokushima.html)** — 遍路発願の23か寺を擁する。宗教法人名簿は未確認、神社庁は公式サイトが不通で公式Instagramのみ稼働
- **[香川県](kagawa.html)** — 宗教法人名簿をカテゴリ別PDFで公開し、金刀比羅宮など国宝社寺も複数現存する
- **[愛媛県](ehime.html)** — 大山祇神社の武具甲冑コレクションと、松山周辺に集中する国宝建造物が特徴
- **[高知県](kochi.html)** — 四国最古級とされる豊楽寺薬師堂（国宝）を擁するが、文化財の個別一覧は組織改編前の旧ドメインでしか辿れない
