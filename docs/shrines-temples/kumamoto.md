# 熊本県の神社仏閣資料

旧国名は肥後。阿蘇山麓や球磨盆地の地勢を背景に、阿蘇神社・青井阿蘇神社など全国的にも著名な社殿群を擁する一方、2016年熊本地震と2020年（令和2年）7月豪雨（球磨川水害）という二度の大規模災害で多くの社寺建造物が被災した。県教育庁文化課がこの二度の災害からの文化財復旧記録を公開しており、行政資料としての厚みがある。宗教法人名簿はオープンデータとしてExcel形式で公開されている。

## 宗教法人名簿

- **[宗教法人名簿](https://data.bodik.jp/dataset/430005_00107)**（熊本県オープンデータカタログ／CKAN）
  熊本県所轄の宗教法人一覧をXLSX形式で公開。2026年8月時点の最新版は「123_宗教法人名簿（R7.8.1現在）」で、年1回更新。CC BY 4.0。

## 文化財データベース

- **[文化遺産オンライン 熊本県検索結果](https://online.bunka.go.jp/index.php/heritages/search?page=1&prefecture_cd=43)**（文化庁）
  国指定文化財等データベースを都道府県コードで絞り込み。社寺建造物も検索可能。
- **[熊本県文化財資料室](https://www.pref.kumamoto.jp/soshiki/125/73467.html)**（熊本県教育庁文化課）
  県指定文化財に関する資料の閲覧窓口の案内ページ。
- **[『令和2年7月豪雨文化財復旧記録集』を作成しました](https://www.pref.kumamoto.jp/soshiki/125/241126.html)**（熊本県教育庁文化課）
  2016年熊本地震と2020年7月豪雨の被害を比較しつつ、有形文化財・民俗文化財・史跡等の被災から復旧までを類型別にまとめた記録集の紹介ページ。2025年3月末時点で復旧率90%超と報告。
- **[熊本地震文化財復旧記録（PDF）](https://www.pref.kumamoto.jp/uploaded/attachment/242108.pdf)**（熊本県教育庁教育総務局文化課）
  2016年熊本地震で被災した文化財の復旧状況を写真付きでまとめた記録集（約14MB）。
- **[文化課](https://www.pref.kumamoto.jp/soshiki/125/)**（熊本県教育庁）
  県指定文化財の答申・審議会資料など一次情報の入口。

## 主要社寺の公式資料

- **[復旧の歩み](https://asojinja.or.jp/restoration/)**（阿蘇神社）
  2016年熊本地震で全壊した重要文化財・楼門ほか6棟の復旧工事を国・県・阿蘇市の補助事業として2016〜2023年度に実施し、2023年12月に完工した経緯をまとめる。
- **[指定文化財一覧](https://www.city.aso.kumamoto.jp/education/cultural-property/list_of_cultural_property/)**（阿蘇市）
  阿蘇神社を含む市内指定文化財の一覧。
- **[国宝指定](https://aoisan.jp/kokuhou/)**（青井阿蘇神社）
  本殿・廊・幣殿・拝殿・楼門の5棟が2008年に国宝指定された経緯を紹介。2020年7月豪雨では境内が浸水し、社殿床上浸水・奉納刀剣類の水没など甚大な被害を受け、その後復旧している。
- **[国宝青井阿蘇神社](https://www.city.hitoyoshi.lg.jp/kosodate_kyoiku/kyoiku_bunka/rekishi_bunka/2421063)**（人吉市）
  市による国宝指定の解説ページ。
- **[八代神社（妙見宮）](https://kumamoto.guide/spots/detail/11744)**（熊本県観光サイト「もっと、もーっと！くまもっと。」）
  1186年創建と伝わる妙見信仰の社。日本三大妙見の一つとされる。
- **[八代妙見祭](https://myouken.com/)**（ユネスコ無形文化遺産 八代妙見祭 公式サイト）
  八代神社の神幸行事で、2011年に国重要無形民俗文化財、2016年にユネスコ無形文化遺産「山・鉾・屋台行事」の構成資産に登録。
- **[八代妙見祭がユネスコ無形文化遺産に登録されました！](https://www.pref.kumamoto.jp/site/kennan/8423.html)**（熊本県）
  県による登録決定の告知ページ。
- **[雲巌禅寺](https://www.city.kumamoto.jp/kankyo/kiji00320629/index.html)**（熊本市公式サイト）
  「岩戸観音」の通称で知られ、宮本武蔵が『五輪書』を著したと伝わる霊巌洞、五百羅漢を有する寺院の紹介。
- **[幣立神宮](https://kumamoto.guide/spots/detail/11820)**（熊本県観光サイト「もっと、もーっと！くまもっと。」）
  上益城郡山都町にある古社。専用の公式サイトは確認できず、県観光サイトの解説ページのみ掲載する。
