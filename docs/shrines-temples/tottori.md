# 鳥取県の神社仏閣資料

旧因幡国・伯耆国からなる鳥取県は、三徳山三佛寺投入堂（国宝）や大山寺・大神山神社奥宮など山岳信仰系の社寺文化財に富む。宗教法人の網羅的な名簿は公開を確認できなかったが、県神社庁が824社の由緒を公開し、4館共同の「とっとりデジタルコレクション」が郷土資料の入口になっている。

## 宗教法人名簿

- ※鳥取県知事所轄の宗教法人名簿は公開を確認できず。[宗教法人 - とりネット](https://www.pref.tottori.lg.jp/223837.htm)（鳥取県総務部行政監察・法人指導課）には設立手続・様式集のみ掲載されており、法人一覧のダウンロードは見当たらない

## 神社庁・仏教会

- **[鳥取縣神社廳](https://tottori-jinjacho.jp/)**（神社本庁包括下の鳥取県事務所）
  県内824社の祭神・由緒を紹介する神社検索機能を持つ
- ※鳥取県仏教会（県レベルの組織）の公式サイトは公開を確認できず。鳥取市仏教会（市内約60ヶ寺）等、市町村単位の組織があることは確認できたが公式サイトは未特定

## 文化財データベース

- **[とっとり文化財ナビ](https://db.pref.tottori.jp/bunkazainavi.nsf/index.htm)**（鳥取県）
  県内の指定文化財を市町村別・種別に検索できるデータベース。社寺建造物・彫刻・絵画等も含む
- **[有形文化財 - とりネット](https://www.pref.tottori.lg.jp/82812.htm)**（鳥取県）
  県指定有形文化財の一覧・解説ページ
- **[国指定文化財等データベース](https://kunishitei.bunka.go.jp/)**（文化庁）
  国宝・重要文化財を全国横断で検索可能。三佛寺投入堂、大山寺阿弥陀堂・弥陀三尊、大神山神社奥宮本殿等が該当

## 主要社寺の公式資料

- **[三徳山三佛寺](https://www.mitokusan.jp/)**（三朝町）
  奥院・投入堂（国宝）を擁する天台宗古刹。投入堂は平安後期建立と判明している
- **[大神山神社](https://www.oogamiyama.or.jp/)**（大山町・米子市）
  大山を祀る古社。奥宮本殿・幣殿・拝殿等は重要文化財
- **[大山寺](https://daisenji.jp/)**（天台宗別格本山、大山町）
  重要文化財の阿弥陀堂・木造阿弥陀三尊像を伝える山陰の名刹。明治の神仏分離までは大神山神社奥宮と一体だった
- **[宇倍神社](https://www.ubejinja.or.jp/)**（鳥取市）
  因幡国一宮
- **[白兎神社](https://hakutojinja.jp/)**（鳥取市）
  『古事記』の因幡の白兎神話に由来する神社

## デジタルアーカイブ

- **[とっとりデジタルコレクション](https://digital-collection.pref.tottori.lg.jp/)**（鳥取県立図書館・鳥取県立公文書館・鳥取県立博物館・鳥取県埋蔵文化財センターの4館共同、58万点超）
  郷土資料・古文書・古絵図等を横断検索できるポータル。[詳細検索](https://digital-collection.pref.tottori.lg.jp/search)でキーワード指定が可能だが、検索結果はJavaScript描画のため個別資料のURLはこの調査では確認できず
- **[公文書館 - とりネット](https://www.pref.tottori.lg.jp/kobunsho/)**（鳥取県立公文書館）
  藩政資料（鳥取藩関連文書約1万4700点）等の特定歴史公文書を所蔵
