# 秋田県の神社仏閣資料

旧国名は羽後国（南部の一部は陸中国）。県神社庁管内には約1,110社が登録され、佐竹氏ゆかりの曹洞宗寺院や、中世以来の山岳信仰・修験の遺構（波宇志別神社神楽殿など）が特徴的である。宗教法人名簿はPDF・Excelでオープンデータとして公開されている。

## 宗教法人名簿

- **[秋田県宗教法人名簿（令和7年12月31日現在）](https://www.pref.akita.lg.jp/pages/archive/37668)**（秋田県生活環境部県民生活課）
  PDF・Excel形式で公開。文化庁の定めるオープンデータ利用規約に基づき利用できる。

## 神社庁・仏教会

- **[秋田県神社庁](http://akita-jinjacho.sakura.ne.jp/)**（秋田県神社庁）
  県内13支部・約1,110社の管内神社を紹介。※httpsは証明書エラーのため`http://`でのみアクセス可
- **[秋田の神社検索](https://akita-jinjacho.sakura.ne.jp/shrine_search/)**（秋田県神社庁）
  市町村別・県全域での神社一覧検索機能。
- ※秋田県仏教会・各宗派の県内組織サイトは公開を確認できず。

## 文化財データベース

- **[文化財の指定や登録、文化財一覧など](https://www.pref.akita.lg.jp/pages/genre/15483)**（秋田県）
  国・県指定文化財の制度概要と一覧へのリンク集。
- **[県内の国・県指定文化財等の件数一覧](https://www.pref.akita.lg.jp/pages/archive/21978)**（秋田県）
  種別ごとの件数一覧および指定文化財一覧PDFへのリンクを掲載。神社仏閣建造物の抽出も可能。

## 主要社寺の公式資料

- **[古四王神社本殿（国指定重要文化財）](https://www.city.daisen.lg.jp/docs/2013110600112/)**（大仙市）
  1908年（明治41年）指定、秋田県内最初の文化財指定建造物。折衷様式の本殿を解説。
- **[保呂羽山波宇志別神社神楽殿](https://www.city.yokote.lg.jp/kanko/1004860/1005082.html)**（横手市）
  室町中期建築、1980年国指定重要文化財。東北で唯一とされる両流造りの神楽殿。
- **[天徳寺 本堂 - 文化遺産オンライン](https://online.bunka.go.jp/heritages/detail/145351)**（文化庁）
  佐竹家菩提寺、1687年建立の本堂（重要文化財）。あわせて[総門](https://online.bunka.go.jp/heritages/detail/120964)も指定。
- **[太平山三吉神社](http://www.miyoshi.or.jp/)**（太平山三吉神社）
  太平山講・全国三吉神社の総本宮。奥宮（太平山山頂）と里宮（秋田市広面）を紹介。

## デジタルアーカイブ

- **[秋田県デジタルアーカイブ（ADEAC）](https://adeac.jp/akita-pref/top/)**（秋田県公文書館・秋田県立図書館・あきた文学資料館）
  県内3施設が横断検索できる統合アーカイブ。絵図約800点、県指定文化財を含む「秋田藩家蔵文書」、『佐竹本三十六歌仙絵巻』（複製）等を収録。
- **[秋田県公文書館デジタルアーカイブについて](https://www.pref.akita.lg.jp/pages/archive/86511)**（秋田県公文書館）
  サービス概要と収録点数（約13万8千点）を案内する公式ページ。
