# 岐阜県の神社仏閣資料

旧美濃国・飛騨国からなる岐阜県は、西濃の南宮大社、東濃の虎渓山永保寺（国宝）、西濃山間部の谷汲山華厳寺（西国三十三所結願寺）、飛騨の飛騨国分寺・白川郷の合掌造り寺院など、地域色の異なる社寺が分布する。宗教法人の網羅的な名簿は公開を確認できなかったが、市町村別法人数の統計はPDFで公開されている。

## 宗教法人名簿

- ※岐阜県知事所轄の宗教法人について、法人名・所在地を網羅した名簿（Excel/PDF等）の公開は確認できなかった。
- **[市町村別宗教法人数（令和6年12月31日現在）](https://www.pref.gifu.lg.jp/uploaded/attachment/438230.pdf)**（岐阜県県民生活課）
  神道系・仏教系など宗教別・市町村別の宗教法人「数」の統計PDF。個別法人名の一覧ではない。
- **[宗教法人 - 岐阜県公式ホームページ](https://www.pref.gifu.lg.jp/page/361.html)**（岐阜県県民生活課）
  宗教法人制度の案内ページ。認証手続きや届出様式へのリンクが中心で、法人名簿へのリンクはない。

## 神社庁・仏教会

- **[岐阜県神社庁](https://www.gifu-jinjacho.jp/)**
  岐阜県内の神社を包括する神社本庁被包括法人。
- **[岐阜県仏教会](https://bukkyogifu.net/)**
  県内各市郡仏教会の連合組織。各宗派の紹介ページを掲載。

## 文化財データベース

- **[文化財 - 岐阜県公式ホームページ（文化伝承課）](https://www.pref.gifu.lg.jp/page/13288.html)**
  県指定・国指定文化財の総合案内ページ。文化庁データベースや県域統合型GISへの導線がある。
- **[建造物 - 岐阜県公式ホームページ（文化伝承課）](https://www.pref.gifu.lg.jp/kyoiku/bunka/bunkazai/17768/kenzoubutsu.html)**
  国宝・重要文化財・県指定の建造物を市町村別に一覧化。南宮神社（垂井町）、永保寺開山堂・観音堂（多治見市）等が個別リンク付きで確認できる。
- **[登録有形文化財（建造物） - 岐阜県公式ホームページ（文化伝承課）](https://www.pref.gifu.lg.jp/kyoiku/bunka/bunkazai/17768/index_61057.html)**
  国登録有形文化財建造物の一覧。
- **[岐阜県文化財マップ（県域統合型GIS）](https://gis-gifu.jp/gifu/maps.action?mp=977)**
  地図上で県内の文化財所在地を検索できるWebGIS。
- **[国指定文化財等データベース](https://kunishitei.bunka.go.jp/)**（文化庁）
  全国横断DBだが県内分の検索・絞り込みが可能。
- **[岐阜県・岐阜市 - 文化遺産オンライン](https://online.bunka.go.jp/heritages/region/21/21201)**（国立文化財機構）
  地域から見る文化遺産オンラインの岐阜県分。

## 主要社寺の公式資料

- **[南宮大社](https://nangu-san.com/)**（垂井町）
  美濃国一宮。金山彦命を祀る鉱山・金属業の総本宮。社殿群は重要文化財。
- **[虎渓山 永保寺（公式サイト）](https://kokeizan.or.jp/)**（多治見市）
  臨済宗の古刹。開山堂・観音堂は国宝、庭園は国の名勝に指定。
- **[谷汲山華厳寺](http://www.kegonji.or.jp/)**（揖斐川町）
  ※httpのみ疎通を確認。西国三十三所観音霊場の第三十三番（結願）札所。
- **[醫王山 飛騨国分寺](https://hidakokubunji.jp/)**（高山市）
  奈良時代創建の国分寺。三重塔は県指定重要文化財で飛騨地方唯一の三重塔。
- **[明善寺本堂 - 白川村役場](https://www.vill.shirakawa.lg.jp/1326.htm)**（白川村・白川郷）
  世界遺産・白川郷荻町集落内の合掌造り寺院。本堂は県指定文化財。
- **[明善寺郷土館 - 白川村役場](https://www.vill.shirakawa.lg.jp/1282.htm)**（白川村・白川郷）
  明善寺庫裡（県指定文化財）を活用した郷土資料館の案内。

## デジタルアーカイブ

- **[デジタルアーカイブ - 岐阜県公式ホームページ（歴史資料館）](https://www.pref.gifu.lg.jp/page/379683.html)**
  県歴史資料館所蔵資料の画像・企画展資料を公開。行政文書・陣屋文書（飛騨郡代高山陣屋文書等）の目録も含み、社寺関連文書が含まれる可能性がある。
- **[デジタルコレクション - 岐阜県図書館](https://www.library.pref.gifu.lg.jp/dc/top.html)**
  絵葉書・郷土写真・民俗資料等を公開。社寺専門コレクションではないが郷土資料の一部に含まれる。
