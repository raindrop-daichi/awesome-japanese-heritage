# 関東

関東は常陸・下野・上野・武蔵・下総・上総・安房・相模の八箇国からなる。筑波山・榛名山・妙義山・赤城山などの山岳信仰に発する古社と、鎌倉五山に代表される中世禅宗の集積、そして世界遺産「日光の社寺」のような近世前期の霊廟建築が併存する点に特徴がある。武蔵国一宮の氷川神社・大國魂神社、下総国一宮の香取神宮、上野国一宮の貫前神社など、旧国ごとの一宮が各県に分散して残る。

宗教法人名簿の公開状況は県によって差が大きい。群馬・埼玉・千葉・東京・神奈川はExcelまたはPDFで名簿を公開しているのに対し、茨城・栃木は制度案内ページのみで一括名簿の公開を確認できていない。文化財データベースも県教育委員会単位の整備が中心で、東京都のように本体データベースが接続不可のまま代替ページで運用されている例もある。

## この地方の資料

- **[栃木県](tochigi.html)** — 世界遺産「日光の社寺」（東照宮・輪王寺・二荒山神社）の二社一寺それぞれが充実した公式資料を公開。
- **[神奈川県](kanagawa.html)** — 鎌倉五山の円覚寺・建長寺に加え、称名寺聖教・金沢文庫文書（国宝）のデータベースを整備。
- **[群馬県](gunma.html)** — 榛名神社・妙義神社など山岳信仰の古社が並び、宗教法人名簿もPDFで公開。
- **[埼玉県](saitama.html)** — 国宝・妻沼聖天山歓喜院聖天堂を擁し、宗教法人一覧をExcel・PDF両形式で公開。
- **[千葉県](chiba.html)** — 香取神宮（国宝・海獣葡萄鏡）と成田山新勝寺を筆頭に、宗教法人名簿を市町村別に公開。
- **[東京都](tokyo.html)** — 浅草寺・明治神宮など全国有数の参拝社寺を抱えるが、都の文化財情報データベース本体は接続不可が続く。
