# 鹿児島県の神社仏閣資料

旧薩摩国・大隅国。宗教法人の網羅的な名簿は公開を確認できず、系統別・宗教別の総括表（統計）のみが確認できる。一方で県内寺院は明治初年の廃仏毀釈により一時的にほぼ全廃という全国でも突出した経緯を辿っており、中近世寺院の実態は現存建造物よりも遺跡・石造物として県立埋蔵文化財センターの調査に記録されているケースが多い点が特徴だ。

## 宗教法人名簿

- ※網羅的な宗教法人名簿（個別法人一覧）の公開は確認できず
- **[鹿児島県／宗教法人に関する事務手続き](http://www.pref.kagoshima.jp/ab04/kyoiku-bunka/bunka/syukyo/toukisyoumei.html)**（鹿児島県）
  認証事務のページ内に「鹿児島県の系統別、宗教別宗教法人総括表」（PDF、法人数の統計表）へのリンクがある。個別法人名は含まない。
- **[鹿児島県／宗教法人](https://www.pref.kagoshima.jp/kyoiku-bunka/bunka/syukyo/index.html)**（鹿児島県）
  宗教法人制度に関する県のトップページ。文化庁通知等の参考情報と事務手続き案内へのリンクのみで、名簿そのものは掲載されていない。

## 神社庁・仏教会

- **[鹿児島県神社庁](https://www.kagojinjacho.or.jp/)**（鹿児島県神社庁）
  地域・市町村別に神社が検索できる「[神社を探す](https://www.kagojinjacho.or.jp/search-page/)」機能を持つ。県内神社の所在確認に有用。
- ※鹿児島県仏教会に相当する組織の公式サイトは確認できず

## 文化財データベース

- **[鹿児島県教育委員会／鹿児島県内の文化財一覧](http://www.pref.kagoshima.jp/ba08/kagosimaitiran.html)**（鹿児島県教育委員会）
  種別一覧・市町村別一覧のPDFで県指定文化財を確認できる。神社・寺院建造物は種別一覧内の「建造物」区分に含まれる。
- **[鹿児島県教育委員会／神社・仏閣](http://www.pref.kagoshima.jp/ba08/pr/gaiyou/rekishi/bunka/zinja.html)**（鹿児島県教育委員会）
  県の歴史・文化紹介ページの中で神社仏閣を扱う概説コーナー。
- **[かごしま文化財事典プラス](http://k-bunkazai.com/)**（鹿児島県教育委員会）
  分類・エリア・キーワードから県内文化財を横断検索できる。建造物区分から神社・寺院を絞り込める。
- **[かごしま文化財事典（学校版）](https://k-bunkazai-school.com/)**（鹿児島県教育委員会）
  上記の学校教育向け簡易版。
- **[国指定文化財等データベース](https://kunishitei.bunka.go.jp/bsys/index)**（文化庁）
  都道府県・種別で絞り込み、鹿児島県内の国宝・重要文化財建造物（社寺含む）を検索できる。
- **[鹿児島県立埋蔵文化財センター 埋蔵文化財情報データベース](https://www2.jomon-no-mori.jp/kmai_public/)**（鹿児島県立埋蔵文化財センター）
  発掘調査報告書を検索でき、廃絶寺院跡の調査記録もここに含まれる。

## 主要社寺の公式資料

- **[霧島神宮](https://kirishimajingu.or.jp/)**（霧島神宮）
  本殿・幣殿・拝殿が令和4年（2022）に国宝指定。県内建造物として初の国宝。
- **[霧島神宮 本殿・幣殿・拝殿](https://online.bunka.go.jp/heritages/detail/148831)**（文化遺産オンライン）
  国宝指定に関する解説。正徳5年（1715）島津吉貴による再建の経緯や意匠を紹介。
- **[霧島神宮 勅使殿](https://bunka.nii.ac.jp/heritages/detail/191473)**（文化遺産オンライン）
  国宝附指定の勅使殿に関する解説。
- **[鹿児島神宮](https://kagoshima-jingu.jp/)**（鹿児島神宮）
  正殿・拝殿等が国の重要文化財。大隅国一宮。
- **[照國神社](https://terukunijinja.jp/)**（照國神社）
  島津斉彬を祀る、鹿児島市内最大級の神社。
- **[枚聞神社](https://www.ibusuki.or.jp/tourism/view/hirakikishrine/)**（いぶすき観光ネット）
  薩摩国一宮。※公式サイトは確認できず、指宿市観光協会のページで概要を掲載。

## デジタルアーカイブ

- **[鹿児島県立図書館・奄美図書館 貴重資料（デジタルアーカイブ）](https://www.library.pref.kagoshima.jp/honkan/cat25)**（鹿児島県立図書館）
  古文書・絵図等の貴重資料をデジタル画像で公開。社寺関連史料が含まれる可能性がある。
- **[「廃寺は語る！よみがえる鹿児島の仏教文化」事業に伴う埋蔵文化財発掘調査報告書](https://www.jomon-no-mori.jp/wp-content/uploads/2024/05/H46001-2-0225.pdf)**（鹿児島県立埋蔵文化財センター、2024年3月）
  廃仏毀釈で失われた寺院跡を対象とした発掘調査報告書。石塔・仏像・寺跡の記録として、現存する数少ない一次資料の一つ。
- **[廃仏毀釈](http://www.pref.kagoshima.jp/ab23/pr/gaiyou/rekishi/bakumatu/haibutu.html)**（鹿児島県）
  薩摩藩における廃仏毀釈の経緯を県が概説するページ。藩内寺院がほぼ全廃した経緯に触れている。

### 編纂メモ

- 掲載URLは2026-08-02時点で実在を確認（すべてHTTP 200）
- 宗教法人の個別名簿は公開を確認できず、系統別・宗教別の総括表（統計）のみ確認できた。個別リストが必要な場合は県文化生活局への直接照会が必要
- 廃仏毀釈により中近世寺院の多くが遺跡化しているため、社寺資料としては神社側の資料に厚みがあり、寺院側は埋蔵文化財センターの発掘調査報告書が実質的な一次資料となっている
