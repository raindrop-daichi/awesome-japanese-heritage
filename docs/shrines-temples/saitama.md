# 埼玉県の神社仏閣資料

旧武蔵国北部にあたる。県は宗教法人一覧をExcel・PDFで公開しており、神社庁・仏教会も所在が確認できる。国宝の妻沼聖天山歓喜院聖天堂をはじめ、重要文化財建造物の一次資料も比較的整っている。

## 宗教法人名簿

- **[埼玉県内の宗教法人一覧](https://www.pref.saitama.lg.jp/a0204/shukyo/shukyo-ichiran.html)**（埼玉県総務部学事課）
  知事所轄宗教法人の一覧をExcel・PDFで公開。市町村・宗教別に整理されている。
  - [Excel版（令和7年12月31日現在）](https://www.pref.saitama.lg.jp/documents/2035/r0712syukyouhoujinichiran.xls)
  - [PDF版（同）](https://www.pref.saitama.lg.jp/documents/2035/r0712pdfsyukyouhoujinichiran.pdf)

## 神社庁・仏教会

- **[埼玉県神社庁](https://www.saitama-jinjacho.or.jp/)**（神社本庁 埼玉県事務所）
  県内約2,000社を管轄。[神社検索ページ](https://www.saitama-jinjacho.or.jp/search/)で地域・郡市別に神社を探せる。
- **[埼玉県佛教会（公式サイト）](http://www.saibutu.net/)**（一般財団法人埼玉県佛教会）
  県内寺院教会の連携組織。「行事・催事」欄が2025年12月更新済みで稼働を確認。埼玉県佛教徒大会等の事業を紹介。

## 文化財データベース

- **[埼玉県内の国・県指定等文化財](https://www.pref.saitama.lg.jp/f2216/bunkazai-kensu.html)**（埼玉県教育委員会）
  国宝・重要文化財・県指定文化財の件数・種別を一覧化。建造物区分から社寺関連を絞り込める。
- **[文化財にはこんな種類があります](https://www.pref.saitama.lg.jp/f2216/bunkazai2011.html)**（埼玉県教育委員会）
  文化財区分の解説ページ。個別の指定文化財詳細ページへの入口になる。
- **[彩の国デジタルアーカイブ 文化財検索](https://www.eizou.pref.saitama.lg.jp/library/OnCuf01)**（埼玉県）
  絵画・彫刻・工芸品・書籍古文書・石造物・史跡遺跡などを横断検索できるデータベース。

## 主要社寺の公式資料

- **[武蔵一宮 氷川神社](https://musashiichinomiya-hikawa.or.jp/)**（さいたま市大宮区）
  武蔵国一宮。境内案内・由緒・年中行事を公式サイトで公開。
- **[妻沼聖天山](https://www.ksky.ne.jp/~shouden/)**（歓喜院、熊谷市）
  歓喜院聖天堂は平成24年に国宝指定。装飾彫刻の詳細解説を公式サイトで公開。
- **[川越大師 喜多院](https://kitain.net/)**（川越市）
  五百羅漢や重要文化財の客殿・書院（徳川家光誕生の間等）で知られる天台宗別格本山。
- **[秩父神社](https://www.chichibu-jinja.or.jp/)**（秩父市）
  秩父夜祭で知られる古社。社殿・境内案内を公式サイトで公開。

## デジタルアーカイブ

- **[埼玉県立文書館](https://monjo.spec.ed.jp/)**
  中近世の古文書・地図等を所蔵。資料検索ページから社寺関連文書を検索できる。
- **[埼玉県立図書館デジタルライブラリー](https://www.lib.pref.saitama.jp/collection/saitama/digi-lib/index.html)**
  貴重書・絵図・古写真をデジタル画像で公開。神社・仏教・寺院分類の資料を含む。
