# 福岡県の神社仏閣資料

旧国名は筑前国・筑後国・豊前国（一部）。世界遺産「『神宿る島』宗像・沖ノ島と関連遺産群」を擁し、太宰府天満宮・観世音寺など大宰府政庁跡周辺の古代寺社群、日本三大八幡宮の一つ筥崎宮、修験道の霊山・英彦山神宮など多様な社寺資料が揃う。宗教法人名簿のオンライン公開は確認できなかったが、九州歴史資料館が発掘調査報告書や収蔵品データベースを公開している点が特徴的だ。

## 宗教法人名簿

- ※福岡県の宗教法人名簿は、オンラインでの一般公開を確認できず。所管と見られる私学振興課のページにも宗教法人関連の掲載はなかった。

## 神社庁・仏教会

- **[福岡県神社庁](https://www.fukuoka-jinjacho.or.jp/)**（福岡県神社庁）
  県内約3,300社を包括。福岡・北九州・筑豊・筑後の4エリア別に神社検索ができる。
- ※福岡県仏教会にあたる組織の公式サイトは確認できず。

## 文化財データベース

- **[国指定文化財等データベース](https://kunishitei.bunka.go.jp/)**（文化庁）
  全国の国宝・重要文化財等を横断検索できる。福岡県分の社寺建造物も抽出可能。
- **[文化財保護課](https://www.pref.fukuoka.lg.jp/soshiki/2114107/)**（福岡県教育委員会）
  「福岡県指定文化財目録」の見出しはあるが、目録本体へのダウンロードリンクは掲載されておらず、個別の指定・登録に関するお知らせが並ぶのみ。
- **[「神宿る島」宗像・沖ノ島と関連遺産群 保存活用協議会](https://www.okinoshima-heritage.jp/)**（同協議会、事務局：福岡県文化振興課ほか）
  世界遺産の公式ポータル。[保存管理計画のページ](https://www.okinoshima-heritage.jp/protects/plan)で包括的保存管理計画（2016年版・2022年更新版）、史跡「宗像神社境内」保存管理計画、史跡「津屋崎古墳群」保存管理計画などをPDF・外部リンクで公開する。

## 主要社寺の公式資料

- **[宗像大社](https://munakata-taisha.or.jp/)**
  沖津宮（沖ノ島）・中津宮・辺津宮の三宮からなる。世界遺産「『神宿る島』宗像・沖ノ島と関連遺産群」の中核。境内の神宝館で沖ノ島祭祀遺跡の出土品を含む収蔵品を公開。
- **[太宰府天満宮](https://www.dazaifutenmangu.or.jp/)**
  菅原道真を祀る全国天満宮の総本宮。大宰府政庁跡と一体の古代都市遺構の中心に位置する。
- **[筥崎宮](https://www.hakozakigu.or.jp/)**
  日本三大八幡宮の一つとされる。本殿・拝殿、楼門、一之鳥居等が国指定重要文化財。
- **[観世音寺](https://kanzeonji.com/)**
  天智天皇が母・斉明天皇の冥福を祈り発願したと伝わる古刹。梵鐘は現存最古級の梵鐘として国宝に指定されている。
- **[英彦山神宮](https://hikosanjingu.or.jp/)**
  福岡県唯一の「神宮」号を持つ。日本三大修験道の霊山の一つとされ、国指定重要文化財を有する。

## デジタルアーカイブ

- **[九州歴史資料館](https://kyureki.jp)**（福岡県教育委員会）
  大宰府史跡等の発掘調査を担う研究機関。[調査報告書ダウンロード](https://kyureki.jp/collections_report)で発掘調査報告書のPDFを、[収蔵品データベース](https://jmapps.ne.jp/8116/)で収蔵資料を検索・閲覧できる。
- **[福岡県関連史料データベース](https://kyurekifukuoka.jp)**（九州歴史資料館）
  黒田家文書等、福岡県に関わる歴史史料のデジタル公開データベース。
- **[むなかた電子博物館](https://munahaku.jp/)**（宗像市）
  宗像・沖ノ島関連の歴史・文化財資料をデジタルで紹介する宗像市の電子博物館。
