# 千葉県の神社仏閣資料

旧国名は下総国・上総国・安房国（房総三国）。国宝・海獣葡萄鏡を伝える香取神宮、成田不動の名で知られる成田山新勝寺、日蓮聖人生誕地の誕生寺、安房国一宮の安房神社など、房総各地に古社寺が点在する。宗教法人名簿は市町村別にExcel・PDFで公開されており、都道府県別としては比較的網羅的である。

## 宗教法人名簿

- **[宗教法人名簿](https://www.pref.chiba.lg.jp/gakuji/shuukyou/houjin/houjinmeibo.html)**（千葉県）
  市町村別一覧（令和8年7月1日現在）をExcel・PDF両形式で公開。あ行〜わ行の市町村ごとにページが分かれ、法人名・所在地等が確認できる。

## 神社庁・仏教会

- **[千葉県神社庁](https://www.jinjacho.or.jp/)**（神社本庁）
  県内神社を包括する神社本庁の地方機関。房総三国（安房国6社・上総国16社・下総国19社）の神社紹介ページを含む。
- **[千葉県仏教会](https://www.jbf.ne.jp/member?id=15730)**（全日本仏教会）
  全日本仏教会の加盟団体一覧に掲載された千葉県仏教会の紹介ページ。※独自の公式サイトは公開を確認できず

## 主要社寺の公式資料

- **[香取神宮](https://katori-jingu.or.jp/)**
  下総国一宮。本殿・楼門は元禄期造営の国指定重要文化財、附指定の直刀とは別に国宝・海獣葡萄鏡（唐鏡）を所蔵する。
- **[宝物・文化財｜香取神宮](https://katori-jingu.or.jp/about/treasure/)**
  県指定以上の宝物約200点を紹介するページ。
- **[大本山成田山新勝寺](https://www.naritasan.or.jp/)**
  真言宗智山派の大本山。光明堂・釈迦堂・三重塔・仁王門・額堂の5棟が国指定重要文化財。
- **[境内案内｜大本山成田山新勝寺](https://www.naritasan.or.jp/tour/)**
  境内諸堂の由緒・解説ページ。
- **[大本山小湊誕生寺](http://www.tanjoh-ji.jp/)**
  日蓮宗大本山。日蓮聖人生誕の地に建立と伝わる。
- **[安房神社](http://awajinjya.org/)**
  安房国一宮。延喜式内の名神大社で、旧官幣大社。境内の海食洞窟遺跡は県史跡に指定。

  文書館収蔵の古文書一覧。寺社文書が含まれるかは個別確認が必要。
