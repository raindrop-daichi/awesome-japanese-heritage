# 香川県の神社仏閣資料

旧国名は讃岐国。「こんぴらさん」金刀比羅宮、弘法大師誕生地の善通寺など全国的知名度の高い社寺を擁し、国宝建造物も複数現存する。宗教法人名簿は県が神道系・仏教系などカテゴリ別のPDFで公開しており、県立図書館デジタルライブラリーには「金毘羅」専用カテゴリが設けられている。

  神道系・仏教系・キリスト教系・諸教の4カテゴリに分けたPDF名簿へのリンクを掲載する案内ページ。

## 主要社寺の公式資料

- **[金刀比羅宮](https://www.konpira.or.jp/)**（金刀比羅宮）
  象頭山に鎮座し、「こんぴらさん」の通称で親しまれる古社。近年も本殿域の建造物が国宝に追加指定されている。
- **[総本山善通寺](https://www.zentsuji.com/)**（総本山善通寺）
  弘法大師空海の誕生地とされ、四国八十八箇所霊場第75番札所。金堂・五重塔が国宝。
- **[本山寺](https://motoyamaji.wixsite.com/shippouzan)**（本山寺）
  三豊市にある四国霊場第70番札所。鎌倉時代再建の本堂が国宝、二王門が重要文化財。
- **[国宝　神谷神社](https://www.city.sakaide.lg.jp/soshiki/sangyoukankou/kandanijinjya.html)**（坂出市）
  建保7年（1219年）建立、建立年代が明らかな流造社殿として最古とされる本殿が国宝。神谷神社自体の公式サイトは確認できず、坂出市による解説ページを掲載。
- **[白峯寺](https://www.shiromineji.com/)**（白峯寺）
  四国霊場第81番札所。崇徳天皇の白峯陵に隣接し、9棟の建造物が国指定重要文化財。
