# 徳島県の神社仏閣資料

旧国名は阿波国。四国八十八箇所霊場のうち発願の地とされる第1番霊山寺から第23番薬王寺までの23か寺を擁し、「四国八十八箇所霊場と遍路道」は徳島・高知・愛媛・香川の四国4県共同で世界遺産暫定一覧表入りを目指し推進協議会が活動している。宗教法人名簿の県による公開は確認できず、県神社庁の公式サイトも現時点で疎通が確認できない状態にある。

## 宗教法人名簿

- ※徳島県知事所轄の宗教法人名簿について、県サイト上での公開ページを確認できず。県庁の所管部局への直接照会が必要。

## 神社庁・仏教会

- ※徳島県神社庁（案内上のURLは `http://awa-jinjacho.jp/`）は、DNSの権威サーバーへの到達ができず現時点でアクセス確認ができなかった。名称のみ記載する。
- **[一般社団法人徳島県仏教会](https://tokukenbutsu.com/)**（徳島県仏教会）
  県内市町村・地域の仏教会が加盟する連合組織。2013年に社団法人から一般社団法人へ移行。活動報告・行事案内を掲載。

## 文化財データベース

- **[徳島県の文化財](https://www.pref.tokushima.lg.jp/ippannokata/kyoiku/bunka/7240152/)**（徳島県教育委員会）
  国・県指定文化財一覧（PDF）と、所在地を地図上で確認できる「文化財の所在」を公開。2024年時点で国指定107件・県指定335件、計442件。
- **[全国遺跡報告総覧　徳島県](https://sitereports.nabunken.go.jp/ja/list/36/36/p/22?sort=jtitle)**（奈良文化財研究所）
  県内で刊行された発掘調査報告書をPDFで検索・閲覧できる。社寺境内地の発掘事例も含まれる。
- **[文化遺産オンライン　徳島県](https://bunka.nii.ac.jp/heritages/region/36/36201)**（文化庁）
  国指定文化財を中心に、地域別に社寺建造物・仏像等の解説を横断検索できる。

## 主要社寺の公式資料

- **[四国八十八箇所霊場第1番　竺和山　霊山寺](https://ryozenji.jp/)**（霊山寺）
  四国遍路の「発願の寺」とされる第1番札所。鳴門市に所在。
- **[四国八十八箇所霊場第23番　薬王寺](https://yakuouji.net/)**（薬王寺）
  美波町日和佐に所在し、徳島県内23か寺の締めくくりとなる第23番札所。厄除けの寺として知られる。
- **[大麻比古神社](https://www.ooasahikojinja.jp/)**（大麻比古神社）
  鳴門市大麻町に鎮座する阿波国一宮。
- **[丈六寺](https://www.city.tokushima.tokushima.jp/kankou/keikan/jourokuji.html)**（徳島市）
  三門・本堂・観音堂・経蔵が国指定重要文化財。「阿波の法隆寺」とも通称される。丈六寺自体の公式サイトは確認できず、徳島市による観光・景観案内ページを掲載。
- **[舎心山　太龍寺](https://tairyuji.com/)**（太龍寺）
  阿南市に所在する四国霊場第21番札所。空海が修行したと伝わる霊山で、太龍寺ロープウェイの運営者による公式サイト。
- **[「四国八十八箇所霊場と遍路道」世界遺産登録推進協議会](https://88sekaiisan.org/eightyeight/)**（同協議会）
  徳島・高知・愛媛・香川の4県・58市町村で構成される推進協議会の公式サイト。
- **[世界遺産暫定一覧表記載資産候補提案書](https://88sekaiisan.org/report/pdf/teiansyo_dl.pdf)**（同協議会）
  四国遍路の世界遺産登録に向けた提案書本文（PDF）。
- **[「四国遍路の世界遺産登録に向けた四国4県の取り組み」](https://www.pref.tokushima.lg.jp/ippannokata/kyoiku/bunka/2014010900104/)**（徳島県）
  文化審議会での審査経緯（2008年の暫定一覧表記載見送りとその評価）を含む取り組み経緯を解説。
