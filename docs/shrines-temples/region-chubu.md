# 中部

中部地方は北陸・甲信・東海の三地域からなり、それぞれ性格が異なる。北陸4県（新潟・富山・石川・福井）は真宗の強い定着や白山信仰の拠点を共有し、加賀藩・越前松平家など大名家ゆかりの寺院も多い。甲信2県（山梨・長野）は富士山信仰・諏訪信仰・武田氏ゆかりの社寺に加え、安楽寺八角三重塔や大法寺三重塔など中世神社建築の国宝が集積する。東海3県（岐阜・静岡・愛知）は美濃・尾張・三河・駿河・遠江といった旧国ごとに南宮大社、富士山本宮浅間大社、久能山東照宮、熱田神宮などの一宮・総本社級の社寺が分布する。

宗教法人名簿の公開状況は県ごとに差がある。山梨県・長野県・愛知県は網羅的な名簿をPDFで公開しているのに対し、新潟県・富山県・石川県・福井県・岐阜県はいずれも網羅的な名簿の公開を確認できなかった。静岡県はかつて名簿を公開していた実績があるが、本稿執筆時点では従来の公開URLが404となっている。文化財データベースについては各県とも「文化遺産オンライン」（文化庁）に加え、いしかわ文化財ナビ、とやまの文化遺産、文化財ナビ愛知など独自の検索システムを整備している。

## この地方の資料

- **[新潟県](niigata.html)** — 越後一宮彌彦神社と佐渡島の日蓮宗寺院群。宗教法人名簿の公開は確認できず
- **[富山県](toyama.html)** — 勝興寺・瑞龍寺の国宝2件と、立山信仰の拠点雄山神社
- **[石川県](ishikawa.html)** — 白山信仰総本宮の白山比咩神社。2024年能登半島地震で能登の社寺が被災し、文化財レスキュー事業が進行中
- **[福井県](fukui.html)** — 曹洞宗大本山永平寺と、古刹が密集し「海のある奈良」と呼ばれる若狭地域
- **[山梨県](yamanashi.html)** — 日蓮宗総本山身延山久遠寺。宗教法人名簿をPDFで公開
- **[長野県](nagano.html)** — 善光寺・諏訪大社に加え、安楽寺八角三重塔・大法寺三重塔・仁科神明宮など中世神社建築の国宝が集積
- **[岐阜県](gifu.html)** — 美濃国一宮南宮大社、国宝の永保寺、白川郷の合掌造り寺院
- **[静岡県](shizuoka.html)** — 富士山本宮浅間大社と久能山東照宮。宗教法人名簿は従来の公開URLが404で現行の所在未確認
- **[愛知県](aichi.html)** — 熱田神宮を筆頭に、宗教法人名簿を定期更新公開し文化財ナビ愛知も充実
