# 岡山県の神社仏閣資料

備前・備中・美作の三国からなる岡山県は、吉備津神社・吉備津彦神社をはじめとする吉備氏族ゆかりの古社と、閑谷学校聖廟・誕生寺・宝福寺など特色ある仏教施設・儒教施設が並ぶ。宗教法人名簿の公開は確認できなかったが、神社庁の神社検索と県文化財課の指定文化財一覧は充実している。

## 宗教法人名簿

- ※岡山県の宗教法人名簿（Excel/PDF等の網羅的リスト）は公開を確認できず。県の[宗教法人に係る各種届出等](https://www.pref.okayama.jp/page/635141.html)（総務学事課）ページには役員名簿等の届出様式（Word）が掲載されているのみで、既存法人の一覧データは見当たらない。

## 神社庁・仏教会

- **[岡山県神社庁](https://www.okayama-jinjacho.or.jp/)**（岡山県神社庁）
  県内神社の情報発信元。[全件一覧表示](https://www.okayama-jinjacho.or.jp/search/list/)から所属神社を一覧・検索できる。
- ※岡山県全体を束ねる「岡山県仏教会」の公式サイトは公開を確認できず。宗派単位の組織として[日蓮宗岡山県宗務所](https://okayama-nichiren.com/)が公式サイトを公開している。

## 文化財データベース

- **[岡山県内所在の国・県指定文化財](https://www.pref.okayama.jp/page/550677.html)**（岡山県文化財課）
  国指定252件・県指定514件（掲載時点）を種別ごとに一覧表示。「重要文化財（建造物）」区分から神社・寺院建築を検索できる。
- **[文化財一覧｜おかやまオープンデータカタログ](https://www.okayama-opendata.jp/datasets/4420)**（岡山県／運営：一般社団法人データクレイドル）
  国指定文化財一覧表・登録有形文化財（建造物）一覧・県指定文化財一覧表をCSVで一括ダウンロード可能。

## 主要社寺の公式資料

- **[吉備津神社](https://www.kibitujinja.com/)**（吉備津神社）
  比翼入母屋造（吉備津造）の本殿・拝殿は国宝。[国宝 本殿拝殿の解説ページ](https://www.kibitujinja.com/about/honden.php)で建築の詳細を確認できる。
- **[吉備津彦神社](https://www.kibitsuhiko.or.jp/)**（吉備津彦神社）
  大吉備津日子命を祀り、「朝日の宮」とも称される。吉備津神社と並ぶ吉備中山山麓の古社。
- **[特別史跡 旧閑谷学校](https://shizutani.jp/)**（旧閑谷学校顕彰保存会）
  聖廟（孔子廟）を含む江戸期庶民教育施設。[備前市の特別史跡 旧閑谷学校ページ](https://www.city.bizen.okayama.jp/site/bizen/655.html)にも解説がある。
- **[西大寺（観音院）](https://www.saidaiji.jp/)**（西大寺観音院）
  会陽（はだか祭り）で知られる真言宗寺院。[西大寺会陽奉賛会](https://www.saidaiji-eyou.com/)が祭礼の詳細を公開している。
- **[井山宝福寺](http://www.iyama-hofukuji.jp/)**（井山宝福寺）
  画聖・雪舟が少年期に修行した臨済宗寺院。三重塔は国重要文化財。※`http://`でのみアクセス可（https非対応）。
- **[誕生寺](https://www.tanjoji.or.jp/)**（誕生寺）
  浄土宗開祖・法然上人の生誕地に建つ寺院。御影堂・山門は国重要文化財。[久米南町の誕生寺紹介ページ](https://www.town.kumenan.lg.jp/sightseeing_event/sightseeing/tanjoji.html)も参照。

## デジタルアーカイブ

- **[デジタル岡山大百科](https://adeac.jp/okayama-pref-digioka/top/)**（岡山県立図書館）
  絵図・古地図・和装本等を収録するデジタルアーカイブ。池田家文庫絵図など一部資料は岡山大学附属図書館が管理。神社仏閣関連資料の有無は個別確認が必要。
