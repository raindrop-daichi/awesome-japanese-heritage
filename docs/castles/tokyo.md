# 東京都の城郭資料

東京都（武蔵国南部）は江戸城を筆頭に、後北条氏の重要拠点だった八王子城・滝山城、中世豊島氏・吉良氏ゆかりの石神井城・世田谷城など、都市化の中に埋もれた中世城館が数多く残る。県教委の悉皆調査報告書『東京都の中世城館』（2006年刊）は全国遺跡報告総覧に書誌のみ登録されておりPDF本文は非公開、遺跡地図は「東京都遺跡地図情報インターネット提供サービス」でWeb公開されている。

## 遺跡地図・埋蔵文化財

- **[東京都遺跡地図情報インターネット提供サービス](https://tokyo-iseki.metro.tokyo.lg.jp/)**（東京都）
  都内の周知の埋蔵文化財包蔵地（遺跡）の分布・概要を地図から検索できるWebサービス。開発行為等の際は所在地の区市町村教育委員会への届出が必要な旨も案内。地図データの著作権は東京都に帰属。

## 中世城館調査報告書

- **[『東京都の中世城館』（東京都教育委員会東京都教育庁生涯学習スポーツ部計画課、2006年3月刊、主要城館編）](https://sitereports.nabunken.go.jp/ja/115561)**（全国遺跡報告総覧）
  平成11〜13年度（1999〜2001年度）実施の「中世城館跡の確認及び分布調査」の成果として206ヶ所の城館跡を収録、うち63ヶ所は詳細な縄張り図・復元図付き。※全国遺跡報告総覧上は書誌情報のみで、本文PDFのダウンロードは未公開（2026-08-02時点確認）。国立国会図書館サーチにも書誌あり（請求記号 GC65-J11）。

## 調査研究機関

- **[東京都埋蔵文化財センター](https://www.tomaibun.jp/)**（公益財団法人東京都教育支援機構）
  1980年設立、多摩ニュータウン地区を中心に都内の埋蔵文化財の発掘・調査・保管を担う中核機関。展示施設「縄文の村」を併設。

## 主要城郭の公式資料

- **[特別史跡江戸城跡｜皇居外苑](https://www.env.go.jp/garden/kokyogaien/1_intro/his_01.html)**（環境省）
  昭和35年（1960）指定の特別史跡江戸城跡について、皇居外苑エリアの解説。太田道灌による長禄元年（1457）築城から徳川将軍家の居城に至る沿革を記載。
- **[皇居東御苑](https://www.kunaicho.go.jp/event/higashigyoen/higashigyoen.html)**（宮内庁）
  旧江戸城本丸・二の丸・三の丸の一部を整備した庭園の公式案内。昭和43年（1968）公開開始。
- **[八王子城跡｜八王子市公式ホームページ](https://www.city.hachioji.tokyo.jp/kurashi/kyoiku/005/bunkazaikanrenshisetsu/p005201.html)**（八王子市教育委員会）
  国指定史跡・八王子城跡（1951年指定）の概要案内。北条氏照の居城としての沿革・遺構を解説。
- **[八王子城跡ガイダンス施設](https://www.city.hachioji.tokyo.jp/kankobunka/003/005/p005205.html)**（八王子市教育委員会）
  現地ガイダンス施設の公式案内。北条氏照や落城の経緯を映像・パネルで紹介。入館無料。
- **[滝山城跡｜八王子市公式ホームページ](https://www.city.hachioji.tokyo.jp/kankobunka/001/002/index.html)**（八王子市）
  国指定史跡・滝山城跡（1951年指定）の観光文化課による案内ページ。大石氏の築城から北条氏照による改修・永禄12年（1569）武田信玄侵攻時の攻防を記載。
- **[史跡滝山城跡保存活用計画](https://www.kensetsu.metro.tokyo.lg.jp/content/000067991.pdf)**（東京都建設局）
  都立滝山公園を管理する東京都建設局による保存活用計画のPDF。史跡の社会的環境・保存管理方針を記載した公的計画文書。
- **[東京都指定旧跡 世田谷城跡](https://www.city.setagaya.lg.jp/02059/3481.html)**（世田谷区）
  大正8年（1919）指定の東京都指定旧跡。吉良氏の本拠地としての沿革、豪徳寺前身「弘徳院」境内の発掘調査で確認された空堀・土塁・掘立柱建物等を紹介。
- **[石神井城跡（しゃくじいじょうあと）](https://www.city.nerima.tokyo.jp/kankomoyoshi/annai/rekishiwoshiru/rekishibunkazai/bunkazai/b007.html)**（練馬区）
  豊島氏の居城跡についての区公式解説。昭和31年（1956）以降の発掘調査で12〜16世紀前半の陶磁器が出土したこと、文明9年（1477）太田道灌による落城の経緯を記載。

## デジタルアーカイブ

- **[東京都立図書館デジタルアーカイブ TOKYOアーカイブ](https://archive.library.metro.tokyo.lg.jp/da/top)**（東京都立図書館）
  江戸・東京関連資料のデジタルアーカイブ。重要文化財「江戸城作事関係資料」（甲良家伝来の作事図面）や浮世絵・古地図等を収録。
- **[江戸東京資料案内](https://www.library.metro.tokyo.lg.jp/edo_tokyo/)**（東京都立図書館）
  江戸・東京の歴史資料を探すための都立図書館所蔵資料の案内ページ。城下絵図・古地図の探索起点として利用可。
