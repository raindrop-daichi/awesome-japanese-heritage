# 福岡県の城郭資料

福岡県は筑前国・筑後国と豊前国の一部にあたる。近世城郭の福岡城・小倉城・久留米城に加え、大宰府防衛のために築かれた特別史跡・大野城跡と水城跡という古代山城の代表例を擁するのが最大の特徴だ。大宰府関連の発掘調査は九州歴史資料館が継続的に担っており情報発信が厚い一方、県レベルの遺跡地図・中世城館悉皆調査報告書のオンライン公開状況は編纂時点で確認が難しく、市町村単位の資料に頼る場面が多い。

## 遺跡地図・埋蔵文化財

- **[福岡県ホームページ：文化財保護](https://www.pref.fukuoka.lg.jp/life/5/45/190/)**（福岡県教育委員会文化財保護課）
  県の文化財保護行政の入口ページ。埋蔵文化財包蔵地図・WebGISへの直接リンクは編纂時点（2026-08-02）で確認できず、県レベルのオンライン地図公開は**実在未確認**。個別の照会は同課への問い合わせが必要と見られる。
- **[全国文化財総覧：福岡県 発行報告書一覧](https://sitereports.nabunken.go.jp/ja/list/40/40)**（奈良文化財研究所）
  福岡県・県内市町教委発行の発掘調査報告書一覧。個別城郭・遺跡の発掘報告書を探す実質的な入口として機能する。

## 中世城館調査報告書

福岡県教育委員会による県内一斉の中世城館悉皆調査報告書は、全国文化財総覧上での書誌情報を編纂時点で特定できず、**実在未確認**。市町村単位の発掘調査報告書（下記「主要城郭の公式資料」参照）が実質的な代替資料になる。

- **[久留米城下町遺跡　－第32次発掘調査報告－](https://sitereports.nabunken.go.jp/ja/list/40/40/item/147240)**（久留米市教育委員会、久留米市文化財調査報告書、2026年3月31日）
  久留米城下町遺跡の発掘調査報告。全国文化財総覧に書誌登録されているが、編纂時点で**PDF未公開・書誌情報のみ**（ファイルダウンロード数0件）。

## 調査研究機関

- **[九州歴史資料館](https://kyureki.jp/)**（福岡県）
  大宰府史跡の発掘調査・研究を昭和43年（1968）以来継続する県立機関。[大宰府史跡の紹介ページ](https://kyureki.jp/excavation/dazaifu)で大野城跡・水城跡・基肄城跡等の解説を公開するほか、刊行物販売・研究論考のページも設ける。
- **[北九州市立埋蔵文化財センター](https://www.city.kitakyushu.lg.jp/)**（北九州市）
  小倉城周辺を含む北九州市域の埋蔵文化財調査を担う機関。※施設独自ドメインは編纂時点で疎通確認できず、北九州市公式サイト経由での案内にとどめる。

## 主要城郭の公式資料

- **[国史跡 福岡城・鴻臚館ホームページ](https://fukuokajyo.com)**（福岡城・鴻臚館ホームページ運営事務局）
  黒田氏の居城として築かれた福岡城跡と、その下層に眠る古代の迎賓施設・鴻臚館跡（国史跡）の解説・調査情報をまとめた公式サイト。
- **[福岡市文化財情報検索システム：鴻臚館跡](https://bunkazai.city.fukuoka.lg.jp/cultural_properties/detail/61)**（福岡市）
  福岡市が管理する文化財情報検索システムの個別ページ。指定年月日・所在地・概要等の基礎情報を掲載。
- **[大宰府史跡の紹介（大野城跡・水城跡）](https://kyureki.jp/excavation/dazaifu)**（九州歴史資料館）
  特別史跡・大野城跡（古代山城）と特別史跡・水城跡（延長約1.2kmの土塁）を含む大宰府防衛施設群の解説。令和5年に大宰府跡出土品1,770点が国重要文化財に指定された旨も紹介。
- **[水城跡（太宰府市）](https://www.city.dazaifu.lg.jp/site/kanko/11428.html)**（太宰府市）
  664年築造の水城跡の解説と、東門近くの水城館（無料・多言語展示）の案内。
- **[大土居水城跡（春日市）](https://www.city.kasuga.fukuoka.jp/miryoku/history/historymuseum/1002240/1002246.html)** / **[天神山水城跡（春日市）](https://www.city.kasuga.fukuoka.jp/miryoku/history/historymuseum/1002240/1004236.html)**（春日市）
  水城跡のうち春日市域に含まれる区間の個別解説ページ。
- **[小倉城公式サイト](https://www.kokura-castle.jp/)**（小倉城）
  北九州市のシンボルである小倉城の公式サイト。沿革・見どころ・イベント情報を掲載。
- **[久留米城下町遺跡　－第32次発掘調査報告－](https://sitereports.nabunken.go.jp/ja/list/40/40/item/147240)**（久留米市教育委員会）
  上記「中世城館調査報告書」参照。久留米城周辺の城下町遺構に関する発掘調査報告。
- **[福岡市文化財情報検索システム：立花山城跡](https://bunkazai.city.fukuoka.lg.jp/cultural_properties/detail/489)**（福岡市）
  福岡市東区・新宮町・久山町にまたがる立花山城跡の基礎情報。
- **[新宮navi：立花山城跡](https://shingu-navi.jp/kankou/450/)**（新宮町）
  新宮町側から見た立花山城跡の観光・歴史紹介ページ。
