# 四国

四国は阿波（徳島）・讃岐（香川）・伊予（愛媛）・土佐（高知）の四国に分かれ、各県それぞれの中心城郭（徳島城、高松城・丸亀城、松山城・宇和島城、高知城）が今も残る。現存12天守のうち丸亀城・松山城・宇和島城・高知城の4城を四国が占め、なかでも高知城は天守と本丸御殿がともに現存する全国唯一の城である。中世は三好氏（阿波）、河野氏・加藤嘉明・藤堂高虎（伊予）、長宗我部氏（土佐）といった勢力の居城・山城も各県に残り、一宮城・天霧城・岡豊城など国史跡の山城も少なくない。

資料公開の状況は四県とも似た弱点を抱える。県レベルの中世城館悉皆調査報告書は、徳島（「徳島県の中世城館」）は実在自体がWeb上で確認できず、香川（『香川県中世城館跡詳細分布調査報告』2003）と愛媛（『愛媛県中世城館跡分布調査報告書』1987）は書誌のみでPDF本文が未公開、高知は県一括の報告書自体が未確認である。県全域を対象としたオンライン遺跡地図・WebGISも四県ともに未整備で、徳島は窓口閲覧、香川はPDF配布、愛媛・高知は市町村単位のPDF地図にとどまる。そのなかで高知県は例外的に、市町村単位の城跡悉皆調査（『高知市の城跡』『高知県南国市中世城館跡』）が全国文化財総覧でPDF全文公開されている点が四国の中では際立つ。

## この地方の資料

- **[徳島県](tokushima.html)** — 勝瑞城館跡・一宮城など。城下絵図のデジタルアーカイブが充実する一方、県教委悉皆調査報告書の実在は未確認
- **[香川県](kagawa.html)** — 現存天守の丸亀城と日本三大水城の高松城。県悉皆調査報告書（2003）はあるがPDF未公開
- **[愛媛県](ehime.html)** — 現存天守2つ（松山城・宇和島城）を擁するが、県レベルの遺跡地図・悉皆調査報告書はともに未整備
- **[高知県](kochi.html)** — 天守と本丸御殿がともに現存する全国唯一の高知城。市町村単位の城跡悉皆調査がPDF全文公開されている
