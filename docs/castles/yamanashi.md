# 山梨県の城郭資料

旧国名は甲斐。武田氏の本拠地であり、居館・詰城・後継城が国史跡として複数残る点が特徴だ。中世城館悉皆調査報告書は全国遺跡報告総覧にPDF全巻公開されている一方、県レベルで統合された遺跡地図GISの存在は確認できず、県の文化財データベースが実質的な代替となっている。

## 遺跡地図・埋蔵文化財

- **[山梨の文化財ガイド（史跡データベース）](https://www.pref.yamanashi.jp/bunka/bunkazaihogo/shiseki.html)**（山梨県）
  国指定16件・県指定29件の史跡を一覧化した公式データベース。武田氏館跡・新府城跡・要害山・甲府城跡はいずれもここに掲載されている。
- **[遺跡分布図・一覧表](https://www.city.yamanashi.yamanashi.jp/soshiki/25/1594.html)**（山梨市）
  市内遺跡の分布図（6区域）と一覧表（3地区）をPDFで公開。県域統合GISがない中、市町村レベルで遺跡地図が公開されている例。
  ※県の統合的な埋蔵文化財包蔵地GISは実在未確認。県地理情報システム「まっぷde山梨」（`https://gis.pref.yamanashi.jp/webgis/`）は存在し閲覧可能（自動ツールのUAでは403を返すが、ブラウザ相当のUAでcurl検証したところ200を確認）だが、埋蔵文化財包蔵地レイヤーを含むかは未確認のため掲載を見送った。

## 中世城館調査報告書

- **[山梨県の中世城館跡](https://sitereports.nabunken.go.jp/ja/7018)**（山梨県教育委員会、1986年）
  全国遺跡報告総覧にPDF全巻公開（フル解像度123.9MB、モバイル版35.3MB）。県内中世城館の分布調査報告書。

## 調査研究機関

- **[山梨県埋蔵文化財センター](https://www.pref.yamanashi.jp/maizou-bnk/)**（山梨県）
  発掘調査・出土品展示・刊行物の情報を集約する公式サイト。
- **[刊行報告書一覧](https://www.pref.yamanashi.jp/maizou-bnk/houkokusyo/houkokusyo-ichiran.html)**（山梨県埋蔵文化財センター）
  1984〜2026年に刊行された発掘調査報告書357件を書誌一覧化。「報告書は全国文化財総覧でダウンロード出来ます（未アップロード有り）」と明記されており、全件PDF化済みではない点に注意。
- **[全国遺跡報告総覧内 山梨県埋蔵文化財センター刊行物一覧](https://sitereports.nabunken.go.jp/ja/list/19/19000-a?sort=set)**（奈良文化財研究所）
  上記報告書のうちPDF化済みのものをまとめて検索できる。
- **[広報誌『埋文やまなし』](https://www.pref.yamanashi.jp/maizou-bnk/maibun-yamanashi/ichi-ran.html)**（山梨県埋蔵文化財センター）

## 主要城郭の公式資料

- **[武田氏館跡（躑躅ヶ崎館）](https://www.city.kofu.yamanashi.jp/shingenkou-no-machi/tsutsujigazaki.html)**（甲府市）
  国史跡。信虎・信玄・勝頼三代の本拠地としての解説。
- **[甲府市武田氏館跡歴史館（信玄ミュージアム）](https://www.city.kofu.yamanashi.jp/rekishi_bunkazai/kofu-takedashirekishikan.html)**（甲府市）
- **[史跡武田氏館跡の整備と活用](https://www.city.kofu.yamanashi.jp/bunkashinko/kyoiku/bunka/zai/documents/takedaseibikatuyou.html)**（甲府市教育委員会）
- **[甲府城御案内（舞鶴城公園）](https://www.yamanashi-kankou.jp/history/koufujo/index.html)**（山梨県公式観光サイト内）
  上記文化財データベースでは国史跡（平成31年追加指定を含む）として扱われている。観光サイトだが県公式運営で、沿革・見どころの解説がある。
- **[新府城跡](https://www.city.nirasaki.lg.jp/soshikiichiran/kyoikuka/bunkazaitanto/1_1/3/1344.html)**（韮崎市教育委員会）
  国史跡（昭和48年指定）。平成10〜18年度の発掘調査内容まで詳細に記載。
- **[要害山（要害山城）データベースエントリ](https://www.pref.yamanashi.jp/bunka/maibun/yamanashinobunkazai_sb0008.html)**（山梨県）
  国史跡（平成3年指定）。武田氏館跡の詰城としての位置づけを記載。

## デジタルアーカイブ

- **[山梨デジタルアーカイブ](https://digi.lib.pref.yamanashi.jp/da/top)**（山梨県立図書館）
  近世以降の県内・甲府市全図などの古地図をデジタル公開。城絵図の有無は個別確認が必要。
