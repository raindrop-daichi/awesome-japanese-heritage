# 香川県の城郭資料

香川県（讃岐）は日本三大水城の高松城、現存天守の丸亀城を擁する。県教委の『香川県中世城館跡詳細分布調査報告』（2003）は各所で引用される基本文献だが、**Web上ではPDF公開が確認できていない**。県遺跡地図はPDF配布方式で、統合GISに埋蔵文化財レイヤーがないのが現状の弱点。

## 遺跡地図・埋蔵文化財

- **[香川県遺跡地図](https://www.pref.kagawa.lg.jp/kenkyoui/shogaigakushu/bunkazai/maizouchizu.html)**（香川県教育委員会）
  周知の埋蔵文化財包蔵地・史跡を示す地図を**PDFダウンロード方式**で公開（1/25,000地形図ベース、地域別図番索引）。※法的手続きの根拠にはならず、境界確認は各市町教委へ。無断複製・転載禁止
- ※県の公開型GIS「BRIDGES」には編纂時点で遺跡・埋蔵文化財レイヤーは見当たらない

## 中世城館調査報告書

- **『香川県中世城館跡詳細分布調査報告』（香川県教育委員会、2003）**
  1999〜2001年の調査に基づく悉皆調査報告。全国文化財総覧の個別城館ページで頻繁に出典として引用されているが、**報告書自体のPDF公開は確認できず**。原本は香川県立図書館等で確認のこと。
- **[全国文化財総覧：香川県の報告書一覧](https://sitereports.nabunken.go.jp/ja/list/37)**（奈良文化財研究所）
  香川県教委発行612件を含む県内の発掘調査報告書の入口。

## 調査研究機関

- **[香川県埋蔵文化財センター](https://www.pref.kagawa.lg.jp/maibun/maibun/index.html)**（香川県）
  発掘調査情報・研究紀要・ニュースレター「いにしえの讃岐」等を公開。

## 主要城郭の公式資料

- **[玉藻公園（高松城跡）](https://www.city.takamatsu.kagawa.jp/kurashi/kurashi/shisetsu/park/tamamo/index.html)**（高松市）
  国史跡・日本三大水城。保存活用計画・発掘調査情報・重要文化財建造物（艮櫓・月見櫓・水手御門ほか）の情報。
- **[丸亀城](https://www.city.marugame.lg.jp/site/castle/)**（丸亀市）
  現存天守。石垣解説・CG復元アプリ・石垣修復事業の公式情報ハブ。
- **[引田城跡](https://www.higashikagawa.jp/soshikikarasagasu/shogaigakushuka/gyomuannai/8/hiketa_z/index.html)**（東かがわ市 生涯学習課）
  国史跡（2020年指定）。登城案内・出土瓦・復元イラスト。[全国文化財総覧の遺跡情報](https://sitereports.nabunken.go.jp/ja/cultural-property/205805)も参照。
- **[天霧城跡](https://www.city.zentsuji.kagawa.jp/soshiki/50/digi-m-culture-detail-029-index.html)**（善通寺市デジタルミュージアム）
  国史跡（1990年指定）。善通寺市・多度津町・三豊市にまたがる香川氏の山城。[文化遺産オンラインの台帳情報](https://online.bunka.go.jp/heritages/detail/139617)も参照。
