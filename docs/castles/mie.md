# 三重県の城郭資料

旧国名でいう伊勢・伊賀・志摩・紀伊の一部にあたる。伊賀盆地は忍者伝承と結びついた土豪の城館が密集し、伊勢・志摩は藤堂高虎による近世城郭の改修事例が多い。県全体の遺跡地図はオンライン公開が確認できなかったが、1976年刊行の中世城館悉皆調査報告書は全国遺跡報告総覧でPDFが無料公開されている。

## 遺跡地図・埋蔵文化財

三重県が運営する遺跡地図・埋蔵文化財包蔵地のオンラインGIS・地図配信サービスは確認できなかった（実在未確認）。代わりに三重県埋蔵文化財センターが遺跡を一件ずつ紹介する読み物ページを公開している。

- **[みえの遺跡紹介](https://www.pref.mie.lg.jp/MAIBUN/HP/P0041000419.htm)**（三重県埋蔵文化財センター）
  北勢・中勢・伊賀・南勢・東紀州の5地域に分けて発掘遺跡を紹介する。座標付き地図ではなく個別記事の一覧である点に注意。

## 中世城館調査報告書

- **[三重の中世城館](https://sitereports.nabunken.go.jp/19906)**（三重県埋蔵文化財調査報告30、三重県教育委員会、1976年）
  開発集中地域を対象にした中世城跡分布調査の報告書。全国遺跡報告総覧（奈良文化財研究所）でPDFが公開されている。
  - PDF直リンク: [19906_1_三重の中世城館.pdf](https://sitereports.nabunken.go.jp/files/attach/27/27587/19906_1_%E4%B8%89%E9%87%8D%E3%81%AE%E4%B8%AD%E4%B8%96%E5%9F%8E%E9%A4%A8.pdf)（約18.3MB）
- **[三重の中世城館](https://sitereports.nabunken.go.jp/111060)**（三重県良書出版会、三重県教育委員会編、1977年）
  上記調査を書籍化した一般頒布版。全国遺跡報告総覧には書誌情報のみ登録されており、PDFは公開されていない（書誌情報のみ）。

  発掘調査・資料整理・普及事業を担う県の機関。
- **[刊行物データベース](https://www.pref.mie.lg.jp/MAIBUN/HP/05146001451.htm)** / **[刊行物一覧](https://www.pref.mie.lg.jp/MAIBUN/HP/P0041000173.htm)**（三重県埋蔵文化財センター）

## 主要城郭の公式資料

- **[史跡松坂城跡発掘調査について](https://www.city.matsusaka.mie.jp/site/bunkazai-center/sisekimatsusakajyouhakkututyousa.html)**（松阪市文化財センター）
  国史跡・松坂城跡（松阪市）の発掘調査に関する公式ページ。
- **[指定・登録文化財のご紹介](https://www.city.iga.lg.jp/0000003870.html)**（伊賀市）
  上野城跡（城代屋敷跡）を含む市指定文化財一覧PDFへのリンクを掲載。伊賀上野城そのものの解説ページは未確認。
- **[県指定史跡 津城跡](https://www.info.city.tsu.mie.jp/kosodate_kyouiku/kyouikuiinkai/1004357/1004663/1004603/1004615/1004617.html)**（津市教育委員会）
  津城（津市）の県指定史跡としての解説ページ。
- **[多気北畠氏遺跡の概要](https://www.info.city.tsu.mie.jp/kosodate_kyouiku/kyouikuiinkai/1004357/1004663/1004603/1004655/1008490.html)**（津市教育委員会）
  国史跡・北畠氏館跡（津市美杉町）の概要ページ。発掘調査・出土品・年表等の関連ページも同サイト内にある。
  - 参考: 名勝北畠氏館跡庭園を管理する[津市美杉ふるさと資料館](https://www.info.city.tsu.mie.jp/kosodate_kyouiku/kyouikuiinkai/1004357/1004663/1004603/1004655/1008490.html)が出土品を展示。
- **[田丸城跡](https://kizuna.town.tamaki.mie.jp/tamarujo/index.html)**（玉城町）
  田丸城（玉城町、三重県指定文化財・史跡）の歴史と見どころを紹介する町の公式ページ。
- **[赤木城跡](https://www.city.kumano.lg.jp/tourism/?content=198)**（熊野市）
  国指定史跡・赤木城（熊野市、藤堂高虎が普請奉行を務めたと伝わる）の解説ページ。石垣構造の説明あり。
