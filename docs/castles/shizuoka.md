# 静岡県の城郭資料

旧国名でいえば駿河・遠江・伊豆にまたがる県で、今川・武田・北条・徳川の勢力が国境を接して争った土地柄だ。北条氏の障子堀・畝堀が奇跡的に残る山中城、武田氏築城で徳川氏が改修した諏訪原城など、遺構保存状態の良い国史跡が複数ある一方、県全域の中世城館悉皆調査報告書（1981年刊）はPDF未公開で書誌のみの確認にとどまる。市町村単位では静岡市・三島市が遺跡地図PDFをオープンデータ／無料配布で公開している。

## 遺跡地図・埋蔵文化財

- **[埋蔵文化財包蔵地について](https://www.pref.shizuoka.jp/kankosports/bunkageijutsu/bunkazai/1002115/1020625.html)**（静岡県）
  県内約9,100件の周知の埋蔵文化財包蔵地について解説し、工事60日前の届出義務を案内する。「ふじのくに統合型GIS」への案内があるが、GIS本体（`gis.pref.shizuoka.jp`）は自動アクセスに403を返すため本ページからのリンクに留める。
- **[静岡市遺跡地図](https://opendata.pref.shizuoka.jp/dataset/12430.html)**（静岡県オープンデータカタログ／静岡市）
  遺跡地名表・図郭割当図・詳細図郭1〜25の計27点のPDFをCC BYで公開。
- **[「静岡市遺跡地図」「静岡市遺跡地名表」の無料配布について](https://www.city.shizuoka.lg.jp/s6725/s005196.html)**（静岡市）
  上記データの窓口配布・利用条件を案内する静岡市公式ページ。
- **[三島市遺跡地図（埋蔵文化財包蔵地の位置）](https://www.city.mishima.shizuoka.jp/page/28575.html)**（三島市）
  市内486件の包蔵地を収録した概要図＋詳細図10枚をPDFで公開。工事前の届出義務も明記。
- **[埋蔵文化財の取り扱いについて](https://www.city.hamamatsu.shizuoka.jp/bunkazai/publish/maibuntoriatukai/maibuntoriatukai.html)**（浜松市）
  「浜松市文化財分布図」は地域遺産センターでの有償頒布（1葉2,000円）。県GISへのリンクもあるが「範囲は変更される場合がある」旨の注記付き。

  [全国遺跡報告総覧の書誌情報](https://sitereports.nabunken.go.jp/102370)。※書誌情報のみ・PDF未公開（ダウンロード数0件）。県内中世城館の悉皆調査本編。

## 調査研究機関

- **[静岡県埋蔵文化財センター](https://www.smaibun.jp)**（[概要](https://www.smaibun.jp/about/)）
  1984年設立の埋蔵文化財調査研究会を前身とし2011年発足。国・県の公共工事に伴う発掘調査を担い、県内約9,000遺跡を管理する。館内にデジタルライブラリーがあり紀要・発掘調査報告書等を扱う（オンライン公開範囲は要確認）。

## 主要城郭の公式資料

- **[駿府城公園](https://sumpu-castlepark.com/)**（静岡市）／**[天守台発掘調査](https://www.city.shizuoka.lg.jp/s6725/s005253.html)**（静岡市）
  2016〜2020年の発掘調査と2022年報告書刊行の経緯、多言語パンフレット・シンポジウム資料等のダウンロードあり。天守台展示施設「きゃっしる」は2025年12月26日で閉鎖し新整備に移行中。
- **[掛川城](https://kakegawajo.com/)**（掛川市）
  1994年再建の日本初本格木造復元天守と、現存4棟のみという二条城クラスの城郭御殿（重要文化財）を解説。
- **[山中城跡](https://www.city.mishima.shizuoka.jp/page/2145.html)**（三島市）
  1973年からの発掘調査で確認された障子堀・畝堀の解説、1981年開園の史跡公園としての案内、PDFリーフレット配布あり。
- **[諏訪原城跡](https://www.city.shimada.shizuoka.jp/shimahaku/docs/kuni-01.html)**（島田市博物館）／**[諏訪原城跡ビジターセンター](https://www.city.shimada.shizuoka.jp/institution/list/suwaharavisitor/)**
  1573年武田勝頼築城、1575年徳川方接収後に牧野城と改称された経緯を解説。ビジターセンターで発掘成果・ジオラマを展示、御城印も頒布。
- **[韮山城跡](https://www.city.izunokuni.shizuoka.jp/bunka_bunkazai/manabi/bunkazai/20140925.html)**（伊豆の国市）
  2025年9月に国史跡指定。「韮山城跡百年の計」として発掘調査・保存整備方針をまとめたPDFを複数章立てで公開。現状は龍城山部分のみ公開。

## デジタルアーカイブ

- **[静岡県立中央図書館 デジタルアーカイブ](https://www.tosyokan.pref.shizuoka.jp/contents/library/index.html)**
  葵文庫・久能文庫・浮世絵・その他貴重書の4区分で構成し、絵図・古地図の閲覧カテゴリを持つ。富士山関連資料や県内公共図書館の郷土資料も横断的に扱う。原本閲覧は要事前予約。
