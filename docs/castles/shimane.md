# 島根県の城郭資料

島根県（出雲・石見・隠岐）は国宝天守の松江城、尼子氏の月山富田城を擁する。県教委の『島根県中近世城館跡分布調査報告書』（石見編1997・出雲隠岐編1998）が**全国文化財総覧でPDF公開**されており、悉皆調査に直接アクセスできる県のひとつ。

## 遺跡地図・埋蔵文化財

- **[マップ on しまね（島根県統合型GIS）](https://web-gis.pref.shimane.lg.jp/)**（島根県）
  埋蔵文化財包蔵地レイヤーで約1万ヶ所の周知の包蔵地を閲覧できる。※個人利用以外の複製・商用二次利用は禁止。工事等の際は市町村教委への確認が必要と明記
- **[島根県遺跡データベース](https://iseki.shimane-u.ac.jp/)**（島根大学 地域貢献推進協議会）
  遺跡・遺構・遺物・調査歴・文献の5種検索が可能な学術DB。城館名（例:「富田城」）での文献検索にも使える。

## 中近世城館跡分布調査報告書

- **[『島根県中近世城館跡分布調査報告書 第1集 石見の城館跡』（1997）](https://sitereports.nabunken.go.jp/ja/13446)**（島根県教育委員会、全国文化財総覧で公開）
  石見地域の城館跡の悉皆調査。**PDF全文をダウンロード可能**（2分冊、モバイル軽量版あり）。
- **[『同 第2集 出雲・隠岐の城館跡』（1998）](https://sitereports.nabunken.go.jp/ja/13678)**（同上）
  出雲・隠岐地域編。こちらもPDF公開。
- **[島根県遺跡地図（出雲・隠岐編、1993）](https://sitereports.nabunken.go.jp/ja/69265)**（島根県教育委員会）
  城館跡を含む遺跡の所在確認に使える県遺跡地図の補訂版。

## 調査研究機関

- **[島根県埋蔵文化財調査センター](https://www.pref.shimane.lg.jp/maizobunkazai/)**（島根県教育庁）
  発掘調査だより・現地説明会資料・刊行物を公開する県の調査拠点。

## 主要城郭の公式資料

- **[国宝 松江城（公式サイト）](https://www.matsue-castle.jp/)** / **[松江市 歴史・文化財ページ](https://www.city.matsue.lg.jp/kanko_bunka_sports/rekishi_bunkazai/3/index.html)**（松江市）
  国宝天守。市ページには国宝指定の経緯・大手門復元事業・調査シンポジウム情報など行政側の資料がある。
- **[月山富田城跡（史跡公園の利用）](https://www.city.yasugi.shimane.jp/kurashi/bunka/bunkazai/sisekikouen.html)**（安来市）
  国史跡。尼子氏の本拠だった巨大山城。遺構紹介と見学・撮影許可の案内。
- **[津和野城跡](https://www.town.tsuwano.lg.jp/www/genre/1490242652552/index.html)**（津和野町）
  石見の山城。町の文化財ページ。[県の史跡紹介ページ](https://www.pref.shimane.lg.jp/life/bunka/bunkazai/shiseki/shisekidesu/shiseki19.html)も併せて。
- **[浜田城跡](https://www.city.hamada.shimane.jp/www/contents/1392950863464/index.html)**（浜田市）
  県指定史跡。1619年古田重治築城から廃城までの歴史を解説。

## デジタルアーカイブ

- **[しまねデジタル百科](https://www.library.pref.shimane.lg.jp/local-materials/webmuseum.html)**（島根県立図書館）
  古絵図・古地図192点（234画像）等を公開。**著作権保護期間満了の画像は出典表示を条件に商用・非商用問わず利用可**という明快な条件。
- **[島根県立古代出雲歴史博物館 収蔵品データベース](https://www.izm.ed.jp/db/)**（島根県）
  収蔵品の横断検索。※同館は改修のため2026年10月頃まで休館中とみられる
