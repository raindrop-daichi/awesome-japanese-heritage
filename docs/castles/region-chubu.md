# 中部

中部地方は北陸（新潟・富山・石川・福井）、甲信（山梨・長野）、東海（岐阜・静岡・愛知）の9県からなり、越後・越中・加賀・能登・越前・若狭・甲斐・信濃・美濃・飛騨・駿河・遠江・伊豆・尾張・三河という旧国名の多さが示すとおり、戦国期に多数の勢力が境を接した土地柄だ。上杉謙信（新潟）、武田氏（山梨・長野・静岡）、朝倉氏（福井）、前田家（富山・石川）、織田・徳川氏（愛知・静岡）など各地の戦国大名の本拠・境目の城が中世山城として密集して残り、新潟や長野では山城の密度が全国有数と言われる。一方で名古屋城・松本城・金沢城のような近世大城郭・現存天守も揃い、時代の異なる城郭が同居する地方でもある。

各県教委による中世城館の悉皆調査報告書は、新潟（1987年）・福井（1987年）・長野（1983年）・岐阜（2003・2005年）・静岡（1981年）・愛知（尾張・西三河・東三河・知多の全4冊）とほぼ出そろっているが、山梨県の1986年報告書が全国遺跡報告総覧でPDF全巻公開されている以外は書誌情報のみでPDF未公開にとどまる。石川県に至っては単独の悉皆調査報告書自体が確認できず、学会誌掲載論考が手がかりとなる。遺跡地図・埋蔵文化財包蔵地の公開状況も県ごとに差があり、岐阜・愛知はWebGIS・オープンデータでの公開が進む一方、山梨・長野は県レベルの統合GISが確認できず市町村単位のPDF公開で補う形になっている。

## この地方の資料

- **[新潟県](niigata.html)** — 上杉謙信の本拠・春日山城を含む中世城館密集地帯。悉皆調査報告書（1987年）は国立国会図書館内限定公開にとどまる
- **[石川県](ishikawa.html)** — 単独の悉皆調査報告書は確認できず、金沢城のみ専門の調査研究所が継続的に報告書を刊行
- **[山梨県](yamanashi.html)** — 武田氏関連の国史跡が複数残り、悉皆調査報告書（1986年）が中部地方で唯一PDF全巻公開されている
- **[長野県](nagano.html)** — 山城密度が全国有数と言われ、宮坂武男氏の城郭鳥瞰図アーカイブが周辺県の山城まで横断的にカバー
- **[岐阜県](gifu.html)** — 悉皆調査報告書（2003・2005年）に加え、発掘調査遺跡マップのオープンデータ公開が進む
- **[愛知県](aichi.html)** — 尾張・西三河・東三河・知多の全4冊の悉皆調査報告書がそろうが、いずれもPDF未公開
