# 城郭

日本の城跡は全国3〜4万ヶ所といわれ、その9割以上は統合データベースを持たない中世山城です。ここでは全国横断で使える資料と、都道府県別の遺跡地図・悉皆調査報告書へのリンクを地方区分ごとに整理します。

まずは [全国横断の資料]({{ '/castles/national/' | relative_url }}) から。都道府県別のページはサイドバーの地方名から展開できます。
