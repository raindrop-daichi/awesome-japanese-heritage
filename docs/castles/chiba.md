# 千葉県の城郭資料

千葉県は下総・上総・安房の三国にまたがり、房総半島の丘陵地帯に中世城館が密集する。県のGIS「ちば情報マップ」に「ふさの国文化財ナビゲーション」が統合され埋蔵文化財包蔵地・指定文化財を地図で確認できる一方、県教委の中近世城館調査報告書は書誌情報止まりでPDF未公開のものが目立つ。本佐倉城跡（国史跡）を中心に、佐倉城・大多喜城・久留里城など主要城郭は自治体の公式解説ページが充実している。

## 遺跡地図・埋蔵文化財

- **[ちば情報マップ](https://www.pref.chiba.lg.jp/jousei/chibamap/index.html)**（千葉県）
  2019年に「ふさの国文化財ナビゲーション」を統合した県の統合型GIS。「文化財（ふさの国文化財ナビゲーション）」カテゴリの下に埋蔵文化財包蔵地・指定文化財の2レイヤーがある。検索は種別・遺跡名・住所に限られ、時代や出土遺物では検索できない。
- **[埋蔵文化財包蔵地マップ](https://map.pref.chiba.lg.jp/pref-chiba/PositionSelect?mid=30)**（千葉県、ちば情報マップ内個別レイヤー）
  上記GISの埋蔵文化財包蔵地レイヤーへの直リンク。※権利・境界の確認には県教委または市町村教委への照会が必要と明記されている。

## 中世城館調査報告書

- **[千葉県中近世城跡研究調査報告書](https://sitereports.nabunken.go.jp/ja/55966)**（千葉県教育委員会／編集: 千葉県立関宿城博物館、1998年）
  全国遺跡報告総覧の書誌ページ。書誌情報のみでPDFは未公開（ダウンロード数0）。
- **[佐倉城跡発掘調査報告書](https://sitereports.nabunken.go.jp/ja/56573)**（国立歴史民俗博物館、2004年）
  同上、全国遺跡報告総覧の書誌ページ。書誌情報のみでPDFは未公開。
- **[千葉県教育委員会埋蔵文化財調査報告一覧](https://www.pref.chiba.lg.jp/kyouiku/bunkazai/hakkutsu/reportlist.html)**（千葉県教育委員会）
  第1集〜第61集の発掘調査報告書一覧。各報告書の抄録は全国遺跡報告総覧にリンクするが、報告書本体のPDFは公開されておらず、県内図書館での閲覧案内にとどまる。

## 調査研究機関

- **[千葉県教育委員会（教育庁文化財課）](https://sitereports.nabunken.go.jp/ja/list/12/12000-a)**（全国遺跡報告総覧の刊行機関ページ）
  千葉県教育委員会名義で刊行された報告書の一覧。
- **[千葉県教育振興財団 文化財トップページ](https://www.echiba.org/bunkazai/)**（公益財団法人千葉県教育振興財団）
  旧・千葉県文化財センターの後継組織。県の大規模開発事業に伴う発掘調査を担う。

## 主要城郭の公式資料

- **[本佐倉城跡](https://www.pref.chiba.lg.jp/kyouiku/bunkazai/bunkazai/n411-033.html)**（千葉県教育委員会）
  国史跡指定の概要ページ。千葉氏の本拠として文明年間（1469-1486）に築かれた経緯を紹介。
- **[国史跡本佐倉城跡案内所からのお知らせ](https://www.town.shisui.chiba.jp/docs/2017122100011/)**（酒々井町）
  現地案内所の情報。出土遺物の展示や解説パネルの案内あり。
- **[本佐倉城跡](https://www.city.sakura.lg.jp/soshiki/bunkaka/bunkazai/kunishiseki/motosakurazyouato/5542.html)**（佐倉市文化課）
  ※ページ内に日本城郭協会選定の「続日本100名城」への言及があるが、これは選定団体の呼称であり本サイトの評価ではない。
- **[佐倉市の文化財-史跡(1)「城跡・遺跡・古墳」](https://www.city.sakura.lg.jp/soshiki/bunkaka/bunkazai/sakurabunkazai/genre/3416.html)**（佐倉市文化課）
  佐倉城跡を含む市内史跡の一覧ページ。
- **[大多喜城](https://www.town.otaki.chiba.jp/kanko_iju_bunka/kanko_iju/kanko_jyouho/5/3/index.html)**（大多喜町）
  観光案内を兼ねた公式解説ページ。
- **[大多喜城（県立中央博物館大多喜城分館）](https://www.town.otaki.chiba.jp/kanko_iju_bunka/kanko_iju/kanko_jyouho/5/3/1488.html)**（大多喜町）
  ※2021年12月27日より改修工事のため休館中と明記。
- **[千葉県立中央博物館 大多喜城分館 ご案内](https://www.chiba-muse.or.jp/sonan/info.htm)**（千葉県立中央博物館）
  「房総の城と城下町」をテーマとした展示の紹介。休館中のため現況は要確認。
- **[久留里城址資料館](https://www.city.kimitsu.lg.jp/soshiki/54/)**（君津市）
  上総武田氏築城、里見氏支配を経て江戸期に久留里藩庁となった経緯を紹介。
- **[久留里城・資料館](https://www.city.kimitsu.lg.jp/site/kanko/2189.html)**（君津市）
  資料館の展示概要・アクセス情報。

## デジタルアーカイブ

- **[千葉県内デジタルアーカイブリンク集（自治体名50音順）](https://www.library.pref.chiba.lg.jp/search_chiba/link_d-archives.html)**（千葉県立図書館）
  県内市町村・機関が公開するデジタルアーカイブへのリンク集。城絵図等の所在確認の起点になる。
- **[千葉県文書館収蔵資料検索](https://wwwa7.musetheque.jp/chiba_prefectural_archives/)**（千葉県文書館）
  歴史公文書・古文書・行政資料約100万点を検索可能。城下絵図等は個別検索が必要。
