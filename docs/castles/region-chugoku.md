# 中国

中国地方は因幡・伯耆（鳥取）、出雲・石見・隠岐（島根）、備前・備中・美作（岡山）、安芸・備後（広島）、周防・長門（山口）の旧国からなり、尼子氏（月山富田城）、毛利氏（吉田郡山城）、大内氏（大内氏館・高嶺城）、小早川氏（三原城・新高山城）など戦国期の有力大名の本拠地が集中する。国宝天守の松江城、現存12天守のひとつ備中松山城、古代山城の鬼ノ城など時代の異なる城郭が揃うのも特徴だ。

各県教委の中世城館分布調査報告書は5県すべてで刊行済みだが、PDF公開状況には差がある。岡山県は2020年刊行の報告書（全3冊）を縄張り図付きで全巻公開しており全国的にも先進的、島根県も石見編・出雲隠岐編ともPDF公開されている。一方、鳥取県・広島県・山口県の報告書は編纂時点で書誌情報のみでPDF本文は未公開。遺跡地図・埋蔵文化財包蔵地の公開方法も県ごとに様々で、山口県はGeoJSON形式のオープンデータ（CC BY-NC-ND）、広島県・島根県はWeb地図（営利目的利用不可等の制限あり）、鳥取県・岡山県は統合型GISの一レイヤーとして提供している。

## この地方の資料

- **[鳥取県](tottori.html)** — 中世城館分布調査報告書はPDF未公開だが、4館共同の「とっとりデジタルコレクション」（58万点超）という横断アーカイブが強み
- **[島根県](shimane.html)** — 『島根県中近世城館跡分布調査報告書』（石見編・出雲隠岐編）が全国文化財総覧でPDF公開されている
- **[岡山県](okayama.html)** — 2020年刊行の『岡山県中世城館跡総合調査報告書』（全3冊）を縄張り図付きで全巻PDF公開する資料公開の先進県
- **[広島県](hiroshima.html)** — 中世城館調査報告書はPDF未公開だが、浅野家伝来の城絵図集「諸国古城之図」（177枚）をデジタル公開
- **[山口県](yamaguchi.html)** — 県遺跡地図をGeoJSON/XLSX形式のオープンデータとして公開（CC BY-NC-ND）
