# 長崎県の城郭資料

長崎県は肥前国西部（島原・大村・平戸・松浦地方）と壱岐・対馬の2島からなる。近世城郭では島原城・平戸城・大村城（玖島城）が知られる一方、南島原の原城跡・日野江城跡は「島原・天草一揆」と潜伏キリシタンの歴史を伝える国史跡・世界遺産構成資産として、対馬の金田城跡は663年白村江敗戦後に築かれた古代山城の特別史跡として、それぞれ全国的にも重要な位置を占める。県全域を対象とした「長崎県中近世城館跡分布調査報告書」が全2巻ともPDFで公開されている点は大きな強みだ。

## 遺跡地図・埋蔵文化財

- **[長崎県遺跡地図](https://iseki.news.ed.jp/iseki/controller/iseki.php)**（長崎県教育委員会）
  周知の埋蔵文化財包蔵地をWeb地図で閲覧できる。長崎県埋蔵文化財センター公式サイトのトップメニューから案内されている。
- **[長崎県埋蔵文化財センター 遺跡情報検索](https://jmapps.ne.jp/nagasaki_maibun_iseki/)**（長崎県埋蔵文化財センター、jMuseum/jMapps基盤）
  発掘調査履歴のある遺跡をデータベース形式で検索できる。城館跡単体での検索精度は個別に要確認。
- **[長崎県の文化財データベース](https://www.pref.nagasaki.jp/bunkadb/)**（長崎県教育庁学芸文化課）
  体系別・エリア別・複合条件検索に対応。国・県指定の史跡（原城跡・金田城跡等）を横断的に確認できる。

## 中世城館調査報告書

- **[長崎県中近世城館跡分布調査報告書1（地名表・分布地図編）](https://sitereports.nabunken.go.jp/14453)**（長崎県教育委員会、長崎県文化財調査報告書第206集、2010年3月）
  全国文化財総覧にPDF公開（通常版48.1MB／モバイル版38.6MB）。編著は寺田正剛・川淵雅行。
- **[長崎県中近世城館跡分布調査報告書2（詳説編）](https://sitereports.nabunken.go.jp/14454)**（長崎県教育委員会、2011年3月）
  1の続巻。PDF公開（38.6MB／モバイル版17.4MB）。県内の中近世城館を悉皆的に扱う基礎資料が2巻ともPDFで揃っている。
- **[尾和谷城跡（長崎県埋蔵文化財センター調査報告書第7集）](http://sitereports.nabunken.go.jp/12572)**（長崎県埋蔵文化財センター）
  個別城郭の発掘調査報告の一例。センターの刊行物一覧には原の辻遺跡や年報が多数を占め、城館単体の報告書は限定的。

## 調査研究機関

- **[長崎県埋蔵文化財センター](http://www.nagasaki-maibun.jp/)**（長崎県）
  刊行物一覧（調査報告書・研究紀要・情報誌「南北市糴」）を公開。※httpsは証明書エラーのため `http://` でのみアクセス可。
- **[対馬歴史研究センター](https://tsushima-hrc.jp/)**（長崎県、対馬博物館内）
  対馬島内の歴史資料の調査研究と収蔵資料の一部公開を行う。金田城を含む対馬の史跡研究の窓口。

## 主要城郭の公式資料

- **[島原城](https://shimabarajou.com/)**（島原城公式サイト）
  西望記念館・観光復興記念館を併設する天守復元城。沿革・見どころを紹介。
- **[長崎県指定史跡島原城跡総合調査報告書](https://sitereports.nabunken.go.jp/141841)**（島原市教育委員会、2024年10月）
  5部構成でPDF公開（標準版61.5〜94.9MB、モバイル版2.4〜3.0MB）。近年刊行の総括報告書。
- **[原城跡（構成資産紹介）](https://kirishitan.jp/components/com001)**（世界遺産「長崎と天草地方の潜伏キリシタン関連遺産」公式サイト）
  国史跡・世界遺産構成資産としての価値、1637年島原・天草一揆の主戦場としての経緯を解説。保全状況ページへのリンクあり。
- **[原城跡発掘情報](https://www.city.minamishimabara.lg.jp/kyouiku/kiji0031574/index.html)**（南島原市教育委員会）
  発掘調査の経緯・成果に関する情報ページ。
- **[日野江城跡（国指定文化財）](https://www.city.minamishimabara.lg.jp/kyouiku/kiji0034730/index.html)**（南島原市教育委員会）
  肥前有馬氏代々の居城で鎌倉〜南北朝期の築城と推定。二ノ丸出土の金箔鳥衾瓦、本丸出土の法花（磁器）等を紹介。原城跡以前の有馬氏本拠として位置づけられる。
- **[平戸城の歴史](https://hirado-castle.jp/history/)**（平戸城公式サイト）
  別名亀岡城。山鹿流築城法により1704年着工・1718年完成の経緯を解説。
- **[金田城跡](https://www.city.tsushima.nagasaki.jp/gyousei/soshiki/kyouiku/bunkazaika/bunkazai/shinainobunkazai/1274.html)**（対馬市 文化財課）
  663年の白村江敗戦後、大宰府防衛のため築かれた古代山城で特別史跡。城山（じょうやま）に築かれた石塁・城戸跡を紹介。
