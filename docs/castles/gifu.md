# 岐阜県の城郭資料

岐阜県は美濃・飛騨の旧二国からなり、県内には山城を中心とする城館跡が数多く残る。県教育委員会による『岐阜県中世城館跡総合調査報告書』（2003・2005年）が悉皆調査の柱で、国立国会図書館サーチ経由で書誌を確認できる。可児市の「山城に行こう!」など、市町村が山城を観光資源として活用する取り組みが盛んな点が特徴だ。

## 遺跡地図・埋蔵文化財

- **[岐阜県発掘調査遺跡マップ](https://www.pref.gifu.lg.jp/page/13348.html)**（岐阜県文化財保護センター）
  県内の発掘調査済み遺跡の位置・時代・出土品を表示するインタラクティブマップ。学校区周辺の検索や現在地からの経路案内機能もある。個別遺跡の詳細ページ・全国遺跡報告総覧へのリンクあり。
- **[岐阜県発掘調査遺跡マップ（R5）データセット](https://gifu-opendata.pref.gifu.lg.jp/dataset/c11148-005)**（岐阜県オープンデータカタログ）
  上記マップの元データをオープンデータとして配布。GISでの二次利用が可能。
- **[岐阜県 県域統合型GISぎふ](https://gis-gifu.jp/gifu/Portal)**（公益財団法人 岐阜県建設研究センター）
  行政・地域情報を地図で公開する県域統合GISポータル。文化財レイヤーの有無は個別に要確認。
- **[岐阜県遺跡地図（1990年版）書誌](https://sitereports.nabunken.go.jp/86872)**（全国文化財総覧・岐阜県教育委員会）
  紙媒体の県遺跡地図（改訂版）の書誌情報。現行版は上記オンラインマップに移行済みとみられる。

## 中世城館調査報告書

- **[『岐阜県中世城館跡総合調査報告書』（岐阜県教育委員会、2005年3月）](https://sitereports.nabunken.go.jp/115539)**（全国文化財総覧）
  県内中世城館の悉皆調査報告書。**書誌情報のみ・PDF未公開**（編纂時点でダウンロードファイル0件）。現物は県立図書館等で閲覧のこと。
- **[『岐阜県中世城館跡総合調査報告書』（岐阜県教育委員会、2003年）](https://sitereports.nabunken.go.jp/115537)**（全国文化財総覧）
  上記と同一シリーズの別巻とみられる書誌ページ。**書誌情報のみ・PDF未公開**。
- **[全国文化財総覧：岐阜県教育委員会・岐阜県文化財保護センター 発行報告書一覧](https://sitereports.nabunken.go.jp/ja/list/21/21000)**（奈良文化財研究所）
  県教委発行の発掘調査報告書一覧。個別遺跡のPDF報告書を探す入口。
- **[恵那市 城館跡の分布調査報告書](https://www.city.ena.lg.jp/soshikiichiran/kyoikuiinkai/bunka/2_1/9781.html)**（恵那市教育委員会）
  市内59城館＋新発見6城を対象とした分布調査報告書（2022〜2025年、全3冊）を紹介。市町村単位の悉皆調査例として参考になる。

## 調査研究機関

- **[岐阜県文化財保護センター](https://www.pref.gifu.lg.jp/soshiki/21807/)**（岐阜県）
  県の埋蔵文化財調査・保護を担う中核機関。上記の発掘調査遺跡マップも同センターが運用。
- **[埋蔵文化財調査事務所](https://gikyobun.or.jp/maibun/)**（公益財団法人 岐阜市教育文化振興事業団）
  岐阜市域の記録保存目的の発掘調査、現地説明会・展示等を実施。岐阜城跡の発掘調査にも携わる。
- **[各務原市埋蔵文化財調査センター](https://www.city.kakamigahara.lg.jp/kankobunka/1010039/maibun/index.html)**（各務原市）
  市域の埋蔵文化財調査・資料公開を担う市の機関。近隣自治体の調査体制の一例。

## 主要城郭の公式資料

- **[史跡岐阜城跡山上部発掘調査](https://www.city.gifu.lg.jp/kankoubunka/bunkazai/1005557/1021639/index.html)**（岐阜市 文化財保護・活用課）
  金華山山上の岐阜城跡発掘調査の年次成果ページ。2018〜2025年度の調査報告PDF・動画を公開。信長期の天守台石垣等の発見を報告。
- **[日本遺産・信長居館発掘調査案内所](https://www.city.gifu.lg.jp/kankoubunka/bunkazai/1005557/1005566.html)**（岐阜市 文化財保護・活用課）
  金華山麓の信長居館跡発掘調査の成果を展示する現地案内所。日本遺産「信長公のおもてなし」関連。
- **[岩村城跡・明知城跡（恵那市の城館跡）](https://www.city.ena.lg.jp/soshikiichiran/kyoikuiinkai/bunka/2_1/9781.html)**（恵那市教育委員会）
  県史跡・岩村城跡（標高717m）と明知城跡の概要、発掘調査報告書の刊行状況を紹介。明知城跡は2024年度から国史跡指定を目指す4か年総合調査中。
  - 参考: [岩村城跡調査の概要（PDF）](https://www.city.ena.lg.jp/material/files/group/33/H20-22iwagaiyou.pdf)（2010〜2012年度調査）
- **[苗木城跡](https://www.city.nakatsugawa.lg.jp/museum/t/naegijo_ruins/index.html)**（中津川市 苗木遠山史料館）
  国指定史跡・苗木城跡の解説。巨岩を活かした石垣構造で知られる山城。
- **[国史跡 美濃金山城跡](https://www.city.kani.lg.jp/5580.htm)**（可児市）
  国史跡・美濃金山城跡の紹介。保存活用計画・整備基本計画等の関連文書を案内。
  - 関連: [美濃金山城跡の発掘調査について](https://www.city.kani.lg.jp/3579.htm)（可児市教育委員会、2006年度以降の発掘調査経過）
  - 関連: [「山城に行こう!」ホームページ](https://www.city.kani.lg.jp/11517.htm) / [「山城に行こう!2026」](https://www.city.kani.lg.jp/25045.htm)（可児市・可児市山城連絡協議会）— 美濃金山城・久々利城・今城の3城を軸にした市の山城PR事業。講演会・スタンプラリー等を毎年開催
- **[郡上八幡城](https://hachiman-castle.com)**（一般財団法人 郡上八幡産業振興公社）
  1933年再建の木造模擬天守（現存木造再建城としては日本最古とされる）を運営する公式サイト。歴史解説ページあり。※日本100名城は日本城郭協会の選定物であり、本項では事実としての言及に留める
