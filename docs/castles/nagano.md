# 長野県の城郭資料

信濃国は武田・上杉・徳川ら諸勢力が競った土地柄で、中世山城の密度が全国有数と言われる。1983年刊行の『長野県の中世城館跡：分布調査報告書』が悉皆調査の基礎資料だが、書誌情報のみでPDF未公開。一方で長野県立歴史館が公開する宮坂武男氏の城郭鳥瞰図アーカイブは、県内外の山城を広くカバーする一次資料として貴重だ。

## 遺跡地図・埋蔵文化財

- 県レベルで統合された遺跡地図・埋蔵文化財包蔵地のオンラインGIS/Web地図は確認できなかった（実在未確認）。長野県文化振興課の[埋蔵文化財関係規定・様式](https://www.pref.nagano.lg.jp/bunkashinko/maibun/maibuntop.html)は手続き様式のみで、地図データの公開ページではない。
- **[上田市 埋蔵文化財包蔵地地図（PDF）](https://www.city.ueda.nagano.jp/uploaded/attachment/83294.pdf)**（上田市教育委員会）
  上田・丸子・真田・武石の各地域を色分けした包蔵地地図をまとめたPDF（約71MB）。開発行為の届出案内ページ（[埋蔵文化財の届出について](https://www.city.ueda.nagano.jp/soshiki/shogaku/1552.html)）からリンクされている。市町村単位での公開例として貴重。

## 中世城館調査報告書

- **『長野県の中世城館跡：分布調査報告書』**（長野県教育委員会・長野県文化財保護協会、1983年、[国立国会図書館サーチ書誌情報](https://ndlsearch.ndl.go.jp/search?cs=bib&keyword=%E9%95%B7%E9%87%8E%E7%9C%8C%E3%81%AE%E4%B8%AD%E4%B8%96%E5%9F%8E%E9%A4%A8%E8%B7%A1)）
  ※書誌情報のみ・PDF未公開。全国遺跡報告総覧（[sitereports.nabunken.go.jp](https://sitereports.nabunken.go.jp/ja)）でも全文検索がJS依存で自動確認できず、収録有無は未確認。1983年の復刊版も同一書誌として存在する。

## 調査研究機関

- **[長野県立歴史館](https://www.npmh.net/)**（長野県教育委員会所管）
  収蔵史資料検索（文献史料・絵図・県内歴史雑誌論文）や信濃史料データベースなど複数の検索基盤を運営。次項のデジタルアーカイブも参照。

## 主要城郭の公式資料

- **[松本城](https://www.matsumoto-castle.jp/)**（松本市松本城管理課）
  現存12天守で唯一の国宝天守。天守構造・歴史の解説を公式に掲載。発掘調査報告書等の学術資料への直接リンクは確認できなかった。
- **[上田市立博物館・上田城跡公園](https://museum.umic.jp/hakubutsukan/)**（上田市教育委員会）
  上田城跡公園内にあり、上田城の資料・展示を扱う市立博物館の公式サイト。
- **[高遠城址公園](https://www.inacity.jp/shisetsu/koenshisetsu/takatojoshikoen.html)**（伊那市）
  国史跡・高遠城跡を含む公園の市公式案内ページ。桜まつり特設サイト（[takato-inacity.jp](https://takato-inacity.jp)）も市関連の公式情報源。
- **[小諸城址・懐古園](https://www.kaikoen.jp/)**（一般社団法人小諸市動物園協会 運営）
  国史跡・小諸城跡（懐古園）の公式サイト。「穴城」と称される特異な縄張りの解説を掲載。
- **[松代城跡](https://www.matsushiro-kankou.com/spot/spot-599/)**（信州松代観光協会）
  国指定史跡・松代城跡の解説ページ。武田信玄配下・山本勘助築城伝承や真田氏入封後の変遷を紹介。あわせて長野市松代町の[真田宝物館](https://www.sanadahoumotsukan.com/)は松代藩・松代城関連資料を所蔵する公的施設。

## デジタルアーカイブ

- **[宮坂武男城郭鳥瞰図](https://www.npmh.net/miyasaka/)**（長野県立歴史館）
  城郭研究家・宮坂武男氏が2016年に寄贈した手描き鳥瞰図（縄張り図）のデジタル化アーカイブ。長野県内および山梨・群馬・岐阜・愛知・静岡の周辺県の山城まで、地域・市町村単位で検索可能。※出版物等への転載には館への申請が必要と明記されている。
- **[長野県明治初期の村絵図・地図アーカイブ](https://www.npmh.net/ezu/)**（長野県立歴史館）
  明治初期の村絵図・地図の高精細デジタル画像。城下絵図に類する資料が含まれる可能性がある（個別確認要）。
- **[信濃史料データベース](https://trc-adeac.trc.co.jp/WJ11C0/WJJS02U/2000710100)**（TRC-ADEAC経由、長野県立歴史館提供）
  古代から江戸初期までの信濃関連史料全30巻を収録。
