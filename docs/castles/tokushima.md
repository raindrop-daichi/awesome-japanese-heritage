# 徳島県の城郭資料

徳島県（阿波）は三好氏の勝瑞城館跡、蜂須賀氏の徳島城、県内最大の山城・一宮城を擁する。県遺跡地図はオンラインGIS未公開（窓口閲覧）で、県教委の中世城館悉皆調査報告書もWeb上では実在を確認できていない。城下絵図のデジタルアーカイブが比較的充実。

## 遺跡地図・埋蔵文化財

- **[徳島県遺跡地図について](https://www.pref.tokushima.lg.jp/ippannokata/kyoiku/bunka/2006013000035/)**（徳島県 文化資源活用課）
  周知の埋蔵文化財包蔵地 約3,000ヶ所を記載した「徳島県遺跡地図」（2006年刊）の案内。※オンラインGIS・デジタル地図は未公開で、閲覧は県庁・市町村教委の窓口

## 発掘調査報告書

- **[徳島県立埋蔵文化財総合センター「レキシルとくしま」](https://www.pref.tokushima.lg.jp/rekishiru)**（徳島県）
  埋蔵文化財の総合学習施設。[発掘調査報告書の案内ページ](https://www.pref.tokushima.lg.jp/rekishiru/gallery/houkokusho/)あり。
- **[公益財団法人 徳島県埋蔵文化財センター](https://www.tokushima-maibun.net/)**
  発掘調査・記録作成の実施法人。報告書・研究紀要『真朱』・年報を刊行。
- **県教委による中世城館の悉皆調査報告書** — 「徳島県の中世城館」（2011年頃刊行）への言及が二次的に見られるが、**公開Web上では実在を確認できず**（全国文化財総覧にも未収録）。CiNii・県立図書館OPACでの書誌確認が必要。

## 主要城郭の公式資料

- **[徳島市立徳島城博物館](https://www.city.tokushima.tokushima.jp/johaku/)**（徳島市）
  国史跡・徳島城跡（徳島中央公園内）の公式博物館。江戸期絵図と現代地図を切り替えて歩ける「城下町とくしま歴史さんぽ」を提供。
- **[国指定史跡 勝瑞城館跡](https://syugomati-syouzui.sakuraweb.com/)**（藍住町教育委員会）
  三好氏の居館と推定される国史跡（2001年指定、指定面積約5.9万㎡）。遺跡解説・出版物案内あり。
- **[一宮城跡 国史跡推進事業](https://www.city.tokushima.tokushima.jp/smph/kankou/bunkazai/ichinomiya2018.html)**（徳島市教育委員会）
  県史跡・一宮城跡（1338年築、県内最大規模の山城）の解説と、**現地説明会資料PDF 3点**（2018〜2020年度）を公開。

## デジタルアーカイブ

- **[とくしまデジタルアーカイブ：絵図・地図](https://adeac.jp/tokushima-bunkanomori/top/topg/archive/ezu_chizu.html)**（徳島県立文書館）
  「阿波徳島城下之図」「阿波国渭津城之図（写）」など城郭・城下町絵図を高精細デジタル画像で公開。
