# 埼玉県の城郭資料

旧武蔵国北部にあたる埼玉県は、鎌倉街道沿いの中世城館が密集する地帯だ。国史跡の鉢形城（寄居町）・比企城館跡群（嵐山町ほか）に加え、川越城・忍城など近世城郭の遺構も残る。県の埋蔵文化財包蔵地情報はオンラインGISで公開されているが、1988年の県教委悉皆調査報告書はPDF未公開で書誌情報のみ確認できた。

## 遺跡地図・埋蔵文化財

- **[埼玉県埋蔵文化財情報公開ページ](https://www.pref.saitama.lg.jp/isekimap/saitama_zeniki.html)**（埼玉県教育委員会）
  文化財保護法第95条に基づく埋蔵文化財包蔵地（遺跡地図）をオンラインで公開する公式システム。地図・住所・遺跡名から検索できる。
- **[彩の国デジタルアーカイブ 文化財検索](https://www.eizou.pref.saitama.lg.jp/library/OnCuf01)**（埼玉県）
  出土品・史跡・城絵図などの文化財画像を横断検索できるデジタルアーカイブ。

## 中世城館調査報告書

- **『埼玉の中世城館跡』**（埼玉県立歴史資料館編、埼玉県教育委員会、1988年3月、325頁）
  県教委による中世城館の悉皆調査報告書。[CiNii Books の書誌情報](https://ci.nii.ac.jp/ncid/BN02996958)で所蔵館を確認できるが、PDF公開は未確認（書誌情報のみ・PDF未公開）。巻末に城館跡関係文献一覧・発掘調査関係文献一覧（p318-325）を収録。

## 調査研究機関

- **[埼玉県埋蔵文化財調査事業団](https://www.saimaibun.or.jp/)**
  県内の発掘調査を担う公益財団法人。発掘調査報告書・研究紀要を刊行しており、全国遺跡報告総覧経由でPDF公開されている報告書も多い。
- **[埼玉県立文書館](https://monjo.spec.ed.jp/)**
  中近世の古文書・地図資料を130万点超収蔵。城絵図を含む地図資料は資料検索機能から所蔵確認できる（個別資料のオンライン画像公開は限定的）。

## 主要城郭の公式資料

- **[鉢形城歴史館（寄居町埋蔵文化財センター）](https://www.town.yorii.saitama.jp/site/rekishikan/)**（寄居町）
  国指定史跡・鉢形城跡のガイダンス施設。二の曲輪・三の曲輪等の発掘調査（平成9〜13年度）成果に基づく復元整備の解説がある。
- **[鉢形城跡 文化遺産オンライン](https://online.bunka.go.jp/heritages/detail/204983)**（文化庁）
  1932年国指定の史跡としての基礎情報。
- **[川越城本丸御殿](https://www.city.kawagoe.saitama.jp/museum/honmaru/index.html)**（川越市）
  嘉永元年（1848年）建築で東日本唯一現存の本丸御殿。川越市立博物館が管理。
- **[行田市郷土博物館](https://www.city.gyoda.lg.jp/soshiki/shougaigakusyubu/kyodohakubutsukan/index.html)**（行田市）
  忍城本丸跡に立地し、石田三成の水攻めなど中近世の忍城関連資料を展示。
- **[国指定史跡 杉山城跡](https://www.town.ranzan.saitama.jp/0000003374.html)**（嵐山町）
  平成14年度以降の発掘調査により戦国期の築城年代・短命な廃城が判明した比企城館跡群の一つ。
- **[菅谷館跡](https://www.ranzan-kanko.jp/sugayayakata)** / **[杉山城跡](https://www.ranzan-kanko.jp/sugiyamajou)**（嵐山町観光協会）
  比企城館跡群（菅谷館跡・松山城跡・杉山城跡・小倉城跡、2008年国史跡拡大指定）の観光協会解説ページ。

## デジタルアーカイブ

- **[埼玉県立図書館デジタルライブラリー](https://www.lib.pref.saitama.jp/collection/saitama/digi-lib/index.html)**（埼玉県立図書館）
  県関連の古地図・古文献等をデジタル公開。城絵図の収録有無は個別確認が必要。
