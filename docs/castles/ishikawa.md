# 石川県の城郭資料

旧国名は加賀・能登。加賀藩前田家の居城として近世城郭の頂点に立つ金沢城と、能登畠山氏の山城七尾城、加賀一向一揆最後の砦鳥越城など、性格の異なる城郭が揃う。中世城館の悉皆調査報告書としてまとまった単独刊行物は確認できず、石川考古掲載の論考にとどまる一方、金沢城については専門の調査研究所が継続的に発掘・史料調査報告書を刊行している。

## 遺跡地図・埋蔵文化財

- **[いしかわ文化財ナビ](https://www.bunkazainavi.pref.ishikawa.lg.jp/)**（石川県教育委員会・石川県埋蔵文化財センター）
  地図または名称・キーワードから県内の文化財・遺跡を検索できるWebサービス。埋蔵文化財包蔵地の分布確認にも使える。

## 中世城館調査報告書

- **石川考古175号「石川県中世城館跡調査事業について」**（著者: 芝田悟、石川考古学研究会、1987年）— [全国遺跡報告総覧の書誌情報](https://sitereports.nabunken.go.jp/ja/search-article/item/80249)
  ※書誌情報のみ・PDF未公開。県教委による中世城館の悉皆調査を単独の報告書としてまとめた刊行物は確認できなかった。
- **[「末森城等城館跡群」](https://sitereports.nabunken.go.jp/ja/list/17/17386/item/37976)**（宝達志水町教育委員会、2007年3月）
  ※書誌情報のみ・PDF未公開。全国遺跡報告総覧に登録されているが、ダウンロード可能な報告書ファイルは掲載されていない。

## 調査研究機関

- **[石川県埋蔵文化財センター](https://www.ishikawa-maibun.net/)**（公益財団法人）
  刊行物ページに紀要「[いしかわの遺跡](https://www.ishikawa-maibun.net/publications/magazine/)」と情報誌「[石川県埋蔵文化財情報](https://www.ishikawa-maibun.net/publications/journal/)」のバックナンバーがある。
- **[石川県金沢城調査研究所](https://www.pref.ishikawa.lg.jp/kyoiku/bunkazai/kanazawazyo/)**（石川県）
  金沢城の文献・絵図・遺構・遺物・伝統技術を横断的に調査する専門機関。[発刊情報](https://www.pref.ishikawa.lg.jp/kyoiku/bunkazai/kanazawazyo/hakkan.html)で研究紀要「金沢城研究」等の既刊一覧を公開。
- **[金沢大学埋蔵文化財調査センター](https://maibun.w3.kanazawa-u.ac.jp/)**
  大学構内の埋蔵文化財調査を担う組織。県内考古調査の関連機関として参考になる。

## 主要城郭の公式資料

- **[史跡七尾城跡](https://www.city.nanao.lg.jp/syougai/nanaojoushi.html)**（七尾市）と**[七尾城史資料館](https://www.city.nanao.lg.jp/syougai/shisetsu/08.html)**
  能登畠山氏の本拠。出土遺物や航空レーザー測量図をもとにした調査成果を紹介。
- **[金沢城公園：金沢城の調査研究](https://shiro-niwa.pref.ishikawa.lg.jp/kanazawa-castle/explore/search.php)**（石川県）と**[金沢城デジタル長屋](https://jmapps.ne.jp/kanazawazyo/)**（石川県金沢城調査研究所）
  発掘調査・史料・研究紀要のデータベース。**[金沢城庭園調査報告書](https://www.pref.ishikawa.lg.jp/kyoiku/bunkazai/kanazawazyo/teien.html)**も公開。
- **[史跡鳥越城跡附二曲城跡](https://www.city.hakusan.lg.jp/bunka/bunkazai/1006096/1002278/1002282.html)**と**[鳥越一向一揆歴史館](https://www.city.hakusan.lg.jp/bunka/bunkazai/1006458/1006459/1002377.html)**（白山市）
  昭和52年以降の発掘調査で越前焼の甕や鉄砲玉等が出土。加賀一向一揆最後の拠点としての解説がある。
- **[末森城跡（県指定文化財）](https://www.hodatsushimizu.jp/kanko/kanko/3/4/historic_site/1522.html)**（宝達志水町）
  前田利家と佐々成政が争った末森合戦の舞台。町教委による解説ページ。

## デジタルアーカイブ

- **[SHOSHO デジタルコレクション「金沢図」](https://www.library.pref.ishikawa.lg.jp/shosho/digicolle/curation/DIGICOLLE04)**（石川県立図書館）
  加賀藩作成の城絵図を含む大型絵図資料をデジタル公開。[デジタルコレクション一覧](https://www.library.pref.ishikawa.lg.jp/shosho/digicolle)から他の絵図史料も検索できる。
- **[石川デジタルミュージアムネットワーク](https://idmn.w3.kanazawa-u.ac.jp/)**（金沢大学）
  [末森城跡](https://idmn.w3.kanazawa-u.ac.jp/detail/230)や[七尾城関連資料](https://idmn.w3.kanazawa-u.ac.jp/detail/101)など県内博物館資料を横断検索できる。
