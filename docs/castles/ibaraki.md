# 茨城県の城郭資料

旧常陸国の全域と下総国の一部を占める。中世を通じて佐竹・小田・江戸・大掾氏らが割拠した係争地であり、県内の城館跡は1,000ヶ所を超えるとされる。2023年に県教育委員会が5年がかりの中世城館跡総合調査を完了し、報告書がPDFで全編公開されている点が最大の特徴だ。

## 遺跡地図・埋蔵文化財

- **[いばらきデジタルまっぷ](https://www2.wagmap.jp/ibaraki/PositionSelect?mid=34)**（茨城県）
  埋蔵文化財包蔵地（ポイント／エリア）と国・県・市町村指定史跡をレイヤー表示できるWeb地図。住所・キーワード検索にも対応する。
- **[いばらきの文化財](https://kyoiku.pref.ibaraki.jp/art-and-culture/ibaraki-bunkazai/)**（茨城県教育委員会）
  県内文化財行政の窓口ページ。埋蔵文化財の取扱いや各種調査事業へのリンクが集約されている。

## 中世城館調査報告書

- **[茨城県中世城館跡総合調査事業](https://kyoiku.pref.ibaraki.jp/art-and-culture/research/jokan/)**（茨城県教育委員会）
  2018〜2022年度に実施した悉皆調査の事業ページ。報告書本編・城郭サミット配布資料（県央・県西編／県北編／県南・鹿行編）へのリンクを掲載する。
- **[茨城県の中世城館 -茨城県中世城館跡総合調査報告書-](https://sitereports.nabunken.go.jp/en/131674)**（茨城県教育委員会、2023年3月刊）
  全国遺跡報告総覧に本文・分布図・遺構一覧等14PDF＋Excel4点が実ファイルとして公開されている。県内城館調査の基本資料。
- **[笠間城跡保存整備基礎調査報告書](https://sitereports.nabunken.go.jp/en/51835)**（笠間市教育委員会、2014年3月刊）
  ※書誌情報のみ・PDF未公開（ダウンロード数0件、外部リンクなし）。
- 茨城県遺跡地図（国・県指定史跡・名勝・天然記念物及び埋蔵文化財包蔵地地図、茨城県、1977年）は[全国遺跡報告総覧に登録あり](https://sitereports.nabunken.go.jp/en/86769)だが、こちらも書誌情報のみでPDF未公開。

## 調査研究機関

- **[公益財団法人茨城県教育財団（発掘情報いばらき）](https://www.ibaraki-maibun.org/)**
  1977年度以降651遺跡・481冊の報告書を刊行してきた県の埋蔵文化財調査機関。[報告書一覧](https://www.ibaraki-maibun.org/know/learn/report/)はシリーズ番号・遺跡名・所在地・時代を表形式で掲載するが、各報告書は全国遺跡報告総覧（奈良文化財研究所）への案内のみでPDFの直接ダウンロードはできない。
- **[茨城県立歴史館](https://rekishikan-ibk.jp/)**（水戸市）
  県立の歴史博物館・文書館。展示・資料検索窓口を持つ。

## 主要城郭の公式資料

- **[水戸城跡](https://www.city.mito.lg.jp/site/education/4400.html)** / **[水戸城跡（塁及び濠）](https://www.city.mito.lg.jp/site/education/4401.html)**（水戸市教育委員会）
  国史跡・水戸城跡の概要と保存整備の解説ページ。
- **[埋蔵文化財関連の刊行図書（水戸市）](https://www.city.mito.lg.jp/site/education/5609.html)**（水戸市教育委員会）
  水戸城跡三の丸土塁・堀の復旧工事に伴う調査報告書PDFのほか、市内遺跡の発掘調査報告書を順次PDF化して公開している。
- **[笠間城跡](https://www.city.kasama.lg.jp/page/page000776.html)** / **[笠間城跡保存整備調査事業](https://www.city.kasama.lg.jp/page/page006590.html)**（笠間市教育委員会）
  2011年度開始の保存整備基礎調査の経緯と、2027年度の史跡指定格上げを目指す現況を解説。報告書のとりまとめは2025年度に着手したばかりで、Web公開はまだない。
- **[土浦城址（亀城公園）の名所・史跡紹介](https://www.city.tsuchiura.lg.jp/kanko-bunka-sports/kanko-matsuri-event/kanko/page001098.html)**（土浦市）
  関東地方に現存する唯一の櫓門を含む土浦城跡（亀城公園）の公式解説。
- **[小田城跡歴史ひろば](https://www.city.tsukuba.lg.jp/soshikikarasagasu/kyoikukyokubunkazaika/gyomuannai/1/13150.html)**（つくば市教育委員会）
  国史跡・小田城跡（1935年指定）。1997年開始の発掘調査成果をもとに本丸周辺を復元整備した史跡公園の公式案内所ページ。

## デジタルアーカイブ

- **[水戸市立図書館デジタルアーカイブ 水戸城下絵図](https://adeac.jp/mito-lib/top/topg/joka.html)**（水戸市立図書館）
  1651年から1841年以降まで7点の水戸城下絵図・水藩画図を高精細画像で公開する。
- **[茨城県立図書館 古地図一覧](https://www.lib.pref.ibaraki.jp/guide/shiryou/digital_lib/sonota_syurui_chizu.html)**（茨城県立図書館）
  貴重資料デジタルライブラリのうち古地図類の一覧ページ。
