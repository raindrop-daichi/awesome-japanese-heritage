# 熊本県の城郭資料

旧国名は肥後。近世三城（熊本城・人吉城・八代城）に加え、古代山城の鞠智城を擁し、時代の幅が広いのが特徴だ。県教委刊行の中世城館・遺跡地図の報告書は全国遺跡報告総覧でPDF公開されており、熊本城は2016年熊本地震からの復旧事業に伴う調査報告が年報として継続刊行されている。

## 遺跡地図・埋蔵文化財

- **[熊本県遺跡地図を閲覧する](https://www.pref.kumamoto.jp/soshiki/125/90282.html)**（熊本県教育委員会文化課）
  埋蔵文化財包蔵地の位置・範囲を示すWeb地図への案内ページ。※熊本市域は県の地図に含まれず、熊本市が別途提供する地図を案内している。
- **[熊本県遺跡地図データ（指定文化財地点一部含む）](https://data.bodik.jp/dataset/430005_00020)**（BODIK・熊本県教育委員会文化課）
  周知の埋蔵文化財包蔵地の位置データを点・線・面のGISデータ（CC BY 4.0）としてダウンロード可能。
- **[熊本県遺跡地図](https://sitereports.nabunken.go.jp/86944)**（全国遺跡報告総覧、熊本県教育委員会 1998年刊）
  紙媒体の遺跡分布地図をPDF化したもの。標準版1.7MB・モバイル版1.3MB。

## 中世城館調査報告書

- **[熊本県の中世城跡](https://sitereports.nabunken.go.jp/16331)**（熊本県教育委員会、1978年刊、熊本県文化財調査報告第30集）
  県内中世城郭の分布調査報告書。縄張り図・遺構実測図を収録。PDF公開（約25.6MB）。
- **[文化財調査報告のダウンロード案内](https://www.pref.kumamoto.jp/soshiki/125/377.html)**（熊本県教育委員会文化課）
  県教委刊行の文化財調査報告は全国遺跡報告総覧から無料ダウンロード可能である旨の案内ページ。

## 調査研究機関

- **[熊本県文化財資料室](https://www.pref.kumamoto.jp/soshiki/125/73467.html)**（熊本県教育委員会）
  県内で発掘された埋蔵文化財の保管・展示・研究支援を行う施設。資料の借用・調査申請も受け付ける。
- **[熊本城調査研究センター](https://www.city.kumamoto.jp/dynamic/hpkiji/pub/Detail.aspx?c_id=3&id=5566)**（熊本市）
  熊本地震からの復旧に伴い設置された調査研究部門。発掘調査・古文書調査・修理復旧に関する研究を担う。
- **[熊本城調査研究センター年報 第10号](https://sitereports.nabunken.go.jp/141725)**（熊本城調査研究センター、2024年刊）
  「二の丸御絵図」の変遷等を扱う年報。PDF公開（フル版98.1MB／軽量版11.7MB）。

## 主要城郭の公式資料

- **[【公式】熊本城](https://castle.kumamoto-guide.jp/)**（熊本城総合事務所）
  復旧事業の進捗報告、歴史解説、公開エリア情報を掲載。※自動アクセスに403を返す場合があるため、ブラウザでの閲覧を推奨。
- **[熊本城調査研究センター 刊行物ページ](https://www.city.kumamoto.jp/kiji00361088/index.html)**（熊本市）
  広報誌連載「熊本城復興へ向けて」等の記事一覧。
- **[史跡人吉城跡整備基本計画 第2版](https://www.city.hitoyoshi.lg.jp/shisei/keikaku/2421056)**（人吉市教育委員会文化財課）
  国史跡・人吉城跡の保存活用と整備方針をまとめた計画書。PDF2分冊で公開。
- **[八代城跡群 古麓城跡 麦島城跡 八代城跡（国指定）](https://www.city.yatsushiro.lg.jp/kiji0032035/index.html)**（八代市教育委員会）
  2014年国史跡指定の中世〜近世三城郭群の解説ページ。麦島城跡は1996〜2019年に発掘調査が行われた旨の記載あり（個別報告書へのリンクなし）。
- **[歴史公園鞠智城・温故創生館](https://kofunkan.pref.kumamoto.jp/kikuchijo/)**（熊本県教育委員会）
  古代山城・鞠智城の公式サイト。史跡整備状況、展示館情報を掲載。
- **[鞠智城と古代社会](https://sitereports.nabunken.go.jp/122247)**（熊本県教育委員会、全国遺跡報告総覧）
  鞠智城跡の土器・地域社会・馬生産・水利に関する論考4編を収録した報告書。PDF公開（約6.2MB）。同シリーズの他年度分も全国遺跡報告総覧で複数確認できる。

## デジタルアーカイブ

- **[くまもとデジタルギャラリー](https://www2.library.pref.kumamoto.jp/cat2/cat6)**（熊本県立図書館）
  古文書・絵図等の所蔵資料を電子化して公開するギャラリー。利用方法は[利用案内ページ](https://www2.library.pref.kumamoto.jp/cat1/cat16)を参照。城絵図の収録有無は個別に要確認。
