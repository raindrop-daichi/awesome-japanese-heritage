# 北海道・東北

北海道はかつての蝦夷地で、和人の城郭（松前城・五稜郭・道南十二館）とアイヌの砦「チャシ」が並存する特異な地域である。東北は陸奥・出羽の旧国域に、津軽・南部（青森）、伊達（宮城）、最上・上杉・酒井（山形）、蒲生・保科・葦名（福島）など戦国期以来の在地勢力・近世大名の居城が分立してきた。一方で岩手の志波城・徳丹城、宮城の多賀城、秋田の払田柵のように、古代律令国家が北方の境界に築いた城柵遺構が広く残る点はこの地方に共通する特徴だ。

資料の公開状況は県ごとの差が大きい。県教育委員会による中世城館跡分布調査報告書は、岩手（全7分冊）と山形（置賜・村山・庄内最上の3地域編）が全巻PDF公開、福島もPDF本文公開に至っているのに対し、青森・秋田は書誌情報のみでPDF未公開、宮城に至っては同種のタイトルの単独報告書自体が確認できなかった。遺跡地図・GISについても、北海道・宮城・山形・岩手はWeb GISやオープンデータ形式での公開が進む一方、福島は県レベルの統合GISが見当たらず市町村単位の公開にとどまる。北海道には本州のような県域一括の中世城館悉皆調査報告書がなく、チャシの分布記録は個別の発掘調査報告書として蓄積されている。

## この地方の資料

- **[北海道](hokkaido.html)** — 和人の城郭とアイヌのチャシが並存。埋蔵文化財包蔵地GISはオープンデータ公開されているが、県域一括の中世城館悉皆調査報告書は存在しない
- **[青森県](aomori.html)** — 弘前城・根城・浪岡城など戦国期在地勢力の拠点が現存。遺跡地図はWeb公開だが、中世城館の悉皆調査報告書は書誌情報のみでPDF未公開
- **[岩手県](iwate.html)** — 中世城館跡分布調査報告書が全7分冊PDFで公開されている、東北では資料状況に恵まれた県
- **[宮城県](miyagi.html)** — 遺跡地図・指定文化財のGISデータがオープンデータ公開され進んでいる一方、県中世城館跡分布調査に相当する単独報告書は確認できなかった
- **[秋田県](akita.html)** — 払田柵跡など古代城柵の資料は充実するが、全県版の中世城館悉皆調査報告書『秋田県の中世城館』（1981年）は書誌情報のみでPDF未公開
- **[山形県](yamagata.html)** — 中世城館遺跡調査報告書が置賜・村山・庄内最上の3地域編すべてPDFで全巻公開されている
- **[福島県](fukushima.html)** — 会津・中通り・浜通りの3地域に城郭が分布。県教委の中世城館跡分布調査報告書はPDF公開されているが、県レベルの統合遺跡地図GISは見当たらない
