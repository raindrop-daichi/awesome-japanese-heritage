# 京都府の城郭資料

京都府は山城・丹波・丹後の旧三国にまたがり、府教育委員会が平成21年度からの6箇年計画で約1,300城館の悉皆調査（『京都府中世城館跡調査報告書』全4冊）を実施している。発掘調査体制は府（府埋蔵文化財調査研究センター）と京都市（市埋蔵文化財研究所）の二本立て。

## 遺跡地図・埋蔵文化財

- **[京都府・市町村共同 統合型地図情報システム（GIS）](https://g-kyoto.gis.pref.kyoto.lg.jp/g-kyoto/top/select.asp?dtp=671)**（京都府・市町村共同運営）
  府内約18,000件の周知の埋蔵文化財包蔵地を地図上で検索・確認できる統合GIS。※利用許諾の確認を推奨
- **[京都市地図情報提供サービス](https://kyoto-gis.city.kyoto.lg.jp/kyotocity/)**（京都市 文化財保護課ほか）
  京都市の遺跡地図（旧「京都市遺跡地図提供システム」）はこのサービスに統合された。トップから「マップ一覧」→遺跡地図と辿る。※旧システムへの直リンクは403になるためトップページ経由で

## 中世城館調査報告書

- **[京都府中世城館跡調査（紹介ページ）](https://www.kyoto-be.ne.jp/bunkazai/cms/?page_id=1521)**（京都府教育委員会 文化財保護課）
  丹後・丹波・山城の約1,300城館を悉皆調査した事業の公式ページ。地域別の成果紹介あり。
- **[『京都府中世城館跡調査報告書』第4冊（2015）の書誌ページ](https://sitereports.nabunken.go.jp/ja/107182)**（全国文化財総覧）
  ※編纂時点でPDF本体は未公開の模様（書誌情報のみ）。第1〜3冊も同サイトに登録されている
- **[全国文化財総覧：京都府教育委員会 発行報告書一覧](https://sitereports.nabunken.go.jp/ja/list/26/26000)**（奈良文化財研究所）
  府教委発行の報告書一覧。城館関連の各冊もここから辿れる。

## 調査研究機関

- **[公益財団法人 京都府埋蔵文化財調査研究センター](https://www.kyotofu-maibun.or.jp/)**
  府内の発掘調査の実施主体。「京都府遺跡調査報告書」「京都府埋蔵文化財情報」等を刊行（[刊行物ページ](https://www.kyotofu-maibun.or.jp/data/Publications.html)）。全国文化財総覧上の[同センター発行一覧](https://sitereports.nabunken.go.jp/ja/list/26/26000-a)から数百件規模の報告書PDFに到達できる。
- **[公益財団法人 京都市埋蔵文化財研究所](https://www.kyoto-arc.or.jp/)**
  平安京をはじめとする京都市内の遺跡調査機関。**[発掘調査報告シリーズ一覧](https://www.kyoto-arc.or.jp/news/chousahoukoku.html)は2001年以降の報告1,000件超を本文・図版PDF付きで公開**しており、一次資料源として特に充実。

## 主要城郭の公式資料

- **[元離宮二条城 調査・報告書](https://nijo-jocastle.city.kyoto.lg.jp/introduction/research/research_report/)**（京都市）
  世界遺産・二条城の保存活用計画等の報告書を公開。
- **[『福知山城跡』（福知山市教育委員会、1986）](https://sitereports.nabunken.go.jp/en/53872)**（全国文化財総覧）
  天守閣再建に伴う発掘調査の報告書。
- **[『勝龍寺城発掘調査報告』（長岡京市埋蔵文化財センター、1991）](https://sitereports.nabunken.go.jp/en/30763)**（全国文化財総覧）
  細川藤孝・忠興ゆかりの勝龍寺城の発掘調査報告。
- **周山城・丹波亀山城** — 自治体単独の公式調査報告書は編纂時点で未発見。『京都府中世城館跡調査報告書』（丹波編）に収録されている可能性が高い。

## デジタルアーカイブ

- **[京都府立京都学・歴彩館](https://www.pref.kyoto.jp/rekisaikan/)**（京都府）
  旧・府立総合資料館。古文書・行政文書・古典籍等を所蔵し、[歴史資料アーカイブ検索](https://www.archives.kyoto.jp/websearchpe/)（2025年3月リニューアル）で横断検索できる。城絵図等の副次的な探索先。
