# 新潟県の城郭資料

旧国名は越後・佐渡。上杉謙信の本拠・春日山城を筆頭に、揚北衆の居城が広がる中世城館密集地帯だ。県教委による中世城館の悉皆調査報告書（1987年）は存在するが国立国会図書館内限定公開にとどまり、県の遺跡地図はPDF形式で公開されている。

## 遺跡地図・埋蔵文化財

- **[新潟県の遺跡地図](https://www.pref.niigata.lg.jp/sec/bunka/1356894579804.html)**（新潟県文化課）
  文化財保護法第95条に基づく周知の埋蔵文化財包蔵地の地図をPDFで市町村別に公開している。オンラインGISではなくPDF配布形式。
- **[新潟県の遺跡一覧表](https://www.pref.niigata.lg.jp/sec/bunka/1356895428816.html)**（新潟県文化課）
  上記地図に対応する遺跡台帳一覧。
- **[新潟市域の遺跡分布図](https://www.city.niigata.lg.jp/kanko/bunka/rekishi/maizobunka/isekibunpu.html)**（新潟市）
  新潟市が把握する約700か所の周知の埋蔵文化財包蔵地を市域限定で公開。
- **[文化財総覧WebGIS](https://heritagemap.nabunken.go.jp/main)**（奈良文化財研究所）
  全国横断のGISだが、地域・時代・キーワードで新潟県分を絞り込んで表示できる。

## 中世城館調査報告書

- **新潟県中世城館跡等分布調査報告書**（新潟県教育委員会、1987年3月）
  書誌情報のみ確認。国立国会図書館デジタルコレクションに収録されているが「[NDL Search該当ページ](https://ndlsearch.ndl.go.jp/books/R100000002-I000001875564)」の通り**国立国会図書館内限定公開**（個人向けデジタル化資料送信サービスも国内居住者限定）で、一般公開PDFではない。
- **中部地方の中世城館 1（新潟・福井）**（東洋書林、都道府県別日本の中世城館調査報告書集成第7巻、2001年）
  上記報告書を含む再編集版。オンライン公開の有無は未確認、図書館所蔵確認が必要。
- **[全国遺跡報告総覧 新潟県一覧](https://sitereports.nabunken.go.jp/ja/list/15)**（奈良文化財研究所）
  新潟県関連の発掘調査報告書・分布調査報告書の書誌・PDFを横断検索できる。中世城館個別報告のPDF収録有無は逐次確認が必要。

## 調査研究機関

- **[新潟県埋蔵文化財センター](https://www.maibun.net/)**
  県内遺跡の発掘調査・整理・研究・普及啓発を担う中核機関。
- **[公益財団法人新潟県埋蔵文化財調査事業団](https://www.maibun.net/jigyo/)**
  発掘調査の実施主体。刊行物情報も掲載。
- **[新潟県立歴史博物館](https://nbz.or.jp/)**
  上杉氏関連資料を含む県域の歴史資料を所蔵・展示。

## 主要城郭の公式資料

- **[国指定史跡春日山城跡保存管理計画](https://www.city.joetsu.niigata.jp/soshiki/bunkagyousei/kasugayamazyouatohozonnkannrikeikaku.html)**（上越市文化行政課）
  上杉謙信の居城・春日山城跡（国史跡）の保存管理計画をPDFで公開。
- **[上越市立歴史博物館](https://www.city.joetsu.niigata.jp/site/museum/)**（上越市）
  春日山城・高田城（高田城址公園）を含む上越市域の歴史資料の展示・案内窓口。
- **[新発田城の復元について](https://www.city.shibata.lg.jp/kanko/bunka/shiro/index.html)**（新発田市）
  現存する旧二の丸隅櫓・表門を含む新発田城の復元整備の経緯を紹介。
- **[国指定史跡 村上城跡](https://www.city.murakami.lg.jp/soshiki/80/shiseki-murakami.html)**（村上市）
  村上城跡（国史跡）の概要ページ。
- **[国指定史跡村上城跡（お城山）](https://www.city.murakami.lg.jp/site/kanko/oshiroyama.html)**（村上市）
  観光案内を兼ねた村上城跡の解説ページ。

## デジタルアーカイブ

- **[越後佐渡デジタルライブラリー](https://opac.pref-lib.niigata.niigata.jp/darc/opac/search-detail.do?lang=ja)**（新潟県立図書館・新潟県立文書館）
  上杉謙信以降400年間の新潟県関係歴史資料を横断検索。古地図・城絵図・古文書を含む。
