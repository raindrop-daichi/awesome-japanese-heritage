# 岩手県の城郭資料

岩手県は旧陸中国、および北部の二戸地方は旧陸奥国糠部郡にあたる。中世は南部氏をはじめとする在地領主の城館が県内全域に分布し、古代には志波城・徳丹城など律令国家最北の城柵が置かれた点も特徴だ。県教育委員会による中世城館跡分布調査報告書が全7分冊PDFで公開されている点は資料状況として特筆できる。

## 遺跡地図・埋蔵文化財

- **[いわて遺跡地図](https://maizobunkazai-web.pref.iwate.jp/)**（岩手県）
  県内の埋蔵文化財包蔵地を検索・地図表示できるWebGIS。城館跡も遺跡種別の一つとして収録されている。
- **[いわてデジタルマップ 遺跡地図](https://www.sonicweb-asp.jp/iwate/map?theme=th_155)**（岩手県）
  県の統合型GIS「いわてデジタルマップ」内のレイヤーとして遺跡地図を提供。
- **[埋蔵文化財包蔵地地図](https://www.city.morioka.iwate.jp/kankou/kankou/1037106/rekishi/1009335/1009369/1009371.html)**（盛岡市）
  盛岡市内の埋蔵文化財包蔵地をPDF地図で公開。
- **[岩手県の埋蔵文化財](https://www.pref.iwate.jp/kyouikubunka/bunka/bunkazai/1006815.html)**（岩手県）
  県内埋蔵文化財行政の概要ページ。県内遺跡数（約13,000件超）や関連リンクの起点となる。

## 中世城館調査報告書

- **[岩手県中世城館跡分布調査報告書](https://sitereports.nabunken.go.jp/ja/63039)**（岩手県教育委員会、1986年）
  全国遺跡報告総覧上でPDF全7分冊が公開されている。1980年代の県悉皆調査の成果で、各城館の位置・現況・縄張り概要を収録。

## 調査研究機関

- **[（公財）岩手県文化振興事業団 埋蔵文化財センター](https://www.iwate-maibun.jp/)**
  県内発掘調査の中核機関。発掘調査情報や刊行物を公開。
- **[遺跡マップ](https://www.iwate-maibun.jp/maps)**（岩手県文化振興事業団埋蔵文化財センター）
  同センターが調査を担当した遺跡の位置図。

## 主要城郭の公式資料

- **[史跡盛岡城跡保存整備事業](https://www.city.morioka.iwate.jp/shisei/keikaku/toshikei/1019398/index.html)**（盛岡市）
  国史跡盛岡城跡の保存管理計画・整備基本計画・発掘調査の経緯をまとめたページ。
- **[九戸城跡（日本中世終焉の場）](http://www.edu.city.ninohe.iwate.jp/kakuka/maibun/kunohejoseki/top%20page.html)**（二戸市教育委員会）
  国史跡九戸城跡の歴史と発掘調査成果を紹介。※ `http://` でのみアクセス可（https非対応）。
- **[志波城跡・志波城古代公園](https://www.city.morioka.iwate.jp/kankou/kankou/1037106/rekishi/1009476/index.html)**（盛岡市）
  国史跡志波城跡の概要と、外郭南門・築地塀を復元した古代公園の案内。
- **[古代の史跡（徳丹城跡）](https://www.town.yahaba.iwate.jp/soshiki/kyouiku/manabi/2016020900181/)**（矢巾町）
  志波城の後継として造営された国史跡徳丹城跡の解説ページ。

## デジタルアーカイブ

- **[イーハトーブ岩手 電子図書館 岩手の古絵図](https://www.library.pref.iwate.jp/ihatov/no6/html6/index.html)**（岩手県立図書館）
  盛岡城下内丸屋敷図など、県立図書館所蔵の古絵図をデジタル画像で公開。
- **[デジタルライブラリーいわて](https://www.library.pref.iwate.jp/dli/index.html)**（岩手県立図書館）
  古文書・古記録・古絵図等のデジタルアーカイブのトップページ。
