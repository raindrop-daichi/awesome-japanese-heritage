# 愛知県の城郭資料

愛知県（尾張国・三河国）は名古屋城・岡崎城のような近世大城郭の到達点と、小牧山城のような織田信長初期の実験的築城、そして数百におよぶ中世山城・平城が混在する城郭密集地帯である。県教育委員会による中世城館の悉皆調査報告書は尾張・西三河・東三河・知多の全4冊がそろっているが、**いずれも書誌情報のみでPDF公開は未確認**。一方で県のWebGIS「マップあいち」による文化財位置情報の公開は進んでいる。

## 遺跡地図・埋蔵文化財

- **[マップあいち：愛知県文化財マップ（埋蔵文化財・記念物）](https://maps.pref.aichi.jp/map/view/?mid=20055)**（愛知県）
  愛知県統合型地理情報システム「マップあいち」上のレイヤーで、埋蔵文化財包蔵地・記念物等の位置情報を表示するWebGIS。JavaScriptによる地図描画のため読み込みに時間がかかる場合がある。
- **[文化財ナビ愛知](https://jmapps.ne.jp/aichi_bunkazai/)**（愛知県県民文化局文化部文化芸術課文化財室）
  県内の国・県指定文化財、国登録文化財の概要を紹介するデータベース。「史跡」区分に城跡も含まれるが、城郭単位での抽出は個別確認が必要。
- **[愛知県 文化財（ネットあいち）](https://www.pref.aichi.jp/life/2/13/43/index.html)**（愛知県）
  文化財行政の総合案内ページ。埋蔵文化財センターの活動報告等の入口。

## 調査研究機関

- **[愛知県埋蔵文化財センター](https://maibun.com/)**（公益財団法人愛知県教育・スポーツ振興財団）
  県内発掘調査の中核機関。[刊行物・資料ダウンロードページ](https://maibun.com/DownData/)で発掘調査だより等を公開。
  ※`www.maibun.com`はTLS証明書がホスト名と一致せずアクセス不可。`https://maibun.com/`（wwwなし）でアクセスすること。
- **[全国文化財総覧：愛知県埋蔵文化財センター 発行報告書一覧](https://sitereports.nabunken.go.jp/ja/list/23/23000)**（奈良文化財研究所）
  同センター発行の発掘調査報告書一覧。個別城郭の発掘報告書を探す入口。

## 主要城郭の公式資料

- **[名古屋城公式サイト](https://www.nagoyajo.city.nagoya.jp/)**（名古屋市）
  特別史跡の概要は[史跡の紹介ページ](https://www.nagoyajo.city.nagoya.jp/learn/outline/)、2018年完成の本丸御殿復元は[本丸御殿ページ](https://www.nagoyajo.city.nagoya.jp/guide/honmarugoten/)、調査研究成果は[刊行物ページ](https://www.nagoyajo.city.nagoya.jp/center/publication/)を参照。
- **[犬山城公式サイト](https://inuyama-castle.jp/)**（犬山城白帝文庫）
  現存12天守のうち国宝指定4城の一つで、現存最古とされる天守を持つ。歴史・調査系の特集記事も掲載。
- **[岡崎城（岡崎公園）](https://okazaki-kanko.jp/point/2)**（岡崎市）
  徳川家康生誕の城として観光案内ページで紹介。
- **[長篠城址史跡保存館](https://www.city.shinshiro.lg.jp/mokuteki/shisetu/shiryokan/nagashinojyoshi/index.html)**（新城市）
  国指定史跡「長篠城跡」に立地する保存館。長篠の戦いの舞台。
- **[小牧山城・小牧山歴史館](https://www.city.komaki.aichi.jp/admin/soshiki/kyoiku/bunkazai/1_1/2/bunkazai/rekishikan/9156.html)**（小牧市）
  織田信長が最初に築いた城とされる。[史跡小牧山案内図](https://www.city.komaki.aichi.jp/admin/soshiki/kyoiku/bunkazai/1_1/2/bunkazai/9165.html)、2026年8月開館の[こまき歴史発見館](https://www.city.komaki.aichi.jp/admin/soshiki/kyoiku/bunkazai/52305.html)も参照。
