# 愛媛県の城郭資料

愛媛県（伊予）は現存天守を2つ（松山城・宇和島城）擁する城郭県。県教委の『愛媛県中世城館跡分布調査報告書』（1987）は書誌のみでPDF未公開、県レベルの遺跡地図GISも未整備で、市町村のPDF地図と埋蔵文化財センターの報告書が主な情報源になる。

## 遺跡地図・埋蔵文化財

- **[松山市 埋蔵文化財包蔵地図及び一覧表](https://www.city.matsuyama.ehime.jp/kurashi/kurashi/jutaku/tatemono/maibun/m_houzouchi_ichiran.html)**（松山市 文化財課）
  松山地区の包蔵地PDF地図10枚と234件の遺跡一覧表（種別・時代付き）を公開。
- ※県全域を対象とするWebGIS・オンライン遺跡地図は編纂時点で未確認。『愛媛県埋蔵文化財包蔵地分布図』（2000）は[全国文化財総覧に書誌のみ登録](https://sitereports.nabunken.go.jp/en/86802)（本文なし）

## 中世城館調査報告書

- **[『愛媛県中世城館跡分布調査報告書』（愛媛県教育委員会、1987）](https://sitereports.nabunken.go.jp/ja/100276)**（全国文化財総覧の書誌ページ）
  ※書誌情報のみで**PDF本文は未公開**。原本は国立国会図書館・県立図書館等で確認のこと

## 調査研究機関

- **[公益財団法人 愛媛県埋蔵文化財センター](http://www.ehime-maibun.or.jp/)**
  県内の発掘調査の実施主体。※サーバー証明書の都合で `http://` でのリンク
- **[全国文化財総覧：愛媛県埋蔵文化財センター 刊行物一覧](https://sitereports.nabunken.go.jp/ja/list/38/38000-a)**（奈良文化財研究所）
  発掘調査報告書・紀要（「紀要愛媛」「愛比売」等）の1986年以降の一覧。

## 主要城郭の公式資料

- **[松山城（えひめの文化財）](https://www.pref.ehime.jp/ehimenotakara/08.html)**（愛媛県）
  現存天守（重要文化財）。加藤嘉明による1602年築城開始からの沿革。
- **[湯築城跡](https://www.city.matsuyama.ehime.jp/kanko/kankoguide/rekishibunka/bunkazai/kuni/yudukijou_ato.html)**（松山市）
  国史跡（2002年指定）。伊予守護・河野氏の居城。道後公園内に復元武家屋敷・資料館あり。
- **[今治城](https://www.city.imabari.ehime.jp/museum/imabarijo/about/)**（今治市 文化振興課）
  藤堂高虎が1602年に築いた海城。現存の石垣・堀と復元天守群。
- **[宇和島城](https://www.city.uwajima.ehime.jp/site/sizen-bunka/100uwajimajo.html)**（宇和島市）
  国史跡（1937年指定）・現存天守。藤堂高虎築城、のち伊達家の居城。
- **[大洲城公式ウェブサイト](https://ozucastle.jp/)**（指定管理者: キタ・マネジメント）
  2004年に木造復元された天守。※市直営ではなく指定管理法人の運営で、観光情報が中心
