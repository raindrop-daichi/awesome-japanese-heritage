# 関東

旧武蔵・相模・上野・下野・上総・下総・安房の七国にまたがり、後北条氏（小田原北条氏）の勢力圏を中心に上杉・武田・真田氏らが競った激戦地である。江戸城・小田原城のような近世に至る大規模城郭から、鎌倉街道沿いに密集する中世山城・平城まで、規模と類型に富む城館が各県に分布する。

資料公開の状況は県によって差が大きい。茨城県・群馬県は県教育委員会の中世城館悉皆調査報告書が全国遺跡報告総覧でPDF全文公開されており良好だが、栃木県・埼玉県・千葉県・東京都は埋蔵文化財包蔵地の遺跡地図こそWebGISで公開しているものの、悉皆調査報告書自体は書誌情報のみでPDF未公開にとどまる。神奈川県に至っては県レベルで統一された遺跡地図・悉皆調査報告書の存在自体を確認できておらず、横浜市・相模原市など基礎自治体単位の公開が中心である。

## この地方の資料

- **[茨城県](ibaraki.html)** — 2023年完了の中世城館跡総合調査報告書がPDF全編公開されている
- **[栃木県](tochigi.html)** — 1982年の悉皆調査はPDF未公開だが、1963・1968年の遺跡目録はPDF全文公開されている
- **[群馬県](gunma.html)** — 『群馬県の中世城館跡』（1989年）が全9分冊PDF公開、遺跡地図もマッピングぐんまでWeb公開されている
- **[埼玉県](saitama.html)** — 埋蔵文化財包蔵地はWebGISで公開されているが、1988年の悉皆調査報告書はPDF未公開
- **[千葉県](chiba.html)** — 「ちば情報マップ」に遺跡地図を統合しているが、中近世城館調査報告書はPDF未公開
- **[東京都](tokyo.html)** — 遺跡地図はWebサービスで公開されているが、『東京都の中世城館』（2006年）はPDF未公開
- **[神奈川県](kanagawa.html)** — 県レベルで統一された遺跡地図・悉皆調査報告書の存在を確認できず、市単位の公開が中心
