# 秋田県の城郭資料

秋田県（出羽国北部、羽後国）は、安東氏（安藤氏）・秋田氏・小野寺氏・戸沢氏ら在地勢力の山城に加え、古代律令国家の城柵遺構（払田柵跡）まで幅広い時代の城郭資料が残る。県遺跡地図はWeb版GISが公開されているが、全県版の中世城館悉皆調査報告書『秋田県の中世城館』（1981年）は書誌情報のみでPDF未公開。一方、脇本城・払田柵跡など個別城郭の発掘調査報告書は全国遺跡報告総覧でPDF公開が進んでいる。

## 遺跡地図・埋蔵文化財

- **[秋田県遺跡地図情報](https://common3.pref.akita.lg.jp/heritage-map/)**（秋田県教育庁生涯学習課文化財保護室）
  県内の周知の埋蔵文化財包蔵地（遺跡）を検索・地図表示できる公式GIS。約6,000件弱の遺跡情報を収録。
- **[秋田県遺跡地図（由利地区版）](https://sitereports.nabunken.go.jp/ja/report-type/b04/p/3/item/86745?sort=alternative)**（秋田県教育委員会、2001年3月刊）
  全国遺跡報告総覧でPDF公開。地区別分冊のため、由利以外の地区版は同総覧の秋田県一覧から個別に検索する必要がある。

## 中世城館調査報告書

- **『秋田県の中世城館』（秋田県文化財調査報告書第86集、秋田県教育委員会、1981年3月31日刊）**
  全国遺跡報告総覧に書誌が登録されている（[該当ページ](https://sitereports.nabunken.go.jp/ja/49441)）。**書誌情報のみ・PDF未公開**（ダウンロード数0件と表示）。安東氏・秋田氏など国人領主の城館を悉皆的にまとめた基礎資料だが、現物は県立図書館等の所蔵に頼る必要がある。
- **『都道府県別日本の中世城館調査報告書集成』第1巻（北海道・青森・秋田）**（秋田県文化財保護協会編、東洋書林、2002年刊）
  市販書籍。[CiNii書誌情報](https://ci.nii.ac.jp/ncid/BA49003233)のみで本文は非公開。
- **[全国遺跡報告総覧：秋田県教育委員会 発行分](https://sitereports.nabunken.go.jp/ja/list/05/05000)**（奈良文化財研究所）
  秋田県教育委員会発行の発掘調査報告書一覧。個別城郭・城柵の報告書を探す入口。

## 調査研究機関

- **[秋田県埋蔵文化財センター](https://common3.pref.akita.lg.jp/maibun/)**
  1981年設立。発掘調査・研究紀要・年報等の刊行物ページを公開。
- **[払田柵跡調査事務所](https://www.pref.akita.lg.jp/pages/genre/hotta)**（秋田県教育委員会）
  1974年設置の古代城柵専従調査機関。年報を継続刊行。

## 主要城郭の公式資料

- **[久保田城について](https://www.city.akita.lg.jp/kanko/kanrenshisetsu/1002685/1009873/1009870/1002300.html)**（秋田市公式サイト）
  佐竹氏の居城で、石垣を用いず土塁と堀で構成される城郭。復元された御隅櫓・表門の解説と沿革を掲載。
- **[脇本城跡](https://www.city.oga.akita.jp/soshik/bunkasportska/bunkazai/2/1514.html)**（男鹿市ホームページ）
  国史跡（2004年指定、2022年追加指定）。安東愛季による大改修で知られる、総面積約150haの東北屈指の規模を誇る山城。
- **[脇本城跡（男鹿市文化財調査報告書第40集、男鹿市教育委員会）](https://sitereports.nabunken.go.jp/ja/75975)**
  国指定史跡の総括報告書。全国遺跡報告総覧でPDF公開（標準版54.0MB／モバイル版36.2MB）。
- **[男鹿市文化財関係刊行物一覧](https://www.city.oga.akita.jp/soshik/bunkasportska/bunkazai/1534.html)**（男鹿市ホームページ）
  脇本城跡を含む男鹿市の発掘調査報告書一覧。
- **[国指定史跡 払田柵跡](https://www.city.daisen.lg.jp/archive/contents-11512)**（大仙市）
  平安時代初期の古代城柵。文献にその名が見えないため「幻の柵」とも呼ばれ、1931年に秋田県内で初めて国史跡に指定された。
- **[払田柵跡調査事務所年報2024（秋田県文化財調査報告書第545集）](https://sitereports.nabunken.go.jp/files/attach/68/68219/142077_1_%E6%89%95%E7%94%B0%E6%9F%B5%E8%B7%A1%EF%BC%8D%E7%AC%AC158%E6%AC%A1%E8%AA%BF%E6%9F%BB%E3%83%BB%E9%96%A2%E9%80%A3%E9%81%BA%E8%B7%A1%E3%81%AE%E8%AA%BF%E6%9F%BB%E6%A6%82%E8%A6%81%EF%BC%8D.pdf)**
  第158次調査を含む最新の発掘調査概要がPDF公開されている。
- **[横手公園展望台（横手城）](https://www.city.yokote.lg.jp/kanko/1004048/1004531.html)**（横手市公式サイト）
  戦国期に小野寺景道が朝倉山に築いた居城跡。模擬天守内は郷土資料館として一般公開。
