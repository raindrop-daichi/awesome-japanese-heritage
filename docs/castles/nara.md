# 奈良県の城郭資料

奈良県（大和）は高取城・信貴山城など大規模山城を擁する。埋蔵文化財調査の中核は県立橿原考古学研究所で、全国でも早くから遺跡地図のWeb公開（GIS）を行っている県のひとつ。

## 遺跡地図・埋蔵文化財

- **[奈良県遺跡地図Web（案内ページ）](https://www.pref.nara.lg.jp/n035/16771.html)**（奈良県）
  県内の周知の埋蔵文化財包蔵地・史跡等を地理院地図上に表示するWeb GIS。地図本体は橿原考古学研究所のサーバーで運用。※観光・研究目的限定で、**文化財保護法上の行政手続には使用不可**（市町村の文化財台帳の確認が必要）。地図の著作権は橿原考古学研究所に帰属し無断転載禁止
- **[全国文化財総覧：奈良県 報告書一覧](https://sitereports.nabunken.go.jp/ja/list/29/29)**（奈良文化財研究所）
  県教委・各市町村・大学等の発掘調査報告書を横断検索。個別城郭の報告書を探す入口。

## 調査研究機関

- **[奈良県立橿原考古学研究所](https://www.kashikoken.jp/)**（奈良県）
  県内の埋蔵文化財調査・研究の中核機関。遺跡地図GIS、紀要『青陵』等を運営・刊行。城郭調査報告書の主要な発行元。
- **[「奈良県文化財調査報告書」シリーズ一覧](https://www.kashikoken.jp/publication/houkokugaihou/kenbunhou/)**（橿原考古学研究所）
  第15集〜第197集（1971年〜）の一覧。
- **奈良文化財研究所（奈文研）** — 全国横断ページの[全国文化財総覧](national.md)を運営する国立機関。所在地は奈良市。

※県教委による中世城館の悉皆調査報告書（『大和国中世城館跡』のような単独シリーズ）は編纂時点で確認できなかった。城館調査の成果は県文化財調査報告書と市町村単位の報告書に分散している。

## 県の城郭ポータル

- **[奈良の城](https://www.pref.nara.lg.jp/ikasu-nara/naranoshiro/index.html)**（奈良県 文化財課）
  多聞城・郡山城・宇陀松山城・信貴山城・高取城の県内主要5城を紹介する公式ページ。

## 主要城郭の自治体公式資料

- **[高取城跡](https://www.town.takatori.nara.jp/contents_detail.php?frmId=236)**（高取町）
  国史跡・日本三大山城のひとつ。町公式の解説ページ。
- **[『国指定史跡高取城跡基礎調査報告書』（高取町教育委員会、2004）](https://sitereports.nabunken.go.jp/en/74425)**（全国文化財総覧）
  高取城の基礎調査報告書。
- **[郡山城](https://www.city.yamatokoriyama.lg.jp/soshiki/chiikishinkoka/kanko/2/1630.html)**（大和郡山市）
  国史跡。市公式ページ。発掘調査報告書は市教委発行で多数あり、全国文化財総覧から検索できる。
- **[多聞城跡](https://www.city.nara.lg.jp/site/bunkazai/263742.html)**（奈良市 文化財課）
  松永久秀の居城。2026年3月に奈良市指定史跡に指定。
- **[信貴山城跡（全国文化財総覧の遺跡情報）](https://sitereports.nabunken.go.jp/ja/cultural-property/236255)**（奈良文化財研究所）
  松永久秀ゆかりの大規模山城（東西約500m×南北約630m）。県指定史跡。

## デジタルアーカイブ
