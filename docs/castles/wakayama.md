# 和歌山県の城郭資料

和歌山県（紀伊）は和歌山城のほか、太田城（秀吉の水攻め）・新宮城・安宅氏城館跡など特色ある城郭を擁する。県単独の中世城館悉皆調査報告書は公開Web上で確認できておらず、県文化財センターの発掘報告書と市町村資料が主な情報源になる。

## 遺跡地図・埋蔵文化財

- **[和歌山県埋蔵文化財包蔵地所在地図（案内ページ）](https://www.pref.wakayama.lg.jp/prefg/500700/maizou/houzouchi.html)**（和歌山県教育庁 文化遺産課）
  県内の包蔵地と国・県指定記念物の位置・範囲を示す地図の案内。WebGIS本体（和歌山県地理情報システム）へはこのページから遷移する。※詳細・最新情報は各市町村文化財担当課への確認が必要と明記されている

## 発掘調査報告書

- **[全国文化財総覧：和歌山県文化財センター 発行報告書一覧](https://sitereports.nabunken.go.jp/ja/list/30/30000-a)**（奈良文化財研究所）
  「新宮城下町遺跡」（2021）、「里野中山城跡・結城城跡・浦屋敷跡」（2024）など城館関連を含む報告書PDF。
- **[公益財団法人 和歌山県文化財センター](http://wabunse.or.jp/)**
  県内の発掘調査・報告書刊行の中核機関。[発掘調査報告書ページ](http://wabunse.or.jp/report/excavation_report/)あり。※サーバー証明書の都合で `http://` でのみアクセス可
- **和歌山県中世城館跡の悉皆調査報告書** — 公開Web上では実在を確認できず（他県のような単独報告書は未実施か非公開の可能性）。『都道府県別日本の中世城館調査報告書集成（15）近畿』（東洋書林）に和歌山分が収録されているとの言及あり。

## 県立博物館施設

- **[和歌山県立紀伊風土記の丘](https://www.kiifudoki.wakayama-c.ed.jp/)**（和歌山県）
  特別史跡・岩橋千塚古墳群の考古系博物館。※2024年3月末から休館中で、2026年下期に「和歌山県考古民俗博物館（仮称）」としてリニューアル予定
- **[和歌山県立博物館](https://hakubutu.wakayama.jp/)**（和歌山県）
  城下町絵図等を収蔵する歴史・美術系博物館。※2026年8月上旬まで改修工事のため休館中

## 主要城郭の公式資料

- **[史跡和歌山城整備計画報告書（平成28年度改訂版）](https://wakayamajo.jp/pdf/seibikeikaku.pdf)**（和歌山市、PDF 約37MB）
  国史跡・和歌山城の整備計画。調査成果がまとまった一次資料。
- **[史跡和歌山城二の丸及び西の丸整備基本計画報告書（2021）](https://wakayamajo.jp/pdf/ninomaru-nishinomaru_seibikihonnkeikaku.pdf)**（和歌山市、PDF 約12MB）
- **[和歌山市の文化財：和歌山城](http://wakayamacity-bunkazai.jp/wakayamajo/)**（和歌山市）
  市の文化財サイト内の和歌山城解説。[市教委発行の報告書一覧](http://wakayamacity-bunkazai.jp/data/hokokusho/kyoiku/)には太田城水攻め堤跡関連の調査概報も。※いずれも `http://` でのみアクセス可
- **[新宮城跡附水野家墓所](https://www.city.shingu.lg.jp/Info/229)**（新宮市）
  国史跡（2003年指定）。水ノ手郭の炭納屋・船着場遺構など調査成果の解説。
- **[安宅氏城館跡（全国文化財総覧の文化財情報）](https://sitereports.nabunken.go.jp/ja/cultural-property/491079)**（奈良文化財研究所）
  国史跡（2020年指定）。熊野水軍・安宅氏の城館群（白浜町）。
