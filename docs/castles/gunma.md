# 群馬県の城郭資料

群馬県（上野国）は関東と信越を結ぶ交通の要衝で、後北条・上杉・武田・真田の勢力が競った激戦地。県教育委員会の中世城館悉皆調査報告書『群馬県の中世城館跡』（1989年刊）が全国遺跡報告総覧でPDF全巻公開されており、資料的な当たりは良い。遺跡地図は「マッピングぐんま」でWeb公開されている。

## 遺跡地図・埋蔵文化財

- **[マッピングぐんま「遺跡・文化財」](https://mapping-gunma.pref.gunma.jp/pref-gunma-iseki/Portal)**（群馬県）
  県内の周知の埋蔵文化財包蔵地（遺跡）と国・県指定文化財を地図から検索できるWebGIS。地図検索・条件検索の2方式。旧・群馬県文化財情報システムは2013年に廃止され、本サービスに統合された。
- **[遺跡・文化財の地図情報について（マッピングぐんま）](https://www.pref.gunma.jp/page/5189.html)**（群馬県文化遺産課）
  上記WebGISの案内ページ。利用方法・注意事項を掲載。

## 中世城館調査報告書

- **[『群馬県の中世城館跡』（群馬県教育委員会、1989年3月刊）](https://sitereports.nabunken.go.jp/ja/101986)**（全国遺跡報告総覧）
  県内中世城館の悉皆調査報告書。全9分冊のPDFが全国遺跡報告総覧上で公開されている。※発行年は1988年度事業だが刊行は1989年3月付。県内城館研究の基礎資料として一次資料性が高い。
- **[全国遺跡報告総覧：（公財）群馬県埋蔵文化財調査事業団 発行報告書一覧](https://sitereports.nabunken.go.jp/ja/list/10/10000-a)**（奈良文化財研究所）
  事業団発行の発掘調査報告書シリーズの一覧。個別城館の発掘調査報告書を探す入口。

## 調査研究機関

- **[公益財団法人 群馬県埋蔵文化財調査事業団](https://gunmaibun.org/)**
  県内埋蔵文化財の発掘調査・研究を担う中核機関。
- **[発掘情報館](https://gunmaibun.org/excavation)**（群馬県埋蔵文化財調査事業団）
  発掘調査速報・出土品展示等を紹介する施設ページ。
- **[図書データ検索](https://gunmaibun.org/excavation/books)**（群馬県埋蔵文化財調査事業団）
  事業団刊行の調査報告書を検索できるデータベース。

## 主要城郭の公式資料

- **[史跡箕輪城跡案内](https://www.city.takasaki.gunma.jp/site/cultural-assets/65909.html)**（高崎市）
  国指定史跡・箕輪城跡（1987年指定）の現地案内。長野氏築城から井伊直政による近世改修までの変遷を解説。
- **[箕輪城跡（高崎市の文化財）](https://www.city.takasaki.gunma.jp/site/cultural-assets/6450.html)**（高崎市）
  文化財としての箕輪城跡の指定概要ページ。
- **[金山城跡の概要](https://www.city.ota.gunma.jp/005gyosei/0170-009kyoiku-bunka/bunkazai/kanayamajo.html)**（太田市教育委員会）
  国指定史跡・金山城跡（1934年指定）の概要。山城全山を利用した縄張り、石垣・堀切の保存状況を解説。
- **[金山城跡](https://www.city.ota.gunma.jp/page/4140.html)**（太田市文化財課）
  金山城跡に関する太田市文化財課の総合案内ページ。
- **[名胡桃城址（県指定史跡）](https://www.enjoy-minakami.jp/spot/8065/)**（みなかみ町観光協会）
  県指定史跡・名胡桃城址（1949年指定）の紹介。真田昌幸による築城、天正18年（1590）小田原合戦の発端となった経緯を記載。※観光協会サイトのため一次資料としては補助的。
- **[沼田城跡](https://www.city.numata.gunma.jp/kyouiku/bunkazai/ichiran/shi/1000876.html)**（沼田市教育委員会）
  真田氏による沼田城の沿革・文化財指定状況を解説。天和2年（1682）の破却経緯にも言及。
- **[岩櫃城跡が国指定史跡へ](https://www.town.higashiagatsuma.gunma.jp/www/contents/1564985209126/index.html)**（東吾妻町）
  令和元年（2019年）の国指定史跡指定を伝える町広報。指定理由・城域規模（136ヘクタール）を記載。
- **[国指定史跡「岩櫃城跡」](https://gunma-kanko.jp/spots/37)**（群馬県観光局）
  岩櫃城跡の概要紹介。武田・真田氏支配下の上州最大規模の中世城館という評価を記載。

## デジタルアーカイブ

- **[群馬県立図書館ポータル デジタルライブラリー](https://www.library.pref.gunma.jp/?page_id=650)**（群馬県立図書館）
  県内7市町の連携図書館所蔵資料を含む郷土資料デジタルライブラリー。絵図・古地図・写真等をJPEG/PDFで公開。館林市立図書館所蔵の『上野国館林城図』等、城下絵図も含まれる。

### 編纂メモ

- 掲載URLは2026-08-02時点で実在を確認（すべてHTTP 200を確認）
- 『群馬県の中世城館跡』は全国遺跡報告総覧で全9分冊PDF公開済みという良好な状態を確認できた。刊行年は書誌上1989年3月（プロンプト指定の1988年ではない）
- マッピングぐんまは静的な地図情報システムではなくインタラクティブGISのため、自動ツールでの深リンク検証は限定的。手動でのポータル確認を推奨
