# 近畿

近畿地方は伊勢・伊賀・志摩（三重）、近江（滋賀）、山城・丹波・丹後（京都）、摂津・河内・和泉（大阪）、播磨・但馬・丹波・摂津・淡路（兵庫）、大和（奈良）、紀伊（和歌山）の旧国からなり、中世山城の密集地帯として知られる。滋賀県では県内1,300ヶ所超、京都府でも約1,300城館が確認されており、大阪府の飯盛城・芥川山城、兵庫県の竹田城・姫路城、奈良県の高取城・信貴山城など、三好長慶や松永久秀ら戦国期の有力勢力の本拠地も多い。伊賀盆地（三重県）のように土豪の城館が密集し忍者伝承と結びついた地域もある。

各県の中世城館悉皆調査は滋賀県（『滋賀県中世城郭分布調査』全10巻＋索引編）、京都府（『京都府中世城館跡調査報告書』全4冊）、三重県（1976年刊行）、兵庫県（1982年刊行）で実施済みだが、いずれも編纂時点でPDF本体は未公開または未確認で書誌情報にとどまる。大阪府・和歌山県は県教委による公式悉皆調査そのものが編纂時点で確認できず、大阪府では民間出版物『大阪府中世城館事典』が体系資料の役割を担う。遺跡地図・埋蔵文化財包蔵地の公開状況も差が大きく、京都府は約18,000件を検索できる統合型GISを運用する一方、三重県・滋賀県は県レベルのオンライン地図が未確認・停止中で市町村レベルの公開に頼る場面が多い。奈良県は橿原考古学研究所が運営するWeb GISを早期から公開している。

## この地方の資料

- **[三重県](mie.html)** — 伊賀盆地の土豪城館が密集し忍者伝承と結びつく。1976年の中世城館悉皆調査報告書は全国遺跡報告総覧でPDF公開
- **[滋賀県](shiga.html)** — 県内1,300ヶ所超の城郭密集地帯。県悉皆調査のデジタル版は未確認だが、甲賀市・草津市など市町村GISが充実
- **[京都府](kyoto.html)** — 約1,300城館の悉皆調査を実施し、統合型GISで約18,000件の包蔵地を検索可能。京都市埋蔵文化財研究所は1,000件超の報告書PDFを公開
- **[大阪府](osaka.html)** — 府教委の公式悉皆調査報告書は未確認で、民間出版物『大阪府中世城館事典』（2015）が体系資料の役割を担う
- **[兵庫県](hyogo.html)** — 播磨・但馬・丹波・摂津・淡路の旧五国にまたがる山城密集地帯。姫路城は保存活用計画の一次資料が充実
- **[奈良県](nara.html)** — 高取城・信貴山城など大規模山城を擁し、橿原考古学研究所が早期からWeb GISの遺跡地図を公開
- **[和歌山県](wakayama.html)** — 県単独の中世城館悉皆調査報告書は公開Web上で確認できず、県文化財センターの発掘報告書と市町村資料が主な情報源
