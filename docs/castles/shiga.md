# 滋賀県の城郭資料

滋賀県（近江）は県内1,300ヶ所超といわれる城郭の密集地帯。県教育委員会による『滋賀県中世城郭分布調査』（1980年代〜1992年、全10巻＋索引編）の悉皆調査があるが、**デジタル版は未確認**で、県レベルの遺跡地図も編纂時点で停止中。市町村レベルの公開が比較的充実している。

## 遺跡地図・埋蔵文化財

- **[滋賀県 文化財保護課（埋蔵文化財）](https://www.pref.shiga.lg.jp/ippan/bunakasports/bunkazaihogo/312340.html)**（滋賀県教育委員会）
  「滋賀県遺跡地図」の掲載ページ。※編纂時点（2026-08-01）で遺跡地図へのリンクは「ただいまご利用になれません」と表示され停止中。復旧を待って再確認
- **[甲賀市遺跡地図（こうかちず）](https://www.city.koka.lg.jp/22388.htm)**（甲賀市教育委員会 歴史文化財課）
  滋賀県遺跡地図から甲賀市分を抽出。2024年6月から公開型GIS「こうかちず」の「歴史文化財」レイヤーで閲覧できる。開発計画時は事前相談必須。
- **[草津市遺跡地図（くさつマップ）](https://www.city.kusatsu.shiga.jp/bunka/rekishi/maizoubunka/isekimap2021.html)**（草津市教育委員会 歴史文化財課）
  住所検索で埋蔵文化財包蔵地の範囲を確認できる。
- **[長浜市遺跡地図](https://www.city.nagahama.lg.jp/0000000138.html)**（長浜市 文化観光課）
  県遺跡地図から長浜市分をPDFで抽出提供。小谷城を含む湖北エリアの基礎資料。

※市町のWebGIS本体は共通の民間ベンダー上にありURL変更リスクが高いため、ここでは各自治体の案内ページにリンクしている。

## 中世城郭分布調査報告書

- **『滋賀県中世城郭分布調査』（滋賀県教育委員会、1980年代〜1992年、全10巻＋索引編）**
  県内約1,300ヶ所の城館を記録した悉皆調査。**編纂時点でオープンなPDF/デジタル版は未発見**（全国文化財総覧にも未収録）。現物は滋賀県立図書館等の所蔵を [国立国会図書館サーチ](https://ndlsearch.ndl.go.jp/) や県立図書館OPACで確認のこと。
- **[全国文化財総覧：滋賀県教育委員会 発行報告書一覧](https://sitereports.nabunken.go.jp/ja/list/25/25000)**（奈良文化財研究所）
  滋賀県教委発行の発掘調査報告書一覧。個別城郭の発掘報告書を探す入口。

## 調査研究機関・博物館

- **[公益財団法人 滋賀県文化財保護協会](https://www.shiga-bunkazai.jp/)**
  県の文化財調査・普及の中核団体。季刊誌「おうみ文化財通信」、現地説明会資料等を刊行（[刊行物ページ](https://www.shiga-bunkazai.jp/publications-top/)）。
- **[滋賀県立安土城考古博物館](https://azuchi-museum.or.jp/)**（滋賀県）
  安土城・織田信長・戦国期を専門とする県立博物館。安土城調査研究の中核拠点。刊行物・紀要あり。
- **[彦根城博物館](https://hikone-castle-museum.jp/)**（彦根市）
  井伊家伝来の美術工芸品・古文書・武具等を収蔵。研究利用申請の窓口あり。

## 主要城郭の自治体公式資料

- **[長浜市 刊行物一覧（小谷城跡ほか）](https://www.city.nagahama.lg.jp/0000000285.html)**（長浜市教育委員会）
  『史跡小谷城跡確認調査報告書』（2019）、『史跡小谷城跡総合調査報告書』（2020）等の刊行物案内。
- **[京極氏遺跡（京極氏城館跡・上平寺城跡・弥高寺跡）](https://www.city.maibara.lg.jp/soshiki/kyoiku/rekishi/shokai/kunishitei/shiseki/2856.html)**（米原市教育委員会）
  国指定史跡。戦国期京極氏の館と詰城のセットが良好に残る。
- **[甲賀の中世城郭](https://www.city.koka.lg.jp/4730.htm)**（甲賀市教育委員会）
  甲賀市内約200城、「単郭方形」構造という甲賀独特の城館群の解説。
- **[近江の城カード](https://www.pref.shiga.lg.jp/ippan/bunakasports/bunkazaihogo/311052.html)**（滋賀県 文化財保護課）
  県内1,300超の城郭をPRするカード配布事業。県が把握する主要城郭のリストとして参考になる。

## デジタルアーカイブ

  絵図・古地図・航空写真等のデジタルアーカイブ。「絵図」区分に城絵図・城下町絵図が含まれる。
