# 青森県の城郭資料

青森県（陸奥国北部、津軽・南部の二大勢力圏）は、津軽為信の弘前城、南部氏系の根城・七戸城、浪岡北畠氏の浪岡城など、戦国期の在地勢力の拠点が国史跡・現存天守として今に残る。県遺跡地図はWeb版が公開されているが、中世城館の悉皆調査報告書は書誌情報のみでPDF未公開のものが多い。

## 遺跡地図・埋蔵文化財

- **[青森県遺跡地図](https://www.pref.aomori.lg.jp/soshiki/kyoiku/e-bunka/isekitizu.html)**（青森県教育庁文化財保護課）
  Web版遺跡地図を公開。1:25000スケールのPDFで、周知の埋蔵文化財包蔵地（遺跡）と国・県指定記念物を色分け表示する。※開発事業を計画する場合は市町村教委または県教委への照会が必須と明記されている。
- **[青森県遺跡地図（Web版）更新履歴一覧](https://www.pref.aomori.lg.jp/soshiki/kyoiku/e-bunka/isekitizu_koushin.html)**（青森県教育庁文化財保護課）
  遺跡地図の更新履歴。定期的に更新されており、最新の反映状況を確認できる。

## 中世城館調査報告書

- **『青森県遺跡詳細分布調査報告書』（青森県教育委員会、2014年3月刊、青森県埋蔵文化財調査報告書第549集）**
  全国文化財総覧に書誌が登録されている（[該当ページ](https://sitereports.nabunken.go.jp/ja/35053)）。**書誌情報のみでPDF未公開**。県内城館を含む詳細分布調査の基礎資料だが、現物確認は県立図書館等の所蔵に頼る必要がある。
- **[全国文化財総覧：青森県 全域](https://sitereports.nabunken.go.jp/ja/list/02/02)**（奈良文化財研究所）
  青森県教育委員会・各市町村教委発行の発掘調査報告書一覧。個別城郭（根城跡、浪岡城遺跡など）の報告書を探す入口。

## 調査研究機関

- **[青森県埋蔵文化財調査センター](https://www.ao-maibun.jp/)**
  県内埋蔵文化財の発掘調査・研究を担う機関。[刊行物ページ](https://www.ao-maibun.jp/book/hakkutuhoukokusyo_menu.html)で発掘調査報告書・研究紀要を公開。
- **[青森県埋蔵文化財調査センター（県庁サイト内）](https://www.pref.aomori.lg.jp/soshiki/kyoiku/e-mzchosa/maibun_1.html)**（青森県教育庁）
  センターの業務概要・組織情報のページ。

## 主要城郭の公式資料

- **[弘前城と石垣修理の歴史](https://www.city.hirosaki.aomori.jp/ishigaki/rekishi.html)**（弘前市）
  現存天守を有する弘前城の本丸石垣修理事業の解説。『弘前城本丸石垣解体調査概報1』（2019年刊）、『弘前城本丸石垣発掘調査報告書』（2022年刊）等の刊行物に言及。
- **[復原された中世の城 -根城-](https://www.city.hachinohe.aomori.jp/soshikikarasagasu/shakaikyoikuka/bunka/2/4935.html)**（八戸市教育委員会）
  国史跡・根城跡の概要。昭和53年から約11年間の発掘調査・整備事業の経緯を解説。
- **[史跡 根城の広場](https://hachinohe-city-museum.jp/guide_square/)**（八戸市博物館）
  発掘調査の成果に基づき安土桃山期の主殿等を復原整備した公開施設の案内。
- **[根城跡](https://sitereports.nabunken.go.jp/ja/cultural-property/33246)**（全国文化財総覧）
  根城跡に関する発掘調査報告書等の一覧。
- **[史跡 浪岡城跡 概要](https://www.city.aomori.aomori.jp/bunka_sports_kankou/bunka_geijutsu/1005024/1005084/1005085/1005098/1005099.html)**（青森市教育委員会）
  浪岡北畠氏の居城、青森県で最初の国史跡指定（昭和15年）の概要解説。
- **[史跡 浪岡城跡の発掘調査や各館の概要](https://www.city.aomori.aomori.jp/bunka_sports_kankou/bunka_geijutsu/1005024/1005084/1005085/1005098/1005100.html)**（青森市教育委員会）
  昭和52年度以降の発掘調査経緯と8つの曲輪（館）ごとの解説。
- **[浪岡城遺跡](https://sitereports.nabunken.go.jp/ja/cultural-property/11960)**（全国文化財総覧）
  浪岡城遺跡に関する発掘調査報告書等の一覧。
- **[史跡七戸城跡](https://www.town.shichinohe.lg.jp/gyosei/cultural-sports/bunka/post-154.html)**（七戸町）
  南部氏一族・七戸南部家の居城とされる国史跡の概要。柏葉公園として整備された現況を紹介。
