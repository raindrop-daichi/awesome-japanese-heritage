# 沖縄県の城郭資料

かつて独立王国・琉球王国であった沖縄には令制国の枠組みがなく、城郭も「グスク」という石造の独自形式を取る。石垣の曲線美と、城内に聖域（御嶽）を抱く点が本土の城と大きく異なる。首里城・今帰仁城・中城城・座喜味城・勝連城など5件のグスクは「琉球王国のグスク及び関連遺産群」として世界遺産に登録されており、特に首里城は2019年火災からの復元事業の記録が充実している。県教委による本土型の全県悉皆調査報告書は確認できず、個別グスクの発掘調査報告が全国遺跡報告総覧に集約される形が中心だ。

## 遺跡地図・埋蔵文化財

- **[遺跡分布地図](https://www.pref.okinawa.lg.jp/bunkakoryu/bunkageijutsu/1009673/1009695/1009696.html)**（沖縄県立埋蔵文化財センター）
  沖縄県地図情報システム上で埋蔵文化財包蔵地の分布を閲覧できる旨の案内ページ。
- **[沖縄県地図情報システム（GISおきなわ）](https://gis.pref.okinawa.jp/pref-okinawa/Portal?mid=6)**（沖縄県）
  遺跡分布地図を含む県のWeb地図ポータル。※レイヤー操作を伴う実際の閲覧はブラウザでの確認を推奨。

## 中世城館調査報告書

本土の県教委がまとめるような全県横断の「中世城館跡分布調査報告書」に相当するものは確認できなかった。代わりに、首里城跡・中城御殿跡・円覚寺跡などグスク・城郭関連遺跡の発掘調査報告書が個別に刊行され、全国遺跡報告総覧に外部リンクで集約されている。

- **[刊行文献一覧](https://www.pref.okinawa.lg.jp/bunkakoryu/bunkageijutsu/1009673/1009695/1009697.html)**（沖縄県立埋蔵文化財センター）
  首里城跡（京の内・御内原等）、中城御殿跡、円覚寺跡、御茶屋御殿跡などの発掘調査報告書、および「沿岸地域遺跡分布調査」報告書（沖縄本島・離島対象）を一覧化し、各報告書は全国遺跡報告総覧へ外部リンクしている。
- **[全国遺跡報告総覧](https://sitereports.nabunken.go.jp/)**（奈良文化財研究所）
  発行機関「沖縄県立埋蔵文化財センター」等で絞り込むことで、上記報告書のPDFを個別に検索・閲覧できる。

## 調査研究機関

- **[沖縄県立埋蔵文化財センター](https://www.pref.okinawa.lg.jp/bunkakoryu/bunkageijutsu/1009673/index.html)**（沖縄県教育庁文化財課）
  西原町に所在する発掘調査・展示・研究支援の拠点施設。刊行物・年報・遺跡分布地図のページもここから辿れる。
- **[沖縄県立埋蔵文化財センター年報](https://www.pref.okinawa.lg.jp/bunkakoryu/bunkageijutsu/1009673/1009695/1009716.html)**（沖縄県立埋蔵文化財センター）
  年次の発掘調査・研究活動をまとめた年報の一覧ページ。

## 主要城郭の公式資料

- **[首里城公園](https://oki-park.jp/shurijo/)**（沖縄県、首里城公園管理センター）
  世界遺産・首里城の公式サイト。2019年火災後の「復元・復興」特設ページ、首里城デジタルミュージアム、復興の軌跡を掲載。正殿の一般公開は2026年11月23日開始予定と告知されている。
- **[今帰仁城跡](https://www.nakijinjoseki-osi.jp/)**（今帰仁村・今帰仁村グスク交流センター）
  北山王の居城とされる今帰仁城跡の公式サイト。今帰仁村歴史文化センターの展示情報も掲載。
- **[中城城跡](https://www.nakagusuku-jo.jp/)**（中城城跡共同管理協議会）
  国指定史跡・世界遺産・日本100名城の中城城跡公式サイト。石積み技法の解説や発掘調査の紹介あり。
- **[座喜味城跡](https://www.vill.yomitan.okinawa.jp/kanko_bunka_sports/rekishi_bunkazai/3682.html)**（読谷村教育委員会）
  読谷村公式サイト内の座喜味城跡の解説ページ。
- **[勝連城跡](https://www.katsuren-jo.jp/)**（うるま市・あまわりパーク管理事務所）
  15世紀の按司・阿麻和利の居城とされる勝連城跡の公式サイト。麓のあまわりパークの案内も兼ねる。

## デジタルアーカイブ
