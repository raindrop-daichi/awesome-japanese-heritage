# 高知県の城郭資料

高知県（土佐）は天守と本丸御殿がともに現存する全国唯一の高知城、長宗我部氏の岡豊城を擁する。県一括の中世城館悉皆調査報告書は確認できていないが、**市町村単位の城跡悉皆調査（高知市・南国市）が全国文化財総覧でPDF全文公開**されている。

## 城跡悉皆調査報告書（市町村単位）

- **[『高知市の城跡』（高知市教育委員会、1984）](https://sitereports.nabunken.go.jp/ja/9807)**（全国文化財総覧）
  高知市内の城跡悉皆調査。**PDF全文公開**（本編56MB＋携帯版）。
- **[『高知県南国市中世城館跡』（南国市教育委員会、1985）](https://sitereports.nabunken.go.jp/ja/9353)**（全国文化財総覧）
  岡豊城を含む南国市域の中世城館跡分布調査。**PDF公開**（4分冊）。
- **[全国文化財総覧：高知県立埋蔵文化財センター 刊行物一覧](https://sitereports.nabunken.go.jp/ja/list/39/39000)**（奈良文化財研究所）
  「史跡 高知城跡」石垣復旧調査等を含む報告書一覧。

## 主要城郭の公式資料

- **[高知城 公式ホームページ](https://kochipark.jp/kochijyo/)**（高知城管理事務所）
  国史跡・重要文化財15棟。天守と本丸御殿（懐徳館）がともに現存する全国唯一の城。[県の紹介ページ](https://www.pref.kochi.lg.jp/doc/kochi-jo/)も併せて。
- **[高知城歴史博物館](https://www.kochi-johaku.jp/)**（土佐山内記念財団）
  山内家伝来資料・高知城関連資料を所蔵。研究者向けデータベース・資料閲覧室あり。
- **[国史跡 岡豊城跡](https://www.city.nankoku.lg.jp/life/life_dtl.php?hdnKey=1137)**（南国市）
  長宗我部元親の居城（2008年国史跡指定）。[高知県立歴史民俗資料館の解説ページ](https://kochi-rekimin.jp/sites/index.html)（城跡に隣接）も参照。
- **[浦戸城天守跡 附 詰東部及び東南部石垣・石塁](https://www.city.kochi.kochi.jp/soshiki/90/cas-city-3400900.html)**（高知市）
  市指定史跡。長宗我部元親が1591年頃に本拠とした城。桂浜・坂本龍馬記念館前の詰ノ段が本丸跡。
