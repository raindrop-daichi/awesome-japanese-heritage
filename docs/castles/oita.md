# 大分県の城郭資料

旧国名は豊後・豊前（一部）。大友宗麟の府内城下と、キリシタン大名の拠点として整備された臼杵城・岡城など、中世〜近世の変遷を追える城が多い。県教委による中世城館跡分布調査報告書は全4集がPDFで無料公開されており、資料の充実度は高い。臼杵城跡は2025年に国史跡指定を受けたばかりで、整備・調査が進行中である。

## 遺跡地図・埋蔵文化財

- **[おおいたマップ（文化財情報レイヤ）](https://www2.wagmap.jp/oitacity/PositionSelect?mid=13&nm=%E6%96%87%E5%8C%96%E8%B2%A1%E6%83%85%E5%A0%B1)**（大分市）
  大分市域の文化財情報を地図から検索できるWebGIS。市域限定で、県全体の埋蔵文化財包蔵地図には未対応。
- **[文化財総覧WebGIS](https://heritagemap.nabunken.go.jp/main)**（奈良文化財研究所）
  全国遺跡報告総覧の登録データを地図上に重ねて表示する全国共通GIS。大分県内の登録報告書もここから位置検索できる。
- **[大分県遺跡地図](https://sitereports.nabunken.go.jp/86810)**（大分県教育委員会、全国遺跡報告総覧）
  書誌情報のみでPDF未公開（ダウンロード件数0件）。県が別途Web公開する統合遺跡地図は確認できなかった。

## 中世城館調査報告書

- **[大分の中世城館 第1集](https://sitereports.nabunken.go.jp/33381)**（大分県教育委員会、2002年刊、大分県文化財調査報告書148「文献史料編」）
  平成7〜15年度の9ヶ年調査（大分県中世城館跡分布調査事業）の一環。県内569か所の中世城館を把握。PDF公開（約62.1MB）。
- **[大分の中世城館 第2集](https://sitereports.nabunken.go.jp/33398)**（大分県教育委員会、2003年刊）
  PDF公開（標準版32.4MB／モバイル版13.6MB）。
- **[大分の中世城館 第3集](https://sitereports.nabunken.go.jp/33399)**（大分県教育委員会、2003年刊、大分県文化財調査報告書161「地名表・分布図編」）
  PDF公開（標準版60.0MB／モバイル版13.7MB）。
- **[大分の中世城館 第4集](https://sitereports.nabunken.go.jp/ja/100651)**（大分県教育委員会、2004年刊、大分県文化財調査報告書170）
  重要152か所の詳述を含む調査事業の総括編。PDF公開（標準版7.3MB／モバイル版2.6MB）。

## 調査研究機関

- **[大分県立埋蔵文化財センター](https://www.pref.oita.jp/site/maizobunka/)**（大分県教育庁）
  県内の発掘調査・出土品の整理保管・展示活用を担う機関。催し物案内や発掘調査最新情報を掲載。刊行物一覧へのリンクあり（個別報告書のPDFは全国遺跡報告総覧経由での確認が確実）。

## 主要城郭の公式資料

- **[府内城跡](https://www.city.oita.oita.jp/o204/bunkasports/shitebunkazai/1352943146749.html)**（大分市教育委員会）
  大分県・大分市指定史跡。廊下橋復元に伴う発掘調査で築城当時の石垣を確認した旨を記載。
- **[府内城（広報おおいた記事）](https://www.pref.oita.jp/site/archive/200920.html)**（大分県デジタルアーカイブ）
  1993年広報記事の再掲。城郭の由来と現況を写真付きで紹介。
- **[国指定史跡岡城跡](https://okajou.jp/)**（竹田市）
  岡城跡の公式サイト。史跡整備状況、見学案内、歴史解説を掲載。
- **[竹田市歴史文化館](https://okajou.jp/culturalhall/)**（竹田市）
  岡城跡に関する出土品・資料の展示施設ページ。
- **[中津城（奥平家歴史資料館）](https://www.city-nakatsu.jp/doc/2013100100011/)**（中津市）
  中津市公式サイトの案内ページ。天守閣は1964年再建の模擬天守で、館内は奥平家歴史資料館として運営。
- **[中津城公式サイト・沿革](http://www.nakatsujyo.jp/history.html)**（中津城）
  黒田孝高築城から奥平氏入城までの沿革を掲載。※運営は奥平家で、市の発掘調査情報は含まない。
- **[中津市の文化財について](https://www.city-nakatsu.jp/doc/2024101700025/)**（中津市教育委員会）
  市指定文化財の一覧・案内ページ。
- **[臼杵城跡](https://www.city.usuki.oita.jp/docs/2014013100402/)**（臼杵市）
  大友宗麟が1562〜63年頃に築城したとされる丹生島城（亀城）の解説。臼杵公園として整備。
- **[臼杵城跡（文化遺産オンライン）](https://online.bunka.go.jp/heritages/detail/597452)**（文化庁）
  史跡名勝天然記念物として2025年3月10日付で指定された旨のデータベース記載。
- **[角牟礼城跡](https://www.town.kusu.oita.jp/soshiki/shakaikyoikuka/2/5/shiteitouroku/930.html)**（玖珠町教育委員会）
  2005年国史跡指定。土づくりの中世山城から石垣主体の近世城郭への変遷を伝える遺構が特徴。
- **[角牟礼城跡（国指定文化財等データベース）](https://kunishitei.bunka.go.jp/heritage/detail/401/3425)**（文化庁）
  指定区分・指定年月日等の公式データ。
- **[史跡大友氏遺跡](http://www.city.oita.oita.jp/bunkasports/rekishi/otomoshiiseki/)**（大分市教育委員会）
  大友氏館跡を中心とする総合情報サイト。発掘調査記録「掘り出せ大分！大友氏遺跡・中世大友府内町跡発掘記」やガイド事業を掲載。
- **[大友氏遺跡（文化遺産オンライン）](https://online.bunka.go.jp/heritages/detail/207143)**（文化庁）
  史跡指定の概要データ。
- **[大友氏遺跡（国指定文化財等データベース）](https://kunishitei.bunka.go.jp/heritage/detail/401/3307)**（文化庁）
  指定区分・指定年月日等の公式データ。
