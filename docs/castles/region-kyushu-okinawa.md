# 九州・沖縄

九州は筑前・肥前・肥後・豊後・日向・薩摩・大隅など旧国名が多岐にわたり、大宰府防衛のために築かれた大野城跡・水城跡（福岡県）、鞠智城（熊本県）、金田城跡（長崎県・対馬）といった古代山城が複数の県にまたがって残る点が本土の他地方と一線を画す特徴だ。近世城郭でも熊本城・福岡城・佐賀城など規模の大きい城が並び、鹿児島県ではシラス台地を空堀で刻み込む「南九州型城郭」という独自の類型が広く分布する。沖縄県は令制国の枠組みを持たず、城郭も「グスク」と呼ばれる石造の独自形式を取り、首里城・今帰仁城・中城城・座喜味城・勝連城の5件が世界遺産「琉球王国のグスク及び関連遺産群」の構成資産となっている点で九州本土とは系譜が異なる。

資料公開の状況は県によって差が大きい。大分県は中世城館跡分布調査報告書が全4集ともPDFで無料公開され、長崎県も県全域の中近世城館跡分布調査報告書が2巻ともPDF公開、鹿児島県も『鹿児島県の中世城館跡』（1987年）が全国遺跡報告総覧でPDF全文公開されており、資料アクセスの土台が比較的整っている。一方、福岡県・宮崎県は県域を横断する中世城館悉皆調査報告書の所在自体を編纂時点で確認できず、市町村単位の発掘調査報告書や自治体の解説ページに頼る場面が多い。沖縄県には本土型の全県悉皆調査報告書に相当するものがなく、個別グスクの発掘調査報告書が全国遺跡報告総覧に集約される形が中心となっている。

## この地方の資料

- **[福岡県](fukuoka.html)** — 大宰府防衛の古代山城（大野城跡・水城跡）が特徴だが、県レベルの遺跡地図・中世城館悉皆調査報告書の所在は未確認。
- **[佐賀県](saga.html)** — 特別史跡・名護屋城跡と吉野ヶ里遺跡を擁し、県遺跡地図がオンライン公開されているほか名護屋城博物館はオープンデータも提供。
- **[長崎県](nagasaki.html)** — 「長崎県中近世城館跡分布調査報告書」全2巻がPDF公開され、原城跡・日野江城跡が世界遺産構成資産、金田城跡が古代山城の特別史跡。
- **[熊本県](kumamoto.html)** — 近世三城（熊本城・人吉城・八代城）と古代山城・鞠智城を擁し、熊本城は地震復旧に伴う調査報告が年報として継続刊行。
- **[大分県](oita.html)** — 中世城館跡分布調査報告書が全4集PDF公開され資料の充実度が高く、臼杵城跡は2025年に国史跡指定を受けた。
- **[宮崎県](miyazaki.html)** — 佐土原城跡・都於郡城跡が国史跡、飫肥城下町が重伝建に指定される一方、県域横断の悉皆調査報告書は所在未確認。
- **[鹿児島県](kagoshima.html)** — 「南九州型城郭」の分布地域で、知覧城・志布志城・清色城など国史跡クラスの中世城館を複数擁する。
- **[沖縄県](okinawa.html)** — 首里城・今帰仁城・中城城・座喜味城・勝連城の5件が世界遺産構成資産で、本土型の悉皆調査報告書に相当するものは未確認。
