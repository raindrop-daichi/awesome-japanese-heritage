# 鹿児島県の城郭資料

旧薩摩国・大隅国。シラス台地を空堀で幾重にも刻み込む「南九州型城郭」と呼ばれる独特の類型が広く分布する地域で、知覧城・志布志城・清色城など国史跡クラスの中世城館が複数残る。県教委による悉皆調査報告書『鹿児島県の中世城館跡』（1987年）は全国遺跡報告総覧でPDF全文が公開されており、資料アクセスの土台は比較的整っている。

## 遺跡地図・埋蔵文化財

- **[鹿児島県埋蔵文化財分布地図検索システム](https://www2.jomon-no-mori.jp/kmai_public/)**（鹿児島県立埋蔵文化財センター）
  簡易検索・詳細検索・分布図検索の3方式で埋蔵文化財包蔵地の情報を検索できる。市町村合併前の地名で登録されている地点がある旨の注記あり。

## 中世城館調査報告書

- **[鹿児島県の中世城館跡](https://sitereports.nabunken.go.jp/23014)**（鹿児島県教育委員会、1987年3月、鹿児島県埋蔵文化財発掘調査報告書第43集）
  1982〜1986年の悉皆調査をまとめた報告書で、[PDF全文](https://sitereports.nabunken.go.jp/files/attach/31/31872/23014_1_%E9%B9%BF%E5%85%90%E5%B3%B6%E7%9C%8C%E3%81%AE%E4%B8%AD%E4%B8%96%E5%9F%8E%E9%A4%A8%E8%B7%A1.pdf)が全国遺跡報告総覧（奈良文化財研究所）で公開されている。
- **[鹿児島市中世城館跡](https://www.city.kagoshima.lg.jp/kyoiku/kanri/bunkazai/documents/documents/06kagoshimashichuseijokanatoall.pdf)**（鹿児島市教育委員会）
  鹿児島市域の中世城館跡をまとめたPDF。市単位での補完資料として利用できる。

## 調査研究機関

- **[鹿児島県立埋蔵文化財センター](https://www.jomon-no-mori.jp/bunkazai-center/)**
  県内の発掘調査を実施し、発掘調査報告書・埋文だより・紀要『縄文の森から』・フォーラム資料集などを刊行。分布地図検索システムも同センターが運営する。
- **[鹿児島県教育委員会 文化財課](https://www.pref.kagoshima.jp/aa02/kyoiku/soshiki/honcho/bunkazai/index2.html)**
  指定文化財の保存・活用、埋蔵文化財調査、文化財の普及啓発を所管。

## 主要城郭の公式資料

- **鹿児島城（鶴丸城）**
  - **[鹿児島城跡 - 国指定文化財等データベース](https://kunishitei.bunka.go.jp/heritage/detail/401/00004178)**（文化庁）。1931年（昭和6年）史跡指定、2023年（令和5年）に指定地追加。
  - **[日本遺産「薩摩の武士が生きた町」](https://www.city.kagoshima.lg.jp/kyoiku/kanri/bunkazai/kagoshimashinihonisan.html)**（鹿児島市教育委員会）。鹿児島城本丸跡・御楼門を構成文化財の一つとして紹介。
  - **[鹿児島城跡 国史跡指定記念展](https://www.pref.kagoshima.jp/ab10/toushinkinen-kagoshima-c.html)**（鹿児島県）。史跡指定を記念した県内各施設での展示情報。
- **知覧城（南九州市、国史跡）**
  - **[【国指定史跡】知覧城跡](https://www.city.minamikyushu.lg.jp/soshikikarasagasu/rekishibunkazaika/bunkazai/4/2/397.html)**（南九州市教育委員会）。1993年（平成5年）史跡指定、41haのうち約24haが指定範囲。
  - **[【国指定史跡】知覧城跡の発掘調査](https://www.city.minamikyushu.lg.jp/soshikikarasagasu/rekishibunkazaika/bunkazai/4/2/2157.html)**（南九州市教育委員会）。1998〜2005年の発掘調査成果（空堀の深さ、中国・タイ産輸入陶磁器等）。
  - **[知覧城跡 - 国指定文化財等データベース](https://kunishitei.bunka.go.jp/heritage/detail/401/3005)**（文化庁）
- **志布志城（志布志市、国史跡）**
  - **[志布志市の文化財](https://www.city.shibushi.lg.jp/soshiki/22/1483.html)**（志布志市）。志布志城跡を含む市内7件の国指定文化財を紹介。
  - **[志布志城跡 - 国指定文化財等データベース](https://kunishitei.bunka.go.jp/heritage/detail/401/00003460)**（文化庁）
- **清色城（薩摩川内市、国史跡）**
  - **[清色城跡と入来麓伝統的建造物群保存地区](https://www.city.satsumasendai.lg.jp/soshiki/1029/1/1/1583.html)**（薩摩川内市）。入来院氏の城跡で2004年（平成16年）史跡指定、隣接する入来麓は2003年（平成15年）重伝建選定。
  - **[清色城跡 - 国指定文化財等データベース](https://kunishitei.bunka.go.jp/heritage/detail/401/3411)**（文化庁）
