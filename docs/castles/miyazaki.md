# 宮崎県の城郭資料

旧国名は日向。伊東氏・島津氏・土持氏など諸勢力の抗争地で、佐土原城跡・都於郡城跡が国史跡指定を受けているほか、飫肥城下町は重要伝統的建造物群保存地区に指定されている。一方で県域を横断する中世城館の悉皆調査報告書はオンラインで所在を確認できず、資料は個別の発掘調査報告書と自治体の解説ページに散在している状態だ。

## 遺跡地図・埋蔵文化財

- **[文化財マップ（みやざき文化財情報）](https://www.miyazaki-archive.jp/d-museum/mch/bunka_map)**（宮崎県教育委員会）
  国指定・国登録・国選定・県指定の文化財を県北・県中・県南・県西の4地域に分けて地図検索できる。史跡区分に佐土原城跡等の国史跡も含まれるが、※市町村悉皆の埋蔵文化財包蔵地（未指定の中世山城跡を含む）を網羅したGISではない点に注意。

## 中世城館調査報告書

県教育委員会による県域横断の中世城館跡分布調査報告書は、全国遺跡報告総覧・県教委サイトいずれでも所在を確認できず、実在未確認とする。代わりに個別の発掘調査報告書がPDF公開されている。

- **[史跡穆佐城跡（宮崎市文化財調査報告書第114号）](https://sitereports.nabunken.go.jp/ja/search/item/22497?f_set=45)**（宮崎市教育委員会、2016年3月刊）
  穆佐城跡保存整備事業に伴う発掘調査報告書。PDF2種（通常版・モバイル版）を公開。
- **[佐土原城跡第6次調査（宮崎市文化財調査報告書第109号）](https://sitereports.nabunken.go.jp/ja/search/item/22491?f_set=45)**（宮崎市教育委員会、2016年3月刊）
  佐土原中学校公民館・城の駅建設事業に伴う調査報告書。PDF公開。
- **[佐土原城跡第8次調査（宮崎市文化財調査報告書第107号）](https://sitereports.nabunken.go.jp/ja/search/item/22489?f_set=45)**（宮崎市教育委員会、2015年3月刊）
  佐土原変電所増強工事に伴う調査報告書。PDF公開。

## 調査研究機関

- **[宮崎県埋蔵文化財センター](https://www.miyazaki-archive.jp/maibun/)**（宮崎県教育委員会）
  本館・分館からなる県の埋蔵文化財調査機関。展示・出前講座のほか刊行物を公開。
- **[発掘調査報告書一覧](https://www.miyazaki-archive.jp/maibun/reportlist/)**（宮崎県埋蔵文化財センター）
  センター発行の報告書第1号〜第97号をPDFで一覧公開。高鍋城跡・本城跡・上日置城空堀跡・三俣城北東曲輪跡など城館関連の調査報告も含む。

## 主要城郭の公式資料

- **[日南市飫肥伝統的建造物群保存地区](https://www.city.nichinan.lg.jp/museum/kunishiteitoubunnkazai/kennzoubutsu_sekizoubutsu/5/index.html)**（日南市文化遺産ミュージアム）
  飫肥城下町が重要伝統的建造物群保存地区として掲載されている。※飫肥城そのものを単独で扱う解説ページは同サイト内に見当たらず、伝建地区ページへの統合掲載にとどまる。
- **[延岡城跡関連情報（延岡市文化財・市史編さん課）](https://www.city.nobeoka.miyazaki.jp/soshiki/62/43112.html)**（延岡市教育委員会）
  江戸期の延岡藩主・有馬氏時代の城下を再現したCG映像の公開案内。※このページ自体に県史跡指定の明記はなく、指定根拠は別途要確認。
- **[国史跡佐土原城跡・穆佐城跡パンフレット](https://www.city.miyazaki.miyazaki.jp/culture/art/376870.html)**（宮崎市教育委員会文化財課）
  佐土原城跡パンフレット（PDF）と佐土原城跡・穆佐城跡合本パンフレット（PDF）の2点を公開。
- **[都於郡歴史館について](https://www.city.saito.lg.jp/kanko_bunka/cat177/post_1620.html)**（西都市）
  国指定史跡・都於郡城跡を、伊東氏の領国支配拠点として解説する令和6年開館の展示施設紹介ページ。伊東マンショ関連展示にも言及。

## デジタルアーカイブ

- **[みやざきデジタルミュージアム](https://www.miyazaki-archive.jp/d-museum/)**（宮崎県教育委員会）
  考古・歴史（文書・絵図）・民俗・美術などのカテゴリで資料を横断検索できるポータル。「絵図（地図）」区分があり城絵図等を含む可能性があるが、城郭専用の分類ではない。
