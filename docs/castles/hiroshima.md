# 広島県の城郭資料

広島県（安芸・備後）は毛利氏の吉田郡山城、小早川氏の三原城・新高山城など戦国期の重要城郭を擁する。県教委の『広島県中世城館遺跡総合調査報告書』（1993〜1996、全4巻）はPDF未公開だが、**県遺跡地図のWeb公開**と、浅野家伝来の城絵図集「諸国古城之図」のデジタル公開が強み。

## 遺跡地図・埋蔵文化財

- **[広島県遺跡地図](https://www.pref.hiroshima.lg.jp/site/bunkazai/bunkazai-map-map.html)**（広島県教育委員会 文化財課）
  国・県指定史跡と周知の埋蔵文化財包蔵地（城跡を含む）を色分け表示するWeb地図。※**営利目的の利用は不可**と明記

## 中世城館調査報告書

- **[『広島県中世城館遺跡総合調査報告書』（広島県教育委員会、1993〜1996、全4巻）](https://sitereports.nabunken.go.jp/ja/107973)**（全国文化財総覧の書誌ページ）
  ※編纂時点で書誌情報のみで**PDF本文は未公開**とみられる。原本は国立国会図書館・県立図書館等で確認のこと

## 調査研究機関

- **[遺跡探訪のへや（広島県教育事業団 埋蔵文化財調査室）](https://www.harc.or.jp/)**（公益財団法人 広島県教育事業団）
  県内発掘調査の実施主体。刊行物・発掘ニュースを掲載。

## 主要城郭の公式資料

- **[広島城（広島市の史跡案内）](https://www.city.hiroshima.lg.jp/tourism-culture/history/1026883/1026891/index.html)**（広島市） / **[広島城公式サイト](https://hiroshimacastle.jp/)**（広島城アソシエイツ）
  国史跡。市の行政案内と、展示・観覧の公式サイト。
- **[福山城](https://www.city.fukuyama.hiroshima.jp/site/miryoku2023/287233.html)**（福山市）
  伏見櫓・筋鉄御門（いずれも重要文化財）の解説。[ふくやま文化財ナビ](https://fukubun.net/)にも福山城関連コンテンツあり。
- **[吉田郡山城跡（毛利氏城跡）](https://www.akitakata.jp/ja/shisei/section/kyouiku/shisekibunkazai/cultural_asset/siseki_kuni/mourisisiroato/kouriyamajyouato/)**（安芸高田市）
  国史跡。毛利氏の本拠だった全山城郭化した巨大山城。
- **[三原城跡](https://www.city.mihara.hiroshima.jp/soshiki/50/139854.html)**（三原市）
  国史跡（小早川氏城跡、1957年指定）。海に浮かぶ天主台等の現存遺構。[新高山城跡（三原観光naviの案内）](https://www.mihara-kankou.com/sightseeing/3208)も併せて。

## デジタルアーカイブ（城絵図）

- **[広島県立文書館 データベースシステム](https://archives.pref.hiroshima.lg.jp/hiroshima_archives/)**（広島県）
  行政文書・古文書・画像DB等9種を横断検索。[地図・絵図資料の解説PDF](https://www.pref.hiroshima.lg.jp/soshiki_file/monjokan/information/03ezu.pdf)は広島城下絵図の所在目録として有用。
- **[諸国古城之図（Webギャラリー）](https://www.library.city.hiroshima.jp/hiroshima/webgallery/kojo.html)**（広島市立図書館）
  旧広島藩主浅野家伝来の城絵図集。**廃城となった諸国の古城177枚**を描いた全国的にも貴重な絵図群。[貴重資料アーカイブ（ADEAC）](https://adeac.jp/hiroshima-city-lib/top/)でデジタル画像を公開。
