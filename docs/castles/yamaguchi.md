# 山口県の城郭資料

山口県（周防・長門）は大内氏・毛利氏の本拠地。県教委の『山口県中世城館遺跡総合調査報告書』（長門国編2017・周防国編2018）があり、県遺跡地図は**オープンデータ（GeoJSON）として公開**されているのが特徴。

## 遺跡地図・埋蔵文化財

- **[山口県遺跡地図（オープンデータカタログ）](https://yamaguchi-opendata.jp/ckan/dataset/iseki-test)**（山口県 文化振興課）
  県内の埋蔵文化財包蔵地をGeoJSON/XLSX形式で公開。継続更新中。※ライセンスは **CC BY-NC-ND**（非営利・改変禁止）のため、二次加工したデータの公開は不可。インタラクティブなWebGIS画面は未確認
- **[山口市埋蔵文化財地図](https://www.city.yamaguchi.lg.jp/soshiki/110/124568.html)**（山口市 文化財保護課）
  市内512遺跡を収録した地図をPDF分割で公開。

## 中世城館遺跡総合調査報告書

- **[『山口県中世城館遺跡総合調査報告書 長門国編』（2017）](https://sitereports.nabunken.go.jp/ja/97203)**（山口県教育委員会、全国文化財総覧の書誌ページ）
  旧長門国域の城館遺跡の悉皆調査。
- **[『同 周防国編』（2018）](https://sitereports.nabunken.go.jp/ja/54361)**（同上）
  旧周防国域217ヶ所のうち城館・要害66ヶ所を詳報。
  ※両編とも編纂時点で書誌ページからのPDF直接ダウンロードは確認できず。公開状況は各ページで要確認

## 調査研究機関

- **[まいぶん山口（山口県埋蔵文化財センター）](https://www.y-maibun.jp/)**（公益財団法人 山口県ひとづくり財団）
  発掘調査速報・刊行物・展示案内。[「やまぐちの遺跡」データベース](https://www.y-maibun.jp/ruins/)でセンターが調査した遺跡・史跡を検索できる。

## 主要城郭の公式資料

- **[大内氏遺跡 附 凌雲寺跡（大内氏館・高嶺城）](https://www.city.yamaguchi.lg.jp/rs/rekibunshigen/r1062.html)**（山口市 文化財保護課）
  国史跡（1959年指定）。大内氏館跡と、毛利氏来襲に備え1556年に大内義長が築いた高嶺城跡。
- **[萩城城下町（文化遺産オンライン）](https://online.bunka.go.jp/heritages/detail/139557)**（文化庁）
  国史跡（1967年指定）。武家屋敷群・旧宅の来歴。※萩城跡単体の萩市公式解説ページは編纂時点で未特定
- **[いわくに文化財探訪](https://iwakuni-bunkazai.jp/)**（岩国市 文化財課）
  岩国城跡の発掘調査・現地説明会情報を含む市の文化財総合サイト。

## デジタルアーカイブ

- **[山口県文書館 絵図・地図検索](https://archives.pref.yamaguchi.lg.jp/document-search/maps/)**（山口県文書館）
  **毛利家文庫絵図・袋入絵図 計2,103点**を検索できる。萩藩作成の防長絵図が中心で、城絵図も含まれるとみられる。
- **[WEB版明治維新資料室](https://adeac.jp/yamaguchi-pref-lib/top/)**（山口県立山口図書館・山口県文書館）
  明治維新関係資料460点をデジタル化。絵地図を含む。
