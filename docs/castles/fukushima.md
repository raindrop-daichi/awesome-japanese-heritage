# 福島県の城郭資料

福島県は旧陸奥国の一部で、会津地方（岩代国）・中通り（岩代国東部〜磐城国北部）・浜通り（磐城国）の3地域からなる。会津は蒲生氏郷・保科正之ゆかりの近世城郭と葦名氏以来の中世山城が密集し、中通りは白河・二本松・三春など奥州街道沿いの藩庁城下町、浜通りは相馬氏・磐城平の海道筋城郭が特徴だ。県レベルの統合遺跡地図GISは見当たらず、全国遺跡報告総覧で県教委の中世城館跡分布調査PDFが公開されている点が資料状況のハイライトになる。

## 遺跡地図・埋蔵文化財

- **[文化財課](https://www.pref.fukushima.lg.jp/sec/70017a/)**（福島県）
  県の文化財行政の窓口ページ。埋蔵文化財包蔵地に関する照会先はここに集約されているが、県全域を対象にしたオンライン遺跡地図（WebGIS）は本ページ内には見当たらない。
- **[文化財総覧WebGIS](https://heritagemap.nabunken.go.jp/)**（奈良文化財研究所）
  全国横断のWebGISで福島県内の遺跡・城館跡も検索可能。県独自GISが手薄な現状では実質的な代替手段になる。
- **[ふくしまeマップ 埋蔵文化財包蔵地](https://www.sonicweb-asp.jp/fukushimacity/map?theme=th_26)**（福島市）
  福島市域に限定した埋蔵文化財包蔵地の地図公開。県内では市町村単位のGIS公開例として参考になる。

## 中世城館調査報告書

- **[福島県の中世城館跡](https://sitereports.nabunken.go.jp/en/89590)**（福島県教育委員会）
  全国遺跡報告総覧上で[PDF本文](https://sitereports.nabunken.go.jp/files/attach_mobile/50/50495/89590_1_%E7%A6%8F%E5%B3%B6%E7%9C%8C%E3%81%AE%E4%B8%AD%E4%B8%96%E5%9F%8E%E9%A4%A8%E8%B7%A1.pdf)が公開されている。県内中世城館の悉皆的な分布調査成果。
- **[史跡若松城跡](https://sitereports.nabunken.go.jp/en/39583)**（会津若松市教育委員会、会津若松市文化財調査報告書第113号、2008年）
  若松城跡（鶴ヶ城）の発掘調査成果をまとめた個別報告書。PDF本文の公開有無は個票側で要確認。

## 調査研究機関

- **[福島県文化財センター白河館「まほろん」](https://www.fcp.or.jp/mahoron/)**（公益財団法人福島県文化振興財団）
  県内出土遺物の展示・体験学習を行う中核施設。発掘調査成果の公開拠点でもある。
- **[遺跡調査部](https://www.fcp.or.jp/iseki/)**（福島県文化振興財団）
  県内の発掘調査を担う部門。調査情報・刊行物ページの起点。

## 主要城郭の公式資料

- **[会津若松市の史跡一覧＜国指定文化財＞ 若松城跡(鶴ヶ城)](https://www.city.aizuwakamatsu.fukushima.jp/docs/2012110600030/)**（会津若松市）
  国史跡若松城跡の指定範囲・概要を掲載する公式ページ。
- **[会津若松市内の文化財](https://www.city.aizuwakamatsu.fukushima.jp/docs/2012100500043/)**（会津若松市）
  若松城跡を含む市内文化財の一覧・案内ページ。
- **[小峰城跡【こみねじょうあと】](https://www.city.shirakawa.fukushima.jp/page/page001390.html)**（白河市）
  国史跡白河小峰城跡の指定経緯・整備の概要を紹介する公式ページ。
- **[小峰城歴史館](https://www.city.shirakawa.fukushima.jp/page/dir000502.html)**（白河市）
  発掘調査・復元整備の成果を展示する史跡整備係所管の関連施設案内。

  国史跡二本松城跡の歴史・概要・発掘調査成果を紹介する公式サイト。※ `http://` でのみアクセス可（https非対応）。
- **[史跡向羽黒山城跡整備計画書（2011年）](https://www.town.aizumisato.fukushima.jp/material/files/group/9/20110606-134611.pdf)**（会津美里町教育委員会）
  国史跡向羽黒山城跡の保存・整備方針をまとめたPDF計画書。
- **[向羽黒山城跡](https://www.town.aizumisato.fukushima.jp/soshiki/1007/6/3/1219.html)**（会津美里町）
  向羽黒山城跡の概要と関連情報を掲載する公式ページ。
