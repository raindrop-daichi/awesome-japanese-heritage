# 佐賀県の城郭資料

佐賀県は肥前国の東部にあたり、佐賀城・唐津城の近世城郭と、豊臣秀吉の朝鮮出兵拠点として築かれた特別史跡・名護屋城跡、さらに弥生時代の環壕集落として世界的に知られる特別史跡・吉野ヶ里遺跡を擁する。県遺跡地図はオンライン公開されており、唐津市の発掘調査報告書はPDFが継続的に公開されている点が特徴だ。名護屋城博物館はオープンデータ提供にも取り組んでいる。

## 遺跡地図・埋蔵文化財

- **[佐賀県遺跡地図](https://www.pref.saga.lg.jp/kiji0031873/index.html)**（佐賀県地域交流部 文化・観光局 文化課 文化財保護・活用室）
  1970年代の詳細分布調査を基に2009年に改訂され、その後の新発見も反映して更新中。遺跡を赤色、消滅済みの遺跡を青色で表記する。※「表示された分布範囲がすべて正確というわけではない」旨の注記あり。周知の埋蔵文化財包蔵地での土木工事は着手60日前までの届出が必要。
- **[佐賀県遺跡地図 検索画面](https://www.pref.saga.lg.jp/kiji0031880/index.html)**（同上）
  地図検索インターフェース。市町・地区別の絞り込みが可能。
- **[唐津デジタルマップ：埋蔵文化財（遺跡）分布マップ](https://www.sonicweb-asp.jp/karatsu/map?theme=th_32)**（唐津市）
  唐津市域に限定した埋蔵文化財包蔵地の分布をWebGISで閲覧できる。名護屋城跡周辺・唐津城跡周辺の詳細確認に有用。

## 中世城館調査報告書

- **[佐賀県の中近世城館](https://sitereports.nabunken.go.jp/ja/98614)**（佐賀県教育委員会、佐賀県文化財調査報告書第192集、2011年3月）
  「佐賀県中近世城館跡緊急分布調査報告書」。全国文化財総覧に書誌情報が登録されているが、編纂時点（2026-08-02）でファイルダウンロード数は0件と表示され、**PDF未公開・書誌情報のみ**。現物は佐賀県立図書館等での閲覧を要確認。
- **[全国文化財総覧：佐賀県 発行報告書一覧](https://sitereports.nabunken.go.jp/ja/list/41/41)**（奈良文化財研究所）
  佐賀県・県内市町教委発行の発掘調査報告書一覧。個別城郭の発掘報告書を探す入口。

## 調査研究機関

- **[佐賀県立佐賀城本丸歴史館](https://saga-museum.jp/sagajou/)**（佐賀県）
  幕末維新期の佐賀を伝える県立博物館。天保期の本丸御殿遺構を保護しつつ本丸御殿を日本で初めて復元。「歴史館ゼミナール」等で発掘調査に関する研究活動を発信している。
- **[佐賀県立名護屋城博物館](https://saga-museum.jp/nagoya/)**（佐賀県）
  特別史跡名護屋城跡と日朝関係史を専門とする県立博物館。図録・研究紀要の販売のほか、後述のオープンデータ提供に取り組む。

## 主要城郭の公式資料

- **[名護屋城跡（佐賀県立名護屋城博物館）](https://saga-museum.jp/nagoya/nagoya-castle/nagoya.html)**（佐賀県立名護屋城博物館）
  1591年築城、文禄・慶長の役の拠点。本丸御殿跡（礎石・玉石敷）、天守台（礎石16箇所・穴蔵石垣）、山里丸（茶室跡）等の発掘調査成果を解説。「諸大名の陣跡」「保存整備事業」「バーチャル名護屋城」への関連リンクあり。
- **[オープンデータ｜佐賀県立名護屋城博物館](https://saga-museum.jp/nagoya/information/opendata.html)**（佐賀県立名護屋城博物館）
  所蔵資料画像を営利・非営利問わず無償で複製・二次利用可能な形で公開。利用時は「佐賀県立名護屋城博物館所蔵」の明示と同館への二次利用報告が必須。AIデータへの取り込みや明度・彩度等の改変は禁止。
- **[佐賀城跡（6区・天守台の調査）](https://sitereports.nabunken.go.jp/ja/35432)**（佐賀市教育委員会、2015年3月31日）
  佐賀城天守台の発掘調査報告。全国文化財総覧に書誌登録されているが、編纂時点でPDF直接ダウンロードは未提供。
- **[唐津城跡12](https://sitereports.nabunken.go.jp/ja/146789)**（唐津市文化財調査報告書199、2026年3月31日）
  唐津市教育委員会による唐津城跡の発掘調査報告書。PDF公開あり（本編21.1MB、モバイル版8.0MB）。同シリーズで唐津城跡本丸・下町跡等の報告書がPDF公開で継続刊行されている。
- **[唐津城の紹介](https://www.city.karatsu.lg.jp/page/1041.html)**（唐津市 観光課）
  慶長13年（1608）築城の経緯、廃藩置県後の舞鶴公園化、天守閣復興（1966年）の沿革を紹介。修復工事に伴う調査で発見された旧石垣についても言及。
- **[吉野ヶ里歴史公園](https://www.pref.saga.lg.jp/kiji00313455/index.html)**（佐賀県）
  弥生時代の環壕集落跡を保存・活用する国営・県営一体の歴史公園（総面積約117ha）。特別史跡。有柄銅剣・ガラス製管玉など国重要文化財の出土にも言及。

## デジタルアーカイブ

- **[佐賀県立図書館データベース](https://www.sagalibdb.jp/)**（佐賀県立図書館）
  2011年度公開、2018年度リニューアル。古文書・絵図等の歴史資料約28,000画像がパブリックドメインとして公開されており、一部はIIIF対応。古地図・絵図データベース（[/ezu](https://www.sagalibdb.jp/ezu)）に城絵図が含まれる可能性が高いが、JavaScript描画のため編纂時点で個別資料の詳細は自動検証未確認。
