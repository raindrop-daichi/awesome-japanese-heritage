# 兵庫県の城郭資料

兵庫県は播磨・但馬・丹波・摂津・淡路の旧五国にまたがり、中世山城の密集地帯。県教育委員会による悉皆調査（1982年）の蓄積があり、県立考古博物館・県立歴史博物館が資料公開の中心を担う。

## 遺跡地図・埋蔵文化財

- **[兵庫県遺跡地図](https://www.hyogo-koukohaku.jp/modules/info/index.php?action=PageView&page_id=19)**（兵庫県立考古博物館）
  遺跡地名表（PDF・Excel）と指定文化財一覧表を公開。インタラクティブGISではなく静的ファイル配布形式。城館跡を含む周知の埋蔵文化財包蔵地の基礎台帳。
- **[兵庫県埋蔵文化財情報「ひょうごの遺跡」](https://www.hyogo-ctc.or.jp/iseki/)**（公益財団法人 兵庫県まちづくり技術センター）
  発掘調査成果を紹介する広報誌のバックナンバー（113号以上）をPDF公開。
- **[兵庫県教育委員会 文化財課（埋蔵文化財）](https://www2.hyogo-c.ed.jp/hpe/bunka/maizobunkazai)**（兵庫県教育委員会）
  埋蔵文化財の届出手続き案内。県事業の調査は考古博物館、市町事業は各市町教委が担当という役割分担が分かる。

## 中世城館調査報告書

- **[『兵庫県の中世城館・荘園遺跡』（1982年・兵庫県教育委員会）](https://sitereports.nabunken.go.jp/ja/67664)**（全国遺跡報告総覧の書誌ページ）
  1982年の中世城館・荘園遺跡緊急悉皆調査の報告書。※編纂時点で書誌ページからのPDF直接ダウンロードは確認できず。現物は県立考古博物館等で閲覧可
- **[全国遺跡報告総覧：兵庫県教育委員会 発行報告書一覧](https://sitereports.nabunken.go.jp/ja/list/28/28000)**（奈良文化財研究所）
  「兵庫県文化財調査報告」シリーズを中心に発掘調査報告書PDFをダウンロード可能。城郭関連報告書を探す包括的な入口。
- **[兵庫県立考古博物館 刊行物（発掘調査報告書）](https://www.hyogo-koukohaku.jp/modules/book/index.php?action=PageList&category_id=5)**（兵庫県立考古博物館）
  県教委実施の発掘調査報告書一覧。報告書は非売品で、PDF実体は全国遺跡報告総覧側で公開されることが多い。

## 県の歴史・文化財ポータル

- **[ひょうご歴史ステーション](https://www.hyogo-c.ed.jp/~rekihaku-bo/historystation/index-sp.html)**（兵庫県立歴史博物館）
  デジタル展覧会・収蔵品紹介などを束ねる歴史文化ポータル。城郭研究情報への導線あり。
- **[兵庫県内の城郭データベース](https://rekihaku.pref.hyogo.lg.jp/castle/)**（兵庫県立歴史博物館）
  播磨8城・淡路1城・但馬2城・丹波2城・摂津2城の計24城を写真・解説・地図付きで紹介。網羅的データベースというより厳選ガイド。

## 主要城郭の自治体公式資料

- **[姫路城 保存活用計画](https://www.city.himeji.lg.jp/kanko/0000030274.html)**（姫路市）
  特別史跡・国宝建造物・世界遺産バッファーゾーンを統合した保存活用計画（2025年文化庁認定）。全13章＋付属資料のPDF一式をダウンロード可能。一次資料として質・分量ともに充実。
- **[竹田城跡（朝来市 文化財課）](https://www.city.asago.hyogo.jp/soshiki/35/)**（朝来市教育委員会）
  竹田城跡の保護・管理・整備を所管する部署ページ。発掘調査の現地説明会資料等は個別ページから。
- **[明石城跡](https://www.city.akashi.lg.jp/bunka/b_shinkou_ka/akashijyouato.html)**（明石市）
  国指定史跡・明石城跡の概要。1619年築城開始、天守未建設のまま天守台のみ現存という沿革を記載。
- **[篠山城跡](https://www.city.tambasasayama.lg.jp/soshikikarasagasu/shinbunkazai/sasayamajo/2858.html)**（丹波篠山市教育委員会）
  国指定史跡篠山城跡（1956年指定）の公式解説。1609年築城、石垣・堀等の現況。
- **[龍野城](https://www.city.tatsuno.lg.jp/soshiki/1026/gyomu/2/1/2831.html)**（たつの市）
  鶏籠山山頂の中世山城跡と麓の近世平山城の2期構成を解説。※所管が文化財課ではなく都市公園（都市計画課）である点に注意
