# 山形県の城郭資料

旧国名は羽前（村山・置賜・庄内の一部）・羽後（庄内の一部）にまたがる。最上氏の山形城、上杉氏の米沢城、庄内酒井氏の鶴ヶ岡城という三つの藩庁城が県内に分立していたのが特徴だ。県教育委員会による中世城館遺跡調査報告書が置賜・村山・庄内最上の3地域に分けて刊行され、いずれもPDFで全巻公開されている点は資料状況として恵まれている。

## 遺跡地図・埋蔵文化財

- **[山形の宝マップ](https://www.pref.yamagata.jp/020077/bunkyo/bunka/bunkazai/yamagatanotakaramap.html)**（山形県）
  埋蔵文化財包蔵地（遺跡）、国・県指定文化財、国登録文化財の位置情報を統合したArcGIS Online製のGISマップ。2026年1月にGISデータのエクスポート機能が追加された。利用には利用規約への同意が必要。
- **[山形県遺跡地図](https://www.pref.yamagata.jp/020077/bunkyo/bunka/bunkazai/bunkazainewstop/yamagataiseki/index.html)**（山形県）
  旧来のPDF版遺跡地図の案内ページ。現行の位置情報提供は上記「山形の宝マップ」に統合されている。

## 中世城館調査報告書

- **[山形県中世城館遺跡調査報告書](https://sitereports.nabunken.go.jp/ja/6284)**（山形県教育委員会、1995年3月）
  置賜地域を対象とした第1冊。全国遺跡報告総覧でPDF公開（標準49.4MB／モバイル版12.3MB）。
  ※続刊として村山地域編（1996年3月）・庄内最上地域編（1997年3月）が刊行されている（全国遺跡報告総覧の同シリーズ内で参照可能）。

## 調査研究機関

- **[公益財団法人山形県埋蔵文化財センター](https://yamagatamaibun.or.jp/)**
  県内の発掘調査全般を担う公益財団法人。
- **[発掘調査報告書一覧](https://yamagatamaibun.or.jp/?page_id=25913)**（同センター）
  1994年から現在まで250件超の発掘調査報告書を年次別に掲載し、全国遺跡報告総覧の該当ページへリンクしている。公開PDFは画質を落とした版で、高精細版は同センターまたは図書館での閲覧案内がある。

## 主要城郭の公式資料

- **[霞城公園（国指定史跡山形城跡）について](https://www.city.yamagata-yamagata.lg.jp/kurashi/koen/1006541/1006545/1015528.html)**（山形市）
  1986年に国史跡指定。史料調査と発掘調査の成果に基づく本丸復元事業の解説、発掘調査現地説明会資料へのリンクを掲載。
- **[山形城跡発掘調査報告書](https://sitereports.nabunken.go.jp/ja/5737)**（山形市教育委員会、1981年3月）
  霞城公園内の夜間照明設備工事に伴う1979年の緊急発掘調査の報告書。PDF公開（標準12.6MB）。
- **[鶴ヶ岡城跡発掘調査報告書](https://sitereports.nabunken.go.jp/ja/6246)**（財団法人山形県埋蔵文化財センター調査報告書第99集、2002年3月）
  鶴ヶ岡城跡の発掘成果をまとめた報告書。PDF公開（標準161.7MB／モバイル版29.9MB）。
- **[鶴岡公園（鶴ヶ岡城址）｜酒井家ゆかりの地](https://www.city.tsuruoka.lg.jp/static/sakai400th/yukarinochi/tsuruokakouen.html)**（鶴岡市）
  庄内藩主酒井家の居城としての沿革解説。
- **[鶴岡市内 指定文化財一覧](https://www.city.tsuruoka.lg.jp/bunka/rekishi/shitei-bunka-ichiran.html)**（鶴岡市）
  鶴ヶ岡城跡を含む市内指定文化財の目録。
- **[市長のやまがた自慢「長谷堂城跡」](https://www.city.yamagata-yamagata.lg.jp/shiseijoho/shicho/1006787/1006792/1005474.html)**（山形市）
  1600年の長谷堂合戦の舞台となった山城の解説。土塁・曲輪など遺構が残る城址公園としての現況を紹介。

## デジタルアーカイブ

- **[デジタルライブラリー](https://www.lib.pref.yamagata.jp/%E3%82%84%E3%81%BE%E3%81%8C%E3%81%9F%E3%81%AE%E6%83%85%E5%A0%B1/%E3%83%87%E3%82%B8%E3%82%BF%E3%83%AB%E3%83%A9%E3%82%A4%E3%83%96%E3%83%A9%E3%83%AA%E3%83%BC)**（山形県立図書館）
  貴重資料のデジタル画像を公開。県関連の絵図資料も一部（15点）公開されているが、城下絵図と明記されたものかは要個別確認。
- **[「明和六年 米沢城下絵図」デジタルマップ](https://www.denkoku-no-mori.yonezawa.yamagata.jp/digital-map/index.html)**（米沢市上杉博物館「伝国の杜」）
  1769年作成の米沢城下絵図と現代地図を重ね合わせて閲覧できるデジタルマップ。実測図ではないため現代地図とは最大100m程度のズレがある旨の注記あり。
