# 栃木県の城郭資料

旧国名は下野（しもつけ）。宇都宮氏・皆川氏・佐野氏・那須氏・那須七党など在地国衆が割拠し、平地の宇都宮城、山城の唐沢山城、方形居館の足利氏館（鑁阿寺）と類型の異なる城郭が揃うのが特徴だ。県レベルの中世城館悉皆調査（1982年）は全国遺跡報告総覧に書誌情報のみ登録されておりPDF未公開だが、より古い遺跡目録（1963・1968年）はPDFが全文公開されている。

## 遺跡地図・埋蔵文化財

- **[埋蔵文化財包蔵地の取扱いと手続き｜とちぎの文化財](https://bunkazai.pref.tochigi.lg.jp/information/502/)**（栃木県教育委員会文化財課）
  「栃木県埋蔵文化財地図」の存在に言及しているが、このページ自体はオンラインGISや検索機能を提供していない。※県レベルの統合WebGISは実在未確認。県内約半数の市町が独自に分布調査地図を作成しているとされるが、市町ごとの公開状況は個別確認が必要。

## 中世城館調査報告書

- **[栃木県の中世城館跡](https://sitereports.nabunken.go.jp/ja/list/09/09000/p/5/item/115551?sort=id:r)**（栃木県文化振興事業団、1982年）
  中世城館を対象とした県レベルの悉皆調査報告書。全国遺跡報告総覧に書誌情報のみ登録されており、PDF未公開（ファイルダウンロード数0）。
- **[栃木県遺跡目録](https://sitereports.nabunken.go.jp/ja/71489)**（栃木県教育委員会、1963年）
  県教委による最初期の埋蔵文化財関連報告書。1,036件の遺跡を収録し、PDFが全文公開されている。
- **[栃木県遺跡目録集成](https://sitereports.nabunken.go.jp/ja/88680)**（栃木県教育委員会、1968年）
  上記の増補改訂版で、1967年度調査分を加え遺跡番号1750番まで拡張。PDFが全文公開されている。
- **[栃木県埋蔵文化財地図](https://sitereports.nabunken.go.jp/en/87179)**（栃木県教育委員会事務局文化課、1997年）
  地図としての報告書だが、全国遺跡報告総覧上は書誌情報のみでPDF未公開。

## デジタルアーカイブ

- **[デジタル史料室｜栃木県立文書館](https://www.pref.tochigi.lg.jp/m58/education/bunka/monjyokan/shiryoushitsu.html)**
  中世〜近代の古文書を時代別に整理しPDF公開（画像・釈文・解説付き）。中世は戦国期の書状・禁制などを収録。城郭に直接関わる絵図の有無はページ上からは未確認で個別閲覧が必要。
- **[栃木県立図書館デジタルコレクション](http://www.lib.pref.tochigi.lg.jp/?page_id=455)**
  貴重書・行政資料をデジタル化して公開。城絵図の収蔵有無はトップページからは判断できず、個別確認が必要。
