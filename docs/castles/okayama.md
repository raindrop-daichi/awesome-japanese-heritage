# 岡山県の城郭資料

岡山県（備前・備中・美作）は、県教委が2020年に『岡山県中世城館跡総合調査報告書』（全3冊）を刊行し、**縄張り図付きの悉皆調査報告書PDFを全巻公開している**、資料公開の先進県。古代山城の鬼ノ城、現存天守の備中松山城も擁する。

## 遺跡地図・埋蔵文化財

- **[おかやま全県統合型GIS](https://www.gis.pref.okayama.jp/)**（岡山県）
  「埋蔵文化財（遺跡）」レイヤーで城跡を含む周知の埋蔵文化財包蔵地の所在・概要を閲覧できる（[案内ページ](https://www.pref.okayama.jp/page/detail-27410.html)）。※レイヤーごとに利用許諾への同意が必要な仕様のため、トップページ経由でリンク

## 中世城館調査報告書

- **[『岡山県中世城館跡総合調査報告書』（岡山県教育委員会、2020）](https://www.pref.okayama.jp/site/kodai/670342.html)**（岡山県古代吉備文化財センター）
  備前編・備中編・美作編の全3冊。**城館跡の位置図・縄張り図と関連史料を収録したPDFを全巻ダウンロード可能**（第1巻・備前編は約37MB、モバイル対応版あり）。都道府県悉皆調査の公開例として全国的にも模範的。
- **[同報告書（全国文化財総覧の書誌ページ）](https://sitereports.nabunken.go.jp/ja/115571)**（奈良文化財研究所）
  横断検索用のエントリ。こちらからもPDFに到達できる。

## 調査研究機関

- **[岡山県古代吉備文化財センター](https://www.pref.okayama.jp/site/kodai/)**（岡山県）
  県の埋蔵文化財調査の拠点。発掘調査報告書・年報・紀要等を「デジタル図書室」で公開。中世城館跡総合調査の実務主体。

## 主要城郭の公式資料

- **[鬼ノ城（古代吉備文化財センターの解説）](https://www.pref.okayama.jp/site/kodai/632641.html)**（岡山県）
  国史跡の古代山城（7世紀後半）。城壁延長2.8km、日本初確認の角楼跡など発掘調査成果を専門的に解説。発掘調査報告書へのリンクあり。[総社市観光協会の案内ページ](https://soja-kankou.com/kinojocastle/)も併せて。
- **[備中松山城の史跡指定遺構](https://www.city.takahashi.lg.jp/site/bichu-matsuyama/shiseki.html)**（高梁市教育委員会）
  現存12天守で唯一の山城。大松山城跡・天神の丸跡など城内8ヶ所の遺構を解説。
- **[岡山城](https://okayama-castle.jp/)**（岡山城ビジターズ&コンベンション協会）
  公式サイト。歴史解説・歴代城主・「令和の大改修」（2022）情報。※観光ガイド的な位置づけで、発掘調査資料は古代吉備文化財センター側を参照
- **[津山城（津山市 文化財ページ）](https://www.city.tsuyama.lg.jp/city/index2.php?id=3085)**（津山市）
  森忠政が築いた近世平山城。※編纂時の自動確認ではページ本文を十分に取得できなかったため、内容はブラウザでの確認を推奨

## デジタルアーカイブ

- **[デジタル岡山大百科](https://adeac.jp/okayama-pref-digioka/top/)**（岡山県立図書館）
  「絵図・古地図」コーナーで国絵図・城下図・城絵図（津山城古図等）を公開。岡山大学附属図書館の池田家文庫絵図（大坂城・赤穂城等の城絵図を含む）にもここから到達できる。※旧URL（digioka.libnet〜）は移転済みのため注意
