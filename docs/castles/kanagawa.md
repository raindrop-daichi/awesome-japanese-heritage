# 神奈川県の城郭資料

旧国名では相模国の全域と武蔵国の一部（横浜・川崎)を占める。後北条氏の本拠・小田原城とその支城網が中心で、総構（そうがまえ）研究が全国的に見ても厚い自治体の一つだ。県レベルで統一された遺跡地図のWeb公開は確認できず、横浜市・相模原市・秦野市など基礎自治体単位での公開が中心となっている。

## 遺跡地図・埋蔵文化財

- **[文化財ハマSite（横浜市行政地図情報提供システム）](https://wwwm.city.yokohama.lg.jp/yokohama-sp/MapPage?dtp=9&flgInit=1&vpc=0)**（横浜市）
  横浜市内の周知の埋蔵文化財包蔵地をWeb地図で確認できる。従来の冊子版「横浜市文化財地図」に代わるもの。制度の説明は[埋蔵文化財の確認・手続](https://www.city.yokohama.lg.jp/kurashi/kyodo-manabi/bunkazai/maizou.html)を参照。
- **[埋蔵文化財包蔵地（相模原市）](https://www.city.sagamihara.kanagawa.jp/kankou/bunka/1022295/bunkazai/1010288.html)**（相模原市）
  神奈川県遺跡分布地図・埋蔵文化財包蔵地一覧表に基づく案内ページ。津久井城を含む同市域の周知の埋蔵文化財包蔵地は「さがみはら地図情報」で閲覧できるとされる。
- **[周知の埋蔵文化財包蔵地(遺跡地図)](https://www.city.hadano.kanagawa.jp/soshiki/4/1019/8/5/6/3033.html)**（秦野市）
  秦野市域の遺跡地図に関する窓口案内ページ。オンライン地図そのものではなく、照会手続きの説明が中心。
- **[神奈川県埋蔵文化財遺跡地図（付遺跡地図地名表）](https://www.kaf2.org/yoshida_bunko/chizu/330-2.html)**（かながわ考古学財団 考古資料館）
  県教育委員会が刊行した紙媒体の遺跡地図・地名表を所蔵資料として紹介するページ。県全域を一元的にWeb地図で見られる公式GISは2026年8月時点で確認できなかった。

- **[神奈川県 - （公財）かながわ考古学財団（全国遺跡報告総覧）](https://sitereports.nabunken.go.jp/ja/list/14/14000-b)**（奈良文化財研究所）

## 主要城郭の公式資料

- **[史跡・小田原城跡](https://www.city.odawara.kanagawa.jp/field/lifelong/property/cultural/historic/s-odawarazyou.html)**（小田原市）
  国史跡。昭和58年（1983）以降、総構を含め400地点超の発掘調査が積み重ねられており、近世遺構の下から戦国期の遺構（御用米曲輪の池泉庭園など）が確認されているとする。
- **[史跡・石垣山](https://www.city.odawara.kanagawa.jp/field/lifelong/property/cultural/historic/s-ishigakiyama.html)**（小田原市）
  国史跡。豊臣秀吉の小田原合戦陣城で、平成元年（1989）からの発掘調査で天正19年銘の瓦が出土し、落城後も築城が継続されたことが判明したとする。
- **小机城跡の試掘調査**（横浜市教育委員会）
  令和3・4年度に二の丸広場付近で柱穴跡・空堀出土土器を確認した試掘調査が行われている。※市教委の調査報告書のオンライン公開は確認できず
- **[神奈川県立津久井湖城山公園 津久井城について](https://www.kanagawa-park.or.jp/tsukuikoshiroyama/history.html)**（指定管理者）
  1996年の旧津久井町時代から続く「御屋敷跡」中心の学術調査を紹介。掘立柱建物・空堀・土塁・焔硝蔵に加え、心字状の池泉庭園も確認されているとする。解説冊子は[「津久井城ものがたり」（PDF）](https://www.kanagawa-park.or.jp/tsukuikoshiroyama/pamph/monogatari1.pdf)でも読める。
