# 宮城県の城郭資料

宮城県は旧陸前国（一部は陸中国・磐城国にまたがる）。伊達62万石の本拠として近世の威容を今に伝える仙台城跡と、古代律令国家の東北支配拠点として特別史跡に指定された多賀城跡が両輪をなす。県の遺跡地図はWeb GIS化され、埋蔵文化財包蔵地・指定文化財のシェープデータがオープンデータとして公開されており、都道府県のGIS整備としては進んでいる部類に入る。一方、他県でしばしば見られる「県中世城館跡分布調査報告書」に相当するタイトルの単独報告書は確認できなかった。

  埋蔵文化財包蔵地・指定文化財・特別名勝地等をレイヤー表示できるWeb GIS地図。
- **[宮城県遺跡地図情報トップ](https://www.pref.miyagi.jp/site/maizou/bunkazaimap.html)**（宮城県）
  上記GIS地図への案内と利用上の注意（データの正確性は保証されない、工事前は必ず市町村教委に確認等）をまとめたページ。
- **[宮城県遺跡地名表](https://www.pref.miyagi.jp/site/maizou/miyagiisekitimeihyou.html)**（宮城県）
  県内全遺跡の一覧をテキストデータでダウンロード可能。
- **[宮城県遺跡地図情報（埋蔵文化財包蔵地）のシェープデータ](https://miyagi.dataeye.jp/datasets/275)**（宮城県及び市町村共同オープンデータポータル）
  CC BY 4.0で提供されるGIS用シェープデータ。QGIS等で読み込み可能。

## 中世城館調査報告書

- **[宮城県文化財調査報告書等刊行物一覧](https://www.pref.miyagi.jp/site/maizou/kakohoukokusho.html)**（宮城県教育委員会）
  刊行物の一覧ページ。確認した限り「中世城館跡分布調査」に相当する県悉皆調査報告書のタイトルは見当たらず、個別城館ごとの発掘調査報告が中心。
- **[岩出山（岩手沢城）発掘調査報告書](https://sitereports.nabunken.go.jp/ja/list/04/04215/item/61854?pdf=f&sort=jtitle)**（岩出山町教育委員会、1986年）
  伊達政宗の仙台入部前の居城・岩出山城の発掘調査報告書。全国遺跡報告総覧に書誌情報は登録されているが、PDF本文は未公開。
- **[全国遺跡報告総覧 宮城県教育委員会 刊行物一覧](https://sitereports.nabunken.go.jp/ja/list/04/04000?pdf=f)**（奈良文化財研究所）
  県教委発行の報告書をPDF公開分に絞って検索できる一覧。城館関連の個別報告書を探す起点になる。

## 調査研究機関

- **[宮城県文化財課](https://www.pref.miyagi.jp/soshiki/bunkazai/)**（宮城県）
  県の文化財行政窓口。埋蔵文化財・指定文化財関連情報の集約先。
- **[宮城県多賀城跡調査研究所](https://www.thm.pref.miyagi.jp/kenkyusyo/)**（宮城県）
  特別史跡多賀城跡附寺跡の調査研究・環境整備を専門に行う機関。
- **[多賀城研の仕事／刊行物](https://www.thm.pref.miyagi.jp/kenkyusyo/work_investigation.html)**（宮城県多賀城跡調査研究所）
  発掘調査報告書・木簡報告書等の刊行物ページ。
- **[多賀城市の文化財／遺跡発掘](https://www.city.tagajo.miyagi.jp/maibun/shiseki/bunkazai/isekihakkutsu/iseki.html)**（多賀城市）
  多賀城市埋蔵文化財調査センターによる発掘調査情報。

## 主要城郭の公式資料

- **[史跡仙台城跡](https://www.city.sendai.jp/kurashi/manabu/kyoiku/inkai/bunkazai/sendaizyouseki/index.html)**（仙台市）
  国史跡仙台城跡の保存整備・調査に関する仙台市文化財課の案内ページ。
- **[仙台城の紹介](https://www.city.sendai.jp/shisekichosa/kurashi/manabu/kyoiku/inkai/bunkazai/bunkazai/joseki/shokai.html)**（仙台市）

- **[指定文化財〈史跡〉仙台城跡](https://www.pref.miyagi.jp/soshiki/bunkazai/kuni-siseki32.html)**（宮城県）
  国史跡指定に関する県の公式解説ページ。
- **[特別史跡多賀城跡附寺跡](https://www.city.tagajo.miyagi.jp/bunkazai/shiseki/bunkazai/shitebunkazai/kunishite/terato.html)**（多賀城市）
  古代城柵としての多賀城跡・附寺跡の解説。
- **[多賀城跡](https://www.pref.miyagi.jp/soshiki/taga/tagajoato.html)**（宮城県）
  県による多賀城跡の概要ページ。
- **[白石城三階櫓（天守閣）](https://www.shiro-f.jp/shiroishijo/shiroishijo/donjon)**（白石市文化体育振興財団）
  発掘調査に基づき1995年に復元された木造天守（三階櫓）の解説。戦後の木造復元天守としては規模が大きい。
- **[白石城の復元秘話にせまる！](https://shiroishi-navi.jp/detail/detail_4552/)**（しろいし観光ナビ／白石市）
  木造復元に至る経緯を紹介する観光公式サイトの記事。
- **[岩出山城址（城山公園）](https://www.city.osaki.miyagi.jp/shisei/soshikikarasagasu/iwadeyamasogoushisho/chiikishinkoka/1/3/2955.html)**（大崎市）
  伊達政宗の一時期の居城・岩出山城跡（現・城山公園）の案内。
