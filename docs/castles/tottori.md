# 鳥取県の城郭資料

鳥取県（因幡・伯耆）は秀吉の兵糧攻めで知られる鳥取城、登り石垣が残る米子城を擁する。県教委の『鳥取県中世城館分布調査報告書』（第1集2002・第2集2004）は書誌のみでPDF未公開だが、**4館共同の「とっとりデジタルコレクション」（58万点超）**という強力な横断アーカイブがある。

## 遺跡地図・埋蔵文化財

- **[とっとりジオマップ](https://pref-tottori.tottori-geomap.jp/)**（鳥取県）
  「文化財情報」レイヤーを含む県の統合型GIS。周知の埋蔵文化財包蔵地の位置・範囲を確認できる。※旧「とっとりWebマップ」から2026年4月に移行
- **[とっとり文化財ナビ](https://db.pref.tottori.jp/bunkazainavi.nsf/index.htm)**（鳥取県教育委員会 文化財課）
  県内の指定・登録文化財（史跡・城跡を含む）を市町村・種別・キーワードで検索できるDB。
- **[鳥取県遺跡MAP](http://db.pref.tottori.jp/ruins.nsf/index.html)**（鳥取県埋蔵文化財センター）
  時代別タブで遺跡を閲覧できるマップ。※`http://` のみ

## 中世城館分布調査報告書

- **[『鳥取県中世城館分布調査報告書』第1集（2002）](https://sitereports.nabunken.go.jp/ja/74855)** / **[第2集（2004）](https://sitereports.nabunken.go.jp/ja/74862)**（鳥取県教育委員会、全国文化財総覧の書誌ページ）
  ※いずれも編纂時点で書誌情報のみで**PDF本文は未公開**。原本は図書館等で確認のこと

## 調査研究機関

- **[鳥取県埋蔵文化財センター](https://www.pref.tottori.lg.jp/4319.htm)**（鳥取県 文化財局）
  施設案内・刊行物申込みの公式ページ。刊行物は[全国文化財総覧の同センター一覧](https://sitereports.nabunken.go.jp/ja/list/31/31000-b)からも探せる。

## 主要城郭の自治体公式資料

- **[史跡 鳥取城跡 附 太閤ヶ平](https://www.city.tottori.lg.jp/page/6234.html)**（鳥取市教育委員会 文化財課）
  国史跡。兵糧攻めの舞台から江戸期の平山城への拡張、中ノ御門等の復元整備事業までを解説。
- **[国史跡 米子城跡](https://www.city.yonago.lg.jp/4439.htm)**（米子市 文化振興課）
  五重天守を持ったとされる城。石垣・登り石垣等の遺構を紹介。
- **[羽衣石城跡](https://www.yurihama.jp/soshiki/20/13380.html)**（湯梨浜町）
  南条氏約250年の居城。**2026年2月に国史跡指定されたばかり**で、既存の資料集には未反映のことが多い。

## デジタルアーカイブ

- **[とっとりデジタルコレクション](https://digital-collection.pref.tottori.lg.jp/)**（県立図書館・県立博物館・県立公文書館・県埋蔵文化財センターの4館共同）
  郷土資料・古絵図・公文書等**58万点超**を横断検索できる統合アーカイブ。「鳥取城」で検索すると各館の絵図・写真が一覧できる。
- **[鳥取県立公文書館](https://www.pref.tottori.lg.jp/kobunsho/)**（鳥取県）
  県史編さん資料への導線あり。
